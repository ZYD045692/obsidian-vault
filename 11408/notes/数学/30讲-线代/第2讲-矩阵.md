# 第2讲 矩阵

> [!abstract] 一句话总结
> 矩阵运算灵魂在于乘法不可交换与秩的结构约束，伴随逆互表，初等变换通解。

## 核心考点
### 考点1：矩阵运算基本律
**乘法不可交换，零因子非零，数乘行列式提 k^n**
1. 乘法：AB 可乘需 A 列=B 行，(AB)^T=B^T A^T，|AB|=|A||B|
2. 数乘：kA 元素全乘 k，|kA|=k^n|A|
3. 零因子：AB=O 推不出 A=O 或 B=O

> [!tip] 考试怎么用
> 注意 |kA| 与 k|A| 区别，乘法顺序不可随意交换

### 考点2：逆矩阵与伴随矩阵
**AA^*=|A|E 是核心，伴随与逆互为表里**
1. 定义：AB=BA=E\Rightarrow A^{-1}=B
2. 伴随：A^* 元素 A_{ij} 在第 j 行 i 列，AA^*=|A|E
3. 关系：A^{-1}=\frac{1}{|A|}A^*，|A^*|=|A|^{n-1}
4. 性质：(A^*)^{-1}=\frac{A}{|A|}

> [!tip] 考试怎么用
> 求逆优先用伴随公式或初等变换，注意 2 阶伴随矩阵特殊形式

### 考点3：矩阵秩的性质
**秩决定等价标准形，AB=O 有秩不等式**
1. 计算：初等行变换化阶梯形，非零行数
2. 性质：r(AB)\leq\min\{r(A),r(B)\}
3. 零积：AB=O\Rightarrow r(A)+r(B)\leq n
4. 伴随秩：r(A^*)=\begin{cases}n, r(A)=n\\1, r(A)=n-1\\0, r(A)<n-1\end{cases}

> [!tip] 考试怎么用
> 求参数时利用 |A|=0 或 r(A) 变化，伴随秩是高频考点

### 考点4：特殊矩阵幂运算
**秩 1 矩阵与分块对角阵幂有简便公式**
1. 秩 1 阵：A=\alpha\beta^T\Rightarrow A^n=(\beta^T\alpha)^{n-1}A
2. 分块对角：\begin{bmatrix}A&O\\O&B\end{bmatrix}^n=\begin{bmatrix}A^n&O\\O&B^n\end{bmatrix}
3. 多项式：f(A) 常数项换 kE

> [!tip] 考试怎么用
> 识别 A=\alpha\beta^T 形式，计算标量 k=\beta^T\alpha 时注意是数

### 考点5：矩阵方程求解
**化简为 AX=B 或构造 XY=E 形式**
1. 标准型：AX=B\Rightarrow X=A^{-1}B，XA=B\Rightarrow X=BA^{-1}
2. 构造法：AB=A+B\Rightarrow (A-E)(B-E)=E
3. 循环性：ABC=E\Leftrightarrow BCA=E\Leftrightarrow CAB=E

> [!tip] 考试怎么用
> 注意乘法顺序，移项时提取公因式方向（左提左乘，右提右乘）

### 考点6：初等变换与逆
**左乘行变换，右乘列变换，[A|E] 求逆**
1. 变换：PA 为行变换，AP 为列变换
2. 求逆：[A|E]\xrightarrow{行变换}[E|A^{-1}]
3. 初等阵：E_{ij} 左乘互换行，右乘互换列

> [!tip] 考试怎么用
> 求逆矩阵首选初等行变换，避免伴随矩阵计算量大

### 考点7：矩阵多项式与二项展开
**仅当 AB=BA 时可用二项式展开**
1. 条件：(A+B)^n 展开需 AB=BA
2. 技巧：分解 A=E+B 且 EB=BE
3. 展开：A^n=E^n+nE^{n-1}B+\frac{n(n-1)}{2!}B^2

> [!tip] 考试怎么用
> 验证交换律是展开前提，否则只能逐项计算

## 易错点
**数乘矩阵与数乘行列式**

|操作|矩阵|行列式|
|---|---|---|
|数乘|kA (元素全乘 k)| |kA|=k^n|A|(提 k^n)|
|注意|矩阵本身不变形|行列式值变 k^n 倍|

- **零矩阵乘积性质**：1. 矩阵：AB=O 不能推出 A=O 或 B=O
  2. 行列式：|AB|=0 不能推出 |A|=0 或 |B|=0
  3. 秩：AB=O 可推出 r(A)+r(B)\leq n
- **二项式展开条件**：1. 标量：(a+b)^n 恒成立
  2. 矩阵：(A+B)^n 仅当 AB=BA 时成立
  3. 错误：(A-B)(A+B)\neq A^2-B^2 (除非 AB=BA)
- **伴随矩阵秩的判定**：1. r(A)=n\Rightarrow r(A^*)=n
  2. r(A)=n-1\Rightarrow r(A^*)=1
  3. r(A)<n-1\Rightarrow r(A^*)=0
  4. 易错：r(A^*) 与 r(A) 非线性关系
- **初等变换方向**：1. 左乘初等阵：行变换
  2. 右乘初等阵：列变换
  3. 求逆：仅用行变换 [A|E]\to[E|A^{-1}]
  4. 解方程：AX=B 左乘 A^{-1}, XA=B 右乘 A^{-1}
