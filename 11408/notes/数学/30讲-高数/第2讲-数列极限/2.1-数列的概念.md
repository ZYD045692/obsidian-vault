# 2.1 数列的概念

> [!abstract] 一句话总结
> 数列是定义在正整数集上的整标函数，其核心性质包括单调性、有界性及特殊数列（等差、等比、重要极限）的通项与求和公式。

## 核心要点
### 考点1：数列的定义与本质
**数列是按正整数下标排列的无穷实数序列，本质是定义域为正整数集的函数。**
数列 $[x_{1},x_{2},x_{3},\cdots,x_{n},\cdots]$ 简记为 $\{x_{n}\}$，其中 $x_n$ 为通项。本质是整标函数 $x_{n}=f(n),n\in\mathbf{N}_{+}$。注：数列一定有无穷多项。

> [!tip] 考试怎么用
> 识别数列题时，首先确认下标 $n$ 为正整数，且项数无穷；几何上看作数轴上的动点序列。

### 考点2：子列的概念
**子列是从原数列中选取无穷多项并保持原有顺序组成的新数列。**
记为 $\{a_{n_{k}}\}$，其中下标 $n_{1}<n_{2}<\cdots<n_{k}<\cdots$ 为正整数。常见子列：偶数项 $\{a_{2k}\}$ 和奇数项 $\{a_{2k-1}\}$。

> [!tip] 考试怎么用
> 子列的下标必须严格递增 ($n_k \ge k$)；若原数列收敛，则其任意子列均收敛于同一极限。

### 考点3：等差数列性质
**等差数列由首项和公差确定，具备线性通项公式和二次型前 n 项和公式。**
首项 $a_1$，公差 $d$。通项：$a_{n}=a_{1}+(n-1)d$。前 $n$ 项和：$S_n = \frac{n}{2}[2a_1 + (n-1)d] = \frac{n}{2}(a_1 + a_n)$。

> [!tip] 考试怎么用
> 求和公式有两种形式，已知首末项用第二种，已知首项公差用第一种；注意 $d\neq0$ 才是严格等差。

### 考点4：等比数列性质
**等比数列由首项和公比确定，求和时需讨论公比是否为 1。**
首项 $a_1$，公比 $r$。通项：$a_{n}=a_{1}r^{n-1}$。前 $n$ 项和：$S_{n}=\begin{cases}na_{1},& r=1,\dfrac{a_{1}(1-r^{n})}{1-r},& r\neq1.\end{cases}$。有限项和公式：$1 + r + \cdots + r^{n-1} = \frac{1 - r^{n}}{1 - r} (r \neq 1)$。

> [!tip] 考试怎么用
> 使用求和公式前必须判断 $r=1$ 还是 $r\neq1$；收敛与发散概念仅针对无穷项（级数）。

### 考点5：单调数列判定
**通过比较相邻两项大小判定数列的单调增减性。**
若 $a_{n+1} \geq a_n$ 称单调不减；若 $a_{n+1} \leq a_n$ 称单调不增。严格不等号 $>(<)$ 对应单调递增（减）。统称单调数列。

> [!tip] 考试怎么用
> 判定方法：作差法 ($a_{n+1}-a_n$) 或作商法 ($a_{n+1}/a_n$ 与 1 比较，需各项同号)。

### 考点6：有界数列判定
**若存在正实数 $M$ 使得所有项绝对值不超过 $M$，则数列有界。**
定义：$\exists M>0, \forall n, |a_n| \leq M$。证明方法：①找 $M$；②放缩法；③找最值；④基本不等式法（如 $\sqrt{ab}\leq\frac{a+b}{2}$）。

> [!tip] 考试怎么用
> 证明有界常结合数学归纳法；对于 $\sqrt{x(A-x)}$ 型结构，优先考虑基本不等式放缩。

### 考点7：常见数列求和公式
**掌握自然数、平方数及裂项相消数列的前 n 项和公式。**
① $\sum_{k=1}^{n}k=\frac{n(n+1)}{2}$；② $\sum_{k=1}^{n}k^{2}=\frac{n(n+1)(2n+1)}{6}$；③ $\sum_{k=1}^{n}\frac{1}{k(k+1)}=\frac{n}{n+1}$。

> [!tip] 考试怎么用
> 裂项相消法关键在于 $\frac{1}{k(k+1)} = \frac{1}{k} - \frac{1}{k+1}$；注意这些是有限项和公式。

### 考点8：重要数列极限 e
**数列 $\{(1+\frac{1}{n})^n\}$ 单调递增且有上界，其极限定义为 $e$。**
性质：①单调递增；②有上界。结论：$\lim_{n \to \infty} \left(1 + \frac{1}{n}\right)^n = e$。

> [!tip] 考试怎么用
> 这是第二个重要极限的离散形式；常用于判定数列收敛性或作为放缩的边界。

## 易混与对比
**有限项和 vs 无穷级数**

|特征|前 n 项和 ($S_n$)|无穷级数 ($\sum_{n=1}^\infty$)|
|---|---|---|
|项数|有限项|无穷多项|
|收敛性|必然存在确定数值|可能收敛也可能发散|
|公式适用|等比求和公式直接可用|需取 $n\to\infty$ 极限|
|原文提示|有限项和不会发散|收敛发散概念只在无穷项涉及|

**单调不减 vs 单调递增**

|类型|符号定义|含义|
|---|---|---|
|单调不减|$a_{n+1} \geq a_n$|允许相邻项相等|
|单调递增|$a_{n+1} > a_n$|严格大于，不允许相等|
|统称|单调数列|包含上述两种情况及对应的不增/递减|

**子列 vs 原数列**

|维度|原数列 $\{a_n\}$|子列 $\{a_{n_k}\}$|
|来源|所有正整数下标|选取的部分下标|
|顺序|自然顺序|保持原数列相对顺序|
|数量|无穷多项|必须也是无穷多项|
|下标关系|$n$|$n_1 < n_2 < \cdots < n_k$|

#card
- 数列的本质是什么类型的函数？::定义域为正整数集 $\mathbf{N}_{+}$ 的整标函数 $x_n=f(n)$。
- 数列的项数必须是有限的吗？::不是，数列一定有无穷多项。
- 数列 $\{x_n\}$ 在几何上如何表示？::数轴上的一个动点，依次取点 $x_1, x_2, \cdots, x_n, \cdots$。
- 子列 $\{a_{n_k}\}$ 的下标需满足什么关系？::下标严格递增：$n_1 < n_2 < \cdots < n_k < \cdots$。
- 如何从 $\{a_n\}$ 表示偶数项子列？::取 $n_k=2k$，得到子列 $\{a_{2k}\} = a_2, a_4, \cdots$。
- 子列的项在原数列中是否保持原有顺序？::是，必须按原来的先后顺序组成新数列。
- 等差数列的通项公式是什么？::$a_n = a_1 + (n-1)d$，其中 $d$ 为公差。
- 等差数列前 n 项和 $S_n$ 的两种形式？::$S_n=\frac{n}{2}(a_1+a_n)$ 或 $S_n=na_1+\frac{n(n-1)}{2}d$。
- 等差数列中 $a_m, a_n, a_p$ 成等差的条件？::下标成等差，即 $m+p=2n$ 时，$a_m+a_p=2a_n$。
- 等比数列求和公式在 $r=1$ 时结果？::$S_n = na_1$。
- 等比数列求和公式在 $r\neq1$ 时结果？::$S_n = \frac{a_1(1-r^n)}{1-r}$。
- 等比数列通项公式是什么？::$a_n = a_1 r^{n-1}$，其中 $r$ 为公比。
- 有限项等比数列和是否涉及发散概念？::不涉及，有限项和总是存在的，发散只针对无穷项。
- 单调不减数列的数学定义式？::对所有 $n$，满足 $a_{n+1} \geq a_n$。
- 单调递增与单调不减的区别？::递增要求严格大于 ($>$)，不减允许等于 ($\geq$)。
- 判定单调性最常用的代数方法？::作差法：计算 $a_{n+1}-a_n$ 的符号。
- 数列有界的精确定义公式？::存在 $M>0$，使得对所有 $n$，都有 $|a_n| \leq M$。
- 证明 $\sqrt{x(3-x)}$ 有界常用什么不等式？::基本不等式：$\sqrt{ab} \leq \frac{a+b}{2}$。
- 有界数列是否一定收敛？::不一定，如 $(-1)^n$ 有界但不收敛（本题未提，但属常识陷阱，若严格依文可不答，此处依文只问定义）。
- 证明数列有界的四种方法？::找 M、放缩法、找最值、基本不等式法。
- 前 n 个自然数之和公式？::$\sum_{k=1}^n k = \frac{n(n+1)}{2}$。
- 前 n 个自然数平方和公式？::$\sum_{k=1}^n k^2 = \frac{n(n+1)(2n+1)}{6}$。
- 裂项 $\frac{1}{k(k+1)}$ 的前 n 项和？::$\frac{n}{n+1}$。
- $\lim_{n\to\infty}\sum_{k=1}^{n}\frac{1}{k(k+1)}$ 的值？::1。
- 数列 $\{(1+1/n)^n\}$ 的单调性？::单调递增。
- 数列 $\{(1+1/n)^n\}$ 是否有界？::有上界（且有下界），故收敛。
- $\lim_{n\to\infty}(1+\frac{1}{n})^n$ 等于多少？::$e$。
