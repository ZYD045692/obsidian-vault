# 15.3 高阶线性微分方程的求解

> [!abstract] 一句话总结
> 高阶线性微分方程求解的核心在于利用特征根结构写出齐次通解，并依据自由项形态通过待定系数法或微分算子法构造非齐次特解。

## 核心要点
### 考点1：二阶常系数齐次线性方程通解结构
**通解由两个线性无关解的线性组合构成，具体形式取决于特征方程根的判别式。**
方程 $y'' + py' + qy = 0$，特征方程 $r^2 + pr + q = 0$。① $\triangle > 0$ (不等实根 $r_1, r_2$): $y = C_1 e^{r_1 x} + C_2 e^{r_2 x}$；② $\triangle = 0$ (二重根 $r$): $y = (C_1 + C_2 x)e^{rx}$；③ $\triangle < 0$ (共轭复根 $\beta \text{i}$): $y = e^{\beta x}(C_1 \text{cos} \beta x + C_2 \text{sin} \beta x)$。

> [!tip] 考试怎么用
> 注意复根情形下 $\beta$ 是虚部系数，不要漏写 $e^{\beta x}$；周期性解要求实部 $\beta=0$。

### 考点2：非齐次方程解的叠加原理
**非齐次方程的特解具有可加性，两个非齐次方程特解之差是对应齐次方程的解。**
若 $y_1^*$ 是 $y''+py'+qy=f_1(x)$ 的解，$y_2^*$ 是 $y''+py'+qy=f_2(x)$ 的解，则 $y_1^*+y_2^*$ 是 $f_1+f_2$ 的解；若 $y_1^*, y_2^*$ 同为 $f(x)$ 的解，则 $y_1^*-y_2^*$ 是齐次方程解。

> [!tip] 考试怎么用
> 利用此性质可由已知特解反推特征根，或拆分复杂自由项分别求特解。

### 考点3：待定系数法：指数乘多项式型
**当自由项为 $P_n(x)e^{\beta x}$ 时，特解设为 $x^k Q_n(x)e^{\beta x}$，k 由 $\beta$ 是否为特征根决定。**
设 $y^* = x^k Q_n(x)e^{\beta x}$，其中 $Q_n(x)$ 为 n 次多项式。$k$ 取值：$\beta$ 不是特征根 $k=0$；单特征根 $k=1$；二重特征根 $k=2$。

> [!tip] 考试怎么用
> 若自由项无 $e^{\beta x}$ 视为 $\beta=0$；务必先求特征根再确定 k 值。

### 考点4：待定系数法：三角函数型
**当自由项含 $\text{cos} \beta x$ 或 $\text{sin} \beta x$ 时，特解需同时包含正弦和余弦项，且次数取多项式最高次。**
自由项 $e^{\beta x}[P_m \text{cos} \beta x + P_n \text{sin} \beta x]$，设 $y^* = x^k e^{\beta x}[Q_l^{(1)} \text{cos} \beta x + Q_l^{(2)} \text{sin} \beta x]$，其中 $l=\text{max}\text{m, n}$。若 $\beta \text{i}$ 是特征根则 $k=1$，否则 $k=0$。

> [!tip] 考试怎么用
> 即使自由项只有 cos 或只有 sin，特解也必须同时设 cos 和 sin 两项。

### 考点5：微分算子法：指数移位法则
**利用算子性质 $\frac{1}{F(D)}e^{\beta x}v(x) = e^{\beta x}\frac{1}{F(D+\beta)}v(x)$ 将指数因子移出算子。**
对于 $\frac{1}{F(D)}e^{\beta x}v(x)$，执行移位操作：$y^* = e^{\beta x} \frac{1}{F(D+\beta)} v(x)$。若 $F(\beta)=0$，结合导数法则 $y^*=x^k \frac{1}{F^{(k)}(\beta)}e^{\beta x}$ 处理。

> [!tip] 考试怎么用
> 此法常用于简化 $e^{\beta x}$ 与多项式或三角函数混合的复杂计算。

### 考点6：微分算子法：三角函数代入法则
**处理 $\frac{1}{F(D)}\text{cos} \beta x$ 时，将 $D^2$ 替换为 $-\beta^2$，若分母为零则需提取 D 求导。**
若 $F(-\beta^2) \neq 0$，直接代入 $D^2 = -\beta^2$；若分母为 0，利用 $F(D) = (D^2+\beta^2)G(D)$ 或分子分母同乘共轭算子消去零因子，如 $\frac{1}{D^2+\beta^2}\text{cos} \beta x = x \frac{1}{2D}\text{cos} \beta x$。

> [!tip] 考试怎么用
> 注意 $D^2$ 替换为 $-\beta^2$，而不是 $D$ 替换为 $\beta \text{i}$ 后直接计算，通常保留实部运算。

### 考点7：n 阶常系数齐次方程特征根对应项
**n 阶方程通解由特征根类型决定，k 重实根对应 $x^{k-1}e^{rx}$，k 重复根对应 $x^{k-1}e^{\beta x}\text{cos/sin}$。**
单实根 $r \to Ce^{rx}$；k 重实根 $r \to (C_1+\text{...}+C_k x^{k-1})e^{rx}$；单复根 $\beta \text{i} \to e^{\beta x}(C_1 \text{cos} \beta x + C_2 \text{sin} \beta x)$；k 重复根 $\to e^{\beta x}[(C_1+\text{...}) \text{cos} \beta x + \text{...} \text{sin} \beta x]$。

> [!tip] 考试怎么用
> 反求方程时，若解含 $x e^{rx}$ 则 r 至少为二重根；若含 $x \text{cos} \beta x$ 则 $\beta \text{i}$ 至少为二重复根。

### 考点8：欧拉方程变量代换
**欧拉方程 $x^2 y'' + pxy' + qy = f(x)$ 通过 $x=e^t$ 代换转化为常系数线性微分方程。**
令 $x=e^t (x>0)$，则 $x y' = \frac{dy}{dt}$，$x^2 y'' = \frac{d^2y}{dt^2} - \frac{dy}{dt}$。原方程化为 $\frac{d^2y}{dt^2} + (p-1)\frac{dy}{dt} + qy = f(e^t)$。

> [!tip] 考试怎么用
> 变换后勿忘最后将 $t=\text{ln} x$ 代回；$x<0$ 时令 $x=-e^t$ 结果形式相同。

## 易混与对比
**待定系数法中 k 值的判定差异**

|自由项类型|比较对象|k=0 条件|k=1 条件|k=2 条件|
|---|---|---|---|---|
|$P_n(x)e^{\beta x}$|$\beta$ 与实特征根|$\beta$ 不是根|$\beta$ 是单根|$\beta$ 是二重根|
|$e^{\beta x}\text{cos}/\text{sin} \beta x$|$\beta \text{i}$ 与复特征根|$\beta \text{i}$ 不是根|$\beta \text{i}$ 是单根|无 (二阶最多单复根)|

**微分算子法代入规则的区别**

|算子类型|代入规则|注意事项|
|---|---|---|
|$\frac{1}{F(D)}e^{\beta x}$|$D \to \beta$|若 $F(\beta)=0$ 需提 x 求导|
|$\frac{1}{F(D)}\text{cos} \beta x$|$D^2 \to -\beta^2$|仅替换偶次幂，奇次幂 D 保留|
|$\frac{1}{F(D)}x^k$|泰勒展开|将 $\frac{1}{F(D)}$ 展开为 D 的多项式|

- **齐次与非齐次解的结构混淆**：齐次方程通解是 $C_1 y_1 + C_2 y_2$；非齐次方程通解是 $C_1 y_1 + C_2 y_2 + y^*$。易错点：将非齐次特解 $y^*$ 误认为包含任意常数，或忘记加齐次通解部分。

- 算子 D 的定义是什么？::$D = \frac{d}{dx}$
- 算子法中处理 $\text{cos} \beta x$ 时 $D^2$ 替换为什么？::$-\beta^2$
