# 第11讲 一元函数积分学的应用（二）——积分等式与积分不等式

> [!abstract] 一句话总结
> 本讲通过中值定理、夹逼准则及微分学工具（单调性、拉格朗日、泰勒）将积分等式与不等式转化为函数性质或代数运算问题。

## 核心考点
### 考点1：推广的积分中值定理
**若$f(x),g(x)$在$[a,b]$连续且$g(x)$不变号，则存在$\xi\in[a,b]$使得$\\_a^bf(x)g(x)dx=f(\\_a^bg(x)dx$。**
定理：$\\_a^bf(x)g(x)dx=f(\\_a^bg(x)dx$，其中$\\_a^bg(x)dx\neq0$。特例：$g(x)=1$时，$\\_a^bf(x)dx=f(\\_a^bf(x)dx=f(\\_a^bf(x)dx=f(\\_a^bf(x)dx=f(\\_a^bf(x)dx=f(\\_a^bf(x)dx=f(\\_a^bf(x)dx=f(\\_a^bf(x)dx=f(\\_a^bf(x)dx=f(\\_a^bf(x)dx$。

> [!tip] 考试怎么用
> 注意$\\_a^bg(x)dx$必须不为0；若被积函数含参数$n$，则中值点$\_n$与$n$有关，求极限时不能直接代入。

### 考点2：夹逼准则求积分极限
**通过放缩被积函数构造不等式，利用$\lim_{n\to\infty}\int_0^1 x^n f(x)dx=0$等结论求极限。**
核心结论：若$f(x)$在$[0,1]$连续，则$\lim_{n\to\infty}\int_0^1 x^n f(x)dx=0$。常用放缩：$0\le \ln(1+t)\le t \Rightarrow [\ln(1+t)]^n \le t^n$。

> [!tip] 考试怎么用
> 关键在于找到合适的放缩函数（如$x^n$），并验证放缩后的积分极限易求且趋于0。

### 考点3：周期函数积分极限
**对于周期为$T$的函数$f(x)$，$\lim_{x\to+\infty}\frac{1}{x}\int_0^x f(t)dt = \frac{1}{T}\int_0^T f(t)dt$。**
方法：利用$nT \le x < (n+1)T$夹逼。公式：$\int_0^{nT} f(t)dt = n\int_0^T f(t)dt$。

> [!tip] 考试怎么用
> 此类题目通常不能用洛必达法则（因原函数可能不连续或不可导），必须用夹逼准则。

### 考点4：分部积分证明等式
**通过两次分部积分将$\int f(x)dx$转化为含$f''(x)$的积分，常用于边界值为0的情况。**
典型结论：若$f(0)=f(1)=0$，则$\int_0^1 f(x)dx = \frac{1}{2}\int_0^1 x(x-1)f''(x)dx$。步骤：先凑$dv=f''(x)dx$或$dv=dx$。

> [!tip] 考试怎么用
> 注意边界项$f(0),f(1)$是否为0以消去项；利用$|\int g(x)h(x)dx| \le \max|h|\int |g|dx$进行放缩。

### 考点5：变限积分构造单调性
**将积分上限变量化构造辅助函数$F(x)$，通过求导判断单调性证明不等式。**
模板：令$F(x) = \int_a^{a+\int_a^x g(t)dt} f(u)du - \int_a^x f(t)g(t)dt$。求导得$F'(x) = [f(A)-f(x)]g(x)$，利用单调性判号。

> [!tip] 考试怎么用
> 关键在于正确写出变上限积分的导数，注意复合函数求导链式法则；区分积分变量与上限变量。

### 考点6：拉格朗日中值定理证不等式
**利用$f(x)-f(x_0)=f'(\xi)(x-x_0)$将被积函数放缩为含$M=\max|f'|$的形式。**
技巧：分段积分。在$[0,x]$用$f(0)$，在$[x,1]$用$f(1)$。结论：若$f(0)=f(1)=0$，则$|\int_0^1 f(x)dx| \le \frac{1}{4}M$。

> [!tip] 考试怎么用
> 常需将积分区间分为两段，分别利用两端点值为0的条件，最后合并求最值。

### 考点7：泰勒公式证积分不等式
**在特殊点（如中点或零点）展开泰勒公式，积分消去一次项，保留二阶余项进行放缩。**
模板：$f(x)=f(x_0)+f'(x_0)(x-x_0)+\frac{f''(\xi)}{2}(x-x_0)^2$。若$x_0$为中点，$\int (x-x_0)dx=0$。结论：$|\int_0^2 f(x)dx| \le \frac{1}{3}M$（若$f(1)=0$）。

> [!tip] 考试怎么用
> 选择展开点$x_0$至关重要，通常选使一次项积分为0的点（如区间中点）或函数值为0的点。

### 考点8：分部积分法证不等式
**对含三角函数或幂函数的积分使用分部积分，将$f(x)$转化为$f'(x)$进行放缩。**
典型：$|\int f(x)\sin nx dx| = |\frac{-1}{n}\int f(x)d(\cos nx)| \le \frac{1}{n}(|f\cos|_a^b + \int |f'|dx)$。若$f'\ge 0$，可进一步化简。

> [!tip] 考试怎么用
> 注意绝对值不等式$|\int u dv| \le |uv| + \int |v du|$的应用；利用$f'$的符号去掉绝对值。

### 考点9：牛顿 - 莱布尼茨公式证不等式
**利用$f(x)=\int_a^x f'(t)dt$将函数值转化为导数积分，结合绝对值不等式证明。**
技巧：双向表示。$f(x)=\int_a^x f'dt$且$f(x)=-\int_x^b f'dt$。相加得$2|f(x)| \le \int_a^b |f'(t)|dt$。

> [!tip] 考试怎么用
> 适用于已知$f(a)=f(b)=0$的情况；通过两个方向积分相加消去$x$，得到全局上界。

### 考点10：积分估值与最大最小值
**利用$m(b-a) \le \int_a^b f(x)dx \le M(b-a)$及$|\int f g| \le \max|g| \int |f|$进行放缩。**
常用不等式：$|\int_a^b f(x)g(x)dx| \le \max_{x\in[a,b]}|g(x)| \cdot \int_a^b |f(x)|dx$（当$f$不变号时更精确）。

> [!tip] 考试怎么用
> 提取最大值$M$时，注意剩余部分的积分是否容易计算（如$\int x(1-x)dx$）。

### 考点11：反函数与分部积分
**涉及反函数$\varphi(x)$的积分，常利用$\varphi(f(x))=x$及分部积分法转化。**
恒等式：$\int_0^1 [\int_0^{f(x)} \varphi(t)dt]dx = 2\int_0^1 x f(x)dx$（当$f(1)=0, \varphi$为$f$反函数）。步骤：先对$x$分部积分。

> [!tip] 考试怎么用
> 注意反函数性质$\varphi(f(x))=x$的代入时机；内层变限积分求导需小心。

## 易错点
**积分中值定理的区间开闭性**

|类型|结论区间|备注|
|:---|:---|:---|
|基础定理|$\xi \in (a,b)$|教材标准形式，开区间|
|推广定理|$\xi \in [a,b]$|闭区间也成立，考试可直接用|
|含参极限|$\xi_n \in (a,b)$|$\xi_n$随$n$变化，不可直接取极限|

**证明不等式的工具选择策略**

|已知条件|首选工具|典型特征|
|:---|:---|:---|
|$f$连续，无导数信息|单调性/估值|构造变限积分函数|
|$f$一阶可导，端点为0|拉格朗日中值|分段积分，利用$f(0)=f(1)=0$|
|$f$二阶可导，有中点值|泰勒公式|展开消去一次项，保留二阶余项|
|含$f'$且$f(a)=f(b)=0$|牛顿 - 莱布尼茨|双向积分相加，$2|f|\le \int|f'|$|

**夹逼准则中的放缩技巧**

|被积函数形式|放缩目标|依据|
|:---|:---|:---|
|$x^n f(x)$|$x^n$|$f(x)$有界，$\int x^n \to 0$|
|$\ln(1+t)$|$t$|$0 \le \ln(1+t) \le t$ ($t\ge0$)|
|$e^{-x^n}$|$x^{-n}$|$e^y > y+1 \Rightarrow e^{-y} < 1/y$|

## 闪卡（Spaced Repetition）
#card
- 推广积分中值定理中$g(x)$需满足什么条件？::$g(x)$在$[a,b]$上连续且不变号。
- 当$g(x)=1$时，积分中值定理公式是什么？::$\int_a^b f(x)dx = f(\xi)(b-a), \xi\in[a,b]$。
- 若被积函数为$f_n(x)$，中值点$\xi$有何特点？::$\xi$依赖于$n$，记为$\xi_n$，随$n$变化。
- 积分中值定理的$\xi$取值范围是开区间还是闭区间？::通常写为$(a,b)$，但结论在$[a,b]$上也成立。
- 若$f(x)$在$[0,1]$连续，$\lim_{n\to\infty}\int_0^1 x^n f(x)dx$等于多少？::0
- 在$[0,1]$上，$\ln(1+t)$与$t$的大小关系如何？::$0 \le \ln(1+t) \le t$。
- 处理$\int_0^1 \frac{x^{n+1}}{1+x}dx$极限时常用的放缩式？::$0 \le \frac{x^{n+1}}{1+x} \le x^{n+1}$。
- 夹逼准则求积分极限的核心步骤是什么？::放缩被积函数，计算两边积分极限，证明相等。
- 周期函数$f(x)$（周期$T$）在无穷远处的平均积分值公式？::$\frac{1}{T}\int_0^T f(t)dt$。
- 为何$\lim_{x\to\infty}\frac{1}{x}\int_0^x f(t)dt$通常不用洛必达法则？::因$f(x)$可能有间断点，原函数不一定可导。
- 若$f(x)=x-[x]$，其周期$T$是多少？::1
- 处理$\int_0^x f(t)dt$（$f$周期）时的关键不等式？::$\int_0^{nT} \le \int_0^x < \int_0^{(n+1)T}$。
- 若$f(0)=f(1)=0$，$\int_0^1 f(x)dx$可转化为含哪阶导数的积分？::二阶导数$f''(x)$。
- 公式$\int_0^1 f(x)dx = \frac{1}{2}\int_0^1 x(x-1)f''(x)dx$成立的条件？::$f(0)=f(1)=0$且$f''$连续。
- 证明此类等式主要使用什么积分方法？::分部积分法（通常两次）。
- 如何利用该等式证明$|\int f| \le \frac{M}{12}$？::提取$M=\max|f''|$，计算$\int_0^1 |x(x-1)|dx$。
- 证明积分不等式时，构造辅助函数通常将哪个限变量化？::通常将上限变量化。
- 若$F(x)=\int_a^{u(x)}f(t)dt$，则$F'(x)$等于什么？::$f(u(x))\cdot u'(x)$。
- 利用单调性证不等式，最后需验证$F(a)$或$F(b)$的值？::通常验证端点值为0。
- 若$f$单调增且$u(x)\le x$，则$f(u(x))-f(x)$符号如何？::$\le 0$。
- 若$f(0)=f(1)=0$，$|\int_0^1 f(x)dx|$的上界（含$M$）？::$\frac{1}{4}M$，其中$M=\max|f'|$。
- 利用拉格朗日中值定理放缩$|f(x)|$的关键条件？::端点函数值为0或已知。
- 证明$|\int f|\le \frac{1}{4}M$时，积分区间通常如何分割？::分为$[0,x]$和$[x,1]$两段。
- $x^2/2 + (1-x)^2/2$在$[0,1]$上的最小值是多少？::$1/4$（当$x=1/2$时）。
- 泰勒公式证积分不等式时，展开点$x_0$通常选哪里？::区间中点或函数值为0的点。
- 若$x_0$为$[0,2]$中点，$\int_0^2 (x-x_0)dx$等于多少？::0
- 若$f(1)=0$，$|\int_0^2 f(x)dx|$的上界（含$M=\max|f''|$）？::$\frac{1}{3}M$。
- 泰勒展开后，哪一项通常通过积分变为0从而简化计算？::一次项$f'(x_0)(x-x_0)$。
- 处理$\int f(x)\sin nx dx$首选什么方法？::分部积分法。
- 分部积分后，不等式放缩的关键公式？::$|\int u dv| \le |uv| + \int |v du|$。
- 若$f'(x)\ge 0$，$\int |f'(x)\cos nx|dx$可放缩为何？::$\int f'(x)dx = f(b)-f(a)$。
- 此类不等式右边通常含有哪个因子？::$1/n$。
- 若$f(a)=f(b)=0$，如何用N-L公式表示$f(x)$？::$f(x)=\int_a^x f'dt$ 或 $f(x)=-\int_x^b f'dt$。
- 证明$|f(x)|\le \frac{1}{2}\int_a^b |f'|dx$的关键操作？::将两个方向的积分表达式相加。
- 牛顿 - 莱布尼茨公式联系$f(x)$与$f'(x)$的前提？::$f'(x)$连续（或$f$可导且$f'$可积）。
- 此类证明中，$\int_a^x |f'| + \int_x^b |f'|$等于什么？::$\int_a^b |f'(t)|dt$。
- 积分估值定理的基本形式（$m,M$为最值）？::$m(b-a) \le \int_a^b f(x)dx \le M(b-a)$。
- 若$g(x)$有界，$|\int f(x)g(x)dx|$如何放缩？::$\le \max|g| \cdot \int |f(x)|dx$。
- 计算$\int_0^1 x(1-x)dx$的结果是多少？::$1/6$
- 提取$M=\max|f''|$后，剩余积分通常是什么类型？::多项式积分，易计算。
- 若$\varphi$是$f$的反函数，则$\varphi(f(x))$等于什么？::$x$
- 处理$\int [\int_0^{f(x)} \varphi(t)dt]dx$首选什么方法？::分部积分法（对$x$）。
- 上述反函数积分等式右边的系数是多少？::2
- 变限积分$\frac{d}{dx}\int_0^{f(x)}\varphi(t)dt$等于什么？::$\varphi(f(x))\cdot f'(x) = x f'(x)$。
