# 第10讲 一元函数积分学的应用（一）——几何应用

> [!abstract] 一句话总结
> 本讲本质是将几何量（面积、体积、弧长等）转化为定积分计算，核心在于选取合适的微元（$dx, dy, d\theta$）并套用对应公式。

## 核心考点
### 考点1：直角坐标系下平面图形面积
**由上下两条曲线 $y_1(x), y_2(x)$ 及直线 $x=a, x=b$ 围成的面积为 $S=\int_{a}^{b}\left|y_{1}(x)-y_{2}(x)\right|\mathrm{d}x$。**
微元法：$\Delta S = |y_1 - y_2| \mathrm{d}x$；若图形在 x 轴下方或跨越 x 轴，必须加绝对值或分段积分保证被积函数非负。

> [!tip] 考试怎么用
> 遇到绝对值函数（如 $|\sin x|$）需利用周期性或分段去绝对值；无界区域可能涉及反常积分。

### 考点2：极坐标系下平面图形面积
**由射线 $\theta=\alpha, \theta=\beta$ 及曲线 $r=r_1(\theta), r=r_2(\theta)$ 围成的面积为 $S=\frac{1}{2}\int_{\alpha}^{\beta}\left|r_{1}^{2}(\theta)-r_{2}^{2}(\theta)\right|\mathrm{d}\theta$。**
微元法：将微元视为小扇形（近似三角形），$\Delta S = \frac{1}{2}r^2 \mathrm{d}\theta$；注意系数 $\frac{1}{2}$ 不可遗漏。

> [!tip] 考试怎么用
> 利用图形对称性可简化计算（如双纽线算 $1/4$ 再乘 4）；注意 $r^2$ 始终非负，但两曲线差值需加绝对值。

### 考点3：参数方程下平面图形面积
**参数方程 $x=x(t), y=y(t)$ 下，面积公式为 $S=\int_{\alpha}^{\beta} y(t)x'(t)\mathrm{d}t$，本质是直角坐标公式的换元法。**
推导：$S=\int y \mathrm{d}x = \int y(t) \mathrm{d}[x(t)] = \int y(t)x'(t)\mathrm{d}t$；需注意积分限 $t$ 的对应关系及 $x'(t)$ 的符号。

> [!tip] 考试怎么用
> 摆线一拱面积计算是经典考题；若 $x(t)$ 非单调，需分段处理或取绝对值保证面积为正。

### 考点4：绕 x 轴旋转体体积（圆盘法）
**曲线 $y=y(x)$ 与 x 轴及 $x=a, x=b$ 围成图形绕 x 轴旋转体积为 $V_{x}=\pi\int_{a}^{b} y^{2}(x)\mathrm{d}x$。**
微元法：切片为圆盘，$\Delta V = \pi y^2 \mathrm{d}x$；若由两条曲线 $y_1, y_2$ 围成，则 $V = \pi \int (y_1^2 - y_2^2) \mathrm{d}x$。

> [!tip] 考试怎么用
> 被积函数是 $y^2$ 而非 $y$；若区域不接触旋转轴，需用大圆减小圆（空心圆柱）。

### 考点5：绕 y 轴旋转体体积（柱壳法）
**曲线 $y=y(x)$ 与 x 轴及 $x=a, x=b$ ($0\le a<b$) 围成图形绕 y 轴旋转体积为 $V_{y}=2\pi\int_{a}^{b}x\left|y(x)\right|\mathrm{d}x$。**
微元法：取竖直条绕 y 轴形成圆柱壳，展开为长方体，$\Delta V = 2\pi x \cdot |y| \cdot \mathrm{d}x$；此法避免了求反函数。

> [!tip] 考试怎么用
> 公式系数是 $2\pi$；若绕其他竖直直线 $x=x_0$ 旋转，半径变为 $|x-x_0|$。

### 考点6：绕任意直线旋转体体积
**曲线 $y=f(x)$ 绕直线 $Ax+By+C=0$ 旋转体积公式为 $V=\frac{\pi}{(A^2+B^2)^{3/2}}\int_a^b [Ax+Bf(x)+C]^2 |Af'(x)-B| \mathrm{d}x$。**
原理：距离 $d = \frac{|Ax+By+C|}{\sqrt{A^2+B^2}}$，体积微元 $\mathrm{d}V = \pi d^2 \cdot \mathrm{d}s_{\perp}$；特例：绕 $x=k$ 或 $y=k$ 可简化。

> [!tip] 考试怎么用
> 考试通常考查特例（如绕 $x=1$），通用公式较复杂，建议掌握微元法推导：$\mathrm{d}V = \pi (\text{距离})^2 \mathrm{d}(\text{沿轴长度})$。

### 考点7：函数的平均值
**函数 $y(x)$ 在区间 $[a,b]$ 上的平均值为 $\bar{y} = \frac{1}{b-a} \int_{a}^{b} y(x) \mathrm{d}x$。**
几何意义：矩形面积等于曲边梯形面积时的高度；与积分中值定理 $\int_a^b f(x)dx = f(\xi)(b-a)$ 联系紧密。

> [!tip] 考试怎么用
> 注意分母是区间长度 $b-a$；若已知 $f(x+T)-f(x)$ 形式，可构造变限积分函数求原函数。

### 考点8：平面区域形心坐标
**区域 $D: 0\le y\le f(x), a\le x\le b$ 的形心坐标为 $\bar{x}=\frac{\int_a^b xf(x)dx}{\int_a^b f(x)dx}, \bar{y}=\frac{\frac{1}{2}\int_a^b f^2(x)dx}{\int_a^b f(x)dx}$。**
推导：$\bar{x} = \frac{\iint_D x d\sigma}{S}, \bar{y} = \frac{\iint_D y d\sigma}{S}$；分子分别是关于 y 轴和 x 轴的静矩。

> [!tip] 考试怎么用
> 仅数一、数二要求；分母即为图形面积 $S$；$\bar{y}$ 分子中有系数 $1/2$，易漏。

### 考点9：平面曲线弧长
**直角坐标 $s=\int_a^b\sqrt{1+y'^2}dx$；参数方程 $s=\int_\alpha^\beta\sqrt{x'^2+y'^2}dt$；极坐标 $s=\int_\alpha^\beta\sqrt{r^2+r'^2}d\theta$。**
核心是弧微分 $ds$：直角 $ds=\sqrt{1+y'^2}dx$，参数 $ds=\sqrt{x'^2+y'^2}dt$，极坐标 $ds=\sqrt{r^2+r'^2}d\theta$。

> [!tip] 考试怎么用
> 仅数一、数二要求；计算时注意根号内配方化简；星形线等对称图形可算 $1/4$ 再乘 4。

### 考点10：旋转曲面侧面积
**曲线 $y=f(x)$ 绕 x 轴旋转侧面积 $S=2\pi\int_a^b |y|\sqrt{1+y'^2}dx$；参数方程类似，极坐标需将 $y$ 换为 $r\sin\theta$。**
微元法：$dS = 2\pi |y| ds$，即周长乘以弧长微元；极坐标下旋转半径为 $r\sin\theta$（到 x 轴距离）。

> [!tip] 考试怎么用
> 仅数一、数二要求；公式比体积多一个 $\sqrt{1+y'^2}$（即 $ds$）；注意是侧面积，不含底面。

### 考点11：平行截面已知立体体积
**若垂直于 x 轴的截面面积为 $A(x)$，则立体体积为 $V=\int_a^b A(x)\mathrm{d}x$。**
微元法：$dV = A(x)dx$；旋转体体积是特例，此时 $A(x) = \pi y^2$；适用于非旋转体（如已知截面形状）。

> [!tip] 考试怎么用
> 考研较少直接考，但需理解其作为体积定义的推广；关键是正确写出截面面积函数 $A(x)$。

## 易错点
**绕轴旋转：圆盘法 vs 柱壳法**

|方法|适用场景|微元形状|积分变量|公式特征|
|---|---|---|---|---|
|圆盘法|绕 x 轴，区域贴近轴|扁平圆盘|$x$|$\pi y^2 dx$|
|柱壳法|绕 y 轴，区域贴近轴|空心圆柱壳|$x$|$2\pi x y dx$|
|易错点|绕 y 轴若用圆盘法需对 $y$ 积分（求反函数）；柱壳法直接对 $x$ 积分，半径是 $x$。| | | |

**弧长公式 vs 侧面积公式**

|项目|弧长 $s$|侧面积 $S$|
|---|---|---|
|核心微元|$ds = \sqrt{1+y'^2}dx$|$dS = 2\pi|y|ds$|
|直角坐标公式|$\int \sqrt{1+y'^2} dx$|$2\pi \int|y|\sqrt{1+y'^2} dx$|
|区别|仅计算曲线长度|长度 $\times$ 旋转周长|
|易错点|侧面积公式容易漏掉 $2\pi|y|$ 或误用体积公式 $\pi y^2$。| |

**极坐标：面积 vs 弧长**

|几何量|面积 $S$|弧长 $s$|
|---|---|---|
|微元依据|小扇形面积 $\frac{1}{2}r^2 d\theta$|勾股定理 $ds=\sqrt{(dr)^2+(rd\theta)^2}$|
|公式|$\frac{1}{2}\int r^2 d\theta$|$\int \sqrt{r^2 + (r')^2} d\theta$|
|易错点|面积公式有系数 $1/2$ 且被积是 $r^2$；弧长公式无 $1/2$ 且根号内含 $r'^2$。| |

## 闪卡（Spaced Repetition）
#card
- 直角坐标系下，由 $y=y_1(x)$ 和 $y=y_2(x)$ 在 $[a,b]$ 围成的面积微元 $\mathrm{d}S$ 是什么？::$\mathrm{d}S = |y_1(x) - y_2(x)| \mathrm{d}x$
- 计算 $y=e^{-x}|\sin x|$ 与 x 轴围成的面积时，如何处理绝对值？::按 $\sin x$ 正负区间分段积分，或利用周期性求和。
- 若 $y_1(x) \ge y_2(x)$ 在 $[a,b]$ 恒成立，面积公式中的绝对值可否去掉？::可以，直接写为 $\int_a^b (y_1(x) - y_2(x)) \mathrm{d}x$。
- 极坐标下，由 $r=r(\theta)$ 及射线 $\theta=\alpha, \beta$ 围成的扇形面积微元 $\mathrm{d}S$ 是什么？::$\mathrm{d}S = \frac{1}{2}r^2(\theta) \mathrm{d}\theta$
- 伯努利双纽线 $r^2=a^2\cos 2\theta$ 的总面积如何利用对称性计算？::计算第一象限 $\theta \in [0, \pi/4]$ 部分面积的 4 倍。
- 极坐标面积公式中，若 $r_1 > r_2$，被积函数是否仍需绝对值？::若已知大小关系可去掉，否则必须保留 $|r_1^2 - r_2^2|$。
- 参数方程 $x=x(t), y=y(t)$ 下，面积积分 $\int y \mathrm{d}x$ 转化为 $t$ 的积分形式是什么？::$\int_{\alpha}^{\beta} y(t)x'(t) \mathrm{d}t$
- 摆线 $x=a(t-\sin t), y=a(1-\cos t)$ 一拱对应的参数 $t$ 范围是多少？::$t$ 从 $0$ 变到 $2\pi$。
- 参数方程求面积时，若 $x'(t)<0$，积分结果可能为负，如何处理？::取绝对值或交换积分上下限，保证面积为正值。
- 曲线 $y=f(x)$ 绕 x 轴旋转的体积微元 $\mathrm{d}V$ 是什么？::$\mathrm{d}V = \pi [f(x)]^2 \mathrm{d}x$
- 由 $y_1(x)$ 和 $y_2(x)$ ($y_1>y_2$) 围成区域绕 x 轴旋转，体积公式是什么？::$V = \pi \int_a^b (y_1^2(x) - y_2^2(x)) \mathrm{d}x$
- 无界区域 $y=1/\sqrt{1+x^2} (x\ge0)$ 绕 x 轴旋转体积是否收敛？::收敛，值为 $\pi^2/2$（反常积分）。
- 柱壳法求绕 y 轴旋转体积时，微元 $\mathrm{d}V$ 的表达式是什么？::$\mathrm{d}V = 2\pi x |y(x)| \mathrm{d}x$
- 若区域由 $y=f(x)$ 与 x 轴围成，绕直线 $x=1$ 旋转，柱壳半径是多少？::半径为 $|x-1|$（假设 $x<1$ 则为 $1-x$）。
- 柱壳法相比圆盘法（对 y 积分）的主要优势是什么？::无需解出反函数 $x=\varphi(y)$，直接对 x 积分。
- 点 $(x, f(x))$ 到直线 $Ax+By+C=0$ 的距离公式是什么？::$d = \frac{|Ax+Bf(x)+C|}{\sqrt{A^2+B^2}}$
- 绕直线 $x=1$ 旋转时，若用通用公式，$A,B,C$ 分别取何值？::$A=1, B=0, C=-1$。
- 通用体积公式中，积分变量 $x$ 对应的弧长投影因子是什么？::$|Af'(x)-B|$（来源于垂直于旋转轴的微元长度）。
- 函数 $f(x)$ 在 $[a,b]$ 上的平均值定义式是什么？::$\bar{f} = \frac{1}{b-a} \int_a^b f(x) \mathrm{d}x$
- 若 $F(x)=\int_x^{x+2} f(t)dt$ 且 $F'(x)=x$，如何求 $f$ 在 $[1,3]$ 的平均值？::平均值为 $\frac{1}{2}F(1)$，先求 $F(x)$ 再代入。
- 积分中值定理中的 $f(\xi)$ 与函数平均值有何关系？::$f(\xi)$ 即为函数在区间上的平均值。
- 曲边梯形 $0\le y\le f(x)$ 的形心横坐标 $\bar{x}$ 公式是什么？::$\bar{x} = \frac{\int_a^b x f(x) \mathrm{d}x}{\int_a^b f(x) \mathrm{d}x}$
- 曲边梯形形心纵坐标 $\bar{y}$ 的分子部分是什么？::$\frac{1}{2} \int_a^b f^2(x) \mathrm{d}x$
- 形心公式的分母代表什么几何量？::代表平面区域 $D$ 的面积 $S$。
- 直角坐标系下，曲线 $y=y(x)$ 的弧微分 $ds$ 表达式是什么？::$ds = \sqrt{1 + [y'(x)]^2} \mathrm{d}x$
- 极坐标系下，曲线 $r=r(\theta)$ 的弧长积分公式是什么？::$s = \int_\alpha^\beta \sqrt{r^2(\theta) + [r'(\theta)]^2} \mathrm{d}\theta$
- 计算星形线 $x=\cos^3 t, y=\sin^3 t$ 全长时，利用对称性只需算哪一段？::只需算第一象限 $t\in[0, \pi/2]$ 然后乘 4。
- 曲线 $y=f(x)$ 绕 x 轴旋转的侧面积微元 $dS$ 是什么？::$dS = 2\pi |y| \sqrt{1+(y')^2} dx$
- 极坐标曲线 $r=r(\theta)$ 绕 x 轴旋转，公式中的旋转半径是多少？::旋转半径是 $|r(\theta)\sin\theta|$。
- 旋转体体积用 $dx$ 积分，侧面积用什么积分？::侧面积用弧微分 $ds$ 积分。
- 已知垂直于 x 轴的截面面积函数 $A(x)$，立体体积公式是什么？::$V = \int_a^b A(x) \mathrm{d}x$
- 绕 x 轴旋转体体积公式 $V=\int \pi y^2 dx$ 中，$A(x)$ 对应什么？::$A(x) = \pi [y(x)]^2$（圆面积）。
- 若截面是边长为 $x$ 的正方形，体积微元 $dV$ 是什么？::$dV = x^2 dx$。
