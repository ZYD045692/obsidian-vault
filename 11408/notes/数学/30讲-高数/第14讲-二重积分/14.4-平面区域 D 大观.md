# 14.4 平面区域 D 大观

> [!abstract] 一句话总结
> 本节通过四大类（直角直线、直角曲线、极坐标、参数方程）典型实例，训练将不等式组转化为直观平面区域图形的能力，为二重积分定限奠基。

## 核心要点
### 考点1：直角坐标系下直线边界型区域
**此类区域由一次不等式（如 $ax+by \neq c$）围成，图形多为多边形、三角形或带状区域。**
常见形式包括矩形 $D = \{(x, y) \mid a \leq x \leq b, c \leq y \leq d\}$，三角形 $D = \{(x, y) \mid x \geq 0, y \geq 0, x+y \leq 1\}$，以及含绝对值的菱形 $D = \{(x, y) \mid |x| + |y| \leq 1\}$。

> [!tip] 考试怎么用
> 遇到绝对值不等式 $|x|+|y|\leq a$ 直接画菱形；遇到 $x \leq y \leq kx$ 注意是过原点的射线夹角区域。

### 考点2：直角坐标系下曲线边界型区域
**此类区域边界包含圆、抛物线、指数对数曲线等，需识别标准方程并确定不等式指向。**
典型如圆域 $x^2+y^2 \leq R^2$，偏心圆 $(x-a)^2+(y-b)^2 \leq R^2$，抛物线 $y \geq x^2$，双曲线 $xy \geq 1$。常见组合如 $D = \{(x, y) \mid 0 \leq x \leq 1, \sqrt[3]{x} \leq y \leq 1\}$。

> [!tip] 考试怎么用
> 见到 $x^2+y^2$ 联想圆，见到 $y=x^2$ 联想抛物线；注意 $y \geq \sqrt{1-x^2}$ 表示圆外或圆上部分。

### 考点3：极坐标方程型区域
**当区域边界为圆、 cardioid 或过原点的射线时，极坐标描述 $D = \{(r, \theta) \mid \alpha \leq \theta \leq \beta, r_1(\theta) \leq r \leq r_2(\theta)\}$ 更简便。**
常见边界：直线 $r = \frac{a}{\cos\theta}$ 或 $r = \frac{a}{\sin\theta}$，圆 $r = 2a\cos\theta$，双纽线 $r^2 = a^2\cos2\theta$，心形线 $r = a(1+\cos\theta)$。例如 $D = \{(r, \theta) \mid 0 \leq r \leq 2\cos\theta, 0 \leq \theta \leq \frac{\pi}{2}\}$。

> [!tip] 考试怎么用
> 若直角坐标表达式含 $(x^2+y^2)$ 的高次幂或复杂根式，优先考虑转为极坐标画图。

### 考点4：参数方程型及动态区域
**区域边界或范围由参数 $t, a$ 控制，图形随参数变化而伸缩或移动，需讨论参数范围。**
例如 $D = \{(x, y) \mid 0 \leq x \leq t, 0 \leq y \leq t-x\}$ 表示随 $t$ 增大的等腰直角三角形；或含参椭圆 $\frac{x^2}{a^2} + \frac{y^2}{b^2} \leq 1$。

> [!tip] 考试怎么用
> 画图时先固定参数画出一个典型图形，再标注参数变化引起的边界移动方向。

## 易混与对比
**直角坐标与极坐标区域描述的转换**

|特征|直角坐标难点|极坐标优势|
|:---|:---|:---|
|**圆形边界**|需写 $\pm\sqrt{R^2-x^2}$，分上下半圆|$r=R$，单一方程|
|**过原点射线**|需写 $y=kx$，斜率无穷大时失效|$\theta = \alpha$，统一表达|
|**复杂高次**|$(x^2+y^2)^n$ 难以处理|$r^{2n}$ 形式简洁|
|**适用场景**|矩形、梯形、直线围成区域|圆、扇形、心形线、双纽线区域|

- **不等式方向与区域位置的判定**：易错点：混淆 $\leq$ 与 $\geq$ 对应的区域内外。
  - **圆**：$x^2+y^2 \leq R^2$ 是圆内，$\geq$ 是圆外。
  - **抛物线**：$y \geq x^2$ 是抛物线上方（开口内），$y \leq x^2$ 是下方。
  - **测试法**：取原点 $(0,0)$ 或特殊点代入不等式，成立则该点所在侧为所求区域。
- **绝对值不等式的图形拆解**：易错点：直接画图导致象限错误。
  - $|x|+|y|\leq 1$：需分四个象限去绝对值，实质是四条直线围成的封闭图形（菱形）。
  - $|x-y|\leq a$：等价于 $-a \leq x-y \leq a$，即两条平行线 $y=x-a$ 与 $y=x+a$ 之间的带状区域。

## 闪卡
#card
- 不等式 $|x| + |y| \leq 1$ 表示什么图形？::顶点在 $(\pm 1, 0), (0, \pm 1)$ 的正方形（菱形）。
- 区域 $0 \leq x \leq 1, x \leq y \leq 1$ 的形状？::由直线 $y=x, y=1, x=0$ 围成的三角形。
- 如何快速画出 $1 \leq x+y \leq 2$ 且 $x,y\geq0$？::第一象限内，两条平行线 $x+y=1$ 与 $x+y=2$ 之间的带状区域。
- 区域 $D=\{(x,y)\mid y\leq x, y\geq -1, x\leq 1\}$ 的顶点？::$(1,1), (1,-1), (-1,-1)$ 围成的三角形。
- 不等式 $(x-1)^2 + (y-1)^2 \leq 1$ 表示什么？::圆心在 $(1,1)$，半径为 1 的圆及其内部。
- 区域 $0 \leq y \leq 1, 0 \leq x \leq 1-\sqrt{2y-y^2}$ 的边界曲线？::右边界是圆 $(x-1)^2+(y-1)^2=1$ 的左半弧。
- $x^2+y^2 \leq \sqrt{2}x$ 表示什么图形？::圆心在 $(\frac{\sqrt{2}}{2}, 0)$，半径为 $\frac{\sqrt{2}}{2}$ 的圆。
- 区域 $4x^2 \leq y \leq 9x^2 (x\geq0)$ 的形状特征？::第一象限内，两条开口向上的抛物线之间的狭长区域。
- 不等式 $x^2+y^2+xy \leq 1$ 表示什么图形？::中心在原点的倾斜椭圆区域。
- 极坐标方程 $r = 2\cos\theta$ 表示什么曲线？::圆心在 $(1,0)$，半径为 1 的圆。
- 区域 $0 \leq r \leq \sec\theta, 0 \leq \theta \leq \frac{\pi}{4}$ 的直角坐标边界？::由 $x=1, y=0, y=x$ 围成的三角形。
- 双纽线 $r^2 = \sin2\theta$ 在哪个象限有图像？::第一、三象限（因 $\sin2\theta \geq 0$）。
- 不等式 $(x^2+y^2)^3 \leq y^4$ 转为极坐标后的形式？::$r^6 \leq r^4\sin^4\theta \Rightarrow r^2 \leq \sin^4\theta$。
- 区域 $1 \leq r \leq 2, 0 \leq \theta \leq \frac{\pi}{2}$ 是什么形状？::第一象限内的圆环扇形（四分之一圆环）。
- 区域 $0 \leq x \leq t, 0 \leq y \leq t-x (t>0)$ 的形状？::直角边长为 $t$ 的等腰直角三角形，随 $t$ 放大。
- 当 $a$ 变化时，$\frac{2}{3}x^2 + \frac{2}{9}y^2 \leq a^2$ 表示什么？::一族中心在原点、轴比固定的同心椭圆。
- 区域 $0 < y < \sqrt{2ax-x^2}, x > y$ 中 $a$ 的作用？::$a$ 决定圆的大小（半径为 $a$），区域为圆内且在 $y=x$ 下方部分。
- 参数区域 $D_t$ 随 $t \to 0^+$ 时的极限状态？::区域收缩为原点或一条线段（取决于具体定义）。
