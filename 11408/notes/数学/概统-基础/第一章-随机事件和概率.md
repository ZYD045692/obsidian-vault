## 核心考点
### 考点1：事件关系与运算律
**掌握事件的包含、和、积、差、互斥与对立关系，熟练运用德摩根律进行事件转换。**
对立事件满足 $A \bar{A}=\emptyset, A+\bar{A}=\Omega$；德摩根律：$\overline{A \cup B} = \bar{A} \cap \bar{B}$，$\overline{A \cap B} = \bar{A} \cup \bar{B}$。

> [!tip] 考试怎么用
> 遇到'至少一个'、'都不'等描述，优先转化为对立事件或和/积事件，利用德摩根律简化。

### 考点2：古典概型与几何概型
**古典概型基于有限等可能样本点计数，几何概型基于长度、面积或体积的比例计算。**
古典：$P(A)=\frac{k}{n}$；几何：$P(A)=\frac{L_A}{L_\Omega}$（或面积/体积比）。

> [!tip] 考试怎么用
> 古典概型注意区分'有序（排列）'与'无序（组合）'；几何概型关键是确定样本空间及事件区域的度量。

### 考点3：概率基本性质与加法公式
**概率具有非负性、规范性和可加性，任意事件和的概率需减去交集部分以防重复。**
加法公式：$P(A \cup B) = P(A) + P(B) - P(AB)$；逆事件：$P(\bar{A}) = 1 - P(A)$。

> [!tip] 考试怎么用
> 计算'至少有一个发生'常用 $1-P(\text{都不发生})$；注意 $P(AB)=0$ 不代表互斥（除非离散）。

### 考点4：条件概率与乘法公式
**条件概率是缩小样本空间后的概率，乘法公式用于计算积事件概率。**
定义：$P(B|A) = \frac{P(AB)}{P(A)}$ ($P(A)>0$)；乘法：$P(AB) = P(A)P(B|A)$。

> [!tip] 考试怎么用
> 抽签原理：不放回抽样中，第 k 次抽到某物的概率与次序无关，均等于第一次的概率。

### 考点5：全概率公式与贝叶斯公式
**全概率公式由因求果（分解复杂事件），贝叶斯公式由果索因（更新后验概率）。**
全概率：$P(B)=\sum P(A_i)P(B|A_i)$；贝叶斯：$P(A_i|B)=\frac{P(A_i)P(B|A_i)}{\sum P(A_j)P(B|A_j)}$。

> [!tip] 考试怎么用
> 关键步骤是找到'完备事件组'（划分）；贝叶斯分母即为全概率公式的结果。

### 考点6：事件的独立性
**独立性指一事件发生不影响另一事件概率，等价于积事件概率等于概率之积。**
定义：$P(AB)=P(A)P(B)$；性质：若 A,B 独立，则 $A,\bar{B}$ 等四对均独立。

> [!tip] 考试怎么用
> 独立与互斥截然不同：若 $P(A),P(B)>0$，独立则必不互斥，互斥则必不独立。

### 考点7：n 重伯努利概型
**n 次独立重复试验中，事件发生 k 次的概率服从二项分布。**
公式：$P_n(k) = C_n^k p^k (1-p)^{n-k}$，其中 $p$ 为单次发生概率。

> [!tip] 考试怎么用
> 识别关键词'独立重复'、'命中率'；注意区分'第 k 次首次发生'与'n 次中发生 k 次'。

## 易混与对比
**互斥（互不相容）vs 对立**

|概念|互斥 (Mutually Exclusive)|对立 (Complementary)|
|:---|:---|:---|
|**定义**|$AB = \emptyset$ (不能同时发生)|$AB=\emptyset$ 且 $A \cup B = \Omega$|
|**关系**|对立一定互斥，互斥不一定对立|对立是互斥的特例|
|**概率**|$P(A \cup B) = P(A) + P(B)$|$P(B) = 1 - P(A)$|

**独立 vs 互斥**

|维度|独立 (Independent)|互斥 (Mutually Exclusive)|
|:---|:---|:---|
|**本质**|概率上互不影响 ($P(B|A)=P(B)$)|集合上无交集 ($AB=\emptyset$)|
|**公式**|$P(AB) = P(A)P(B)$|$P(AB) = 0$|
|**冲突**|若 $P(A),P(B)>0$，独立则 $P(AB)>0$，故**不互斥**|若 $P(A),P(B)>0$，互斥则 $P(AB)=0 \neq P(A)P(B)$，故**不独立**|

**两两独立 vs 相互独立**

|类型|条件要求|关系|
|:---|:---|:---|
|**两两独立**|$P(AB)=P(A)P(B)$, $P(AC)=P(A)P(C)$, $P(BC)=P(B)P(C)$|相互独立 $\Rightarrow$ 两两独立|
|**相互独立**|上述三式 + $P(ABC)=P(A)P(B)P(C)$|两两独立 $\nRightarrow$ 相互独立|
|**注意**|三个事件两两独立不能推出三者相互独立|需额外验证三事件积的概率|

**概率为 0 vs 不可能事件**

|概念|不可能事件|概率为 0 的事件|
|:---|:---|:---|
|**集合表示**|空集 $\emptyset$|可以是空集，也可以是非空集（如几何概型单点）|
|**概率值**|$P(\emptyset) = 0$|$P(A) = 0$|
|**逆命题**|概率为 0 不一定是不可能事件|不可能事件概率一定为 0|

## 闪卡（Spaced Repetition）
#card
- 事件 A 与 B 互不相容（互斥）的定义是什么？::两事件不能同时发生，即 $AB = \emptyset$。
- 事件 A 与 B 互为对立事件的充要条件？::$A \cup B = \Omega$ 且 $A \cap B = \emptyset$。
- 写出德摩根律中 $\overline{A \cup B}$ 的等价形式。::$\overline{A \cup B} = \bar{A} \cap \bar{B}$（都发生的对立）。
- 若 $A \subset B$，则 $P(B-A)$ 等于什么？::$P(B-A) = P(B) - P(A)$。
- 古典概型的两个核心特征是什么？::样本空间有限；每个基本事件发生可能性相等。
- 几何概型中，概率计算公式的分母代表什么？::样本空间 $\Omega$ 的长度、面积或体积。
- 从 n 个元素取 r 个不放回排列的公式？::$A_n^r = n(n-1)\cdots(n-r+1)$。
- 从 n 个元素取 r 个组合的公式？::$C_n^r = \frac{A_n^r}{r!}$。
- 必然事件和不可能事件的概率分别是多少？::$P(\Omega)=1$，$P(\emptyset)=0$。
- 若 $A \subset B$，则 $P(A)$ 与 $P(B)$ 大小关系？::$P(A) \leq P(B)$。
- 三个事件和的概率公式中 $P(ABC)$ 的符号？::正号（$+P(ABC)$）。
- 概率为 0 的事件一定是不可能事件吗？::不一定（如几何概型中取到某一点）。
- 条件概率 $P(B|A)$ 的定义公式？::$P(B|A) = \frac{P(AB)}{P(A)}$，要求 $P(A)>0$。
- 三个事件积的乘法公式？::$P(ABC) = P(A)P(B|A)P(C|AB)$。
- 抽签原理的核心结论是什么？::不放回抽样中，各次抽中概率相等，与次序无关。
- $P(A|B)$ 与 $P(A)$ 有固定大小关系吗？::没有，取决于 A 与 B 的相关性。
- 使用全概率公式的前提条件是什么？::存在一组两两互斥且和为 $\Omega$ 的完备事件组。
- 贝叶斯公式主要用于解决什么问题？::已知结果发生，求导致该结果的某原因的概率。
- 全概率公式中 $P(B)$ 的计算本质？::将 B 分解为若干互斥部分 $BA_i$ 的概率之和。
- 贝叶斯公式的分母代表什么？::事件 B 发生的总概率（全概率）。
- 两个事件独立的充要条件公式？::$P(AB) = P(A)P(B)$。
- 若 A,B 独立，A 与 $\bar{B}$ 是否独立？::是，独立事件的对立事件仍相互独立。
- 概率为 0 的事件与任何事件的关系？::相互独立。
- 非零概率事件，独立与互斥能同时成立吗？::不能，独立则 $P(AB)>0$，互斥则 $P(AB)=0$。
- n 重伯努利试验的两个核心特征？::试验独立重复；每次只有两个结果（成功/失败）。
- 二项概率公式中 $C_n^k$ 的含义？::n 次试验中成功 k 次的组合数（顺序不同）。
- 若 $X \sim B(n,p)$，则 $P(X=k)$ 公式？::$C_n^k p^k (1-p)^{n-k}$。
- '第 4 次恰好第 2 次命中'如何计算？::$C_3^1 p(1-p)^2 \cdot p$（前 3 次 1 中，第 4 次中）。
