# 3.3 本章疑难点

> [!abstract] 一句话总结
> 分页是系统导向的一维固定划分（有内碎无外碎），分段是用户导向的二维可变划分（有外碎无内碎）。

## 核心要点
### 考点1：管理目的与单位性质
**分页是系统管理需要以实现离散分配，分段是用户逻辑单位以满足编程需要。**
页：系统决定的物理单位；段：含一组意义相对完整信息的逻辑单位。

> [!tip] 考试怎么用
> 区分‘谁的需要’：分页非用户需要，分段更好地满足用户需要。

### 考点2：长度决定与划分机制
**页大小固定由系统硬件决定，段长度不固定由用户程序及编译程序决定。**
页：机器硬件将逻辑地址划分为页号和页内地址；段：编译时根据信息性质划分。

> [!tip] 考试怎么用
> 关键词匹配：‘固定’对应分页，‘不固定’对应分段；‘硬件’对应分页，‘编译程序’对应分段。

### 考点3：地址空间维度
**分页是一维线性地址空间，分段是二维地址空间（需段名 + 段内地址）。**
分页：单一线性地址，一个记忆符表示；分段：需给出段名和段内地址。

> [!tip] 考试怎么用
> 编程视角：一维只需偏移量，二维需‘段号 + 偏移’或‘段名 + 偏移’。

### 考点4：碎片类型特征
**分页有内部碎片无外部碎片，分段有外部碎片无内部碎片。**
分页：页内最后部分可能浪费（内碎）；分段：段间空闲区太小无法利用（外碎）。

> [!tip] 考试怎么用
> 死记硬背点：固定大小导致内碎，可变大小导致外碎。

## 易混与对比
**分页与分段核心差异对比**

|比较维度|分页|分段|
|:---|:---|:---|
|**目的**|系统管理需要（提高利用率）|用户需要（逻辑完整信息）|
|**长度**|固定（系统决定）|不固定（用户程序/编译决定）|
|**地址空间**|一维（线性）|二维（段名 + 段内地址）|
|**碎片类型**|有内部碎片，无外部碎片|有外部碎片，无内部碎片|
|**实现机制**|机器硬件划分|编译程序划分|

## 闪卡
#card
- 分页管理的根本目的是什么？::实现离散分配方式，提高内存利用率，是系统管理需要。
- 分段管理中‘段’的定义是什么？::信息的逻辑单位，含有一组意义相对完整的信息。
- 哪种管理方式是为了更好地满足用户的需要？::分段管理方式。
- 分页是否由用户的需要决定？::否，分页仅是系统管理上的需要，而不是用户的需要。
- 页的大小由谁决定且是否固定？::由系统决定，大小固定。
- 段的长度由什么决定？::决定于用户所编写的程序，通常由编译程序根据信息性质划分。
- 逻辑地址划分为页号和页内地址是由什么实现的？::由机器硬件实现。
- 分段管理中地址划分发生在什么时候？::通常在编译程序编译时进行。
- 分页管理的程序地址空间是几维的？::一维的，即单一的线性地址空间。
- 分段管理中程序员如何标识一个地址？::既需给出段名，又需给出段内地址。
- 哪种管理方式下程序员利用一个记忆符即可表示地址？::分页管理方式。
- 分段的程序地址空间维度及其原因？::二维的，因为需要同时指定段名和段内地址。
- 分页管理方式会产生哪种碎片？::有内部碎片，无外部碎片。
- 分段管理方式会产生哪种碎片？::有外部碎片，无内部碎片。
- 为什么分页管理没有外部碎片？::因为页大小固定，内存分配以页为单位，不留分散小空闲区。
- 为什么分段管理没有内部碎片？::因为段长度不固定，按实际需要的长度分配内存。
