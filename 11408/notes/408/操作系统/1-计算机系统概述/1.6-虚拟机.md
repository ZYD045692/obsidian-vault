# 1.6 虚拟机

> [!abstract] 一句话总结
> 虚拟机通过虚拟化技术将物理机抽象为多台逻辑独立的完整硬件复制品，核心在于隐藏底层细节并提供隔离执行平台。

## 核心要点
### 考点1：虚拟机基本概念
**虚拟机是将一台物理计算机抽象为多台逻辑上独立的计算环境，表现为完整硬件系统的精确复制品。**
核心目标：隐藏底层物理硬件细节，向上层提供统一且隔离的执行平台。

> [!tip] 考试怎么用
> 注意区分'逻辑独立'与'物理独立'，虚拟机共享物理资源但在逻辑上完全隔离。

### 考点2：第一类虚拟机管理程序
**第一类管理程序直接运行在物理硬件之上，处于最高特权级，负责管理硬件资源和调度多个虚拟机。**
架构特点：裸金属架构；客户 OS 运行于虚拟内核态，敏感指令触发异常陷入管理程序。

> [!tip] 考试怎么用
> 重点掌握敏感指令的处理机制：硬件支持时区分来源，不支持时全部重定向模拟。

### 考点3：第二类虚拟机管理程序
**第二类管理程序以应用程序形式运行在宿主操作系统之上，本质是用户态进程，依赖宿主系统进行资源分配。**
架构特点：寄居架构；模拟新计算机行为，虚拟磁盘实为宿主 OS 中的普通文件。

> [!tip] 考试怎么用
> 易错点：第二类管理程序不是操作系统，而是运行在 OS 之上的应用，性能低于第一类。

### 考点4：虚拟化技术的应用场景
**虚拟化技术解决了 Web 主机领域共享托管无法控制环境与独占托管成本高昂的矛盾。**
应用价值：单台物理服务器运行多个虚拟机，支持自定义 OS 与软件，显著降低成本。

> [!tip] 考试怎么用
> 结合云服务器背景理解，虚拟化是当前主流云服务的基础架构。

## 易混与对比
**第一类与第二类虚拟机管理程序对比**

|特性|第一类 (裸金属)|第二类 (寄居)|
|---|---|---|
|运行位置|直接运行在物理硬件上|运行在宿主操作系统之上|
|特权级|最高特权级|用户态进程|
|资源管理|直接管理硬件资源|依赖宿主 OS 分配调度|
|典型代表|图 1.8(a) 架构|VMware Workstation|
|性能特点|高效，接近原生|较低，经过宿主 OS 层

**敏感指令处理机制差异**

|CPU 类型|指令来源|处理方式|
|---|---|---|
|支持硬件虚拟化|客户操作系统|管理程序代为完成功能|
|支持硬件虚拟化|用户程序|模拟真实硬件异常响应|
|不支持硬件虚拟化|任意来源|全部重定向至管理程序软件模拟|

## 闪卡
#card
- 虚拟机的本质定义是什么？::物理计算机抽象为多台逻辑独立、表现为完整硬件系统精确复制品的计算环境。
- 虚拟化技术的核心作用是什么？::隐藏底层物理硬件细节，提供统一且隔离的执行平台。
- 虚拟机之间是否相互影响？::否，彼此完全隔离，每台虚拟机表现为独立的完整硬件系统。
- 第一类虚拟机管理程序的运行位置？::直接运行在物理硬件之上，是系统中唯一处于最高特权级的软件。
- 客户操作系统在第一类架构中的状态？::运行于虚拟内核态，自认为处于真实内核态，实际用户进程运行在真实用户态。
- 敏感指令触发异常后如何处理（硬件支持虚拟化）？::若源自客户 OS 则代为完成；若源自用户程序则模拟真实硬件异常响应。
- 早期不支持硬件虚拟化时敏感指令如何处理？::所有敏感指令均被透明重定向到虚拟机管理程序，由软件模拟实现功能。
- 第二类虚拟机管理程序的运行形态？::以应用程序形式运行在宿主操作系统之上，本质是一个用户态进程。
- 第二类架构中资源由谁分配调度？::依赖宿主操作系统进行资源分配与调度。
- 虚拟磁盘在第二类架构中是什么？::宿主操作系统中的一个普通文件。
- x86 平台首个广泛使用的第二类管理程序？::VMware Workstation。
- 无虚拟化时 Web 主机服务的两种模式？::共享托管（无法控制软件环境）或独占托管（成本高昂）。
- 虚拟化在 Web 主机领域的核心优势？::单台物理机运行多个虚拟机，支持自定义环境且成本显著降低。
- 当前主流云服务器服务的基础是什么？::虚拟化技术。
