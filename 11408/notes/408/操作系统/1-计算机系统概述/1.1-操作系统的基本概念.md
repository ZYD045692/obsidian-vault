# 1.1 操作系统的基本概念

> [!abstract] 一句话总结
> 操作系统是管理软硬件资源、提供用户接口并扩充机器功能的系统软件，其核心特征为并发、共享、虚拟和异步。

## 核心要点
### 考点1：操作系统的定义与层次
**操作系统是控制和管理计算机系统软/硬件资源、合理调度任务与分配资源，并为用户及其他软件提供统一接口与运行环境的最基本的系统软件。**
计算机系统四层结构：硬件 $\to$ 操作系统 $\to$ 应用程序 $\to$ 用户。

> [!tip] 考试怎么用
> 区分计算机组成原理的分层（侧重硬件结构）与操作系统的分层（侧重人机交互视角）。

### 考点2：操作系统的四大功能
**操作系统具备处理机管理、存储器管理、设备管理和文件管理四大核心功能，并提供用户接口。**
1. 处理机管理：进程控制、同步、通信、死锁、调度。
2. 存储器管理：分配回收、地址映射、保护共享、扩充。
3. 文件管理：空间管理、目录、读写、访问保护。
4. 设备管理：缓冲、分配、驱动、虚拟设备。

> [!tip] 考试怎么用
> 处理机管理的本质是对进程的管理；文件管理的对象是用户可见的持久化信息。

### 考点3：操作系统的接口分类
**操作系统提供用户接口（命令方式、图形方式）供终端用户使用，提供程序接口（系统调用）供应用程序使用。**
程序接口核心：系统调用。
库函数关系：$\text{库函数} \xrightarrow{\text{封装}} \text{系统调用}$（纯计算库函数除外）。

> [!tip] 考试怎么用
> 库函数不是操作系统接口，只有系统调用才是应用程序访问系统资源的唯一合法途径。

### 考点4：扩充机器概念
**操作系统将裸机抽象并扩展为功能更强、使用更便捷的逻辑机器，称为扩充机器。**
层次模型：$\text{裸机} \subset \text{操作系统} \subset \text{扩充机器}$。

> [!tip] 考试怎么用
> 理解“工人”比喻：操作系统作为工人操作原始机器，使其发挥远超本身的能力。

### 考点5：并发与并行
**并发指多个事件在同一时间间隔内交替发生，并行指多个事件在同一时刻真正同时发生。**
单处理机系统：宏观并发，微观串行（非并行）。
多核/多处理机：可实现进程级并行。

> [!tip] 考试怎么用
> 单 CPU 系统中，CPU 与 I/O 设备之间可并行，但多道程序之间只能并发。

### 考点6：资源共享方式
**共享分为互斥共享（临界资源）和同时访问（分时共享），并发与共享互为前提。**
临界资源：一段时间内只允许一个进程访问（如打印机）。
同时访问：宏观同时，微观分时（如只读文件）。

> [!tip] 考试怎么用
> 互斥共享防止数据混乱；同时访问要求最终效果等同于连续访问。

### 考点7：虚拟技术
**虚拟通过时分复用和空分复用技术，将一个物理实体映射为多个逻辑对应物。**
时分复用：处理器分时共享（逻辑多 CPU）。
空分复用：虚拟存储器（逻辑大容量内存）。
虚拟设备：SPOOLing 技术（独占变共享）。

> [!tip] 考试怎么用
> 虚拟设备的核心是将独占设备转化为可并发使用的共享资源。

### 考点8：异步性特征
**进程以不可预知的速度断续推进，称为异步性，需同步机制保障结果正确性。**
成因：资源有限导致进程执行不连续。
风险：缺乏协调可能导致与时间相关的错误。

> [!tip] 考试怎么用
> 异步性不代表结果不可再现，正确使用同步机制可保障正确性。

## 易混与对比
**并发 vs 并行**

|特征|并发 (Concurrency)|并行 (Parallelism)|
|---|---|---|
|定义|同一**时间间隔**内交替发生|同一**时刻**真正同时发生|
|微观表现|任一时刻仅一个事件执行|任一时刻多个事件同时执行|
|硬件要求|单处理机即可实现|需多核或多处理机支持|
|实例|单 CPU 多道程序交替运行|多核 CPU 同时运行多进程|

**系统调用 vs 库函数**

|项目|系统调用|库函数|
|---|---|---|
|性质|操作系统提供的唯一合法接口|编程语言提供的功能封装|
|运行空间|内核态|用户态（纯计算类）或触发内核态|
|关系|被库函数封装调用|可能调用系统调用（如 printf）|
|例外|无|纯计算函数（如 strlen）不调用系统调用|

**互斥共享 vs 同时访问**

|维度|互斥共享|同时访问|
|---|---|---|
|访问限制|任一时刻仅允许一个进程访问|宏观同时，微观分时交替访问|
|典型资源|打印机、磁带机、临界区变量|只读文件、重入代码|
|目的|防止数据混淆或设备冲突|提高资源利用率，逻辑上同时|

## 闪卡
#card
- 操作系统在计算机系统四层结构中的位置？::位于硬件之上，应用程序和用户之下。
- 操作系统的核心职责是什么？::管理软硬件资源，提供统一接口与运行环境。
- 操作系统属于哪类软件？::最基本的系统软件。
- 处理机管理的基本单位是什么？::进程（或线程）。
- 文件管理系统的主要功能包括哪些？::文件存储空间管理、目录管理、读写操作及访问保护。
- 设备管理如何屏蔽设备差异？::通过缓冲管理、设备分配、驱动处理和虚拟设备功能。
- 存储器管理中“地址映射”的作用？::将逻辑地址转换为物理地址，方便用户使用。
- 应用程序请求操作系统服务的唯一合法途径？::系统调用。
- printf() 函数是否直接属于操作系统接口？::否，它是库函数，内部封装了 write 系统调用。
- 联机用户接口适用于什么场景？::交互式场景，用户输入命令系统立即执行。
- 脱机用户接口主要用于哪种系统？::批处理系统，通过作业说明书自动控制。
- 未安装任何软件的计算机称为什么？::裸机。
- 什么是扩充机器？::经操作系统抽象和扩展后的逻辑机器。
- 操作系统如何实现扩充机器？::通过资源管理和用户服务功能抽象硬件。
- 单处理机系统中多道程序的执行特征？::宏观上同时运行，微观上交替执行（并发）。
- 并行发生的必要条件是什么？::同一时刻真正同时发生，需多核或多处理机支持。
- CPU 与 I/O 设备之间能否并行工作？::能，属于硬件层面的真正并行。
- 什么是临界资源？::一段时间内只允许一个进程访问的资源。
- 打印机属于哪种共享方式？::互斥共享。
- 只读文件通常采用哪种共享方式？::同时访问（分时共享）。
- 并发与共享的关系？::互为前提，无并发无需共享，无共享机制无法并发。
- 虚拟存储器利用了什么技术？::空分复用，将物理内存扩展为更大的逻辑地址空间。
- 如何实现处理器的虚拟化？::时分复用（时间片轮转），使单 CPU 逻辑表现为多处理单元。
- SPOOLing 技术实现了什么虚拟？::虚拟设备，将独占设备转化为多台逻辑设备。
- 进程异步性的根本原因？::系统资源有限，进程执行断续且速度不可预知。
- 异步性可能导致什么错误？::与时间相关的错误（如并发修改全局变量）。
- 如何保障异步环境下的执行结果正确？::正确使用操作系统提供的同步机制。
