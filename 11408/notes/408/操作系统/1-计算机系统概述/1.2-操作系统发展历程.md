# 1.2 操作系统发展历程

> [!abstract] 一句话总结
> 操作系统演进的核心矛盾始终是解决人机速度不匹配及提升资源利用率，从人工独占走向多道并发与实时响应。

## 核心要点
### 考点1：手工操作与脱机 I/O
**手工操作阶段用户独占全机导致 CPU 空闲，脱机 I/O 利用外围机独立控制 I/O 以缓解人机速度矛盾。**
脱机 I/O 流程：外围机读入纸带$\to$磁带$\to$CPU 处理$\to$磁带$\to$外围机输出。

> [!tip] 考试怎么用
> 区分联机 I/O（主机直接管理）与脱机 I/O（外围机独立控制），考点在于谁控制 I/O 设备。

### 考点2：单道批处理系统
**单道批处理系统通过监督程序实现作业自动连续处理，但内存中始终仅驻留一道程序，I/O 时 CPU 仍空闲。**
特征：1) 自动性；2) 顺序性；3) 单道性（内存仅一道程序）。

> [!tip] 考试怎么用
> 易错点：虽成批提交，但内存中只有一道程序，无法克服 I/O 等待瓶颈。

### 考点3：多道批处理系统
**多道批处理系统内存驻留多道程序，宏观并行微观串行，显著提升资源利用率和吞吐量但缺乏交互性。**
核心特点：1) 多道；2) 宏观上并行；3) 微观上串行。

> [!tip] 考试怎么用
> 必考辨析：'宏观并行'指多程序均在运行过程中，'微观串行'指轮流占用 CPU。

### 考点4：分时操作系统
**分时系统采用时间片轮转策略，以人机交互为核心目标，具备同时性、交互性、独立性和及时性。**
特征：1) 同时性；2) 交互性；3) 独立性；4) 及时性。

> [!tip] 考试怎么用
> 对比多道批处理：分时追求交互响应，批处理追求吞吐量；分时是时间片轮转。

### 考点5：实时操作系统
**实时系统基于任务紧迫性调度，分为硬实时（绝对截止）和软实时（可容忍偶尔错过），强调确定性与高可靠。**
分类：1) 硬实时（灾难性后果）；2) 软实时（可容忍短暂延迟）。

> [!tip] 考试怎么用
> 实例对应：飞行控制/导弹制导属硬实时；订票/银行系统属软实时。

### 考点6：网络与分布式操作系统
**网络 OS 需用户显式指定远程资源，分布式 OS 提供透明性，用户感知为单一系统且任务可分布并行执行。**
分布式核心：分布性、并行性、透明性（用户无须感知多机结构）。

> [!tip] 考试怎么用
> 关键判据：是否需要用户主动干预远程操作（网络 OS 需要，分布式 OS 不需要）。

### 考点7：微机操作系统分类
**微机 OS 按用户数和任务数分为单用户单任务、单用户多任务、多用户多任务三类。**
代表：1) 单用户单任务 (MS-DOS)；2) 单用户多任务 (Windows XP)；3) 多用户多任务 (UNIX/Linux Server)。

> [!tip] 考试怎么用
> 注意 Windows XP 是单用户多任务，Linux 服务器版是多用户多任务。

## 易混与对比
**单道 vs 多道批处理**

|特征|单道批处理|多道批处理|
|---|---|---|
|内存程序数|仅 1 道|多道|
|CPU 利用率|I/O 时 CPU 空闲|I/O 时切换其他程序|
|执行方式|顺序执行|宏观并行，微观串行|
|交互性|无|无|

**多道批处理 vs 分时系统**

|维度|多道批处理|分时系统|
|---|---|---|
|核心目标|高吞吐量、资源利用率|人机交互、及时响应|
|用户干预|无须干预|用户直接控制|
|调度策略|作业调度算法|时间片轮转|
|响应时间|长|短（及时性）|

**网络 OS vs 分布式 OS**

|特性|网络操作系统|分布式操作系统|
|---|---|---|
|资源访问|用户需显式指定位置|透明共享，用户无感知|
|任务执行|各机独立运行|任务分解分布并行执行|
|系统视图|多台独立计算机|单一系统映像|
|节点关系|可有主从|地位对等|

**硬实时 vs 软实时**

|类型|截止时间要求|错过后果|典型实例|
|---|---|---|---|
|硬实时|必须严格满足|灾难性后果|飞机控制、导弹制导|
|软实时|允许偶尔错过|可容忍，无永久损害|订票系统、银行管理|

## 闪卡
#card
- 手工操作阶段最突出的两个缺点是什么？::用户独占全机资源利用率低；CPU 长时间空闲等待人工 I/O。
- 脱机 I/O 技术中，输入时数据流向是怎样的？::纸带/卡片$\to$外围机$\to$磁带$\to$内存（CPU 不参与 I/O 准备）。
- 脱机 I/O 相比手工操作的主要优点？::减少 CPU 空闲时间；利用高速磁带提升 I/O 效率。
- 由主机直接管理 I/O 设备的方式称为什么？::联机 I/O。
- 单道批处理系统的三个主要特征？::自动性、顺序性、单道性。
- 单道批处理系统中，当运行作业发起 I/O 请求时 CPU 状态？::CPU 空闲等待，直到 I/O 结束。
- 单道批处理系统内存中允许驻留几道用户程序？::仅允许一道。
- 单道批处理系统如何解决作业连续执行问题？::配备监督程序（Monitor），自动从磁带调入下一道作业。
- 多道程序设计技术的三个核心特点？::多道、宏观上并行、微观上串行。
- 多道批处理系统中，当某程序因 I/O 暂停时 CPU 做什么？::立即切换至另一就绪程序继续执行。
- 多道批处理系统的主要缺点是什么？::缺乏交互能力，用户无法干预，响应时间长。
- 实现多道程序设计需解决的关键问题不包括？::不需要解决人机交互界面设计（这是分时系统的目标）。
- 分时操作系统的四个主要特征？::同时性、交互性、独立性、及时性。
- 分时系统如何实现用户'独占计算机'的感觉？::时间片极短且轮转迅速，用户请求能快速得到响应。
- 分时系统与多道批处理系统的本质区别？::分时以人机交互为核心，批处理追求高吞吐量无须干预。
- 若程序在时间片内未完成，分时系统如何处理？::暂停运行释放 CPU，待下一轮时间片再继续执行。
- 硬实时操作系统与软实时操作系统的核心区别？::硬实时必须严格满足截止时间，否则灾难；软实时允许偶尔错过。
- 飞机控制系统属于哪种实时系统？::硬实时操作系统。
- 银行管理系统属于哪种实时系统？::软实时操作系统。
- 实时操作系统的主要特点？::确定性（响应可预测）、高可靠性、强时效性。
- 网络操作系统与分布式操作系统的最大区别？::网络 OS 需用户显式指定资源位置；分布式 OS 提供透明性（单一系统映像）。
- 分布式系统的节点关系特征？::节点地位对等，无固定主从关系。
- 分布式操作系统的三个核心特点？::分布性、并行性、透明性。
- 用户无须感知底层多机结构体现了什么特性？::透明性。
- MS-DOS 属于哪种类型的微机操作系统？::单用户单任务操作系统。
- Windows XP 和 macOS 属于哪种类型？::单用户多任务操作系统。
- UNIX 和 Linux 服务器版属于哪种类型？::多用户多任务操作系统。
- 单用户多任务系统如何实现任务切换？::通过时间片轮转实现。
