# 2.2 CPU 调度

> [!abstract] 一句话总结
> CPU 调度通过多级调度体系与多样化算法，在公平性与效率之间权衡，解决多进程争用单/多 CPU 资源的矛盾。

## 核心要点
### 考点1：调度的三级层次
**作业调度负责外存到内存的调入，中级调度负责内存与外存的对换，进程调度负责就绪队列到 CPU 的分配。**
调度频率：作业调度 < 中级调度 < 进程调度；进程调度是所有系统必须存在的最低级调度。

> [!tip] 考试怎么用
> 注意分时/实时系统通常无作业调度；中级调度对应进程状态中的'挂起态'。

### 考点2：进程调度时机与方式
**调度发生在进程创建、终止、阻塞或 I/O 中断时；分为非抢占（自愿让出）和抢占（强制剥夺）两种方式。**
不可调度时机：处理中断过程中、执行原子操作（如加锁/解锁）过程中。

> [!tip] 考试怎么用
> 区分'调度决策'与'切换执行'；中断处理期间严禁切换，需设标志延后处理。

### 考点3：上下文切换与模式切换
**上下文切换涉及保存旧进程 PCB 并恢复新进程 PCB，仅在内核态发生；模式切换是同一进程内用户态与内核态的转换。**
切换步骤：1.挂起当前进程存上下文；2.PCB 入队；3.选新进程；4.恢复新上下文；5.跳转 PC。

> [!tip] 考试怎么用
> 模式切换不改变进程，无上下文切换开销；上下文切换必然伴随模式切换（至内核态）。

### 考点4：调度性能评价指标
**核心指标包括 CPU 利用率、吞吐量、周转时间、等待时间和响应时间，不同系统侧重不同。**
公式：$周转时间 = 完成时间 - 提交时间$；$带权周转时间 = 周转时间 / 实际运行时间$。

> [!tip] 考试怎么用
> 计算时注意 CPU 与 I/O 可并行；交互式系统最关注响应时间而非周转时间。

### 考点5：FCFS 与 SJF 调度算法
**FCFS 公平但利于长作业；SJF 平均等待时间最优但可能导致长作业饥饿，且依赖用户估计。**
SJF 抢占式称为最短剩余时间优先；当所有作业同时到达时，SJF 平均等待时间最优。

> [!tip] 考试怎么用
> FCFS 不利于 I/O 繁忙型作业；SJF 的'短'由用户估计值决定，可能被恶意低估。

### 考点6：高响应比与优先级调度
**高响应比平衡了 FCFS 和 SJF，避免长作业饥饿；优先级调度分静态/动态及抢占/非抢占。**
公式：$响应比 =( 等待时间 + 估计运行时间 )/ 估计运行时间$；优先级原则：系统>用户，交互>非交互，I/O>计算。

> [!tip] 考试怎么用
> 动态优先级随等待时间增加而提高可防止饥饿；I/O 型进程优先级高是为了尽早启动 I/O 设备。

### 考点7：时间片轮转与多级反馈队列
**RR 适用于分时系统，时间片大小需平衡响应速度与切换开销；多级反馈队列综合了多种算法优点。**
多级反馈队列机制：新进程进第 1 级（高优先、小时间片），用完时间片未完成则降级；仅当高优先级队列为空才调度低级。

> [!tip] 考试怎么用
> 时间片过大退化为 FCFS，过小导致频繁切换开销大；多级反馈队列无须事先知道进程运行时间。

### 考点8：多处理机调度
**SMP 系统需平衡处理器亲和性（利用缓存）与负载平衡（充分利用 CPU），分为公共队列和私有队列方案。**
软亲和由调度程序尽量保持进程在原 CPU；硬亲和由用户通过系统调用绑定 CPU。

> [!tip] 考试怎么用
> 公共队列利于负载平衡但亲和性差；私有队列利于亲和性但需推/拉迁移机制平衡负载。

## 易混与对比
**上下文切换 vs 模式切换**

|特性|上下文切换|模式切换|
|---|---|---|
|**对象变化**|从一个进程切换到另一个进程|同一进程内用户态与内核态切换|
|**PCB 操作**|必须保存旧 PCB，加载新 PCB|不涉及 PCB 切换|
|**发生场景**|进程调度、时间片用完|系统调用、中断发生/返回|
|**开销**|大（涉及寄存器、TLB、缓存）|小（仅状态位变化）|

- **饥饿 vs 死锁**：**饥饿**：由于调度策略（如 SJF 中长作业遇连续短作业）导致某进程无限期等待，但系统仍在运行其他进程。
  **死锁**：多个进程因循环等待资源而互相阻塞，导致所有相关进程都无法推进，系统停滞。
**非抢占 vs 抢占调度**

|类型|触发条件|适用场景|优缺点|
|---|---|---|---|
|**非抢占**|进程完成或主动阻塞|早期批处理系统|实现简单、开销小；响应慢|
|**抢占**|高优先级到达或时间片用完|分时、实时系统|响应快、吞吐高；实现复杂、开销大|

- **多级队列 vs 多级反馈队列**：**多级队列**：进程固定属于某队列，各队列独立算法，高优先级队列空时才调度低优先级（无反馈）。
  **多级反馈队列**：进程可随执行情况在不同队列间移动（反馈），新进程进高优，长作业降级，兼顾响应与公平。

## 闪卡
#card
- 哪级调度负责从外存后备队列挑选作业并创建进程？::高级调度（作业调度），实现内存与外存间的调度。
- 中级调度将进程换出到外存后，进程处于什么状态？::挂起态；换入内存后恢复为就绪态。
- 三级调度中频率最高且所有系统必须存在的是哪一级？::低级调度（进程调度），通常每几十毫秒执行一次。
- 分时系统和实时系统通常是否设置独立的作业调度？::否，因用户进程由交互式命令直接创建。
- 进程因 I/O 请求进入阻塞态时，是否触发调度？::是，必须调度其他进程运行。
- 在处理中断的过程中能否进行进程切换？为什么？::不能，中断处理逻辑复杂且不属于任何用户进程，不应被剥夺 CPU。
- 非抢占式调度下，高优先级进程进入就绪队列会发生什么？::当前进程继续执行直到完成或主动阻塞，高优先级进程需等待。
- 抢占式调度的主要原则有哪些？::优先级原则、短进程优先原则、时间片原则。
- 上下文切换与模式切换的核心区别是什么？::上下文切换换进程（改 PCB），模式切换不换进程（仅改 CPU 状态位）。
- 上下文切换过程运行在什么模式下？::内核态，因需访问和修改内核数据结构（如 PCB）。
- 减少上下文切换开销的硬件方法是什么？::采用两组寄存器，切换时仅改变指向当前寄存器组的指针。
- 调度与切换的关系是什么？::调度是决策行为（选谁），切换是执行行为（移交 CPU），先调度后切换。
- 带权周转时间的定义公式是什么？::$带权周转时间 = 作业周转时间 / 作业实际运行时间$。
- 哪个指标衡量单位时间内系统完成的作业数量？::系统吞吐量，长作业多会降低吞吐量。
- 交互式系统中用户最关注的指标是什么？::响应时间，即从提交请求到首次产生响应的时间。
- CPU 调度算法主要影响作业的哪部分时间？::等待时间（在就绪队列排队的时间），不影响实际执行和 I/O 时间。
- FCFS 算法对哪类作业有利，对哪类不利？::利于长作业和 CPU 繁忙型作业，不利于短作业和 I/O 繁忙型作业。
- SJF 算法在什么条件下平均等待时间最优？::当所有作业同时到达且运行时间已知时。
- SJF 算法中'饥饿现象'产生的原因是什么？::长作业进入队列后，若不断有新短作业到达，长作业将无限期等待。
- 抢占式 SJF 算法的触发条件是什么？::新进程到达且其估计运行时间短于当前进程的剩余执行时间。
- 高响应比优先算法如何避免长作业饥饿？::随等待时间增加，长作业的响应比会不断提高，最终超过短作业。
- 为何 I/O 型进程的优先级通常高于计算型进程？::让 I/O 型进程尽快获得 CPU 启动 I/O 操作，提高设备利用率和系统吞吐量。
- 静态优先级调度的主要缺点是什么？::不够灵活，低优先级进程可能长期得不到调度而产生饥饿。
- 动态优先级调整的一个常见策略是什么？::优先级随进程等待时间的增加而提高。
- 时间片轮转算法中，时间片过大会导致什么后果？::退化为 FCFS 算法，无法满足短作业和交互式用户的快速响应需求。
- 多级反馈队列中，新创建的进程放入哪个队列？::第 1 级队列（优先级最高、时间片最小）的末尾。
- 多级反馈队列中，进程在当前时间片用完未完成会怎样？::被移至下一级（优先级更低、时间片更大）队列的末尾。
- 多级反馈队列如何解决长作业饥饿问题？::长作业虽降至低优先级，但仍能轮转获得 CPU，且高优先级队列空闲时可执行。
- 什么是处理器亲和性？为何重要？::让进程尽量在同一 CPU 运行以利用缓存；迁移会导致缓存失效，开销大。
- 多处理机调度中'推迁移'是指什么？::特定程序检查负载，从超载 CPU 的就绪队列'推'出进程到空闲 CPU。
- 多处理机调度中'拉迁移'是指什么？::空闲 CPU 主动从超载 CPU 的就绪队列'拉'取进程到自己的队列。
- 对称多处理机（SMP）与非对称（AMP）的核心区别？::SMP 所有 CPU 地位对等均可调度；AMP 仅主 CPU 负责调度，从 CPU 只执行。
