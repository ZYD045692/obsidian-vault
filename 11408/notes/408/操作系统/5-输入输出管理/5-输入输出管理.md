# 输入输出管理

> [!abstract] 一句话总结
> I/O 管理的核心矛盾是高速 CPU 与低速外设的速度差异，通过分层软件架构、缓冲技术及智能调度算法，以最小化 CPU 干预并最大化设备并行性。

## 核心考点
### 考点1：I/O 控制方式演进
**I/O 控制方式从程序轮询发展到通道控制，核心趋势是不断减少 CPU 对数据传输的干预频率和粒度。**
程序轮询（CPU 全程等待）$\to$ 中断驱动（字/字节级干预）$\to$ DMA（块级干预，仅始末介入）$\to$ 通道（执行专用程序，管理多设备）。

> [!tip] 考试怎么用
> 重点区分中断与 DMA 的数据传输路径：中断需经 CPU 寄存器，DMA 直接在内存与设备间传输。

### 考点2：I/O 软件层次结构
**I/O 软件采用四层结构，自下而上依次为中断处理程序、设备驱动程序、设备独立性软件和用户层 I/O 软件。**
中断处理（响应硬件）$\to$ 驱动程序（转换抽象命令为具体指令）$\to$ 设备独立性软件（缓冲、映射、统一接口）$\to$ 用户层（库函数）。

> [!tip] 考试怎么用
> 陷阱指令（Trap）是用户态进入内核态的唯一入口；中断是设备通知 CPU 操作完成的机制。

### 考点3：缓冲技术与性能计算
**缓冲技术用于缓和 CPU 与 I/O 设备速度不匹配，单缓冲和双缓冲的处理时间计算公式不同。**
单缓冲时间：$\max(T, C) + M$；双缓冲时间：$\max(T, C + M)$。其中 $T$ 为输入时间，$C$ 为处理时间，$M$ 为传送时间。

> [!tip] 考试怎么用
> 计算时务必判断 $T$ 与 $C$（或 $C+M$）的大小关系，取最大值作为瓶颈时间，最后加上数据传送时间 $M$（单缓冲）。

### 考点4：SPOOLing 技术
**SPOOLing 技术利用磁盘作为巨大缓冲区，将独占设备改造为共享设备，实现了虚拟设备功能。**
组成：输入/输出井（磁盘）、输入/输出缓冲区（内存）、输入/输出进程。本质：以空间换时间，模拟脱机 I/O。

> [!tip] 考试怎么用
> SPOOLing 并未真正改变设备的物理属性，而是通过排队和暂存，让多个进程感觉独占设备。

### 考点5：磁盘存取时间构成
**磁盘一次读写时间由寻道时间、旋转延迟时间和数据传输时间组成，其中寻道时间占比最大。**
总时间 $T_a = T_s + T_r + T_t$。$T_s = mn+s$（寻道），$T_r = 1/(2r)$（旋转延迟），$T_t = b/(rN)$（传输）。

> [!tip] 考试怎么用
> 磁盘调度的主要目标是减少平均寻道时间 $T_s$；旋转延迟与转速成反比，传输时间由硬件决定。

### 考点6：磁盘调度算法对比
**常用磁盘调度算法包括 FCFS、SSTF、SCAN 和 C-SCAN，各自在公平性、吞吐量和饥饿问题上表现不同。**
FCFS（公平但慢）；SSTF（局部最优但饥饿）；SCAN（电梯算法，避免饥饿）；C-SCAN（单向循环，消除两端不公平）。

> [!tip] 考试怎么用
> 计算题常考 SSTF 和 SCAN/C-SCAN 的磁头移动总距离；注意 C-SCAN 回程不服务请求。

### 考点7：固态硬盘特性与管理
**SSD 基于闪存技术，无机械部件，随机访问快，但存在擦写寿命限制，需采用磨损均衡技术。**
特性：读/写以页为单位，擦除以块为单位。磨损均衡：动态（选空闲块）和静态（迁移数据）策略延长寿命。

> [!tip] 考试怎么用
> SSD 不需要磁盘调度算法（无寻道时间），但需要闪存翻译层（FTL）进行地址映射和坏块管理。

### 考点8：设备分配与独立性
**设备独立性通过逻辑设备名到物理设备名的映射实现，分配过程需检查设备、控制器和通道三级状态。**
数据结构：DCT（设备）、COCT（控制器）、CHCT（通道）、SDT（系统表）、LUT（逻辑设备表）。分配原则：避免死锁。

> [!tip] 考试怎么用
> 安全分配方式（请求后阻塞）可避免死锁但效率低；不安全分配方式效率高但可能死锁。

## 易混与对比
**高速缓存 (Cache) 与缓冲区 (Buffer) 的区别**

|特性|高速缓存 (Cache)|缓冲区 (Buffer)|
|:---|:---|:---|
|**数据内容**|慢速设备上数据的副本|正在传输过程中的数据|
|**存在目的**|提高重复访问效率，减少访问慢速设备|缓和速度差异，匹配数据粒度，减少中断频率|
|**数据生命周期**|可长期驻留，直到被替换|传输完成后通常立即释放|
|**典型应用**|磁盘高速缓存|单缓冲、双缓冲、缓冲池|

**中断驱动方式与 DMA 方式的区别**

|特性|中断驱动方式|DMA 方式|
|:---|:---|:---|
|**数据传送单位**|字或字节|数据块|
|**数据路径**|设备 $\to$ 控制器 $\to$ CPU 寄存器 $\to$ 内存|设备 $\to$ 控制器 $\to$ 内存（不经过 CPU）|
|**CPU 干预频率**|每个字/字节干预一次|仅在数据块传送开始和结束时干预|
|**适用场景**|低速字符设备|高速块设备（如磁盘）|

**SCAN 算法与 C-SCAN 算法的区别**

|特性|SCAN (电梯算法)|C-SCAN (循环扫描)|
|:---|:---|:---|
|**移动方向**|双向移动（到头后反向服务）|单向移动（到头后快速返回起点）|
|**回程服务**|回程途中处理请求|回程途中不处理任何请求|
|**公平性**|对两端磁道请求响应较快，中间较慢|消除了对两端磁道请求的不公平性|
|**平均等待时间**|较均匀，但两端略优|更加均匀，方差更小|

**逻辑格式化与物理格式化的区别**

|特性|物理格式化 (低级格式化)|逻辑格式化 (高级格式化)|
|:---|:---|:---|
|**执行阶段**|出厂时或初始化时|分区后，建立文件系统前|
|**主要操作**|划分扇区，设置扇区头尾信息，检测坏块|建立文件系统，初始化根目录，创建空闲管理结构|
|**结果**|产生物理扇区地址|产生逻辑块地址（簇/块）|
|**可见性**|对操作系统透明（通常由控制器完成）|操作系统可见并管理|

## 闪卡
#card
- DMA 方式中数据传送的基本单位是什么？::数据块（Block），而非字或字节。
- DMA 控制器接管总线后，CPU 处于什么状态？::CPU 暂停访问总线，转去执行其他任务，仅在传送始末干预。
- 通道与 DMA 的主要区别是什么？::通道能执行通道程序自主管理多设备，DMA 仅按预设参数传输单块数据。
- 中断驱动方式中，数据从设备到内存经过哪里？::必须经过 CPU 的通用寄存器中转。
- 哪一层负责将逻辑设备名映射为物理设备名？::设备独立性软件（设备无关层）。
- 设备驱动程序的主要功能是什么？::接收抽象 I/O 请求，将其转换为设备控制器能识别的具体指令。
- 用户程序发起 I/O 请求时，如何从用户态进入内核态？::执行陷阱指令（如 int 0x80），触发软中断。
- 中断处理程序执行时能否调用可能引起睡眠的函数？::不能，必须快速执行且非阻塞。
- 单缓冲模式下，若设备输入时间 T 大于 CPU 处理时间 C，处理一块数据耗时多少？::$T + M$，因为 CPU 需等待设备填满缓冲区。
- 双缓冲模式下，若设备输入时间 T 小于 CPU 处理加传送时间 (C+M)，耗时多少？::$C + M$，因为设备需等待 CPU 处理完数据。
- 缓冲池中包含哪三种队列？::空缓冲队列、输入队列（装满输入数据）、输出队列（装满输出数据）。
- 引入缓冲区的主要目的不包括哪项？::不包括提高磁盘存储容量（目的是缓和速度矛盾、减少中断频率等）。
- SPOOLing 技术将独占设备改造为什么类型的设备？::共享设备（逻辑上），实现了虚拟设备功能。
- SPOOLing 系统中的“井”位于哪里？::位于磁盘上，分为输入井和输出井。
- SPOOLing 技术的核心思想是什么？::利用高速共享设备（磁盘）模拟低速独占设备，实现并行操作。
- 在 SPOOLing 系统中，用户进程何时认为打印完成？::当数据写入磁盘输出井后，而非物理打印完成后。
- 磁盘存取时间中通常占比最大的是哪部分？::寻道时间（磁头移动到目标磁道的时间）。
- 旋转延迟时间的平均值是多少？::磁盘旋转半圈所需的时间，即 $1/(2r)$。
- 若磁盘转速为 6000 转/分，旋转一圈需多少毫秒？::10ms（60 秒/6000 转 = 0.01 秒/转）。
- 数据传输时间与什么因素成反比？::与磁盘转速 $r$ 和每磁道字节数 $N$ 成反比。
- 哪种磁盘调度算法可能导致远处磁道请求长期得不到服务（饥饿）？::最短寻道时间优先（SSTF）算法。
- SCAN 算法为何被称为电梯调度算法？::因为磁头像电梯一样，只在到达端点后才改变移动方向。
- C-SCAN 算法在磁头返回起始端时是否处理请求？::不处理，直接快速返回，仅单向提供服务。
- LOOK 调度与 SCAN 调度的主要区别是什么？::LOOK 只需移动到最远请求处即返回，无需走到物理端点。
- SSD 中擦除操作的最小单位是什么？::块（Block），而读写操作的最小单位是页（Page）。
- 为什么 SSD 需要磨损均衡技术？::防止某些闪存块因频繁擦写而过早损坏，延长整体寿命。
- 静态磨损均衡是如何工作的？::定期将高磨损块中的数据迁移到低磨损块，让高磨损块休息。
- SSD 的随机写入速度较慢的主要原因是什么？::写入前需先擦除整块，且涉及有效数据的复制迁移。
- 实现设备独立性的关键数据结构是什么？::逻辑设备表（LUT），用于映射逻辑名到物理名及驱动入口。
- 设备分配时需要依次检查哪三个组件的状态？::设备、控制器、通道（需三者皆空闲）。
- 安全分配方式如何避免死锁？::进程请求 I/O 后立即阻塞，不再请求其他资源，直到 I/O 完成。
- 独占设备分配给进程后，何时释放？::进程主动释放或终止时，若等待队列非空则唤醒队首进程。
