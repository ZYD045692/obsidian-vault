# 7.3 IO 方式

> [!abstract] 一句话总结
> I/O 控制方式的核心矛盾是 CPU 参与度与数据传输效率的权衡，从程序查询的完全串行到 DMA 的硬件并行，CPU 负担逐级降低。

## 核心要点
### 考点1：程序查询方式
**CPU 通过循环读取状态寄存器控制数据传送，导致 CPU 与外设串行工作，效率低但硬件简单。**
工作流程：①初始化参数 ②发命令启动 ③循环查状态 ④就绪则传送 ⑤修改参数 ⑥未完则返回③。

> [!tip] 考试怎么用
> 计算题重点：查询间隔必须小于外设填满缓冲区的时间，否则数据丢失；注意区分独占查询（忙等待）与定时查询。

### 考点2：程序中断方式基本概念
**CPU 暂停当前程序转去处理紧急事件，处理完返回断点，实现了 CPU 与外设的并行工作。**
中断基本思想：进程发起 I/O 后进入阻塞，CPU 执行其他进程；外设就绪发中断，CPU 保存现场转中断服务程序。

> [!tip] 考试怎么用
> 易错点：中断发生在指令执行结束后（异常除外）；区分中断（外部事件）与异常（内部事件/指令执行中）。

### 考点3：中断响应条件与过程
**CPU 响应中断需满足有请求、开中断、指令结束三条件；响应后由硬件自动执行关中断、保存断点、引向服务程序。**
响应条件：①有效中断请求 ②开中断（$IF=1$）③当前指令结束。中断隐指令步骤：1) 关中断 2) 保存断点 (PC, PSW) 3) 引出服务程序。

> [!tip] 考试怎么用
> 核心考点：中断隐指令是硬件自动完成的，不是软件指令；断点由硬件保存，现场由软件保存。

### 考点4：中断向量与中断处理流程
**向量中断通过中断类型号查表获取服务程序入口；完整流程包含硬件自动步骤和软件服务程序步骤。**
向量法：CPU 获中断类型号 $\to$ 计算向量表地址 $\to$ 取入口地址送 PC。流程：①关中断 ②存断点 ③寻址 ④存现场 (软) ⑤开中断 ⑥服务 ⑦关中断 ⑧恢复 ⑨返回。

> [!tip] 考试怎么用
> 单重中断省略步骤⑤和⑦；多重中断必须在服务程序中开中断以实现嵌套；屏蔽字由软件加载。

### 考点5：多重中断与中断屏蔽技术
**通过设置中断屏蔽字动态调整处理优先级，高优先级中断可打断低优先级服务程序形成嵌套。**
屏蔽字规则：对应位为 1 表示屏蔽该中断，0 表示允许。新优先级下，某中断源的屏蔽字应屏蔽所有优先级低于或等于自身的中断。

> [!tip] 考试怎么用
> 解题关键：先按新优先级排序，某中断源需屏蔽自身及所有比它优先级低的中断（置 1），其余置 0。

### 考点6：DMA 方式特点与组成
**DMA 由硬件直接控制主存与外设间数据传送，无需 CPU 干预数据块传输，仅预处理和后处理需 CPU 参与。**
DMA 控制器功能：1) 发总线请求 2) 接管总线 3) 自动更新地址/计数 4) 发读写信号 5) 传完发中断。组件：地址计数器、长度计数器、数据缓冲寄存器。

> [!tip] 考试怎么用
> 适用场景：高速设备大批量数据传送；DMA 请求响应不需等待指令结束，只需总线周期结束。

### 考点7：DMA 传送方式与效率
**DMA 与 CPU 共享主存有停止 CPU 访存、周期挪用、交替访存三种方式，其中周期挪用最常用。**
周期挪用：I/O 请求时若 CPU 正访存则等待，否则挪用总线传一字；交替访存：将 CPU 周期分为 $C_1$ (DMA) 和 $C_2$ (CPU)。效率计算：$\text{占比} = \frac{\text{传送次数} \times \text{预处理 + 后处理周期}}{\text{CPU 总周期}}$。

> [!tip] 考试怎么用
> 计算题陷阱：DMA 只有预处理和后处理占用 CPU 时间，数据传送本身不占；注意单位换算（B, KB, MB）。

### 考点8：DMA 与中断方式对比
**DMA 不中断程序、不保存现场、硬件直接传送数据块；中断需切换程序、保存现场、软件逐字传送。**
区别点：①程序切换（中断有，DMA 无）②响应时机（指令末 vs 总线周期末）③数据通路（经 CPU vs 直通）④适用场景（低速随机 vs 高速成组）。

> [!tip] 考试怎么用
> 判断题高频点：DMA 请求优先级通常高于 CPU 访存；DMA 也能发中断（仅用于结束通知）。

## 易混与对比
**中断响应优先级 vs 处理优先级**

|特性|响应优先级|处理优先级|
|:---|:---|:---|
|**定义**|多个中断同时到达时，CPU 先响应谁的顺序|多重中断时，实际执行服务程序的先后顺序|
|**决定因素**|硬件排队器或查询顺序（固定）|中断屏蔽字设置（可动态调整）|
|**可变性**|不可动态更改|可通过软件修改屏蔽字改变|
|**关系**|只有未被屏蔽的中断才参与响应优先级判定|处理优先级可高于、等于或低于响应优先级|

**断点保存 vs 现场保存**

|项目|断点 (PC, PSW)|现场 (通用寄存器等)|
|:---|:---|:---|
|**含义**|程序中断处的下一条指令地址及状态|可能被服务程序修改的寄存器内容|
|**保存者**|**硬件**自动完成（中断隐指令）|**软件**在中断服务程序中显式保存|
|**时机**|中断响应阶段|进入中断服务程序后|
|**目的**|保证能返回原程序继续执行|保证原程序数据不被破坏|

**三种 DMA 传送方式对比**

|方式|总线控制权|CPU 状态|适用场景|硬件复杂度|
|:---|:---|:---|:---|:---|
|**停止 CPU 访存**|DMA 独占直到块传完|暂停/空闲|极高速、成组传送|简单|
|**周期挪用**|每次传一字后释放|仅在挪用瞬间暂停|高速设备，最常用|中等|
|**交替访存**|固定分时 ($C_1/C_2$)|仅在 $C_2$ 访存|CPU 周期 > 存储周期|复杂|

**程序查询 vs 程序中断 vs DMA**

|维度|程序查询|程序中断|DMA|
|:---|:---|:---|:---|
|**CPU 参与度**|全程参与，忙等待|数据准备时并行，传送时介入|仅预处理/后处理，传送不介入|
|**数据单位**|字/字节|字/字节|数据块|
|**并行性**|串行|部分并行|高度并行|
|**适用设备**|低速、简单|中低速、随机|高速、大批量|

## 闪卡
#card
- 程序查询方式中 CPU 与外设的工作关系？::完全串行工作，CPU 处于忙等待状态，无法执行其他任务。
- 定时查询方式中，避免数据丢失的查询间隔条件？::查询间隔必须小于外设填满数据缓冲寄存器所需的时间。
- 程序查询方式中，CPU 何时读取设备状态？::在循环中不断读取状态寄存器，直到设备状态显示就绪。
- 若外设数据传输率为 2MB/s，缓冲区 4B，最大查询间隔？::$4\text{B} \div 2\text{MB/s} = 2\mu\text{s}$。
- 程序中断方式如何实现 CPU 与外设并行？::外设准备数据时 CPU 执行其他程序，外设就绪后发中断请求 CPU 处理。
- CPU 响应 I/O 中断的具体时机是什么？::当前指令执行完毕之后，且 CPU 处于开中断状态。
- 中断技术最初的主要用途是什么？::实现主机与 I/O 设备之间的异步通信。
- 故障类异常（如缺页）处理后的断点位置？::当前指令地址，处理后需重新执行该指令。
- CPU 响应可屏蔽中断的三个必要条件？::存在有效请求、CPU 开中断、当前指令执行完毕。
- 中断隐指令是否属于指令系统中的真实指令？::不是，它是对硬件自动完成一系列操作的统称。
- 中断响应阶段，断点信息保存在哪里？::由硬件自动保存至栈或专用寄存器中。
- 不可屏蔽中断（NMI）是否受中断允许标志影响？::不受影响，优先级最高，用于处理电源掉电等紧急硬件事件。
- 中断向量表中存放的是什么内容？::各中断源对应的中断服务程序的入口地址（中断向量）。
- 中断类型号通过哪条总线传输给 CPU？::数据总线（在中断响应阶段由中断控制器提供）。
- 多重中断流程中，哪一步实现了中断嵌套？::步骤⑤开中断，允许更高优先级中断请求被响应。
- 单重中断处理流程与多重中断的主要区别？::单重中断省略了服务程序中的“开中断”和再次“关中断”步骤。
- 中断屏蔽字中某位为 1 代表什么含义？::屏蔽对应的中断请求，使其无法进入判优电路。
- 若要求处理优先级 A>D>C>B，A 的屏蔽字如何设置？::1111（屏蔽所有中断，包括自身，因其优先级最高）。
- 中断响应优先级由什么决定？能否动态改变？::由硬件线路或查询顺序固定决定，不可动态更改。
- 多重中断中，若有多个未屏蔽中断同时到达，谁先处理？::仍由硬件中断判优电路决定的响应优先级次序处理。
- DMA 方式中，数据传送过程是否需要 CPU 执行指令？::不需要，由 DMA 控制器硬件直接完成，CPU 仅在预处理和后处理参与。
- DMA 控制器中，哪个部件记录待传送数据的总长度？::传送长度计数器，每传送一个字减 1，归零表示结束。
- DMA 方式适用于什么样的 I/O 设备？::磁盘、显卡等高速设备的大批量数据传输场景。
- DMA 传送结束后，如何通知 CPU？::DMA 控制器向 CPU 发出中断请求，由 CPU 执行后处理。
- 周期挪用方式中，若 CPU 正在访存，DMA 如何处理？::等待当前存储周期结束，CPU 释放总线后，DMA 再挪用总线。
- DMA 与 CPU 交替访存方式适用于什么场景？::CPU 工作周期长于主存存储周期的场景。
- 停止 CPU 访存方式的主要缺点是什么？::DMA 访存期间 CPU 基本空闲，资源利用率较低。
- 若数据率 40MB/s，块大小 1000B，每秒 DMA 请求次数？::$40\text{MB/s} \div 1000\text{B} = 40000$ 次。
- 中断方式和 DMA 方式在数据传送路径上的区别？::中断方式数据经 CPU 寄存器传送，DMA 方式在主存与外设间直接传送。
- DMA 请求被响应的时机与中断请求有何不同？::DMA 请求在当前总线周期结束后即可响应，无需等待指令执行结束。
- 哪种方式需要保存和恢复 CPU 现场？::中断方式需要，DMA 方式不需要（不中断现行程序）。
- 当 CPU 和 DMA 同时访问主存时，谁优先级更高？::DMA 请求的优先级通常更高，以保证高速数据不丢失。
