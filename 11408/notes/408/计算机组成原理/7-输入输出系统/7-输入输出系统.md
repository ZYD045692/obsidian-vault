# 输入输出系统

> [!abstract] 一句话总结
> 本章核心矛盾在于 CPU 高速处理能力与外设低速随机性之间的差异，通过程序查询、中断及 DMA 三种方式逐级提升并行度与传输效率。

## 核心考点
### 考点1：I/O 接口功能与结构
**I/O 接口是主机与外设间的逻辑部件，负责地址译码、数据缓冲、信号转换及联络控制。**
内部包含数据缓冲寄存器（双向）、状态寄存器（只读）、控制寄存器（只写）；部分设计可复用端口地址。

> [!tip] 考试怎么用
> 区分端口与接口概念：端口是接口内可寻址的寄存器；注意状态/控制寄存器读写方向相反。

### 考点2：I/O 端口编址方式
**独立编址使用专用指令访问独立空间，统一编址将 I/O 映射到内存空间使用访存指令。**
独立编址需 IN/OUT 指令，译码简单但指令功能弱；统一编址编程灵活但占用内存地址空间。

> [!tip] 考试怎么用
> x86 采用独立编址；统一编址下 I/O 端口占用主存容量，需通过地址范围区分。

### 考点3：程序查询方式
**CPU 通过循环读取状态寄存器控制数据传输，导致 CPU 与外设串行工作，效率低下。**
流程：初始化→启动外设→循环查询状态→就绪则传送→修改参数→判断结束；分为独占查询和定时查询。

> [!tip] 考试怎么用
> 重点掌握定时查询的时间间隔计算：间隔必须小于外设填满缓冲区的时间。

### 考点4：中断响应与隐指令
**CPU 仅在指令执行完毕且开中断时响应请求，硬件自动执行关中断、保存断点等隐指令操作。**
响应条件：有请求、开中断、指令结束；隐指令完成：关中断、保存断点 (PC/PSW)、引出服务程序。

> [!tip] 考试怎么用
> 断点由硬件自动保存，现场由软件保存；异常不受指令结束限制，可立即响应。

### 考点5：中断向量与处理流程
**向量中断通过中断类型号查表获取入口地址；处理流程包含保存现场、开中断、执行服务、恢复现场。**
向量地址 = 基址 + 类型号×项长；软件保存现场和屏蔽字，硬件保存断点；支持嵌套需中途开中断。

> [!tip] 考试怎么用
> 区分单重与多重中断：多重中断需在服务程序中显式执行“开中断”指令以允许嵌套。

### 考点6：多重中断与屏蔽技术
**通过设置中断屏蔽字动态调整处理优先级，屏蔽字为 1 表示屏蔽该中断源，为 0 表示允许。**
处理优先级 = 响应优先级 ∩ 屏蔽策略；屏蔽字通常在进入服务程序时由软件加载，决定后续嵌套行为。

> [!tip] 考试怎么用
> 解题关键：某中断源的屏蔽字中，对自己和低级中断置 1，对高级中断置 0（按 desired 优先级）。

### 考点7：DMA 控制器组成与功能
**DMA 控制器接管总线直接在主存与外设间传送数据块，仅在预处理和后处理阶段需要 CPU 干预。**
核心部件：主存地址计数器、传送长度计数器、数据缓冲寄存器、控制逻辑；传输结束发中断。

> [!tip] 考试怎么用
> DMA 请求可在总线周期结束后立即响应，无需等待指令结束；适用于高速大批量数据。

### 考点8：DMA 数据传送方式
**DMA 与 CPU 共享主存有三种策略：停止 CPU 访存、周期挪用、DMA 与 CPU 交替访存。**
周期挪用最常用，挪用单个存储周期；交替访存无需总线申请但硬件复杂；停止访存 CPU 效率最低。

> [!tip] 考试怎么用
> 周期挪用适用于高速设备防丢失；交替访存要求 CPU 周期大于存储周期。

### 考点9：中断与 DMA 方式对比
**中断方式以字为单位由软件传送且需保存现场，DMA 方式以块为单位由硬件传送且不中断程序。**
中断响应需等指令结束，DMA 响应只需等总线周期；DMA 优先级通常高于 CPU 访存。

> [!tip] 考试怎么用
> 计算题注意：中断开销=次数×(响应 + 处理)；DMA 开销=次数×(预处理 + 后处理)。

### 考点10：显存带宽与容量计算
**显存容量取决于分辨率与色彩深度，带宽还需乘以帧频以支持实时刷新。**
$VRAM 容量 = 分辨率 \times 色彩深度 (位)$；$VRAM 带宽 = 分辨率 \times 色彩深度 \times 帧频$。

> [!tip] 考试怎么用
> 注意单位换算：色彩深度通常为位 (bit)，容量常求字节 (Byte)，带宽常求 B/s 或 b/s。

## 易混与对比
**中断相关概念辨析**

|概念|定义与区别|
|---|---|
|中断向量|中断服务程序的入口地址|
|向量地址|中断向量表中的索引位置（基址 + 类型号×长度）|
|向量中断|硬件自动提供类型号并查表跳转的中断机制|
|断点|被中断程序的下一条指令地址（由硬件保存）|
|现场|CPU 寄存器内容（由软件在服务程序中保存）|

**三种 I/O 方式对比**

|特性|程序查询|程序中断|DMA|
|---|---|---|---|
|数据传送单位|字|字|数据块|
|CPU 干预程度|全程干预（忙等待）|仅传送时干预|仅首尾干预|
|并行性|串行|部分并行|高度并行|
|适用场景|低速、简单设备|中低速、随机事件|高速、大批量数据|

**编址方式差异**

|特性|独立编址|统一编址|
|---|---|---|
|地址空间|独立于主存|与主存共享|
|访问指令|专用 I/O 指令 (IN/OUT)|普通访存指令 (LOAD/STORE)|
|地址线利用|较少，译码简单|需全地址译码，较复杂|
|对主存影响|不占用主存空间|占用部分主存地址空间|

**响应优先级 vs 处理优先级**

|维度|响应优先级|处理优先级|
|---|---|---|
|决定因素|硬件排队电路或查询顺序|软件设置的中断屏蔽字|
|可变性|固定，不可动态更改|灵活，可动态调整|
|作用阶段|多个请求同时到达时的仲裁|中断嵌套时的执行顺序|
|关系|只有未被屏蔽的请求才参与响应判优|可高于或低于响应优先级|

## 闪卡
#card
- I/O 接口中哪个寄存器仅支持 CPU 读操作？::状态寄存器，用于记录外设当前工作状态。
- I/O 接口中哪个寄存器仅支持 CPU 写操作？::控制寄存器，用于保存 CPU 发给外设的命令。
- I/O 接口如何实现主机与外设的速度匹配？::通过数据缓冲寄存器暂存数据，协调传输节奏。
- I/O 接口的信号格式转换功能包括哪些？::电平转换、并/串转换、模/数或数/模转换。
- 独立编址方式下 CPU 如何访问 I/O 端口？::使用专用的 I/O 指令（如 IN、OUT）和独立的地址空间。
- 统一编址方式的主要缺点是什么？::I/O 端口占用主存地址空间，减少了系统可用内存容量。
- 哪种编址方式无需专用 I/O 指令？::统一编址（存储器映射方式），使用普通加载存储指令。
- 独立编址方式的优点有哪些？::地址线少、译码简单、程序中 I/O 操作清晰可辨。
- 程序查询方式中 CPU 处于什么状态等待外设？::忙等待状态，无法执行其他任务，CPU 与外设串行工作。
- 定时查询方式中，查询间隔过大会导致什么后果？::外设缓冲区溢出，新数据覆盖旧数据导致丢失。
- 程序查询方式的主要硬件特点是什么？::设计简单、硬件开销小，但 CPU 时间利用率极低。
- 程序查询方式的数据传送由谁控制？::完全由 CPU 通过执行程序指令来控制。
- CPU 响应可屏蔽中断的时机是什么时候？::当前指令执行完毕之后，且中断允许标志为 1。
- 中断隐指令是否是一条真实的机器指令？::不是，它是 CPU 响应中断时硬件自动完成的一系列操作。
- 中断响应过程中，断点信息保存在哪里？::由硬件自动保存至堆栈或专用寄存器中。
- 不可屏蔽中断 (NMI) 主要用于处理什么事件？::电源掉电、总线错误等紧急且关键的硬件事件。
- 中断向量表中存放的是什么内容？::各个中断源对应的中断服务程序的入口地址。
- 中断服务程序中由软件完成的操作有哪些？::保存现场、设置屏蔽字、执行服务、恢复现场、中断返回。
- 实现中断嵌套的关键操作是什么？::在中断服务程序中执行“开中断”指令，允许更高优先级中断。
- 向量中断中，中断类型号通过哪条总线传输？::数据总线，由中断控制器在中断响应阶段提供给 CPU。
- 中断屏蔽字中某位为 1 表示什么含义？::屏蔽对应的中断请求，使其无法进入判优电路。
- 中断处理优先级由什么决定？::由硬件响应优先级和软件设置的中断屏蔽字共同决定。
- 若希望中断 A 能打断中断 B，A 的屏蔽字应如何设？::A 的屏蔽字中对应 B 的位应为 0（允许 B 被中断，实则是 A 不被 B 屏蔽，逻辑需反推：B 屏蔽 A 为 0）。
- 中断屏蔽技术主要改变了什么优先级？::改变了中断的处理优先级，而非硬件固定的响应优先级。
- DMA 方式中，数据传送过程由谁控制？::由 DMA 控制器硬件直接控制，无需 CPU 干预。
- DMA 控制器中哪个部件记录剩余传送字数？::传送长度计数器，每传送一个字减 1，归零表示结束。
- DMA 传送结束后如何通知 CPU？::向 CPU 发出中断请求，由 CPU 执行后处理程序。
- DMA 方式特别适合哪种类型的设备？::磁盘、显卡等高速设备的大批量数据传输。
- 周期挪用方式中，DMA 每次占用多长时间？::挪用一个个主存存储周期，传送完一个数据字后立即释放。
- 哪种 DMA 方式无需动态申请和释放总线控制权？::DMA 与 CPU 交替访存，通过固定分时分配子周期。
- 停止 CPU 访存方式的主要缺点是什么？::DMA 期间 CPU 完全空闲，资源利用率低。
- 周期挪用方式适用于什么场景？::高速 I/O 设备，需及时访存以防数据丢失。
- 中断方式和 DMA 方式在数据传送单位上有何不同？::中断以字为单位，DMA 以数据块为单位。
- DMA 请求响应是否需要等待当前指令执行结束？::不需要，只需等待当前总线周期结束即可响应。
- 哪种方式在数据传输过程中不需要保存 CPU 现场？::DMA 方式，因为它不中断现行程序的执行流。
- 当 CPU 和 DMA 同时请求访存时，谁优先级高？::DMA 请求优先级通常更高，以保证高速数据传输不丢失。
- 计算显存带宽时，除了分辨率和色深还需乘什么？::帧频（刷新频率），即每秒刷新的次数。
- 若分辨率为 $1920\times1080$，色深 24 位，显存容量至少多少字节？::$(1920\times1080\times24) \div 8$ 字节。
- 刷新频率低于多少 Hz 时人眼会感知闪烁？::通常低于 30Hz 时人眼会感知到屏幕闪烁。
- 24 位真彩色能表示多少种颜色？::$2^{24}$ 种，约 1677 万种颜色。
