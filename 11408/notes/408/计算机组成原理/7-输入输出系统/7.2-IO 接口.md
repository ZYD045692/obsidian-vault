# 7.2 IO 接口

> [!abstract] 一句话总结
> I/O 接口通过地址译码、缓冲、格式转换及联络机制，弥合主机与异构外设在速度、格式及电平上的差异。

## 核心要点
### 考点1：I/O 接口的五大功能
**接口负责地址译码选设备、联络协调时序、缓冲暂存数据、转换信号格式、传递控制与状态信息。**
功能包括：1) 地址译码与设备选择；2) 通信联络与时序协调；3) 数据缓冲；4) 信号格式转换（电平/并串/模数）；5) 控制命令与状态传递（含中断请求）。

> [!tip] 考试怎么用
> 区分‘数据缓冲’（防丢失）与‘信号格式转换’（物理兼容），勿混淆两者作用。

### 考点2：I/O 接口的基本结构与寄存器
**接口内含数据缓冲、状态、控制三类寄存器，状态与控制寄存器在特定设计下可复用同一端口地址。**
三类寄存器：数据缓冲寄存器（双向）、状态寄存器（仅 CPU 读）、控制寄存器（仅 CPU 写）。读操作访状态，写操作访控制，二者可复用地址。

> [!tip] 考试怎么用
> 牢记状态寄存器只读、控制寄存器只写，这是判断端口复用可行性的关键依据。

### 考点3：I/O 接口上的信号线内容
**数据线传数据/状态/控制/中断号，地址线选端口，控制线传读写信号及握手/仲裁/中断信号。**
数据线：读/写数据、状态、控制信息、中断类型号。地址线：端口地址。控制线：读/写信号、中断请求/响应、总线仲裁、握手信号。

> [!tip] 考试怎么用
> 注意数据线不仅传数据，还传状态和控制信息（如向量中断中的中断类型号）。

### 考点4：I/O 接口的分类体系
**接口按传送方式分并行/串行，按控制方式分查询/中断/DMA，按灵活性分可编程/不可编程。**
1) 数据传送方式：并行（多位同时）、串行（一位有序）；2) 控制方式：程序查询、中断、DMA；3) 功能灵活性：可编程、不可编程。

> [!tip] 考试怎么用
> 并行/串行是指外设与接口一侧的传送方式，接口需负责并/串或串/并转换。

### 考点5：I/O 端口的定义与特性
**端口是接口内可被 CPU 直接访问的寄存器，分为数据端口（读写）、状态端口（只读）、控制端口（只写）。**
端口定义：I/O 接口电路中可被 CPU 直接访问的寄存器。分类：数据端口（读/写）、状态端口（仅读）、控制端口（仅写）。

> [!tip] 考试怎么用
> 严格区分‘接口’（整体电路）与‘端口’（内部寄存器），端口是编址的最小单位。

### 考点6：独立编址（I/O 映射方式）
**建立独立于主存的地址空间，使用专用 I/O 指令（IN/OUT），地址线少但指令功能有限。**
特点：地址空间独立，可用专用指令（如 IN/OUT）。优点：地址线少、译码简单、程序清晰。缺点：指令功能有限、需两组控制信号。

> [!tip] 考试怎么用
> 独立编址下，I/O 地址与内存地址数值可相同但不冲突，因空间分离。

### 考点7：统一编址（存储器映射方式）
**I/O 端口占用主存地址空间，使用普通访存指令访问，编程灵活但减少可用内存容量。**
特点：共享主存地址空间，用普通访存指令（LOAD/STORE）。优点：编程灵活、地址空间大、保护机制统一。缺点：占用内存容量、译码复杂。

> [!tip] 考试怎么用
> 统一编址无需专用 I/O 指令，但会减少系统实际可用的主存容量。

## 易混与对比
**接口与端口的概念辨析**

|概念|定义|关系|
|---|---|---|
|I/O 接口|主机与外设之间的交接界面（整体电路）|包含多个端口|
|I/O 端口|接口内部可被 CPU 直接访问的寄存器|接口的编址单元|

**独立编址 vs 统一编址**

|特性|独立编址|统一编址|
|---|---|---|
|地址空间|独立于主存|与主存共享|
|访问指令|专用 I/O 指令 (IN/OUT)|普通访存指令|
|地址线需求|较少|较多 (需覆盖全空间)|
|对内存影响|无占用|减少可用内存容量|
|编程灵活性|较差 (指令功能有限)|较好 (指令丰富)|

**三类寄存器的访问方向**

|寄存器类型|功能|CPU 访问方向|备注|
|---|---|---|---|
|数据缓冲寄存器|暂存传输数据|读/写|双向|
|状态寄存器|记录外设状态|仅读|可与控制端口复用地址|
|控制寄存器|保存控制命令|仅写|可与状态端口复用地址|

## 闪卡
#card
- 接口如何解决主机与外设速度不匹配导致的数据丢失？::设置数据缓冲寄存器暂存传输数据。
- 接口如何实现主机与外设在电平或数据位宽上的物理兼容？::进行信号格式转换（如电平、并/串、模/数转换）。
- 当外设需要主动通知 CPU 数据到达时，接口执行什么操作？::向 CPU 发出中断请求信号。
- CPU 发出 I/O 请求时，接口如何利用地址码确保只与指定设备通信？::对地址进行译码，产生设备选择信号。
- I/O 接口中哪类寄存器用于记录接口及外设的当前状态？::状态寄存器。
- CPU 向接口发送启动命令时，写入的是哪个寄存器？::控制寄存器。
- 为何状态寄存器和控制寄存器在某些设计中可复用同一端口地址？::访问方向相反（一读一写）且时间错开。
- I/O 控制逻辑在输入操作时的具体动作是什么？::将外设数据写入数据缓冲寄存器。
- 在向量中断方式下，I/O 接口通过数据线向 CPU 传送什么特殊信息？::中断类型号。
- I/O 接口地址线的主要作用是指定什么？::要访问的 I/O 接口内部寄存器的端口地址。
- I/O 接口的控制线上传送的信号包含哪些类型（列举 3 种）？::读/写控制信号、中断请求与响应信号、设备握手信号。
- 区分寄存器访问方向（读或写）的信号在哪类线上传送？::控制线。
- 若外设与接口间一位一位有序传送数据，该接口属于什么类型？::串行接口。
- 按主机访问 I/O 设备的控制方式，接口可分为哪三类？::程序查询接口、中断接口、DMA 接口。
- 哪种类型的接口可以通过编程改变其功能？::可编程接口。
- 并行接口在数据传送时需完成什么格式转换？::并/串或串/并转换（视另一侧而定，此处指内部处理逻辑适配）。
- I/O 端口的本质是什么？::I/O 接口电路中可被 CPU 直接访问的寄存器。
- CPU 对状态端口只能执行什么操作？::读操作。
- CPU 对控制端口只能执行什么操作？::写操作。
- 每个 I/O 端口必须对应什么以确保 CPU 能访问？::一个唯一的端口地址。
- 独立编址方式下，CPU 使用什么指令访问 I/O 端口？::专用的 I/O 指令（如 IN 和 OUT）。
- 独立编址的主要优点之一是关于地址线的什么特性？::所需地址线较少，译码电路简单。
- 独立编址方式的主要缺点 regarding 程序设计是什么？::I/O 指令功能有限，程序设计灵活性较差。
- 独立编址中 I/O 地址与内存地址数值相同时会发生冲突吗？::不会，因为属于不同的地址空间。
- 统一编址方式下，CPU 使用什么指令访问 I/O 端口？::普通的访存指令（如加载和存储指令）。
- 统一编址的主要缺点 regarding 内存资源是什么？::I/O 端口占用主存地址空间，减少了系统可用内存容量。
- 统一编址方式下，I/O 访问的保护机制由谁实现？::虚拟存储管理系统。
- 统一编址为何可能导致译码速度降低？::需根据完整地址判断是否为 I/O 区域，译码电路相对复杂。
