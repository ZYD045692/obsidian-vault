# 3.5 高速缓冲存储器

> [!abstract] 一句话总结
> 利用程序访问局部性原理，通过硬件自动将主存活跃块副本存入高速 SRAM，以命中率换取平均访问时间的显著降低。

## 核心要点
### 考点1：程序访问的局部性原理
**时间局部性指最近被访问的项不久后很可能再次被访问，空间局部性指最近被访问的项邻近单元不久后很可能被访问。**
时间局部性源于循环和重复调用；空间局部性源于指令顺序执行和数据连续存储（如数组）。

> [!tip] 考试怎么用
> 分析代码时，嵌套循环内层变量变化快对应空间局部性，外层循环变量对应时间局部性；行优先数组按行访问空间局部性好，按列访问差。

### 考点2：Cache 基本工作原理与命中率
**Cache 命中时直接读取耗时$T_c$，未命中时需调入块再读取耗时$T_m+T_c$，平均访问时间由命中率决定。**
命中率 $H=N_{c}/(N_{c}+N_{m})$；平均访问时间 $T_{a}=H T_{c}+(1-H)(T_{m}+T_{c})=T_{c}+(1-H)T_{m}$。

> [!tip] 考试怎么用
> 注意未命中总耗时包含$T_c$（查 Cache）和$T_m$（调块），公式常简化为$T_c + (1-H)T_m$；性能提升倍数=无 Cache 时间/有 Cache 时间。

### 考点3：直接映射方式
**主存块只能装入 Cache 中唯一指定位置，映射关系为行号等于主存块号模 Cache 总行数。**
映射公式：$\text{Cache 行号} = \text{主存块号} \bmod 2^c$；地址结构：标记 ($t$) + 行号 ($c$) + 块内地址。

> [!tip] 考试怎么用
> 只需 1 个比较器；冲突概率最高，即使其他行空闲也无法使用；标记位长度为$m-c$。

### 考点4：全相联映射方式
**主存块可装入 Cache 任意位置，需并行比较所有行的标记，冲突概率最低但硬件成本最高。**
地址结构：标记 ($\text{主存块号}$) + 块内地址；需$2^c$个比较器并行工作。

> [!tip] 考试怎么用
> 适合小容量 Cache；标记比较慢，需相联存储器；只要有空闲行就不会冲突。

### 考点5：组相联映射方式
**组间直接映射、组内全相联，主存块只能放入固定组内的任意行，是直接映射与全相联的折中。**
映射公式：$\text{Cache 组号} = \text{主存块号} \bmod Q$；需$r$个比较器（$r$为路数）。

> [!tip] 考试怎么用
> $r$路组相联需$r$个比较器；$Q=1$退化为全相联，$Q=$总行数退化为直接映射。

### 考点6：替换算法 (LRU)
**LRU 算法优先替换最近最久未被访问的行，基于局部性原理，命中率通常高于 FIFO 和随机算法。**
2 路需 1 位 LRU 位，4 路需 2 位；命中时该行计数器清零，其余加 1；替换计数值最大者。

> [!tip] 考试怎么用
> 直接映射无需替换算法；注意 LRU 位位数与路数关系（$/log_2 r$）；访问序列长度超过路数可能导致抖动。

### 考点7：Cache 写策略
**写命中分直写（同时写主存）和回写（仅写 Cache，替换时写回）；写不命中分写分配（调入块）和非写分配。**
回写法需设脏位（修改位）；直写法无需脏位但需写缓冲；L1 Cache 常用写分配 + 回写。

> [!tip] 考试怎么用
> 回写法减少主存访问但有一致性风险；直写法保证实时一致但性能低；脏位仅在回写时存在。

### 考点8：Cache 容量计算
**Cache 总容量等于行数乘以（每行数据位数 + 标记位 + 有效位 + 脏位 +LRU 位）。**
总容量 $= \text{行数} \times (\text{块长} \times 8 + \text{标记位} + 1 + \text{脏位} + \text{LRU 位})$。

> [!tip] 考试怎么用
> 注意单位换算（字节转位）；标记位长度=主存地址位 - 组号位 - 块内地址位；脏位和 LRU 位视策略而定。

### 考点9：分离 Cache 与多级 Cache
**分离 Cache 解决取指与执行冲突，多级 Cache 利用 L1 高速小容量和 L2 较大容量平衡速度与成本。**
L1 通常分离指令/数据 Cache；L1/L2 常采用回写法，L1 写命中不访主存，脏块替换时写回 L2。

> [!tip] 考试怎么用
> 分离 Cache 消除流水线冲突；多级结构中 L1 写命中仅更新 L1，避免频繁访问主存导致写缓冲溢出。

## 易混与对比
**三种映射方式对比**

|特性|直接映射|全相联映射|组相联映射|
|---|---|---|---|
|灵活性|最差（唯一位置）|最好（任意位置）|折中（组内任意）|
|冲突概率|最高|最低|中等|
|比较器数量|1 个|等于行数|等于路数|
|硬件成本|最低|最高|中等|
|适用场景|大容量 Cache|小容量 Cache|通用主流方案|

- **写策略中的脏位需求**：**直写法**：数据同时写入 Cache 和主存，主存始终最新，替换时无需写回，因此**不需要**脏位。
  **回写法**：数据仅写入 Cache，主存可能过时，替换时需判断是否写回，因此**必须**设置脏位（1 表示已修改，0 表示一致）。
- **写不命中的两种处理**：**写分配法**：先调块入 Cache 再写，利用空间局部性，适合与回写法配合。
  **非写分配法**：直接写主存，不调块，适合与直写法配合（因直写本就频繁访存）。
- **LRU 计数器更新规则**：**命中时**：命中行计数器置 0，比它小的加 1，大的不变。
  **未命中有空闲**：新行置 0，其他非空闲行全加 1。
  **未命中无空闲**：替换计数值最大者，新行置 0，其余全加 1。

## 闪卡
#card
- 什么是时间局部性？其产生原因是什么？::最近访问的项不久后再次被访问；源于循环、子程序重复调用及同一数据多次操作。
- 什么是空间局部性？其产生原因是什么？::最近访问的项邻近单元不久后被访问；源于指令顺序存放执行及数据连续块存储。
- 行优先存储的二维数组，按行遍历和按列遍历哪个空间局部性更好？::按行遍历更好，因为访问顺序与存放顺序一致，连续访问相邻地址。
- 循环体内的指令访问具有怎样的局部性特征？::空间局部性良好（指令连续存放），时间局部性良好（循环多次执行）。
- Cache 命中率的定义公式是什么？::$H=N_{c}/(N_{c}+N_{m})$，其中$N_c$为命中次数，$N_m$为未命中次数。
- Cache 未命中时的总访问时间由哪两部分组成？::缺失损失$T_m$（从主存调块）加上命中时间$T_c$（从 Cache 读数据），即$T_m+T_c$。
- 平均访问时间$T_a$的简化计算公式是什么？::$T_{a}=T_{c}+(1-H)T_{m}$，其中$(1-H)$为缺失率。
- Cache 机制对程序员是否透明？由什么实现？::透明；完全由硬件实现，必须在单条指令执行周期内完成。
- 直接映射中，主存块如何确定其 Cache 行号？::行号 = 主存块号 mod Cache 总行数，即主存块号的低$c$位。
- 直接映射地址结构中，标记位长度如何计算？::标记位长度 $t = m - c$，即主存块号高位部分。
- 直接映射方式需要多少个比较器？::只需 1 个比较器，用于比较选定行的标记与地址高位。
- 若目标 Cache 行已被占用，直接映射如何处理？::无条件替换原块，无须替换算法，即使其他行空闲也不能用。
- 全相联映射中，主存块可以存放在哪里？::可以装入 Cache 中的任何一行，只要有空闲位置。
- 全相联映射需要多少个比较器？::需要与 Cache 行数相同的比较器数量，对所有行标记并行比较。
- 全相联映射的地址结构包含哪些字段？::仅包含标记（整个主存块号）和块内地址，无行号或组号字段。
- 全相联映射的主要缺点是什么？::标记比较速度慢，硬件实现成本高，不适合大容量 Cache。
- 组相联映射中，主存块如何确定目标组？::组号 = 主存块号 mod Cache 组数$Q$。
- 4 路组相联映射需要多少个比较器？::需要 4 个比较器，用于并行比较组内 4 行的标记。
- 当组数$Q=1$时，组相联映射退化为什么映射？::退化为全相联映射，整个 Cache 作为一个组。
- 当每组行数$r=1$时，组相联映射退化为什么映射？::退化为直接映射，每组仅一行，主存块位置唯一。
- 哪种映射方式不需要替换算法？为什么？::直接映射；因为每个主存块只能映射到唯一行，新块直接覆盖旧块。
- LRU 算法中，命中某行时计数器如何更新？::所命中行计数器清零，比其小的计数器加 1，其余不变。
- 4 路组相联映射需要几位 LRU 替换位？::需要 2 位，因为需区分 4 种相对访问顺序状态。
- 什么情况下 LRU 算法会导致命中率为 0（抖动）？::当频繁访问的主存块数量超过 Cache 每组行数时，每次访问都驱逐即将访问的块。
- 直写法（Write Through）的主要特点是什么？::写命中时同时写入 Cache 和主存，主存始终同步，无需脏位，但性能较低。
- 回写法（Write Back）何时将数据写入主存？::仅当被修改的 Cache 块（脏块）被替换时才写回主存。
- 哪种写策略必须设置脏位（修改位）？::回写法；用于标识该行数据是否被修改过，直写法不需要。
- 写分配法（Write Allocate）在写不命中时做什么？::先将主存块调入 Cache，再在 Cache 中进行写操作，利用空间局部性。
- 计算 Cache 总容量时，每行包含哪些部分？::数据部分、有效位、标记位，以及可选的脏位和 LRU 替换位。
- 直接映射中，标记位长度如何由地址结构得出？::标记位 = 主存地址总位数 - 行号位数 - 块内地址位数。
- 若采用回写法，每行必须增加哪一位？::必须增加 1 位脏位（修改位），用于指示数据是否被修改。
- 256MB 主存，64B 块长，8 行直接映射，标记位多少位？::28 位地址 - 6 位块内 - 3 位行号 = 19 位标记。
- 为什么要采用分离的指令 Cache 和数据 Cache？::消除流水线中取指部件和执行部件同时访问同一 Cache 产生的冲突。
- 多级 Cache 中，L1 和 L2 的主要区别是什么？::L1 离 CPU 最近、速度最快、容量小；L2 较远、速度稍慢、容量大。
- 典型两级 Cache 系统中，L1 写命中时是否访问主存？::不访问主存，仅更新 L1；脏块替换时写回 L2，由 L2 负责后续写回主存。
- 多级 Cache 结构如何避免写缓冲饱和？::L1 采用回写法，写操作由 L2 高效承接，减少直接对主存的频繁写入。
