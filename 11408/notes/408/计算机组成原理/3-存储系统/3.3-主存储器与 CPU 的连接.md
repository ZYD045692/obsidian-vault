# 3.3 主存储器与 CPU 的连接

> [!abstract] 一句话总结
> 主存与 CPU 通过三类总线协同，利用位扩展增字长、字扩展增容量、字位同时扩展解决单芯片规格不足问题。

## 核心要点
### 考点1：主存与 CPU 连接原理
**数据总线位数与频率决定带宽，地址总线位数决定最大寻址空间，控制线依存储器类型而异。**
SRAM 含片选和读/写线；ROM 仅需片选线；DRAM 通常无独立片选，靠行/列选通或外部译码实现。

> [!tip] 考试怎么用
> 注意 DRAM 片选信号的特殊性，勿默认所有芯片都有独立片选引脚。

### 考点2：位扩展法
**位扩展用于增加存储字长度，适用于 CPU 数据总线宽度大于单芯片位宽的场景。**
各芯片地址线、片选线、读/写线并联；数据线分别接系统数据总线不同位；所有芯片同时工作。

> [!tip] 考试怎么用
> 识别特征：地址线全连，数据线分接，片选信号相同，目的是凑够数据位宽。

### 考点3：字扩展法
**字扩展用于增加存储单元数量，适用于系统地址总线位数多于芯片地址线位数的场景。**
低位地址线并联；数据线、读/写线并联；高位地址线经译码器生成片选信号，分时选中芯片。

> [!tip] 考试怎么用
> 核心是高位地址译码产生片选，同一时刻只能有一个芯片被选中。

### 考点4：字扩展地址范围计算
**利用高位地址译码值确定片选，结合低位地址全 0 和全 1 计算每片芯片的地址范围。**
若 $A_{15}A_{14}=00$ 选中第一片，则范围：$0000000000000000_2 \sim 0011111111111111_2$。

> [!tip] 考试怎么用
> 先写二进制高位固定值，低位补 0 得始址，补 1 得终址，再转十六进制。

### 考点5：字位同时扩展法
**当字长和容量均不足时，先位扩展成组，再对组进行字扩展。**
步骤 1：若干芯片位扩展成一组（满足字长）；步骤 2：多组字扩展（满足容量）；高位译码选组。

> [!tip] 考试怎么用
> 先算每组需几片（位扩展），再算需几组（字扩展），总片数=每组片数×组数。

## 易混与对比
**位扩展与字扩展的连接差异**

|特征|位扩展|字扩展|
|---|---|---|
|目的|增加字长（数据位宽）|增加容量（地址空间）|
|数据线连接|分别接数据总线不同位|并联接数据总线|
|片选信号|所有芯片共用同一信号|高位地址译码，分时选中|
|工作状态|同时工作|分时工作|

- **DRAM 与 SRAM/ROM 控制线区别**：SRAM 有独立片选和读/写线；ROM 仅需片选线；DRAM 一般不设独立片选线，依赖行/列选通或外部逻辑，这是常考的特殊点。
- **地址范围计算的边界陷阱**：计算地址范围时，高位由译码值固定，低位全 0 为起始，全 1 为结束；易错点是混淆高位位数与总地址位数，导致范围计算偏移。

## 闪卡
#card
- 决定 CPU 可寻址最大内存空间的因素是什么？::地址总线的位数。
- SRAM 芯片通常包含哪些控制信号线？::片选信号线和读/写控制信号线。
- ROM 芯片通常只需要哪种控制线？::仅需片选线。
- DRAM 芯片如何实现芯片选择？::通过行/列地址选通或外部译码逻辑，一般不设独立片选线。
- 位扩展法主要解决什么需求？::增加存储字的长度（数据位宽）。
- 位扩展时，各芯片的地址线和片选线如何连接？::并联，接至系统对应总线。
- 位扩展时，各芯片的数据线如何连接？::单独引出，分别连接到系统数据总线的不同位。
- 位扩展中，多个芯片是同时工作还是分时工作？::所有芯片同时工作，共同提供一个完整字。
- 字扩展法主要解决什么需求？::增加存储单元的数量（扩大地址空间）。
- 字扩展时，系统地址总线的高位用于做什么？::经译码器生成片选信号，分时选中不同芯片。
- 字扩展中，多个芯片的工作状态是怎样的？::各芯片分时工作，同一时刻只有一个被选中。
- 字扩展时，各芯片的数据线如何连接？::并联至系统数据总线。
- 4 片 16K×8 构成 64K×8，高位 $A_{15}A_{14}=01$ 选中哪片？::选中第 2 号芯片。
- 若高位为 10，低位 14 位全 0，对应的二进制地址前缀是？::1000000000000000。
- 字扩展中，同一时刻可以有几个芯片被选中？::只能有一个芯片被选中。
- 计算某芯片最高地址时，其低位地址应取何值？::低位地址全部取 1。
- 字位同时扩展的第一步操作是什么？::将若干芯片按位扩展方式组成一组。
- 字位同时扩展中，系统高位地址线用于控制什么？::经译码器生成各组的片选信号。
- 用 16K×4 位芯片构成 64K×8 位，需分几组？::4 组（每组 2 片位扩展，共 4 组字扩展）。
- 字位同时扩展中，组内芯片的地址线如何连接？::接系统地址线低位，组内所有芯片地址线并联。
