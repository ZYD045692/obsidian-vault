# 2.2 运算方法和运算电路

> [!abstract] 一句话总结
> 本节核心在于利用加法器与移位器构建 ALU，通过补码统一加减法，并采用迭代移位策略实现乘除法。

## 核心要点
### 考点1：基本运算部件与加法器
**ALU 核心是加法器，串行进位延迟大，并行进位速度快但电路复杂，带标志加法器生成 OF、CF、SF、ZF。**
进位表达式：$C_{i}=A_{i}B_{i}+(A_{i}\oplus B_{i})C_{i-1}$；溢出标志：$OF = C_n \oplus C_{n-1}$；符号标志：$SF = F_{n-1}$。

> [!tip] 考试怎么用
> 区分 OF（有符号溢出）与 CF（无符号进位/借位），OF 由最高位进位与次高位进位异或得到。

### 考点2：定点数移位运算
**逻辑移位补 0，算术移位右移补符号位；算术左移若符号位改变则溢出。**
逻辑右移：高位补 0；算术右移：高位补符号位；算术左移：低位补 0，若移出位与原符号位不同则溢出。

> [!tip] 考试怎么用
> 算术左移溢出判据是符号位改变，逻辑左移溢出判据是高位 1 被移出。

### 考点3：补码加减运算与溢出判断
**补码加减法统一为加法，$[A-B]_补=[A]_补+[-B]_补$；溢出可通过单符号位、双符号位或进位判断。**
减法公式：$[A-B]_{ 补 }=[A]_{ 补 }+[-B]_{ 补 }(mod2^{n+1})$；双符号位溢出：$V=S_{s1}\oplus S_{s2}$。

> [!tip] 考试怎么用
> 双符号位 01 为正溢出，10 为负溢出；单符号位仅当同号相加结果异号时溢出。

### 考点4：加减运算电路与标志位
**一套电路实现加减，Sub=1 时 Y 取反且$C_{in}=1$；CF 判断无符号溢出，OF 判断有符号溢出。**
减法操作：$X + \overline{Y} + 1$；CF 计算：$CF = Sub \oplus C_{out}$；有符号比较：$A<B \iff OF \neq SF$。

> [!tip] 考试怎么用
> 无符号数比较看 ZF 和 CF，有符号数比较看 ZF、OF 和 SF；CF 在减法时等于$C_{out}$取反。

### 考点5：原码与补码乘法运算
**原码乘法符号异或、数值绝对值相乘；补码乘法（Booth 算法）符号数值统一运算，需附加位。**
原码符号：$x_s \oplus y_s$；Booth 判断：$y_i y_{i-1}$为 10 则$P-X$，01 则$P+X$；移位：原码逻辑右移，补码算术右移。

> [!tip] 考试怎么用
> Booth 算法需附加位$y_{-1}$初始为 0；无符号乘法溢出看高 n 位非零，有符号看高 n 位是否为低 n 位符号扩展。

### 考点6：定点数除法运算
**除法通过移位和减法迭代实现；无符号数高位补 0，补码需符号扩展；除数为 0 触发异常。**
无符号初始化：被除数高位补 0 至 2n 位；补码初始化：R 寄存器初始化为被除数符号位；异常：除数为 0 或$-2^{n-1}/-1$。

> [!tip] 考试怎么用
> 无符号除法不会溢出；补码除法唯一溢出情形是被除数为最小负数且除数为 -1。

## 易混与对比
**OF 与 CF 标志位的区别**

|标志位|适用数据类型|含义|判定依据|
|---|---|---|---|
|OF (Overflow)|有符号数|运算结果超出表示范围|$C_n \oplus C_{n-1}$ 或双符号位不同|
|CF (Carry)|无符号数|加法进位或减法借位|加法为$C_{out}$，减法为$\overline{C_{out}}$|

**逻辑移位与算术移位的区别**

|操作|逻辑移位 (无符号)|算术移位 (有符号/补码)|
|---|---|---|
|左移|低位补 0，高位 1 移出则溢出|低位补 0，符号位改变则溢出|
|右移|高位补 0|高位补符号位|
|目的|乘除 2 (无符号)|乘除 2 (保持符号)

**有符号与无符号数大小比较规则**

|数据类型|判断依据 (A-B 后)|A=B|A>B|A<B|
|---|---|---|---|---|
|无符号|ZF, CF|ZF=1|ZF=0 且 CF=0|CF=1|
|有符号|ZF, OF, SF|ZF=1|ZF=0 且 OF=SF|ZF=0 且 OF≠SF|

**乘法溢出判断差异**

|类型|结果存储|溢出判据|
|---|---|---|
|无符号乘法|[P:Y] (高：低)|高 n 位 P $\neq$ 0|
|有符号乘法|[P:Y] (高：低)|高 n 位 P $\neq$ 低 n 位 Y 的符号扩展|

## 闪卡
#card
- 一位全加器的进位输出 $C_i$ 逻辑表达式是什么？::$C_{i}=A_{i}B_{i}+(A_{i}\oplus B_{i})C_{i-1}$
- 串行进位加法器的主要缺点是什么？::进位信号逐级传递，位数越多延迟越大，速度受限。
- 并行进位加法器如何提升速度？::通过先行进位逻辑部件几乎同时生成所有进位，而非逐级传递。
- 溢出标志 OF 为 1 表示什么含义？::表示有符号数加法运算发生了溢出。
- 零标志 ZF 何时置为 1？::当运算结果的所有位均为 0 时，ZF=1。
- 无符号数逻辑右移时，高位补什么？::高位补 0。
- 有符号数（补码）算术右移时，高位补什么？::高位补符号位。
- 补码算术左移发生溢出的条件是什么？::移出的高位与原符号位不同（即左移后符号位改变）。
- 4 位补码 1001(-7) 算术右移一位的结果及影响？::结果为 1100(-4)，保留符号位但丢失最低有效位，影响精度。
- 逻辑移位将操作数视为何种类型？::无符号整数。
- 补码减法运算在硬件上如何实现？::将被减数与减数的负数补码相加，即$[A]_补+[-B]_补$。
- 采用双符号位时，01 表示什么状态？::表示结果正溢出。
- 采用一位符号位结合进位判断溢出的公式？::$V=C_{n}\oplus C_{n-1}$，即符号位进位与最高数值位进位不同。
- 两个正数相加结果为负，是否发生溢出？::是，这是同号相加结果异号的典型溢出情况。
- 补码运算结果自动截断为多少位？::自动截断为$n+1$位（模$2^{n+1}$），高位进位被丢弃。
- 执行减法操作时，控制信号 Sub 和$C_{in}$分别为多少？::Sub=1，$C_{in}=1$。
- 无符号数减法中，CF=1 表示什么？::表示有借位（不够减），即发生无符号溢出。
- 如何综合计算进/借位标志 CF？::$CF = Sub \oplus C_{out}$。
- 有符号数比较中，A<B 的判定条件（ZF=0 时）？::$OF \neq SF$（或$OF \oplus SF = 1$）。
- 运算器能否自动识别操作数是有符号还是无符号？::不能，需依靠标志位（OF/CF）由软件或后续逻辑解释。
- 原码乘法中，乘积的符号位如何确定？::由两个乘数的符号位异或得到（$x_s \oplus y_s$）。
- Booth 算法中，若$y_i y_{i-1}$为 10，执行什么操作？::执行$P = P - X$（部分积减去被乘数）。
- 无符号数乘法运算中，如何判断发生溢出？::若高 n 位结果（寄存器 P）不为零，则发生溢出。
- 有符号数（补码）乘法中，部分积右移采用何种移位？::算术右移。
- Booth 算法初始化时，辅助位$y_{-1}$的值是多少？::初始化为 0。
- 无符号数除法初始化时，被除数寄存器如何设置？::高位补 0 扩展为 2n 位，低 n 位存实际被除数。
- 补码除法初始化时，余数寄存器 R 如何设置？::所有位初始化为被除数的符号位（完成符号扩展）。
- 无符号数除法是否会发生溢出？为什么？::不会，因为商最大为$2^n-1$，恰好在 n 位无符号数表示范围内。
- 补码除法中，哪种情况会导致商溢出？::被除数为最大负数$-2^{n-1}$且除数为 -1。
- 除法运算中，若除数为 0 会发生什么？::立即触发“除零错误”异常，停止运算。
