## 核心考点
### 考点1：进位计数制与进制转换
**二进制是计算机内部唯一编码形式，不同进制间转换遵循按权展开（转十进制）和除基取余/乘基取整（十进制转其他）原则。**
任意 $r$ 进制数数值：$\sum K_i r^i$；十进制小数转二进制：乘 2 取整，仅当小数为 $k/2^n$ 形式时可精确表示。

> [!tip] 考试怎么用
> 注意十进制小数转二进制可能无限循环（如 0.3），考试常考转换精度判断及二进制与八/十六进制的分组转换（3 位/4 位）。

### 考点2：定点数编码与原/补/反/移码
**现代计算机统一采用补码表示有符号整数，因其零表示唯一且加减法可统一为加法；移码主要用于浮点数阶码以便比较大小。**
补码定义：$[x]_补 = 2^{n+1} + x \pmod{2^{n+1}}$；移码定义：$[x]_移 = 2^n + x$；补码与移码仅符号位相反。

> [!tip] 考试怎么用
> 重点掌握补码表示范围（多一个最小负数 $-2^n$）、零的唯一性，以及移码全 0 对应真值最小值的特性。

### 考点3：C 语言整型转换与位操作
**整型转换本质是位模式的重新解释或位扩展/截断，长转短截断高位，短转长根据符号性进行零扩展或符号扩展。**
短转长：有符号数符号扩展（补符号位），无符号数零扩展（补 0）；长转短：直接丢弃高位，可能导致语义改变。

> [!tip] 考试怎么用
> 警惕 long 转 short 时的截断溢出（非运算溢出），以及 signed 转 unsigned 时位模式不变但解释规则改变导致的数值剧变。

### 考点4：加法器结构与标志位生成
**ALU 通过一套加法电路实现加减运算，利用进位链生成 CF（无符号溢出）和 OF（有符号溢出）等标志位。**
溢出判断：$OF = C_n \oplus C_{n-1}$（最高位进位异或次高位进位）；$CF = C_{out}$（无符号进位/借位）。

> [!tip] 考试怎么用
> 区分 OF 和 CF 的适用场景：OF 仅对有符号数有意义，CF 仅对无符号数有意义；减法时 $CF = Sub \oplus C_{out}$。

### 考点5：定点数移位与乘除运算
**逻辑移位用于无符号数，算术移位用于有符号数（右移补符号位）；乘除法通过“移位 + 加减”迭代实现，Booth 算法优化补码乘法。**
算术右移：低位丢弃，高位补符号位；Booth 算法：根据 $y_i y_{i-1}$ 决定加/减/空操作，统一处理正负数乘法。

> [!tip] 考试怎么用
> 注意算术左移可能溢出（符号位改变），算术右移可能丢失精度；除法中除数为 0 或商溢出需异常处理。

### 考点6：IEEE 754 浮点数表示
**IEEE 754 标准通过隐藏位技术提高精度，阶码用移码（偏置值 $2^{k-1}-1$）表示，特殊值（0, ∞, NaN）由阶码全 0 或全 1 定义。**
单精度公式：$(-1)^s \times 1.f \times 2^{e-127}$；阶码 $e \in [1, 254]$ 为规格化数，$e=0$ 为非规格化或 0，$e=255$ 为无穷或 NaN。

> [!tip] 考试怎么用
> 熟记单/双精度位数分布（1-8-23 / 1-11-52）及偏置值（127/1023）；掌握实数与机器码互转及特殊值判断。

### 考点7：浮点数加减运算流程
**浮点加减需经对阶（小阶向大阶看齐）、尾数加减、规格化、舍入和溢出判断五步，对阶时小阶尾数右移会损失精度。**
对阶原则：小阶向大阶看齐；舍入模式：默认就近舍入（向偶数舍入）；溢出由阶码决定而非尾数。

> [!tip] 考试怎么用
> 重点掌握对阶方向（严禁大阶向小阶）、左规/右规操作（左规阶码减，右规阶码加）及舍入规则。

### 考点8：数据大小端存储与边界对齐
**大端模式 MSB 存低地址，小端模式 LSB 存低地址；边界对齐通过填充字节使数据地址为类型大小的整数倍，以空间换时间。**
小端：低地址存低位字节；对齐规则：成员地址 % 对齐值 == 0，结构体总大小 % 最大对齐值 == 0。

> [!tip] 考试怎么用
> 考试常给出一串内存字节要求还原数值（需先判大小端），或计算 struct 大小（注意填充字节和最大对齐值）。

## 易混与对比
**溢出标志 OF 与进位标志 CF 的区别**

|特征|OF (Overflow Flag)|CF (Carry Flag)|
|---|---|---|
|**适用对象**|有符号数运算|无符号数运算|
|**产生原因**|结果超出有符号数表示范围|结果超出无符号数表示范围（进位/借位）|
|**判断逻辑**|$C_n \oplus C_{n-1}$ (双符号位不等)|加法看最高位进位，减法看借位|
|**典型场景**|正 + 正=负，负 - 正=正|无符号加法溢出，无符号减法不够减|

**逻辑移位与算术移位的区别**

|特征|逻辑移位|算术移位|
|---|---|---|
|**看待对象**|无符号整数|有符号整数（补码）|
|**左移规则**|高位移出，低位补 0|高位移出，低位补 0（溢出判据：符号位变）|
|**右移规则**|低位移出，**高位补 0**|低位移出，**高位补符号位**|
|**数学意义**|乘/除 2（无符号）|乘/除 2（保持符号不变）|

**原码、补码、反码中零的表示**

|编码方式|+0 的表示|-0 的表示|零的唯一性|
|---|---|---|---|
|**原码**|$0,00\dots0$|$1,00\dots0$|不唯一（两种）|
|**反码**|$0,00\dots0$|$1,11\dots1$|不唯一（两种）|
|**补码**|$0,00\dots0$|$0,00\dots0$|**唯一**|
|**移码**|$1,00\dots0$|$1,00\dots0$|**唯一**|

**定点数与浮点数的范围与精度权衡**

|特性|定点数|浮点数|
|---|---|---|
|**表示范围**|较小，受字长直接限制|极大，由阶码位数决定|
|**精度特点**|绝对精度固定，均匀分布|相对精度固定，数值越大精度越低|
|**应用场景**|整数运算、高精度小数（如货币）|科学计算、极大/极小数值|
|**本质 trade-off**|牺牲范围换取固定高精度|牺牲部分精度换取巨大范围|

## 闪卡
#card
- 二进制转十六进制的分组规则是什么？::以小数点为界，整数向左、小数向右每 4 位一组，不足补 0。
- 十进制小数 0.3 能否用有限位二进制精确表示？::不能，因为 0.3=3/10，分母含非 2 质因数，转换结果为无限循环小数。
- 将十进制整数转二进制的算法名称及规则？::除基取余法：不断除以 2 取余数，先得低位后得高位，直到商为 0。
- 8 位补码整数的表示范围是多少？::-128 到 +127，即 $-2^7 \le x \le 2^7-1$，比原码多表示一个 -128。
- 补码和移码在相同字长下有何关系？::数值位相同，仅符号位相反；将补码符号位取反即得移码。
- 为什么浮点数阶码常用移码表示？::移码保持了真值的大小顺序，阶码值越大真值越大，便于硬件直接比较大小。
- short(-4321) 转为 int 时高位如何填充？::执行符号扩展，因符号位为 1，高 16 位全部填充 1。
- int 转 short 时若数值超出 short 范围会发生什么？::发生位截断，保留低 16 位，高位丢弃，结果按 short 类型重新解释，数值可能突变。
- 相同字长的 signed 转 unsigned 规则是什么？::二进制位模式完全不变，仅改变解释方式：原补码解释变为无符号整数解释。
- 如何根据进位信号判断有符号数溢出？::若最高数值位进位 $C_{n-1}$ 与符号位进位 $C_n$ 不同（异或为 1），则发生溢出。
- 无符号数减法中 CF=1 代表什么含义？::代表发生借位，即被减数小于减数，结果超出无符号数表示范围（下溢）。
- 串行进位加法器的主要缺点是什么？::进位信号逐级传递，位数越多延迟越大，运算速度受限于最长进位链。
- 补码算术右移一位的操作规则？::低位移出，高位补符号位（原符号位是什么就补什么），相当于除以 2。
- Booth 算法中辅助位 $y_{-1}$ 初始值是多少？::初始化为 0，与乘数最低位 $y_0$ 组合判断执行加、减还是空操作。
- 无符号数左移一位发生溢出的条件？::若移出的最高位为 1，则发生溢出，因为结果超出了原字长表示范围。
- IEEE 754 单精度浮点数的偏置值是多少？::127（即 $2^{8-1}-1$），阶码真值 = 机器码 - 127。
- 阶码全 1 且尾数非 0 表示什么数值？::表示 NaN（Not a Number），用于标识未定义或无效运算结果（如 0/0）。
- 规格化浮点数尾数的隐藏位机制？::尾数最高位恒为 1，不存储，计算时自动补在整数部分，使 23 位尾数具备 24 位精度。
- 浮点数对阶时为什么要小阶向大阶看齐？::若大阶向小阶看齐需左移尾数，会导致最高有效位丢失，造成不可逆的精度错误。
- 浮点数结果需要右规的条件及操作？::当尾数绝对值 $\ge 2$ 时，尾数右移一位，阶码加 1，以恢复规格化形式。
- IEEE 754 默认采用的舍入模式是什么？::就近舍入（Round to Nearest），若恰好在中间则向偶数（末位为 0）舍入。
- 小端方式（Little Endian）的存储特征？::数据的最低有效字节（LSB）存储在内存的最低地址处。
- 32 位系统中 int 型变量的边界对齐要求？::存储地址必须是 4 的倍数，否则 CPU 需多次访存，降低效率。
- 结构体大小计算时的尾部填充规则？::结构体总大小必须是其内部最大成员对齐值的整数倍，不足则在尾部填充。
