# 2.3 浮点数的表示与运算

> [!abstract] 一句话总结
> 浮点数通过阶码控制范围、尾数控制精度，利用隐藏位和移码优化存储，运算需经对阶、加减、规格化、舍入四步并处理特殊值。

## 核心要点
### 考点1：IEEE 754 浮点数格式与真值
**IEEE 754 单/双精度浮点数由符号位、移码阶码和含隐藏位的原码尾数组成，偏置值分别为 127 和 1023。**
单精度真值：$(-1)^{s}\times1.f\times2^{e-127}$；双精度真值：$(-1)^{s}\times1.f\times2^{e-1023}$。其中 $1.f$ 为含隐藏位 1 的尾数。

> [!tip] 考试怎么用
> 注意阶码是全 0 或全 1 时为特殊值，规格化数阶码范围为 $1\sim254$ (单) 或 $1\sim2046$ (双)。

### 考点2：IEEE 754 特殊值与表示范围
**阶码全 0 表示零或非规格化数，全 1 表示无穷大或 NaN，溢出时置无穷大，下溢时采用渐进下溢机制。**
上溢处理：结果设为 $\pm\infty$；下溢处理：若在非规格化范围内则用非规格化数表示，否则置为 $\pm0$。

> [!tip] 考试怎么用
> 非规格化数阶码真值固定为 $-126$ (单) 或 $-1022$ (双)，尾数无隐藏位 1，用于填补 0 与最小规格化数间隙。

### 考点3：实数与 IEEE 754 格式互转
**转换步骤为：转二进制、规格化、计算阶码（加偏置）、确定符号、组合字段（注意隐藏位）。**
例：$-8.25 = -1000.01_2 = -1.00001\times2^3$。符号 1，阶码 $3+127=130$，尾数取小数部分补 0。

> [!tip] 考试怎么用
> 还原时切记尾数要补回隐藏的'1.'，阶码要减去偏置值，符号位单独判断。

### 考点4：浮点数加减运算流程
**运算分五步：对阶（小阶向大阶）、尾数加减、规格化（左规/右规）、舍入、溢出判断。**
对阶原则：小阶向大阶看齐，尾数右移；左规是尾数左移阶码减 1，右规是尾数右移阶码加 1。

> [!tip] 考试怎么用
> 对阶时尾数右移丢失的位需保留参与运算；右规最多一次，左规可能多次；溢出只看阶码。

### 考点5：舍入模式与辅助位
**IEEE 754 利用保护位、舍入位、粘滞位辅助舍入，默认采用'就近舍入到偶数'模式。**
就近舍入规则：若处于中间值（保护位 1，其余 0），看末位，奇进偶不进；非中间值按四舍五入逻辑。

> [!tip] 考试怎么用
> 粘滞位只要移出位中有 1 就置 1；截断法是朝原点舍入，正向/负向舍入分别朝 $+\infty/-\infty$。

### 考点6：C 语言浮点类型转换
**int 转 float 可能损失精度，float 转 int 截断小数且可能溢出，double 与 float 互转涉及范围与精度变化。**
int(32 位) 转 float(24 位有效)：有效位超 24 位时舍入；float/double 转 int：直接丢弃小数部分。

> [!tip] 考试怎么用
> long 转 double 通常无损，double 转 float 可能溢出或舍入；混合运算自动向高精度类型转换。

### 考点7：大小端存储与边界对齐
**大端模式 MSB 存低地址，小端模式 LSB 存低地址；边界对齐要求地址为数据大小的整数倍以提升效率。**
结构体对齐：成员地址需是对齐值倍数，结构体总大小需是最大成员对齐值的倍数（尾部填充）。

> [!tip] 考试怎么用
> 判断大小端看低地址存的是高位还是低位字节；结构体大小计算需注意内部填充和尾部填充。

## 易混与对比
- **移码偏置值差异**：通常 n 位移码偏置为 $2^{n-1}$，但 IEEE 754 阶码偏置为 $2^{n-1}-1$（单精度 127，双精度 1023），目的是方便比较大小且保留全 0/全 1 作特殊用途。
- **非规格化数指数真值**：规格化数指数为 $e-Bias$；非规格化数（阶码全 0）指数固定为 $1-Bias$（单精度 -126），而非 $0-Bias$，以保证平滑过渡到 0。
- **左规与右规触发条件**：右规：尾数溢出（如 $10.xxxx$ 或 $-10.xxxx$），仅需一次；左规：尾数非规格化（如 $0.001xxx$），需多次直到最高位为 1。
- **大小端判断依据**：大端：低地址 = 高字节（MSB），符合人类阅读习惯；小端：低地址 = 低字节（LSB），符合 CPU 低位优先处理习惯，反汇编需注意逆序。
- **结构体填充规则**：成员间填充：满足下一成员起始地址对齐；尾部填充：满足结构体总大小是最大成员对齐值的倍数，确保数组元素对齐。

## 闪卡
#card
- IEEE 754 单精度浮点数的阶码偏置值是多少？::127（即 $2^{8-1}-1$）。
- 规格化 IEEE 754 浮点数的尾数最高位如何处理？::恒为 1，不存储，称为隐藏位，实际精度加 1 位。
- 单精度浮点数阶码字段为 8 位，其规格化数的取值范围？::1 到 254（全 0 和全 1 保留给特殊值）。
- 若指数真值为 3，单精度浮点数的阶码字段值是多少？::130（即 $3+127$，二进制 10000010）。
- IEEE 754 中阶码全 1 且尾数非 0 表示什么？::NaN（Not a Number，非数）。
- 非规格化数的阶码字段和尾数特征是什么？::阶码全 0，尾数非 0，且不使用隐藏位 1。
- 正上溢发生时，IEEE 754 标准如何处理结果？::将结果设为 $+\infty$，并置位溢出异常标志（默认不中断）。
- 单精度浮点数能表示的最小正规格化数是多少？::$2^{-126}$（阶码为 1，尾数为 0）。
- 将十进制数 -8.25 转为 IEEE 754 单精度，阶码字段二进制为何？::10000010（真值 3 加偏置 127 得 130）。
- 已知单精度机器数 C6400000H，其阶码真值是多少？::13（阶码字段 10001100 即 140，减去 127）。
- IEEE 754 转换中，尾数字段存储的是哪部分？::规格化后小数点后的部分，小数点前的 1 被隐藏。
- 若某单精度数阶码为 0，尾数非 0，其指数真值固定为？::-126（非规格化数，不采用 $e-127$ 公式）。
- 浮点数对阶时，若两数阶码不同，应如何操作？::小阶向大阶看齐，将小阶数的尾数右移，阶码增大。
- 为何不能采用'大阶向小阶看齐'的对阶方式？::会导致大阶数尾数左移，最高有效位丢失，造成不可逆精度错误。
- 尾数相加结果出现 $10.xxxx$ 形式时需进行什么操作？::右规：尾数右移一位，阶码加 1。
- 浮点数运算中，真正的溢出是指什么溢出？::阶码溢出（上溢或下溢），尾数溢出可通过右规修正。
- IEEE 754 舍入中，粘滞位（Sticky Bit）何时置 1？::只要被移出的低位中存在至少一个 1，粘滞位即为 1。
- 默认舍入模式下，若结果恰好在两个可表示数正中间如何处理？::选择尾数最低有效位为 0 的那个（向偶数舍入）。
- '截断法'舍入对正负数的效果是什么？::直接丢弃多余位，结果总是更接近原点（朝零舍入）。
- 保护位和舍入位位于尾数的什么位置？::紧邻尾数最低有效位之后，依次为保护位、舍入位。
- 32 位 int 转换为 float 型时，一定会发生溢出吗？::不会溢出，但若有效位超过 24 位会发生精度损失（舍入）。
- float 型数据转换为 int 型时，小数部分如何处理？::直接丢弃（向零截断），若数值超出 int 范围则整数溢出。
- double 转 float 时可能发生哪两类问题？::数值过大导致溢出，或有效位过多导致舍入误差。
- C 语言中 float 与 double 混合运算，结果类型是什么？::double（float 自动提升为 double 后运算）。
- 小端方式（Little Endian）存储数据的特点是什么？::最低有效字节（LSB）存储在最低地址，最高有效字节在高地址。
- 32 位系统中，int 型变量地址必须满足什么条件？::地址必须是 4 的倍数（边界对齐）。
- 结构体大小计算中，若当前大小不是最大对齐值倍数怎么办？::在结构体尾部填充空白字节，直到总大小是最大对齐值的倍数。
- 大端方式下，数据字节顺序与十六进制书写顺序关系如何？::一致（高地址存低位，低地址存高位，符合阅读习惯）。
