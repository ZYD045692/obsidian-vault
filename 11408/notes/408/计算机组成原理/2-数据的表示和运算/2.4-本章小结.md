# 2.4 本章小结

> [!abstract] 一句话总结
> 二进制无法精确表示所有十进制小数，浮点数通过阶码扩展范围但牺牲精度，移码编码阶码以简化比较并支持特殊值。

## 核心要点
### 考点1：二进制数的精确表示能力
**整数在字长范围内可精确表示，而小数仅能精确表示形如若干个 $1/(2^k)$ 之和的有理数。**
许多十进制有限小数在二进制下是无限循环小数，例如 $0.1 = (0.000110011\ 0011\cdots)_2$。

> [!tip] 考试怎么用
> 遇到判断能否精确表示的问题，检查该小数是否能写成 $1/2^k$ 的累加和，不能则必为近似值。

### 考点2：浮点数与定点数的范围精度权衡
**相同字长下，浮点数以牺牲精度换取更大表示范围，定点数以固定精度为代价限制数值范围。**
浮点数精度随数值增大而下降；定点数具有恒定且较高的绝对精度。

> [!tip] 考试怎么用
> 比较时需强调：浮点数范围大但精度不恒定，定点数范围小但精度恒定。

### 考点3：移码表示阶码的优势
**移码便于阶码大小比较，并支持通过全 0 和全 1 阶码统一编码特殊值。**
阶码全 0：尾数为 0 表±0，非 0 表非规格化数；阶码全 1：尾数为 0 表±∞，非 0 表 NaN。

> [!tip] 考试怎么用
> 牢记阶码全 0 和全 1 的特殊含义，这是 IEEE 754 标准考查高频点。

## 易混与对比
**定点数与浮点数的精度特性对比**

|特性|定点数|浮点数|
|---|---|---|
|精度分布|恒定且较高|随数值增大而下降|
|位数分配|全部用于数值|部分给阶码，部分给尾数|
|核心代价|限制数值范围|牺牲有效精度|

**IEEE 754 阶码特殊值判据**

|阶码状态|尾数状态|表示含义|
|---|---|---|
|全 0|全 0|±0|
|全 0|非 0|非规格化数|
|全 1|全 0|±∞|
|全 1|非 0|NaN (无效运算)|

## 闪卡
#card
- 字长足够时，计算机能精确表示所有实数吗？::不能，只能精确表示形如若干个 $1/(2^k)$ 之和的有理数。
- 十进制小数 0.1 在二进制中是有限小数吗？::不是，它是无限循环小数 $(0.000110011\cdots)_2$，只能近似表示。
- 整数在字长范围内能否被精确表示？::能，只要数值在当前字长可表示的范围内即可精确表示。
- 相同字长下，浮点数和定点数谁的表示范围更大？::浮点数，因为它通过阶码可表示极大或极小的数值。
- 相同字长下，哪种数制具有恒定且较高的绝对精度？::定点数，因为它将所有位用于数值本身。
- 浮点数的精度随数值变化有什么特点？::精度随数值增大而下降，因为尾数位数相对减少。
- 浮点数为了获得大范围付出了什么代价？::牺牲了精度，需分配部分位给阶码导致尾数位数减少。
- IEEE 754 标准为何用移码表示阶码？::便于浮点数加减运算时比较阶码大小，并支持特殊值编码。
- 浮点数阶码全 0 且尾数非 0 时表示什么？::表示非规格化数。
- 浮点数阶码全 1 且尾数为 0 时表示什么？::表示±∞。
- 浮点数阶码全 1 且尾数非 0 时表示什么？::表示 NaN（如 0/0 等无效运算结果）。
- 浮点数阶码全 0 且尾数也为 0 时表示什么？::表示±0。
