# 5.5 异常和中断机制

> [!abstract] 一句话总结
> 异常是 CPU 内部同步触发的指令级事件（需重执或终止），中断是外部异步触发的设备级事件（顺序执行），两者均通过关中断、存现场、向量跳转的硬件原子流程转入内核。

## 核心要点
### 考点1：异常与中断的本质区别
**异常是 CPU 内部检测的同步事件，由当前指令直接引发；中断是外部设备发起的异步事件，与当前指令无关。**
异常响应时机：指令执行中或完成时立即响应；中断响应时机：仅在第 $i$ 条指令完整执行结束后检测。

> [!tip] 考试怎么用
> 判断依据：是否由当前指令直接导致（同步=异常，异步=中断）；注意缺页是异常而非中断。

### 考点2：故障（Fault）的特性
**故障是在指令启动后、完成前检测到的异常，处理后通常重新执行同一条指令。**
典型故障：非法操作码、缺页、除数为零。流程：检测→保存现场→处理→重执指令（若可恢复）。

> [!tip] 考试怎么用
> 缺页异常是典型故障，页面调入后必须重试原访存指令，不能执行下一条。

### 考点3：自陷（Trap）的特性
**自陷是预先安排的同步事件，在指令正常执行完毕后触发，处理后执行下一条指令。**
典型应用：系统调用（syscall）、断点调试、单步跟踪。机制：通过特殊指令或标志位显式设置。

> [!tip] 考试怎么用
> 系统调用是典型的自陷，属于程序性异常（软件中断），执行完后继续执行下一条用户指令。

### 考点4：终止（Abort）与硬件中断
**终止是严重硬件故障导致的不可预测事件，程序被迫终止；不可屏蔽中断（NMI）用于处理电源掉电等关键故障。**
终止原因：控制器出错、存储器校验错、总线错误。NMI 特征：专用线路，无法被软件屏蔽。

> [!tip] 考试怎么用
> 终止异常不关联特定指令，往往导致系统重启；NMI 优先级最高，不能被 IF 标志屏蔽。

### 考点5：中断的分类与屏蔽
**中断分为可屏蔽中断（INTR）和不可屏蔽中断（NMI），前者受 IF 标志控制，后者用于高优先级事件。**
可屏蔽中断：通过 INTR 线，受 IF 位控制（IF=0 屏蔽）；不可屏蔽中断：通过 NMI 线，始终响应。

> [!tip] 考试怎么用
> 关中断仅屏蔽可屏蔽中断，NMI 和高优先级异常仍可能发生；向量中断由硬件直接提供入口地址。

### 考点6：异常与中断响应流程
**响应过程由硬件自动完成，包含关中断、保存断点与 PSW、向量跳转三个阶段，具有原子性。**
1. 关中断（IF=0）；2. 保存断点（异常存当前指令地址，中断存下一条地址）和 PSW 到内核栈；3. 查向量表跳转。

> [!tip] 考试怎么用
> 断点保存位置不同是考点：异常返回当前指令，中断返回下一条指令；PSW 包含特权级和条件码。

## 易混与对比
**故障 vs 自陷 vs 终止**

|类型|触发时机|指令结果提交|返回行为|典型例子|
|---|---|---|---|---|
|故障 (Fault)|指令执行中/完成前|未提交|重执当前指令|缺页、除零|
|自陷 (Trap)|指令执行完毕后|已提交|执行下一条指令|系统调用、断点|
|终止 (Abort)|执行过程中（随机）|不确定|终止进程/重启|内存校验错、总线错|

**异常 vs 中断**

|维度|异常 (内中断)|中断 (外中断)|
|---|---|---|
|来源|CPU 内部逻辑|外部设备 (I/O, 定时器)|
|同步性|同步 (由当前指令引发)|异步 (与指令无关)|
|响应时机|指令执行中或完成时|仅指令结束后|
|返回地址|当前指令 (重执)|下一条指令 (顺序)|
|可屏蔽性|部分可屏蔽/不可屏蔽|分为可屏蔽 (INTR) 和不可屏蔽 (NMI)|

**可屏蔽 vs 不可屏蔽中断**

|特性|可屏蔽中断 (INTR)|不可屏蔽中断 (NMI)|
|---|---|---|
|信号线|普通中断请求线|专用 NMI 线|
|软件控制|可通过 IF 标志屏蔽|无法被软件屏蔽|
|用途|普通 I/O、定时器|电源掉电、严重硬件故障|
|优先级|较低|最高|

## 闪卡
#card
- 除零错误属于异常还是中断？为什么？::异常；由当前除法指令直接引发，具有同步性和确定性。
- 键盘输入数据就绪属于异常还是中断？::中断；由外部 I/O 设备发起，与当前执行指令无关，具有随机性。
- CPU 何时采样外部中断请求信号？::仅在当前指令完整执行结束后，指令执行期间不采样。
- 异常处理后通常返回哪条指令执行？::可恢复异常（如缺页）重执当前指令；不可恢复异常终止进程。
- 故障发生时，引发异常的指令结果是否已提交？::否；CPU 在尚未提交该指令结果时即响应故障。
- 缺页异常处理完成后，PC 指向哪里？::指向引发缺页的当前指令地址，以便重新执行该指令。
- 非法指令属于哪种异常？能否恢复？::属于故障；不可恢复，通常导致当前进程终止。
- 故障与自陷的主要区别是什么？::故障在指令完成前触发并重执；自陷在指令完成后触发并执行下一条。
- 执行系统调用指令（syscall）属于哪类异常？::自陷（Trap）；是预先安排的主动转入内核的同步事件。
- 自陷处理完成后，CPU 从何处继续执行？::从自陷指令的下一条指令开始继续执行。
- 单步跟踪机制利用了什么异常？::自陷；通过设置单步跟踪标志，每条指令后自动触发。
- 自陷是否由硬件故障引起？::否；自陷是程序性异常，由特定指令或标志显式触发。
- 存储器校验错属于哪类事件？::终止（Abort）；属于严重的硬件故障，导致系统无法正常运行。
- 终止异常处理后能否返回原程序？::不能；通常用于记录错误或重启系统，进程被迫终止。
- 电源掉电预警通过什么中断线发送？::不可屏蔽中断（NMI）；确保 CPU 能及时响应关键故障。
- 软件能否屏蔽 NMI 中断？::不能；NMI 通过专用线路发送，无法被中断屏蔽寄存器屏蔽。
- IF=0 时，CPU 能响应哪种中断？::仅能响应不可屏蔽中断（NMI），可屏蔽中断（INTR）被屏蔽。
- 向量中断与非向量中断的核心区别？::向量中断由硬件直接提供服务程序入口地址；非向量中断需软件轮询查询。
- 定时器中断通常属于哪类中断？::可屏蔽中断；通过 INTR 线请求，可由操作系统按需屏蔽。
- 多重中断允许什么情况发生？::允许高优先级中断嵌套低优先级中断的服务过程。
- 响应中断时，断点（返回地址）保存的是什么？::当前指令执行完毕后的下一条指令地址（PC+1 或类似）。
- 响应异常时，断点（返回地址）保存的是什么？::当前正在执行（或引发异常）的指令地址，以便重执。
- 为什么响应初期要自动关中断？::确保保存上下文（断点、PSW）操作的原子性，防止被其他中断打断。
- 中断向量表的作用是什么？::存储各类事件服务程序的入口地址，CPU 凭类型号索引直接跳转。
