# 5.7 多处理器的基本概念

> [!abstract] 一句话总结
> 多处理器通过 MIMD 架构实现任务级并行，利用硬件多线程隐藏延迟，并依赖共享内存一致性协议解决并发冲突。

## 核心要点
### 考点1：Flynn 分类法 (SISD/SIMD/MISD/MIMD)
**常规单处理器属 SISD，常规多处理器属 MIMD，SIMD 适用于规则数据级并行。**
分类依据：指令流数 $N_I$ 与数据流数 $N_D$。MIMD 分两类：①多计算机系统（消息传递型，私有存储）；②多处理器系统（共享存储型，全局地址空间）。

> [!tip] 考试怎么用
> 区分 SIMD 与 MIMD 的关键在于是否执行同一条指令；MISD 理论上存在但无实际应用。

### 考点2：硬件多线程技术
**通过为每个线程配备独立寄存器组减少切换开销，分为细粒度、粗粒度和同时多线程。**
切换机制：激活对应线程寄存器组，无须读写内存上下文。SMT 公式化描述：单周期发射多条不同线程指令，利用指令级 + 线程级并行。

> [!tip] 考试怎么用
> 细粒度是周期级切换，粗粒度是阻塞级切换，SMT 是单周期并发；Intel 超线程是 SMT 典型。

### 考点3：多核处理器架构
**多核是将多个独立处理单元集成到单芯片，支持多线程物理上同时执行。**
存储层次：每核私有 L1 (有时 L2)，多核共享 L3 及主存。并行模型：$T_{serial} = N \times t$, $T_{multi-core} = (N/K) \times t$ (K 为核数)。

> [!tip] 考试怎么用
> 区分多核并行（任务级）与向量处理（数据级）；多核必须有多线程/多进程模型才能发挥性能。

### 考点4：共享内存多处理器 (SMP)
**SMP 具有统一物理地址空间，分为 UMA（延迟相同）和 NUMA（延迟依赖位置）。**
NUMA 架构：内存控制器集成于 CPU，访问本地内存延迟 < 远程内存。同步机制：互斥锁保证原子性；硬件一致性协议维护 Cache 副本一致。

> [!tip] 考试怎么用
> NUMA 下程序性能对数据布局敏感；Cache 一致性在 SMP 中要求所有 CPU 副本时刻一致。

## 易混与对比
**SIMD 与 MIMD 的适用场景对比**

|特性|SIMD|MIMD|
|---|---|---|
|指令流|单指令流|多指令流|
|数据流|多数据流|多数据流|
|并行级别|数据级并行|线程级/任务级并行|
|适用场景|规则计算（如数组运算、数值模拟）|通用并行计算，含条件分支|
|典型代表|向量处理器|多处理器系统、多计算机系统|

**三种硬件多线程切换机制对比**

|类型|切换时机|并发能力|资源利用率目标|
|---|---|---|---|
|细粒度|每个时钟周期|无指令级并行|隐藏短延迟，均衡利用功能部件|
|粗粒度|长延迟事件（如 Cache 缺失）|无指令级并行|隐藏长延迟，避免流水线空闲|
|同时多线程 (SMT)|单周期内同时发射|支持指令级 + 线程级并行|最大化执行单元和缓存利用率|

**UMA 与 NUMA 架构差异**

|特性|UMA (统一存储访问)|NUMA (非统一存储访问)|
|---|---|---|
|访问延迟|所有 CPU 访问任意单元延迟相同|延迟取决于 CPU 与内存的距离|
|内存连接|通常通过共享总线或交叉开关|内存控制器集成于 CPU，分本地/远程|
|性能瓶颈|总线争用（早期北桥架构）|远程访问延迟高，数据布局敏感|
|扩展性|较差，受限于总线带宽|较好，适合大规模多处理器系统|

## 闪卡
#card
- 常规单处理器和常规多处理器分别属于 Flynn 分类中的哪一类？::单处理器属 SISD，多处理器属 MIMD。
- SIMD 结构在处理包含条件分支代码时效率如何？为什么？::效率显著降低，因各处理单元需执行不同操作，难以保持同步。
- MIMD 系统中，多计算机系统与多处理器系统的核心区别是什么？::前者私有存储需消息传递通信，后者共享全局地址空间可直接访存。
- MISD 结构在通用计算机中的应用情况如何？::极为罕见，几乎没有实际应用。
- 细粒度多线程的线程切换触发时机是什么？::每个时钟周期切换，交替执行不同线程指令。
- 粗粒度多线程在什么情况下进行线程切换？::仅当当前线程因高延迟事件（如 Cache 缺失）导致流水线阻塞时。
- 细粒度和粗粒度多线程是否支持真正的指令级并行？::不支持，同一时刻仅执行一个线程的指令。
- 同时多线程 (SMT) 如何提升整体吞吐率？::单周期同时发射多条不同线程指令，共享执行单元和缓存资源。
- 多核处理器中，各核通常如何配置 Cache？::每核配备私有 L1 Cache，多核共享更高层级 Cache（如 L3）。
- 多核系统与单核系统在多线程执行上的本质区别是什么？::多核支持多线程物理上同时执行，单核（非 SMT）仅是时间交错执行。
- 向量处理器与多核处理器实现并行的方式有何不同？::向量处理器是单指令多数据（数据级），多核是多指令多数据（任务级）。
- UMA 与 NUMA 多处理器系统的核心区别是什么？::UMA 访问任意内存延迟相同，NUMA 延迟取决于 CPU 与内存的物理位置关系。
- 在 NUMA 架构中，访问本地内存与远程内存的延迟关系如何？::访问本地内存的延迟显著低于访问远程内存。
- SMP 系统中为何需要硬件一致性协议？::确保多个 CPU 缓存的同一物理地址副本在任意时刻保持一致。
- SMP 系统中各 CPU 的虚拟地址空间是否统一？::不统一，各 CPU 在独立虚拟空间运行，由 OS 映射到统一物理空间。
