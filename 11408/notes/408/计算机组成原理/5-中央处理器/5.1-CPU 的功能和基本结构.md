# 5.1 CPU 的功能和基本结构

> [!abstract] 一句话总结
> CPU 通过寄存器组暂存指令与数据，由控制单元协调时序与微操作，在 ALU 执行运算并响应中断以完成程序执行。

## 核心要点
### 考点1：CPU 的六大基本功能
**CPU 需具备取指译码、更新 PC、算术逻辑运算、存取操作数、处理异常中断及时序控制六大功能。**
1. 取指译码：从主存取指令并生成控制信号
2. 更新 PC：确定下条指令地址（顺序或转移）
3. 运算：ALU 执行算术/逻辑运算
4. 存取：读写主存或 I/O 接口
5. 中断：检测并转入处理程序
6. 时序：时钟协调操作顺序与时长

> [!tip] 考试怎么用
> 区分'时序控制'与'操作控制'，前者管时间节奏，后者管具体动作信号。

### 考点2：程序计数器 PC 与指令寄存器 IR
**PC 存放即将执行指令地址且位数取决于地址总线宽度，IR 暂存当前指令且位数等于指令字长。**
PC 更新规则：顺序执行 $PC \leftarrow PC + \text{指令字节数}$；转移执行 $PC \leftarrow \text{目标地址}$。\nIR 作用：指令从主存取出后首先送入 IR，供译码器使用。

> [!tip] 考试怎么用
> PC 位数决定寻址空间大小，IR 位数决定指令最大长度，二者不可混淆。

### 考点3：存储器接口寄存器 MAR 与 MDR
**MAR 存放待访问主存地址且位数同地址总线，MDR 暂存读写数据以缓冲 CPU 与主存速度差异。**
数据通路步骤：
1. 地址送入 MAR $\to$ 地址总线 $\to$ 存储器
2. 数据在 MDR 与主存间双向传输\nMDR 作用：缓解 CPU 与主存之间的速度差异，起到缓冲与同步作用。

> [!tip] 考试怎么用
> MAR 和 MDR 是用户不可见寄存器，任何主存访问（取指或读写数据）都必须经过它们。

### 考点4：运算部件 ALU 与标志寄存器 FR
**ALU 执行算术逻辑运算，产生的状态信息存入标志寄存器 FR 供条件转移判断使用。**
运算流程：
1. 操作数送入 ALU 进行运算
2. 结果送回通用寄存器
3. 状态标志写入 FR（PSWR）\nFR 特点：由触发器实现，用户程序不能直接修改其值（只读型）。

> [!tip] 考试怎么用
> FR 是用户可见但只读的寄存器，其内容完全由 ALU 运算结果自动生成。

### 考点5：控制单元 CU 与时序信号
**CU 综合译码结果、时序信号与状态标志生成微操作控制信号，时序部件提供周期节拍基准。**
控制信号形成逻辑：
$$ \text{微操作信号} = f(\text{译码信号}, \text{时序信号}, \text{状态标志}) $$
时序信号产生：以系统时钟为基础，生成周期、节拍和工作脉冲。

> [!tip] 考试怎么用
> CU 不是直接执行指令，而是发出控制信号驱动其他部件协同工作。

### 考点6：用户可见与不可见寄存器分类
**用户可见寄存器包括 GPRs、PC 及只读 FR，用户不可见寄存器包括 IR、MAR、MDR 等硬件专用寄存器。**
分类判据：汇编语言程序能否直接访问（读取或修改）。
用户可见：GPRs、专用地址寄存器、PC、FR（只读）。
用户不可见：IR、MAR、MDR、页表基址寄存器。

> [!tip] 考试怎么用
> IR、MAR、MDR 对用户完全透明，程序员无法在汇编代码中直接操作它们。

## 易混与对比
**PC 与 IR 的功能与位数区别**

|寄存器|存放内容|位数决定因素|用户可见性|
|---|---|---|---|
|PC|即将执行的指令地址|地址总线宽度|可见|
|IR|当前正在执行的指令|指令字长|不可见|

**MAR/MDR 与通用寄存器的区别**

|特性|MAR/MDR|通用寄存器 (GPRs)|
|---|---|---|
|用途|专门用于 CPU 与主存接口缓冲|暂存操作数、中间结果、地址指针|
|可见性|用户不可见（透明）|用户可见，可编程使用|
|数量|通常各一个|一组（多个）|

**用户可见寄存器的读写权限**

|寄存器类型|代表寄存器|读权限|写权限|
|---|---|---|---|
|通用/专用|GPRs, PC, SP|可 read|可 write|
|状态标志|FR (PSWR)|可 read|不可 write (只读，由 ALU 自动更新)|
|内部缓冲|IR, MAR, MDR|不可 read|不可 write|

- 决定下一条指令地址的功能部件动作是什么？::更新程序计数器（PC）：支持顺序执行或程序转移。
- 协调各操作执行顺序和持续时间依靠什么信号？::时序控制：通过时钟信号确保指令按序执行。
- 从主存取出指令并解析操作码属于哪个功能？::取指令并译码：生成相应的控制信号。
- 程序计数器 PC 的位数由什么决定？::由地址总线宽度决定，反映 CPU 可直接寻址的内存空间大小。
- 指令寄存器 IR 的位数等于什么？::等于指令字长，用于暂存当前正在执行的指令。
- 顺序执行指令时，PC 如何自动更新？::自动递增，增量为当前指令所占的字节数。
- 程序启动前，首条指令地址被装入哪个寄存器？::程序计数器（PC）。
- MAR 的位数由什么决定？::由地址总线宽度决定，存放当前要访问的主存地址。
- MDR 在 CPU 与主存交换数据时起什么作用？::暂存读出或写入的数据，起到缓冲与同步作用，缓解速度差异。
- 取指或数据读写时，地址先送入哪个寄存器？::存储器地址寄存器（MAR），再通过地址总线传至存储器。
- MDR 中暂存的数据流向有哪些？::从主存读出的数据或将要写入主存的数据。
- 标志寄存器 FR 的内容是如何生成的？::由 ALU 运算结果自动生成，用户程序不能直接修改。
- 标志寄存器 FR 的主要用途是什么？::保存 ALU 运算状态信息，用于条件判断与转移控制。
- ALU 运算产生的状态标志写入哪个部件？::标志寄存器（FR），也称程序状态字寄存器（PSWR）。
- FR 通常由什么硬件电路实现？::通常由触发器实现，整体构成程序状态字。
- 控制单元 CU 生成微操作信号的依据有哪些？::综合译码结果、时序信号与状态标志。
- 时序信号产生部件以什么为基础生成信号？::以系统时钟为基础，生成周期、节拍和工作脉冲。
- 指令译码器 ID 的输出信号送给哪个部件？::送给控制单元（CU），用于识别指令类型并生成控制信号。
- 整个 CPU 的时序基准由谁提供？::时序信号产生部件，为 CPU 提供周期、节拍和脉冲。
- 指令寄存器 IR 属于用户可见还是不可见寄存器？::用户不可见寄存器，对用户程序完全透明，不能被读取或修改。
- 标志寄存器 FR 对用户程序是否可写？::用户可见但只读，内容由 ALU 自动生成，用户不能直接修改。
- 通用寄存器组 GPRs 属于哪类寄存器？::用户可见寄存器，供用户程序灵活使用，暂存数据或地址。
- 存储器数据寄存器 MDR 能否被用户程序直接访问？::不能，属于用户不可见寄存器，仅由 CPU 硬件或内核使用。
