# 1.4 本章小结

> [!abstract] 一句话总结
> CPU 性能由主频与架构（IPC）共同决定，仅机器语言可被硬件直接执行。

## 核心要点
### 考点1：CPU 主频与性能关系
**主频高的 CPU 不一定比主频低的 CPU 性能更高，因为性能受微架构、流水线、缓存等多因素影响。**
性能取决于：主频、微架构设计、流水线深度、缓存容量与层级、指令集效率、位宽、并行能力。

> [!tip] 考试怎么用
> 判断题常考'主频越高性能越强'，必须回答'不一定'并列举 IPC 或架构因素。

### 考点2：翻译程序分类与特征
**翻译程序包括汇编、编译和解释程序，它们将不同级别语言转换为机器可执行形式。**
分类：汇编程序（汇编语言→机器语言）、编译程序（高级语言→目标程序）、解释程序（边解释边执行）。

> [!tip] 考试怎么用
> 区分编译与解释：编译生成独立目标文件，解释不生成目标文件且逐行执行。

### 考点3：语言级别与硬件执行
**只有机器语言能被硬件直接执行，汇编语言和高级语言均需转换。**
机器语言：二进制指令，与硬件一一对应；汇编语言：助记符，需汇编；高级语言：抽象，需编译或解释。

> [!tip] 考试怎么用
> 选择题常问'哪种语言直接被 CPU 执行'，答案唯一为机器语言。

## 易混与对比
**主频与性能的关系误区**

|观点|正误|原因|
|---|---|---|
|主频越高性能越强|错|忽略 IPC、架构、缓存等因素，低主频高 IPC 可超越高主频低 IPC|
|主频反映实际运算速度|错|主频仅反映时钟振荡频率和指令执行节奏，非最终速度|

**语言执行方式对比**

|语言类型|直接执行|需转换|转换工具|
|---|---|---|---|
|机器语言|是|否|无|
|汇编语言|否|是|汇编程序|
|高级语言|否|是|编译程序或解释程序|

## 闪卡
#card
- 主频高的 CPU 性能一定更高吗？::不一定，还取决于微架构、IPC、缓存等因素。
- 主频反映的是什么物理量？::CPU 内部时钟信号的振荡频率，反映指令执行节奏。
- 低主频 CPU 超越高主频 CPU 的关键指标是什么？::更高的每周期指令数（IPC）。
- 除主频外，列举两个影响 CPU 性能的因素。::微架构设计、流水线深度（或缓存、指令集效率等）。
- 翻译程序主要包含哪三类？::汇编程序、编译程序、解释程序。
- 汇编程序的输入和输出分别是什么？::输入是汇编语言，输出是机器语言。
- 编译程序与解释程序的核心区别是什么？::编译生成目标程序，解释边解释边执行不生成目标文件。
- 哪种程序处理高级语言并直接控制执行过程？::解释程序。
- 哪一类语言可被硬件直接执行？::只有机器语言。
- 机器语言的构成形式是什么？::由二进制指令构成，与硬件指令一一对应。
- 汇编语言使用什么符号表示指令？::助记符。
- 高级语言执行前必须经过什么处理？::编译或解释转换。
