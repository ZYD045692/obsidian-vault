# 6.3 文件传输协议

> [!abstract] 一句话总结
> FTP 通过分离的控制连接（端口 21）与数据连接（端口 20）实现带外控制，利用双 TCP 连接机制屏蔽异构系统差异以可靠传输文件。

## 核心要点
### 考点1：FTP 基本功能与工作模式
**FTP 是基于 TCP 的客户/服务器协议，支持异构系统间文件传输、权限管理及匿名共享。**
工作模式：C/S 架构；传输层协议：TCP；特性：有状态协议（需维护用户账户与当前目录位置）。

> [!tip] 考试怎么用
> 注意 FTP 是‘有状态’协议，而 HTTP 是无状态；FTP 屏蔽底层细节适用于异构网络。

### 考点2：FTP 服务器进程工作流程
**主进程监听端口 21，收到请求后启动从属进程处理，主进程立即返回等待状态实现并发。**
步骤：①打开端口 21；②等待连接；③启动从属进程处理并终止；④主进程继续等待。

> [!tip] 考试怎么用
> 区分主进程（常驻）与从属进程（临时）；主进程与从属进程是并发执行的。

### 考点3：控制连接与控制信息传输
**控制连接全程保持打开，仅传输命令（如登录、目录操作），不传输文件数据，属于带外传送。**
端口：服务器 21；内容：控制命令；状态：整个会话期间保持打开；特性：带外（Out-of-band）传送。

> [!tip] 考试怎么用
> 控制连接不传数据；‘带外传送’指控制信息与数据信息在不同连接上传输。

### 考点4：数据连接与传输模式
**数据连接用于实际文件传输，传输结束即关闭；分为主动模式（PORT）和被动模式（PASV）。**
端口：主动模式服务器用 20；建立者：主动模式由服务器发起，被动模式由客户端发起。

> [!tip] 考试怎么用
> 默认考查主动模式；区分谁主动发起数据连接是解题关键（PORT vs PASV）。

### 考点5：FTP 与 NFS 的文件修改机制对比
**FTP 修改文件需完整下载再上传，效率低；NFS 允许直接读写远程文件特定片段。**
FTP 流程：下载整个文件 -> 本地修改 -> 上传整个文件；NFS 流程：直接打开远程文件读写片段。

> [!tip] 考试怎么用
> 理解 FTP 非网络文件系统的局限性：不支持原地修改，必须两次完整传输。

## 易混与对比
**控制连接与数据连接的区别**

|特征|控制连接|数据连接|
|---|---|---|
|**端口号**|服务器 21|服务器 20（主动模式）或随机（被动模式）|
|**生命周期**|整个会话期间保持打开|仅在一次文件传输期间存在，传完即关|
|**传输内容**|控制命令（登录、目录、传送请求）|实际文件内容|
|**连接发起**|客户端主动发起|主动模式由服务器发起，被动模式由客户端发起|

**主动模式 (PORT) 与被动模式 (PASV)**

|模式|控制命令交互|数据连接建立方向|服务器数据端口|
|---|---|---|---|
|**主动 (PORT)**|客户端发 PORT 命令告知端口|服务器 -> 客户端|20|
|**被动 (PASV)**|客户端发 PASV 命令，服务器回端口|客户端 -> 服务器|随机开放|
|**核心差异**|均由客户端决定模式|谁主动发起数据 TCP 连接|主动模式固定，被动模式随机|

**FTP 进程模型：主进程 vs 从属进程**

|进程类型|职责|生命周期|并发关系|
|---|---|---|---|
|**主进程**|监听端口 21，接收新连接请求|长期运行，不终止|与从属进程并发执行|
|**从属进程**|处理单个客户的具体请求|请求处理完毕后立即终止|每个客户对应一个独立从属进程|

## 闪卡
#card
- FTP 在传输层使用什么协议？::TCP，提供可靠的传输服务。
- FTP 服务器进程由哪两部分组成？::一个主进程（接收新请求）和若干从属进程（处理单个客户请求）。
- FTP 为何被称为有状态协议？::服务器需在整个会话期间维护用户账户及远程目录树当前位置。
- FTP 支持的三种主要功能是什么？::异构系统文件传输、远程文件权限管理、匿名 FTP 公用文件共享。
- FTP 主进程监听的熟知端口号是多少？::21 号端口（控制端口）。
- FTP 从属进程何时终止？::处理完单个客户的请求后立即终止。
- 主进程在处理一个请求时是否阻塞？::否，启动从属进程后主进程立即返回等待状态，两者并发执行。
- 一个 FTP 服务器进程可同时为多少客户服务？::多个，通过主进程派生多个从属进程分别处理。
- FTP 控制连接使用的服务器端口号？::21 号端口。
- 控制连接在文件传输过程中是否关闭？::否，整个会话期间保持打开，可发送中断等指令。
- FTP 的控制信息传送方式称为什么？::带外（Out-of-band）传送，因为使用独立于数据连接的通道。
- 控制连接是否用于传输实际文件内容？::否，仅传输控制命令，文件数据通过数据连接传输。
- FTP 主动模式（PORT）中数据连接的发起方？::服务器（通过 20 号端口主动连接客户端指定端口）。
- FTP 被动模式（PASV）中数据连接的发起方？::客户端（主动连接服务器随机开放的端口）。
- FTP 数据连接在传输结束后状态如何？::立即关闭，数据传送进程随之终止。
- 主动模式下客户端如何告知服务器数据端口？::通过 PORT 命令将随机选择的本地端口号告知服务器。
- 使用 FTP 修改远程文件需要几次完整传输？::两次（先下载到本地，修改后再传回服务器）。
- NFS 允许进程如何操作远程文件？::直接打开远程文件，并在指定位置进行读/写操作。
- 相比 NFS，FTP 文件修改的主要缺点是什么？::效率较低，因为无须复制整个文件时 FTP 仍需传输完整文件。
