## 核心考点
### 考点1：网络应用模型架构
**C/S 模型中服务器地位集中且被动等待，P2P 模型中节点地位对等且兼具客户与服务器双重角色。**
C/S 特点：管理集中、可扩展性差；P2P 特点：可扩展性好、健壮性强、占用本地资源多。

> [!tip] 考试怎么用
> 区分两者在可扩展性、服务器依赖度及节点角色上的本质差异，注意 P2P 仍基于 C/S 机制实现。

### 考点2：DNS 层次结构与服务器类型
**DNS 采用树状层次域名空间，由根、顶级、权限和本地四类域名服务器分布式协同完成解析。**
域名格式：$<主机>.<二级域>.<顶级域>$；根服务器知悉所有顶级域 IP，不直接解析具体主机。

> [!tip] 考试怎么用
> 牢记四类服务器的职责划分，特别是根服务器只返回下一步查询地址而非最终 IP。

### 考点3：DNS 解析查询机制
**主机向本地域名服务器采用递归查询，本地域名服务器向其他服务器通常采用迭代查询。**
递归：代理完成所有后续查询；迭代：返回下一步查询地址，由请求方继续查询。

> [!tip] 考试怎么用
> 考试常考查询报文流向，注意区分“谁替谁查”，实际中根服务器负载重故多用迭代。

### 考点4：FTP 双连接工作机制
**FTP 使用两个并行 TCP 连接：21 端口控制连接全程保持，20 端口数据连接按需建立与释放。**
控制连接：传输命令（带外传送）；数据连接：传输文件内容；主动模式由服务器发起数据连接。

> [!tip] 考试怎么用
> 区分控制与数据连接的端口号及生命周期，注意控制信息属于带外传送。

### 考点5：电子邮件系统协议栈
**邮件发送使用 SMTP（推模式），邮件读取使用 POP3/IMAP（拉模式），MIME 扩展了非 ASCII 内容传输。**
SMTP 端口 25（TCP），POP3 端口 110（TCP）；MIME 将非 ASCII 编码为 ASCII 经 SMTP 传输。

> [!tip] 考试怎么用
> 明确 SMTP 仅用于发送（服务器间或用户到服务器），接收必须用 POP3 或 IMAP。

### 考点6：HTTP 无状态与连接管理
**HTTP 是无状态协议，依靠 Cookie 跟踪用户；HTTP/1.1 默认使用持续连接减少 RTT 开销。**
非持续连接耗时 $= 2 \times RTT + 传输时间$；持续连接流水线方式可进一步减少等待时间。

> [!tip] 考试怎么用
> 计算页面加载时间时，需区分 HTTP 版本及是否流水线，注意 TCP 拥塞窗口限制。

### 考点7：HTTP 报文结构与方法
**HTTP 报文由开始行、首部行和实体主体组成，请求行含方法/URL/版本，状态行含版本/码/短语。**
常用方法：GET（读）、POST（添）、PUT（存）、DELETE（删）；状态码 200/404/500 等。

> [!tip] 考试怎么用
> 熟记常用请求方法的语义及典型状态码含义，注意请求报文通常无实体主体。

### 考点8：URL 结构与万维网组成
**万维网由 URL 标识资源、HTTP 传输数据、HTML 描述结构三要素构成，采用 C/S 模型。**
URL 格式：$<协议>://<主机>:<端口>/<路径>$；默认 HTTP 端口为 80，HTTPS 为 443。

> [!tip] 考试怎么用
> 掌握 URL 各组成部分含义，理解浏览器访问网页时 DNS 解析先于 TCP 连接建立。

## 易混与对比
**DNS 查询方式对比**

|特征|递归查询|迭代查询|
|---|---|---|
|执行者|本地域名服务器代理完成|请求方（本地服务器）自行继续|
|负担|被查询服务器负担重|根/顶级服务器负担轻|
|应用场景|主机到本地服务器|本地服务器到根/顶级服务器|

**FTP 连接模式对比**

|特征|主动模式 (PORT)|被动模式 (PASV)|
|---|---|---|
|数据连接发起方|服务器主动连接客户端|客户端主动连接服务器|
|服务器端口|固定使用 20 号端口|随机开放一个端口|
|防火墙友好度|较差（需开放客户端高位端口）|较好（只需开放服务器随机端口）|

**邮件协议功能对比**

|协议|方向|模式|端口|特点|
|---|---|---|---|---|
|SMTP|发送|推 (Push)|25|仅支持 7 位 ASCII，需 MIME 扩展|
|POP3|读取|拉 (Pull)|110|简单，通常下载后删除或保留副本|
|IMAP|读取|拉 (Pull)|143|强大，支持服务器端文件夹管理及在线操作|

**HTTP 连接方式对比**

|特性|非持续连接 (HTTP/1.0)|持续连接 - 非流水线|持续连接 - 流水线|
|---|---|---|---|
|TCP 连接数|每个对象一个连接|所有对象复用同一连接|所有对象复用同一连接|
|请求发送时机|收到前一响应后|收到前一响应后|可连续发送多个请求|
|RTT 开销|每个对象 2RTT|首对象 2RTT，后续 1RTT|首对象 2RTT，后续对象仅需 1RTT 总耗时|

## 闪卡
#card
- C/S 模型中服务器程序如何运行？::始终运行，被动等待并接收来自各地客户程序的请求。
- P2P 模型中节点的角色是什么？::任意节点既是资源提供者（服务器）又是资源获取者（客户）。
- 哪种模型的可扩展性随节点增加而自然增长？::P2P 模型，因其容量随节点数量增加而增长，无单点瓶颈。
- C/S 模型中客户之间通常如何通信？::客户之间通常不直接通信，必须通过服务器中转。
- DNS 层次结构中最高层级是什么？::根域名服务器，知悉全部顶级域名服务器的域名和 IP 地址。
- 负责管理特定区所有主机映射的服务器是？::权限域名服务器（授权域名服务器），总能将管辖主机名解析为 IP。
- 主机发起 DNS 查询时首先接触哪类服务器？::本地域名服务器，通常由 ISP 或单位部署，作为查询入口。
- 顶级域名服务器管理什么范围的域名？::管理在其下注册的所有二级域名，如.com 管理所有以.com 结尾的域名。
- 主机向本地域名服务器的查询方式是什么？::递归查询，本地服务器需代替主机完成后续所有查询步骤。
- 本地域名服务器向根域名服务器的查询方式？::通常采用迭代查询，根服务器返回下一步应查询的顶级域服务器地址。
- 迭代查询中若无法直接解析，服务器返回什么？::返回下一步应当向哪个域名服务器查询的地址，而非最终 IP。
- DNS 缓存记录失效的依据是什么？::生存时间（TTL），到期后记录自动失效并被清除。
- FTP 控制连接使用的熟知端口号是多少？::21 号端口，用于传输控制命令，整个会话期间保持打开。
- FTP 数据连接在主动模式下由谁发起？::服务器通过 20 号端口主动连接到客户端指定的随机端口。
- FTP 控制连接是否传输文件数据？::否，控制连接仅传输控制命令，文件数据通过独立的数据连接传输。
- FTP 协议在传输层使用什么协议？::TCP，提供可靠的传输服务，一个 FTP 服务器可并发处理多个客户。
- 用户代理从邮件服务器获取邮件使用什么协议？::POP3 或 IMAP，采用拉（Pull）方式主动从服务器下载邮件。
- SMTP 协议在传输层使用什么协议及端口？::基于 TCP 连接，使用熟知端口号 25。
- MIME 协议的主要作用是什么？::将非 ASCII 数据编码为 ASCII 格式，以便通过仅支持 7 位 ASCII 的 SMTP 传输。
- 邮件服务器之间传递邮件使用什么协议？::SMTP，发送端服务器作为客户，接收端服务器作为服务器。
- HTTP 协议的无状态特性指什么？::服务器不记录此前与该客户的交互历史，每次请求视为独立新请求。
- HTTP/1.1 默认采用的连接方式是什么？::持续连接，服务器发送响应后保持 TCP 连接以供后续请求复用。
- Cookie 在 HTTP 交互中如何工作？::服务器响应设 Set-cookie，浏览器后续请求自动附加 Cookie 首部以标识用户。
- 非持续连接模式下获取一个对象需几个 RTT？::2 个 RTT：一个用于 TCP 三次握手前两次，一个用于请求与响应。
- HTTP 请求报文中用于读取资源的方法是？::GET，请求读取由 URL 标识的信息。
- HTTP 响应报文状态行包含哪三个字段？::HTTP 版本、状态码、解释状态码的短语。
- HTTP 报文首部行与实体主体如何分隔？::用一个空行（仅含 CRLF）分隔首部行与后面的实体主体。
- POST 方法的主要用途是什么？::给服务器添加信息，如提交表单数据或注释。
- URL 中默认 HTTP 协议的端口号是多少？::80，若在 URL 中省略端口且协议为 http，则默认使用 80。
- 万维网中用于描述文档结构的标记语言是？::超文本标记语言（HTML），通过标记组织文字、图像等多媒体内容。
- 统一资源定位符（URL）的作用是什么？::唯一标识万维网上的各类文档，指明资源位置及访问方式。
- 万维网客户程序通常指什么软件？::浏览器，负责向服务器发起请求并解析显示返回的 Web 页面。
