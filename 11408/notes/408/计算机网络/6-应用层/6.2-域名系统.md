# 6.2 域名系统

> [!abstract] 一句话总结
> DNS 通过层次化命名空间与分布式服务器集群，利用递归与迭代相结合的查询机制，高效完成域名到 IP 地址的映射解析。

## 核心要点
### 考点1：DNS 概述与协议基础
**DNS 是运行在 UDP 53 号端口上的客户/服务器模型命名系统，用于将主机名转换为 IP 地址。**
协议栈：应用层 DNS $\to$ 传输层 UDP (端口 53)。

> [!tip] 考试怎么用
> 注意 DNS 主要使用 UDP，仅在响应报文超过 512 字节或进行区域传送时才使用 TCP。

### 考点2：层次域名空间结构
**域名采用树状层次结构，标号不区分大小写，总长度不超过 255 字符，单标号不超过 63 字符。**
域名格式：$\text{三级域}.\text{二级域}.\text{顶级域}$（如 www.cskaoyan.com）。

> [!tip] 考试怎么用
> 牢记标号限制（63/255）及书写顺序（低级在左，高级在右），常考判断题。

### 考点3：四类域名服务器
**DNS 服务器分为根、顶级、权限和本地域名服务器，各自管辖不同范围的域名映射。**
管辖范围：根 (TLD 指引) $\to$ 顶级 (二级域指引) $\to$ 权限 (具体 IP) $\to$ 本地 (代理查询)。

> [!tip] 考试怎么用
> 区分“权限域名服务器”与“本地域名服务器”的角色，前者存最终映射，后者是查询入口。

### 考点4：递归查询与迭代查询
**主机到本地服务器必用递归查询，本地服务器到其他服务器通常采用迭代查询。**
递归：请求者等待最终结果；迭代：请求者自行发起下一级查询。

> [!tip] 考试怎么用
> 考试常考查询流程图中箭头的指向及报文类型，注意根服务器负载问题导致递归不被采用。

### 考点5：域名解析详细流程
**完整解析过程最多涉及 8 个 UDP 报文（4 查 4 答），包含缓存查询、根、顶级、权限服务器交互。**
流程：主机$\to$本地 (递归)$\to$根$\to$顶级$\to$权限 (迭代)$\to$本地$\to$主机。

> [!tip] 考试怎么用
> 需能画出或描述从 y.abc.com 解析的 8 步交互过程，注意缓存命中可跳过后续步骤。

## 易混与对比
**递归查询 vs 迭代查询**

|特征|递归查询|迭代查询|
|:---|:---|:---|
|**发起者**|主机向本地服务器|本地服务器向其他服务器|
|**工作量**|服务器承担全部查询工作|请求者自行发起后续查询|
|**返回结果**|最终 IP 地址或错误|下一步服务器地址或最终 IP|
|**负载影响**|根服务器负载过重，实际少用|分散负载，实际常用|

- **域 (Domain) vs 区 (Zone)**：**域**是名字空间中可被管理的划分（逻辑概念）；**区**是服务器实际管辖的范围（物理/管理概念）。一个区内的节点必须连通，区的范围小于或等于域，一个域可划分为多个区由不同服务器管理。
- **各类顶级域名含义**：**ccTLD**：国家顶级域（如.cn, .us）；**gTLD**：通用顶级域（.com 公司，.edu 教育，.gov 政府）；**arpa**：基础结构域，专用于反向域名解析（IP 转域名）。

## 闪卡
#card
- DNS 协议默认使用的传输层协议及端口号？::UDP 协议，端口号 53。
- DNS 系统采用的基本工作模型是什么？::客户/服务器（C/S）模型。
- DNS 系统的核心功能是什么？::将便于记忆的主机名转换为便于机器处理的 IP 地址。
- 域名中标号的长度限制及总长度限制分别是多少？::单标号$\le$63 字符，总长度$\le$255 字符。
- 域名标号中允许使用的特殊符号有哪些？::仅允许连字符（-），不得使用其他标点。
- 域名书写时，级别最高和最低的标号分别位于何处？::级别最低在最左边，级别最高（顶级域）在最右边。
- 顶级域名（TLD）主要分为哪三大类？::国家顶级域名 (ccTLD)、通用顶级域名 (gTLD)、基础结构域名 (arpa)。
- 全球根域名服务器的数量及其实际部署形式？::逻辑上 13 个，实际为多个冗余服务器组成的集群。
- 哪种服务器总是能将管辖的主机名解析为对应 IP 地址？::权限域名服务器（授权域名服务器）。
- 主机发起 DNS 查询时，首先访问的是哪种服务器？::本地域名服务器。
- 根域名服务器通常直接返回 IP 地址吗？::不直接返回，通常返回下一步应查询的顶级域名服务器地址。
- 主机向本地域名服务器发起的查询采用什么方式？::递归查询。
- 本地域名服务器向根域名服务器发起的查询通常采用什么方式？::迭代查询。
- 为何实际中根域名服务器几乎不采用递归查询？::会给根域名服务器带来过重负载。
- 在迭代查询中，若服务器无法解析，它会返回什么信息？::返回下一步应向哪个域名服务器查询的地址。
- 假设缓存未命中，解析 y.abc.com 最多涉及多少个 UDP 报文？::8 个（4 个查询报文和 4 个回答报文）。
- 本地域名服务器在收到根服务器响应后，下一步向谁查询？::向顶级域名服务器（如 dns.com）查询。
- 权限域名服务器 dns.abc.com 收到请求后返回什么？::返回 y.abc.com 对应的 IP 地址。
- DNS 缓存记录失效的机制是什么？::设置生存时间（TTL），到期后自动失效清除。
