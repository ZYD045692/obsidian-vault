# 6.5 万维网

> [!abstract] 一句话总结
> 万维网是基于 URL 定位、HTML 描述、HTTP 传输的分布式信息系统，其核心矛盾在于无状态协议如何通过 Cookie 和持续连接优化用户体验与传输效率。

## 核心要点
### 考点1：万维网组成与 URL 结构
**万维网由 URL 唯一标识资源、HTTP 协议传输数据、HTML 语言描述结构三大标准构成，采用 C/S 模式工作。**
URL 一般形式：$$<协议>://< 主机 >:<端口>/<路径>$$，其中 HTTP 默认端口为 80，字符通常不区分大小写。

> [!tip] 考试怎么用
> 注意 URL 中协议、主机、端口、路径的省略规则；区分万维网（应用）与互联网（基础设施）的概念范围。

### 考点2：HTTP 操作过程与协议栈
**浏览器访问网页需依次完成 DNS 解析、TCP 连接建立、HTTP 请求/响应交互、TCP 连接释放四个步骤。**
典型时延公式（非持续连接）：$$T = 2 \times RTT + T_{trans}$$，其中 2RTT 分别用于 TCP 握手和请求响应。

> [!tip] 考试怎么用
> 计算总时延时需累加 DNS 解析时间、TCP 连接建立时间（1RTT 或 2RTT 视是否捎带请求）、对象传输时间。

### 考点3：HTTP 无状态与 Cookie 机制
**HTTP 是无状态协议，服务器不记录客户历史，需通过 Cookie 机制在客户端存储识别码以实现状态跟踪。**
Cookie 流程：服务器响应设 `Set-cookie:ID` -> 浏览器保存 -> 后续请求带 `Cookie:ID` -> 服务器查库识别。

> [!tip] 考试怎么用
> 区分 HTTP 无状态（协议特性）与 Cookie 有状态（应用层补偿机制）；Cookie 存储在客户端而非服务器。

### 考点4：持续连接与非/流水线方式
**HTTP/1.1 默认使用持续连接，分为非流水线（串行请求）和流水线（并行请求）两种方式，后者效率更高。**
流水线时延优势：获取 N 个引用对象仅需 $$1 \times RTT$$（非流水线需 $$N \times RTT$$）。

> [!tip] 考试怎么用
> 计算多对象页面加载时间时，务必判断是持续连接还是非持续连接，以及是否采用流水线方式。

### 考点5：HTTP 报文结构与常用方法
**HTTP 报文由开始行、首部行、实体主体三部分组成，请求行含方法/URL/版本，状态行含版本/状态码/短语。**
常用方法：GET(读), HEAD(读首部), POST(添加), PUT(存储), DELETE(删除), CONNECT(代理)。

> [!tip] 考试怎么用
> 注意请求报文通常无实体主体；首部行与实体主体间必须有一个空行（CRLF）；状态码 200/404 含义。

### 考点6：代理服务器与 Wireshark 分析
**代理服务器（Web 缓存）暂存请求响应，命中时直接返回，可减少外网流量并降低访问延迟。**
帧结构解析：以太网首部 (14B) + IP 首部 (20B) + TCP 首部 (20B) + HTTP 数据；IP 地址需 hex 转 dec。

> [!tip] 考试怎么用
> 抓包题常考各层首部长度及字段含义；注意 MAC 地址、IP 地址的十六进制到十进制转换。

## 易混与对比
**HTTP 无连接 vs 无状态**

|特性|含义|表现|
|---|---|---|
|**无连接**|交换报文前无需建立专门 HTTP 连接|依赖底层 TCP 连接，但 HTTP 层不维护连接状态|
|**无状态**|服务器不记录客户历史交互|同一客户二次访问，服务器响应完全相同（需 Cookie 补偿）|

**非持续连接 vs 持续连接**

|模式|连接行为|时延开销 (N 个对象)|适用版本|
|---|---|---|---|
|**非持续**|每个对象单独建 TCP 连接|$$N \times 2RTT$$|HTTP/1.0|
|**持续 (非流水)**|复用连接，串行请求响应|$$2RTT + N \times 1RTT$$|HTTP/1.1|
|**持续 (流水)**|复用连接，连续发送请求|$$2RTT + 1RTT$$|HTTP/1.1|

**常见应用层协议端口与传输层**

|协议|传输层协议|熟知端口|备注|
|---|---|---|---|
|**HTTP**|TCP|80|万维网|
|**DNS**|UDP|53|域名解析|
|**FTP**|TCP|21(控)/20(数)|文件传输|
|**SMTP**|TCP|25|邮件发送|
|**POP3**|TCP|110|邮件接收|

## 闪卡
#card
- 万维网的三个核心标准是什么？::统一资源定位符 (URL)、超文本传输协议 (HTTP)、超文本标记语言 (HTML)。
- URL 中若省略端口号，HTTP 协议默认使用哪个端口？::默认使用端口 80。
- URL 中的字符是否区分大小写？::URL 中的字符通常不区分大小写。
- 万维网的工作模式是什么？::客户/服务器 (C/S) 模式，浏览器是客户程序，主机运行服务器程序。
- 用户单击链接后，浏览器首先执行的操作是什么？::向 DNS 服务器请求解析域名对应的 IP 地址。
- HTTP 协议直接依赖于哪种传输层协议？::TCP 协议，用于提供可靠的数据传输。
- 在非持续连接中，获取一个对象需要几个 RTT？::需要 2 个 RTT（1 个建连接，1 个请求响应）。
- HTTP 报文交换前是否需要建立专门的 HTTP 连接？::不需要，HTTP 本身是无连接的，依赖底层 TCP 连接。
- HTTP 协议的无状态特性指什么？::服务器不记录客户之前的交互历史，每次响应独立。
- Cookie 识别码存储在哪里？::存储在用户代理（浏览器）本地的 Cookie 文件中。
- 服务器如何识别再次访问的旧用户？::通过解析请求报文中的 Cookie 首部行获取识别码。
- Set-cookie 首部行出现在哪种报文中？::出现在服务器的 HTTP 响应报文中。
- HTTP/1.0 和 HTTP/1.1 在连接管理上的主要区别？::HTTP/1.0 仅支持非持续连接，HTTP/1.1 默认支持持续连接。
- 非流水线方式下，客户端何时发送下一个请求？::必须等待前一个响应完全到达后才能发送。
- 流水线方式获取所有引用对象需多少 RTT？::仅需 1 个 RTT（假设所有请求响应连续传输）。
- 持续连接中 Connection 首部行应设为什么值？::Keep-Alive（若为 close 则表示非持续连接）。
- HTTP 请求报文的第一行叫什么？包含哪三个字段？::叫请求行，包含方法、请求资源的 URL、HTTP 版本。
- GET 方法和 POST 方法的主要区别是什么？::GET 请求读取信息，POST 给服务器添加信息（如提交表单）。
- HTTP 响应报文状态行 404 Not Found 表示什么？::表示服务器找不到请求的页面或资源。
- HTTP 报文首部行与实体主体之间如何分隔？::用一个空行（仅含 CRLF）分隔。
- 代理服务器（Web 缓存）的主要作用是什么？::暂存近期请求响应，命中时直接返回，减少外网流量和延迟。
- 以太网帧中类型字段 08 00 表示上层协议是什么？::表示上层协议为 IP 协议。
- IP 数据报首部通常占用多少字节？::通常占用 20 字节（不含选项字段）。
- 代理服务器可部署在哪些位置？::可部署在客户端、服务器端或网络中间节点。
