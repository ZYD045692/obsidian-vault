# 6.4 电子邮件

> [!abstract] 一句话总结
> 电子邮件系统通过用户代理、邮件服务器及 SMTP/POP3/IMAP 协议协作，利用推/拉机制和 MIME 扩展实现异步可靠的多媒体通信。

## 核心要点
### 考点1：电子邮件系统组成与角色
**系统由用户代理、邮件服务器和协议组成，邮件服务器兼具 SMTP 客户和服务器的双重角色。**
邮件服务器 A 向 B 发送时：A 为 SMTP 客户，B 为 SMTP 服务器；反之亦然。

> [!tip] 考试怎么用
> 注意邮件服务器在发送和接收不同阶段的角色切换，不要误认为服务器只有一种角色。

### 考点2：邮件发送与读取机制
**SMTP 采用推（Push）方式主动发送，POP3/IMAP 采用拉（Pull）方式主动获取。**
发送流程：UA→SMTP→发送服务器→SMTP→接收服务器→存入邮箱；读取流程：UA→POP3/IMAP→拉取邮件。

> [!tip] 考试怎么用
> 区分推和拉的方向：发送端主动推给服务器，接收端主动从服务器拉。

### 考点3：电子邮件格式与地址规范
**邮件由信封和内容组成，内容分首部（含 To/From/Subject）和主体，首部与主体以空行分隔。**
地址格式：$用户名@域名$；首部必填：To, From；可选：Subject；分隔符：空行。

> [!tip] 考试怎么用
> 信封由系统自动生成，用户只需填写首部；To 是必填项，Subject 是可选项。

### 考点4：MIME 扩展机制
**MIME 将非 ASCII 数据编码为 ASCII 格式以便 SMTP 传输，接收端再解码还原，不取代 SMTP。**
MIME 三要素：5 个新首部字段、标准化内容格式、传送编码机制。

> [!tip] 考试怎么用
> MIME 解决 SMTP 仅支持 7 位 ASCII 的限制，用于传输中文、二进制文件等。

### 考点5：SMTP 协议通信过程
**SMTP 基于 TCP 端口 25，通信分连接建立、邮件传送、连接释放三个阶段。**
阶段命令：HELO→MAIL FROM→RCPT TO→DATA→QUIT；结束标志：$<CRLF>.<CRLF>$。

> [!tip] 考试怎么用
> RCPT 命令用于预先验证收件人地址；DATA 后以<CRLF>.<CRLF>结束邮件内容。

### 考点6：POP3 与 IMAP 协议对比
**POP3 功能简单支持下载并保留或删除，IMAP 功能强大支持服务器端管理和选择性获取。**
POP3 端口 110；IMAP 特性：文件夹管理、搜索、部分下载、维护会话状态。

> [!tip] 考试怎么用
> IMAP 适合多设备访问，POP3 适合单设备；IMAP 可只下载邮件首部节省带宽。

### 考点7：Web 电子邮件服务
**Web 邮件服务中用户与服务器交互通过 HTTP 完成，服务器间传递仍使用 SMTP。**
交互模式：浏览器↔HTTP↔邮件服务器；服务器间：SMTP。

> [!tip] 考试怎么用
> 区分用户访问方式（HTTP）和服务器间传输方式（SMTP），不要混淆。

## 易混与对比
**SMTP 与 POP3/IMAP 的功能定位**

|协议|功能定位|传输方向|端口|特点|
|---|---|---|---|---|
|SMTP|邮件发送|推（Push）|25|服务器间传输，不支持读取|
|POP3|邮件读取|拉（Pull）|110|简单，下载后可能删除|
|IMAP|邮件读取|拉（Pull）|143/993|强大，支持服务器端管理|

- **MIME 与 SMTP 的关系**：SMTP 仅支持 7 位 ASCII 码，无法直接传输非英语字符和二进制文件；MIME 不是独立传输协议，而是将非 ASCII 数据编码为 ASCII 后交给 SMTP 传输，接收端再解码还原。
- **邮件服务器双重角色**：邮件服务器既是 SMTP 服务器（接收其他服务器发来的邮件），又是 SMTP 客户（向其他服务器发送邮件），角色取决于当前操作是发送还是接收。
- **POP3 两种工作模式区别**：下载并保留：邮件读取后仍留在服务器，可多次访问；下载并删除：邮件成功读取后立即从服务器删除，适合单设备用户。
- **Web 邮件与传统邮件协议差异**：Web 邮件：用户通过浏览器 HTTP 访问服务器；传统邮件：用户通过 UA 使用 SMTP/POP3/IMAP；两者服务器间传输均用 SMTP。

## 闪卡
#card
- 电子邮件系统的三个主要组成部分是什么？::用户代理（UA）、邮件服务器、电子邮件协议（SMTP/POP3/IMAP）。
- 邮件服务器在发送邮件时扮演什么角色？::SMTP 客户（主动发起连接发送邮件）。
- 邮件服务器在接收邮件时扮演什么角色？::SMTP 服务器（监听端口接收邮件）。
- 用户代理的主要功能有哪些？::撰写、显示、处理邮件，提供用户与系统接口。
- SMTP 协议采用哪种数据传输方式？::推（Push）方式，发送端主动将邮件推送至目标服务器。
- POP3 协议采用哪种数据传输方式？::拉（Pull）方式，用户代理主动向服务器请求拉取邮件。
- 邮件从发件人 UA 到收件人邮箱经过哪些关键步骤？::UA 发送→发送服务器缓存→SMTP 传输→接收服务器存入邮箱。
- 收件人如何从服务器获取邮件？::启动 UA，通过 POP3 或 IMAP 协议从服务器下载邮件。
- 电子邮件地址的标准格式是什么？::收件人邮箱名@邮箱所在主机的域名（如 abc@cskaoyan.com）。
- 邮件首部中哪个关键字是必填且指定收件人的？::To。
- 邮件首部与主体之间如何分隔？::以一个空行分隔。
- 邮件信封由谁生成？::邮件系统自动从首部提取信息生成，用户无须手动填写。
- MIME 的主要作用是什么？::将非 ASCII 数据编码为 ASCII 格式，使 SMTP 能传输多媒体和二进制数据。
- MIME 是否取代了 SMTP 协议？::否，MIME 是在 SMTP 基础上的扩展，不修改或取代 SMTP。
- MIME 定义了多少个新的首部字段？::5 个（版本、内容描述、内容标识、传送编码、内容类型）。
- 接收端收到 MIME 邮件后如何处理？::通过 MIME 对 ASCII 数据进行解码还原，恢复原始非 ASCII 内容。
- SMTP 协议使用的熟知端口号是多少？::25。
- SMTP 连接建立后服务器首先发送什么响应？::220 Service ready（服务就绪）。
- RCPT 命令的主要作用是什么？::预先验证收件人地址有效性，避免资源浪费。
- SMTP 邮件内容传送的结束标志是什么？::<CRLF>.<CRLF>（回车换行 + 点 + 回车换行）。
- SMTP 连接释放时客户端发送什么命令？::QUIT 命令。
- POP3 协议使用的端口号是多少？::110。
- POP3 支持的两种工作模式是什么？::下载并保留、下载并删除。
- IMAP 相比 POP3 的主要优势是什么？::支持服务器端文件夹管理、搜索和选择性获取邮件内容。
- IMAP 在低带宽环境下有何实用特性？::可只下载邮件首部或 MIME 某部分，无须下载整封邮件。
- 哪种协议需要维护用户的会话状态信息？::IMAP。
- Web 电子邮件服务中用户与服务器交互使用什么协议？::HTTP。
- Web 邮件服务中不同邮件服务器之间传递邮件使用什么协议？::SMTP。
- Gmail、Hotmail 等属于哪种类型的电子邮件服务？::基于 Web 的电子邮件服务。
