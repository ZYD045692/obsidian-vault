# 1.2 计算机网络体系结构与参考模型

> [!abstract] 一句话总结
> 网络体系结构通过分层将复杂系统解耦，利用垂直的服务接口与水平的对等协议，实现异构系统间的标准化通信。

## 核心要点
### 考点1：网络体系结构与分层原则
**网络体系结构是各层及其协议的集合，是抽象的功能定义，独立于具体的硬件或软件实现。**
分层原则：1.每层功能相对独立；2.接口清晰依赖少；3.定义独立于实现；4.下层对上层透明（单向服务）；5.利于标准化。

> [!tip] 考试怎么用
> 区分'体系结构'（抽象定义）与'实现'（具体软硬件），考题常问某功能属于哪者。

### 考点2：数据单元封装与传递
**数据在层间传递时，下层将上层的 PDU 作为 SDU，加上本层 PCI 封装成本层 PDU。**
关系公式：$n\text{-SDU} + n\text{-PCI} = n\text{-PDU} = (n-1)\text{-SDU}$。物理层 PDU 为比特，链路层为帧，网络层为分组，传输层为报文段/数据报。

> [!tip] 考试怎么用
> 牢记 PDU 名称及封装公式，注意接收方是逆向拆解过程。

### 考点3：协议、服务与接口
**协议是水平控制对等实体通信的规则（语法/语义/同步），服务是垂直向下层向上层提供的功能。**
协议三要素：1.语法（格式）；2.语义（动作/应答）；3.同步（时序/顺序）。服务通过 SAP 提供，下层协议对上层透明。

> [!tip] 考试怎么用
> 辨析'水平'与'垂直'，协议控制通信，服务提供功能，接口是访问点。

### 考点4：服务分类特性
**网络服务可按连接性（面向连接/无连接）、可靠性（可靠/不可靠）及应答机制进行分类。**
面向连接含建立、传输、释放三阶段；无连接为'尽最大努力交付'。可靠服务含检错纠错应答，不可靠服务不保证送达。

> [!tip] 考试怎么用
> 注意'尽最大努力交付'对应无连接且不可靠，可靠性可由高层协议弥补。

### 考点5：OSI 参考模型七层功能
**OSI 模型自下而上为物理、数据链路、网络、传输、会话、表示、应用层，各层职责明确。**
物理层传比特（机械/电气特性）；链路层传帧（差错/流量控制）；网络层传分组（路由/拥塞）；传输层端到端（复用/分用）；会话层管理会话；表示层格式转换/加密；应用层用户接口。

> [!tip] 考试怎么用
> 重点记忆传输层（端到端/端口）、网络层（主机到主机/IP）、链路层（节点到节点/MAC）的区别。

### 考点6：TCP/IP 模型与五层结构
**TCP/IP 模型分四层（网络接口、网际、传输、应用），实际教学常用融合两者的五层结构。**
网际层核心是 IP（无连接/不可靠）；传输层有 TCP（可靠/面向连接）和 UDP（不可靠/无连接）。五层结构：应用、传输、网络、数据链路、物理。

> [!tip] 考试怎么用
> 掌握 TCP/IP 各层对应 OSI 的哪些层，以及 IP 的核心地位（Everything over IP）。

### 考点7：OSI 与 TCP/IP 模型对比
**OSI 理论严谨但复杂未普及，TCP/IP 先有协议后成模型，简洁高效成为事实标准。**
差异：1.OSI 严格区分服务/协议/接口，TCP/IP 未明确；2.OSI 七层，TCP/IP 四层；3.OSI 先模型后协议，TCP/IP 反之；4.OSI 网络层支持两种模式，TCP/IP 网际层仅无连接。

> [!tip] 考试怎么用
> 理解为何 TCP/IP 成功（市场驱动、简洁），OSI 失败（复杂、缺乏商业驱动）。

## 易混与对比
**协议 vs 服务 vs 接口**

|概念|方向|定义|可见性|
|---|---|---|---|
|协议|水平|控制对等实体通信的规则（语法/语义/同步）|对等层可见|
|服务|垂直|下层为上层提供的功能调用|上层可见，底层细节透明|
|接口|垂直|相邻层交换信息的逻辑点（SAP）|层间访问入口|

**各层通信范围与寻址**

|层次|通信范围|寻址依据|数据单元|
|---|---|---|---|
|数据链路层|节点到节点（相邻）|MAC 地址|帧|
|网络层|主机到主机|IP 地址|分组/IP 数据报|
|传输层|进程到进程（端到端）|端口号|报文段/数据报|

**OSI 与 TCP/IP 层次对应**

|OSI 七层|TCP/IP 四层|五层结构|
|---|---|---|
|应用层、表示层、会话层|应用层|应用层|
|传输层|传输层|传输层|
|网络层|网际层|网络层|
|数据链路层、物理层|网络接口层|数据链路层、物理层|

## 闪卡
#card
- 计算机网络体系结构的定义是什么？::计算机网络各层及其协议的集合，是对网络功能的精确定义。
- 体系结构与实现的区别是什么？::体系结构是抽象的功能定义，实现是具体的硬件或软件执行。
- 分层结构中第 n 层实体的定义？::第 n 层的活动元素，指任何可发送或接收信息的硬件或软件进程。
- 对等实体是指什么？::不同机器上同一层的实体互为对等实体。
- 上层能否跨层调用下层服务？::不能，上层只能通过相邻层接口使用下层服务。
- 协议数据单元（PDU）的定义？::对等层之间传送的数据单位，由 SDU 和 PCI 组成。
- 服务数据单元（SDU）的定义？::相邻层之间交换的数据单位，即上层传下来的 PDU。
- 写出 n 层 PDU、SDU 与 PCI 的关系式。::$n\text{-PDU} = n\text{-SDU} + n\text{-PCI}$
- 数据链路层的 PDU 叫什么？::帧（Frame）。
- 传输层的 PDU 叫什么？::TCP 报文段或 UDP 数据报。
- 网络协议的三要素是什么？::语法（格式）、语义（动作）、同步（时序）。
- 协议的'同步'要素规定什么？::规定执行操作的条件及事件发生的先后顺序。
- 服务访问点（SAP）的作用？::同一节点内相邻两层实体交换信息的逻辑接口，是上层访问下层服务的入口。
- 协议与服务在方向上有何不同？::协议是水平的（对等层间），服务是垂直的（相邻层间）。
- 下层协议对上层是否可见？::不可见，下层协议对上层是透明的。
- 面向连接服务的三个阶段？::连接建立、数据传输、连接释放。
- 什么是'尽最大努力交付'？::无连接服务，不预先建立连接，不保证可靠性，分组独立传输。
- 可靠服务的核心机制有哪些？::检错、纠错和应答机制，确保数据正确完整有序。
- 无应答服务如何确认数据收到？::接收方不自动返回应答，需由高层协议或应用实现确认。
- 不可靠网络如何实现可靠传输？::由高层协议（如接收方校验、出错重传）保障可靠性。
- OSI 模型中负责路由选择的层？::网络层。
- 传输层实现的是什么通信？::不同主机中进程之间的端到端通信。
- 数据链路层的主要作用？::将物理连接改造为逻辑无差错链路，实现节点间差错与流量控制。
- 表示层处理哪些功能？::数据格式转换、压缩、加密与解密。
- 会话层的检查点功能作用？::通信中断时从最近检查点恢复，实现断点续传。
- TCP/IP 模型的网际层对应 OSI 哪层？::网络层。
- TCP/IP 模型中提供可靠传输的协议？::TCP（传输控制协议）。
- IP 协议提供的服务类型？::无连接、不可靠的服务。
- 五层协议体系结构自下而上依次是？::物理层、数据链路层、网络层、传输层、应用层。
- TCP/IP 应用层对应 OSI 的哪些层？::会话层、表示层和应用层。
- OSI 模型的最大贡献是什么？::精确定义了'服务'、'协议'、'接口'三个核心概念。
- TCP/IP 模型网际层支持面向连接吗？::不支持，仅提供无连接服务。
- 为何 OSI 模型未广泛实现？::结构复杂、效率低、缺乏市场与商业驱动力。
- TCP/IP 模型的设计哲学？::Everything over IP 和 IP over Everything。
- OSI 传输层提供什么服务？::仅提供面向连接的可靠服务。
