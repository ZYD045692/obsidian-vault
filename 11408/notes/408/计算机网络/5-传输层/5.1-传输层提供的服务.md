# 5.1 传输层提供的服务

> [!abstract] 一句话总结
> 传输层通过端口实现进程间端到端逻辑通信，利用 TCP/UDP 分别提供可靠面向连接与不可靠无连接服务以屏蔽底层网络差异。

## 核心要点
### 考点1：传输层核心功能
**传输层为不同主机上的应用进程提供逻辑通信，具备复用分用、差错检测及屏蔽底层网络复杂性的能力。**
即使网络层不可靠（丢失/失序/重复），传输层仍能提供可靠服务；TCP 对整个报文（首部 + 数据）校验，IP 仅校验首部。

> [!tip] 考试怎么用
> 区分网络层与传输层差错检测范围：IP 只查头，TCP 查全报文；注意复用分用在两层的不同含义。

### 考点2：端口号分类与分配
**端口号长 16 比特共 65536 个，仅具本地意义，分为熟知端口、登记端口和短暂端口三类。**
熟知端口 $0 \sim 1023$（IANA 分配）；登记端口 $1024 \sim 49151$；短暂端口 $49152 \sim 65535$（客户端动态分配）。

> [!tip] 考试怎么用
> 牢记常见熟知端口号（FTP 21, SSH 22, Telnet 23, SMTP 25, DNS 53, HTTP 80）；注意 UDP/TCP 端口号彼此独立。

### 考点3：套接字定义与作用
**套接字由 IP 地址与端口号拼接而成，唯一标识网络中某台主机上的一个应用进程，是通信的端点。**
$$套接字 (Socket)=(IP 地址：端口号 )$$；同一 IP 或同一端口号可参与多个不同的 TCP 连接。

> [!tip] 考试怎么用
> 理解五元组确定唯一连接，单靠 IP 或单靠端口无法唯一标识进程；注意源端口作为“返回地址”的作用。

### 考点4：TCP 与 UDP 服务特性对比
**TCP 提供面向连接的可靠全双工信道，UDP 提供无连接的不可靠信道，两者适用场景截然不同。**
TCP 需建立/释放连接，支持确认/流量控制/重传；UDP 无连接、无确认，仅提供复用分用和差错检测。

> [!tip] 考试怎么用
> 根据应用需求选协议：高可靠选 TCP（HTTP/FTP/SMTP），低时延/容忍丢包选 UDP（DNS/TFTP/RIP/DHCP）。

## 易混与对比
**网络层与传输层复用分用的区别**

|层级|复用含义|分用依据|
|---|---|---|
|网络层|将不同传输层协议数据封装成 IP 数据报|IP 首部“协议”字段|
|传输层|多个应用进程使用同一传输层协议|首部“端口号”字段|

**IP 数据报与 UDP 数据报的校验范围**

|协议|校验对象|出错处理|
|---|---|---|
|IP (网络层)|仅首部|丢弃，不通知发送方|
|TCP (传输层)|首部 + 数据|要求重传|
|UDP (传输层)|首部 + 数据|直接丢弃|

- **IP 数据报与 UDP 数据报的可见性**：IP 数据报在网络层经路由器存储转发，路由器可见其首部；UDP 数据报作为 IP 数据报的载荷，在网络层传输时对路由器不可见，路由器不检查 UDP 内容。

## 闪卡
#card
- 传输层通信的真正端点是什么？::主机中的进程，而非主机本身。
- TCP 发现报文出错如何处理？::要求发送方重传。
- UDP 发现数据报出错如何处理？::直接丢弃，不重传。
- 传输层复用是指什么？::发送方多个进程使用同一传输层协议传送数据。
- 网络层分用的依据是什么字段？::IP 数据报首部的协议字段。
- 端口号的总数量是多少？::$2^{16}=65536$个。
- 熟知端口号的范围是多少？::0 到 1023。
- 客户端使用的短暂端口号范围？::49152 到 65535。
- 不同主机的相同端口号有关联吗？::无关联，端口号仅具本地意义。
- HTTP 协议对应的熟知端口号？::80。
- 套接字的构成公式是什么？::(IP 地址：端口号)。
- 套接字在网络中的作用？::唯一标识主机上的应用进程，作为通信端点。
- 同一 IP 地址能否参与多个 TCP 连接？::能，只要端口号不同或对方 IP/端口不同。
- B 回复 A 时，目的端口如何确定？::使用 A 原报文中的源端口号。
- UDP 和 TCP 的端口号是否独立？::是，彼此独立。
- TCP 是否提供广播或多播服务？::不提供，仅支持单播。
- UDP 在 IP 层之上提供哪两项服务？::多路复用与分用、数据差错检测。
- DNS 协议通常使用哪种传输层协议？::UDP。
- SMTP 协议使用哪种传输层协议？::TCP。
- TCP 可靠传输的代价是什么？::首部开销大、处理资源消耗高。
