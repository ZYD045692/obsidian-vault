# 4.5 IP 多播

> [!abstract] 一句话总结
> IP 多播通过 D 类地址实现一对多通信，利用 IGMP 管理本地组成员并构建多播转发树以节省网络资源。

## 核心要点
### 考点1：多播概念与优势
**多播是一对多通信，源主机发送单个分组经路由器复制后抵达组内所有主机，显著节省带宽和服务器负载。**
单播需发送 $N$ 份分组，多播仅发送 $1$ 份，在分岔节点复制转发。

> [!tip] 考试怎么用
> 区分单播与多播在分岔节点的行为：单播直接转发不同副本，多播仅在分岔处复制。

### 考点2：IP 多播地址特性
**IP 多播地址即 IPv4 D 类地址（224.0.0.0~239.255.255.255），前四位为 1110，仅能作目的地址。**
D 类地址范围：$224.0.0.0 \sim 239.255.255.255$，支持 $2^{28}$ 个多播组。

> [!tip] 考试怎么用
> 牢记多播地址不能作源地址，且不产生 ICMP 差错报文，协议字段依上层而定（UDP 为 17，IGMP 为 2）。

### 考点3：局域网硬件多播映射
**IP 多播地址映射为以太网多播 MAC 地址时，高 5 位丢失，导致 32 个 IP 地址映射到同一 MAC 地址。**
映射关系：IP 后 23 位映射到 MAC 后 23 位，前 25 位固定为 01-00-5E-00-00-00 至 01-00-5E-7F-FF-FF。

> [!tip] 考试怎么用
> 主机收到帧后必须在 IP 层过滤，丢弃不属于本机多播组的数据报，因为存在多对一映射冲突。

### 考点4：IGMP 协议功能
**IGMP 用于本地局域网内主机与多播路由器通信，报告加入或退出多播组，不管理全网成员分布。**
阶段一：主机发送 IGMP 报文声明加入；阶段二：路由器周期性查询，无响应则停止通告。

> [!tip] 考试怎么用
> IGMP 仅作用于本地子网，路由器靠它知晓本地是否有活跃成员，而非全局成员数量。

### 考点5：多播路由选择机制
**多播路由旨在构造以源主机为根的多播转发树，确保每条链路只传送一次且无重复数据报。**
转发树特性：不同多播组对应不同树；同组不同源主机也对应不同树。

> [!tip] 考试怎么用
> 多播转发树是动态构建的，核心目标是避免环路和重复接收，实现最小代价分发。

## 易混与对比
**单播与多播的传输效率对比**

|特性|单播|多播|
|---|---|---|
|发送份数|$N$ 份（$N$ 为目的主机数）|1 份|
|路由器行为|直接转发不同副本|仅在分岔节点复制|
|服务器负载|高|低|

**IP 多播地址与 MAC 地址映射关系**

|项目|IP 多播地址 (D 类)|以太网多播 MAC 地址|
|---|---|---|
|可用位数|28 位|23 位 (后 23 位)|
|映射比例|32 个 IP 地址|1 个 MAC 地址|
|冲突处理|需 IP 层过滤|硬件直接接收所有映射帧|

**IGMP 与多播路由协议的区别**

|协议|作用范围|主要功能|
|---|---|---|
|IGMP|本地局域网|管理主机加入/退出，告知路由器本地有无成员|
|多播路由协议|互联网范围|协同其他路由器，构建转发树分发数据报|

## 闪卡
#card
- 多播通信的基本模式是什么？::一对多通信，源发送单份分组，路由器在分岔点复制。
- 多播相比单播的核心优势？::大幅减轻服务器负担和网络负载，节省带宽资源。
- 多播分组何时被复制？::仅在传输路径遇到分岔节点时被复制并转发。
- 支持多播的路由器称为什么？::多播路由器，需支持多播路由协议。
- IP 多播地址属于哪类 IP 地址？::D 类地址，前四位二进制为 1110。
- D 类地址的十进制范围是多少？::224.0.0.0 到 239.255.255.255。
- 多播地址能否用作源地址？::不能，只能用于目的地址。
- 对多播数据报是否产生 ICMP 差错报文？::不产生 ICMP 差错报文。
- 多播机制适用于 TCP 还是 UDP？::仅适用于 UDP，TCP 是一对一连接无法支持多播。
- 以太网多播 MAC 地址的前 25 位特征？::保持不变，范围为 01-00-5E-00-00-00 到 01-00-5E-7F-FF-FF。
- D 类 IP 地址有多少位用于标志多播组？::28 位，但只有低 23 位能映射到 MAC 地址。
- 多少个不同的 IP 多播地址会映射到同一个 MAC 地址？::32 个（$2^5$），因为高 5 位无法映射。
- 主机如何解决 MAC 地址映射冲突？::在 IP 层检查目的 IP 地址，丢弃非本组数据报。
- IGMP 协议的作用范围是哪里？::仅作用于本地局域网（子网），不管理互联网范围。
- 主机加入多播组时发送什么报文？::向多播 IP 地址发送 IGMP 报文声明加入。
- 路由器如何探测组内是否有活跃成员？::周期性查询本地主机，只要有一台响应即认为活跃。
- 路由器何时停止通告某组成员关系？::连续多次查询无任何主机响应时。
- IGMP 报文封装在什么协议中？::封装在 IP 数据报中，协议字段值为 2。
- 多播路由选择的目标结构是什么？::构造一棵以源主机为根节点的多播转发树。
- 多播转发树上分组传送有何特点？::每条链路上仅传送一次，路由器不会收到重复数据报。
- 不同多播组的转发树是否相同？::不同，每个多播组对应不同的转发树。
- 同一多播组不同源主机的转发树是否相同？::不同，源主机不同则对应的转发树也不同。
