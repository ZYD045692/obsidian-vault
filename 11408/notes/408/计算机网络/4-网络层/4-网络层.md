# 网络层

> [!abstract] 一句话总结
> 网络层通过无连接的数据报服务和动态路由算法，在异构网络间实现主机到主机的逻辑寻址与分组转发，核心矛盾在于路由表的规模压缩与转发效率的平衡。

## 核心考点
### 考点1：网络层服务模型与 SDN 架构
**互联网网络层提供无连接、尽最大努力交付的数据报服务，而 SDN 通过控制平面与数据平面解耦实现集中式路由管理。**
数据报特点：无需建立连接、分组独立选路、不保证有序可靠；SDN 架构：控制器（控制平面）+ 交换机（数据平面），通过 OpenFlow 南向接口下发流表。

> [!tip] 考试怎么用
> 区分虚电路与数据报的 5 大差异（连接、地址、路由、顺序、可靠性）；记住 SDN 南向接口连接控制器与转发设备。

### 考点2：IPv4 分组格式与分片机制
**IPv4 首部包含标识、标志和片偏移字段以支持分片，分片仅在目的主机重组，中间路由器可再次分片。**
分片条件：数据报长度 $>$ MTU 且 $DF=0$；片偏移单位：$8B$；重组依据：标识字段相同、片偏移连续、$MF=0$ 为最后一片。

> [!tip] 考试怎么用
> 计算分片数时注意每片需加 20B 首部；片偏移必须是 8 的整数倍（除最后一片）；TTL 每跳减 1，为 0 时丢弃。

### 考点3：IP 地址分类、子网划分与 CIDR
**CIDR 消除分类地址限制，采用网络前缀和最长前缀匹配机制，支持路由聚合以压缩路由表。**
CIDR 记法：$IP/前缀长度$；子网掩码运算：$网络地址 = IP \ AND \ Mask$；路由聚合：提取共同前缀，如 $206.1.0.0/16$ 聚合两个$/17$。

> [!tip] 考试怎么用
> 计算可用主机数需减 2（网络地址 + 广播地址）；最长前缀匹配优先匹配掩码最长的路由项；私有地址不可在互联网路由。

### 考点4：NAT、ARP 与 DHCP 协议机制
**NAT 实现私有地址与公网地址映射，ARP 解析同局域网 IP 到 MAC 映射，DHCP 动态分配 IP 配置信息。**
NAT 转换表：$\{私 IP:端口\} \leftrightarrow \{公 IP:端口\}$；ARP 流程：广播请求（FF-FF-FF-FF-FF-FF）-> 单播响应；DHCP 四步：Discover-Offer-Request-ACK。

> [!tip] 考试怎么用
> ARP 仅作用于同一广播域，跨网通信解析的是默认网关 MAC；DHCP 客户端初始源 IP 为 0.0.0.0，目的 IP 为 255.255.255.255。

### 考点5：ICMP 协议与差错控制
**ICMP 用于报告网络差错和询问状态，封装在 IP 数据报中，但不报告 ICMP 差错或多播/广播地址的差错。**
差错类型：终点不可达、时间超过（TTL=0）、参数问题、重定向；应用：Ping（回送请求/回答）、Traceroute（利用 TTL 超时）。

> [!tip] 考试怎么用
> Traceroute 原理是逐步增大 TTL 触发沿途路由器的 ICMP 时间超过报文；不对 ICMP 差错报文本身再发差错报告。

### 考点6：IPv6 地址结构与过渡技术
**IPv6 地址长 128 位，取消首部检验和与中间分片，通过双协议栈和隧道技术实现向 IPv4 过渡。**
地址类型：单播、多播、任播（就近交付）；首部简化：固定 40B，无检验和，分片仅由源主机进行；过渡：双栈（同时运行）、隧道（IPv6 封装在 IPv4 中）。

> [!tip] 考试怎么用
> IPv6 任播地址标识一组接口，但只交付给最近的一个；双冒号::在一个地址中只能出现一次。

### 考点7：距离向量路由算法与 RIP 协议
**RIP 基于距离向量算法，以跳数为度量，最大跳数 15，存在好消息传得快、坏消息传得慢的问题。**
更新规则：$d_x(y) = \min\{c(x,v) + d_v(y)\}$；度量：跳数（直连为 1）；缺陷：无穷计数问题，收敛慢；传输层：UDP 端口 520。

> [!tip] 考试怎么用
> RIP 交换的是完整路由表；跳数 16 表示不可达；收到邻居路由表先加 1 再比较更新。

### 考点8：链路状态路由算法与 OSPF 协议
**OSPF 基于链路状态算法，使用 Dijkstra 计算最短路径，支持区域划分和负载均衡，收敛速度快于 RIP。**
机制：洪泛法发送链路状态（LSA），构建 LSDB，运行 Dijkstra；分层：主干区域（Area 0）连接其他区域；传输层：直接封装在 IP 中（协议号 89）。

> [!tip] 考试怎么用
> OSPF 发送的是链路状态信息而非路由表；仅在链路状态变化时触发更新；支持 VLSM 和认证。

### 考点9：边界网关协议 BGP
**BGP 是外部网关协议，采用路径向量算法，基于 TCP 连接，旨在寻找可达且较好的路由而非绝对最优。**
路由属性：AS-PATH（经过的 AS 序列）、NEXT-HOP；选路原则：本地偏好 > AS 路径最短 > 热土豆路由；会话：eBGP（跨 AS）、iBGP（AS 内）。

> [!tip] 考试怎么用
> BGP 交换的是 AS 路径而非具体路由器；iBGP 会话不需要物理直连；BGP 报文类型：Open, Update, Keepalive, Notification。

### 考点10：IP 多播与移动 IP
**IP 多播利用 D 类地址和 IGMP 协议实现一对多通信，移动 IP 通过归属代理和转交地址保持移动主机 IP 不变。**
多播地址：224.0.0.0~239.255.255.255；IGMP：管理组成员关系；移动 IP 实体：移动节点、归属代理、外地代理；隧道技术：归属代理封装分组至转交地址。

> [!tip] 考试怎么用
> 多播 MAC 地址映射是多对一（32 个 IP 映射到 1 个 MAC）；移动主机发送数据时直接用永久地址，无需经过归属代理。

## 易混与对比
**路由器、交换机与集线器的域划分**

|设备|工作层次|冲突域|广播域|
|---|---|---|---|
|集线器|物理层|所有端口同一冲突域|所有端口同一广播域|
|交换机/网桥|数据链路层|每个端口独立冲突域|所有端口同一广播域|
|路由器|网络层|每个端口独立冲突域|每个端口独立广播域|

**RIP、OSPF 与 BGP 协议对比**

|特性|RIP|OSPF|BGP|
|---|---|---|---|
|类型|内部网关协议 (IGP)|内部网关协议 (IGP)|外部网关协议 (EGP)|
|算法|距离向量|链路状态|路径向量|
|度量|跳数 (Max 15)|代价 (带宽等)|策略/AS 路径|
|传输协议|UDP (520)|IP (协议号 89)|TCP (179)|
|收敛速度|慢 (坏消息慢)|快|较慢 (策略复杂)|

**虚电路与数据报服务对比**

|特性|虚电路 (VC)|数据报 (Datagram)|
|---|---|---|
|连接建立|需要 (呼叫请求/应答)|不需要|
|地址携带|仅建立时用完整地址，后用 VCID|每个分组携带完整源/目的 IP|
|路由选择|建立时确定，路径固定|每个分组独立选路，路径可变|
|可靠性|网络保证 (有序、不丢失)|网络不保证 (尽最大努力)|
|故障适应|差 (故障导致连接中断)|强 (动态绕开故障)|

**NAT 与普通路由器转发区别**

|操作|普通路由器|NAT 路由器|
|---|---|---|
|IP 地址修改|不修改源/目的 IP|出站改源 IP，入站改目的 IP|
|端口处理|不处理传输层端口|需查看并转换端口号 (NAPT)|
|工作层次|纯网络层|网络层 + 传输层特征|
|转发表依据|目的 IP 网络前缀|NAT 转换表 (IP:Port 映射)|

**ARP 解析场景辨析**

|场景|发送方|接收方|ARP 解析目标|
|---|---|---|---|
|同网通信|主机 A|主机 B|主机 B 的 MAC 地址|
|跨网通信|主机 A|主机 B (异网)|默认网关的 MAC 地址|
|路由器转发|路由器 R1|主机 C (直连)|主机 C 的 MAC 地址|
|路由器转发|路由器 R1|主机 D (非直连)|下一跳路由器 R2 的 MAC 地址|

## 闪卡
#card
- 数据报服务中，若某链路故障，后续分组如何处理？::路由器动态更新转发表，后续分组自动选择新路径，可能失序到达。
- SDN 架构中，负责计算最优路径并下发流表的是哪个平面？::控制平面（由逻辑集中的远程控制器实现）。
- 虚电路服务在哪个阶段确定传输路径？::连接建立阶段，一旦建立路径即固定，直到连接释放。
- SDN 的南向接口主要使用什么协议通信？::OpenFlow 协议，用于控制器与转发设备间的双向通信。
- IP 数据报分片后，哪个字段在所有分片中保持不变？::标识（Identification）字段，用于目的主机重组原始数据报。
- 若 IP 首部 TTL 字段初值为 1，该数据报能经过几个路由器？::0 个，仅限本局域网传输，经过第一个路由器时 TTL 减为 0 被丢弃。
- IP 分片中，片偏移字段的单位是多少字节？::8 字节，除最后一个分片外，数据长度必须是 8 的整数倍。
- DF 标志位为 1 时，若数据报长度超过 MTU 会发生什么？::路由器丢弃该数据报，并向源点发送 ICMP 终点不可达报文。
- CIDR 地址块 192.168.0.0/22 包含多少个 IP 地址？::$2^{32-22} = 2^{10} = 1024$ 个地址。
- 路由表中存在 192.168.1.0/24 和 192.168.0.0/16，目的 IP 为 192.168.1.5 时匹配哪项？::匹配 192.168.1.0/24，遵循最长前缀匹配原则。
- 将 C 类网络 192.168.1.0 划分为 4 个子网，子网掩码是多少？::借 2 位主机号，掩码为 255.255.255.192（即/26）。
- 私有 IP 地址 172.16.0.0/12 的范围是什么？::172.16.0.0 到 172.31.255.255，共 16 个连续的 B 类网络。
- 主机 A 向异网主机 B 发送数据，ARP 解析的是谁的 MAC 地址？::解析默认网关（路由器接口）的 MAC 地址，而非主机 B 的 MAC。
- DHCP 客户端在发送 Discover 报文时，源 IP 地址填什么？::0.0.0.0，因为此时客户端尚未获得 IP 地址。
- NAT 路由器在转发分组时，会修改 IP 首部的哪些字段？::出站修改源 IP 和源端口，入站修改目的 IP 和目的端口。
- ARP 响应报文是以什么方式发送的？::单播发送，直接回复给请求者的 MAC 地址。
- Traceroute 工具利用 ICMP 的哪种报文来探测路径？::利用路由器返回的 ICMP 时间超过（Time Exceeded）报文。
- 当路由器丢弃 TTL 为 0 的数据报时，向谁发送什么报文？::向源主机发送 ICMP 时间超过报文。
- 对于目的地址是多播地址的数据报，是否发送 ICMP 差错报告？::不发送，避免产生大量无用反馈。
- Ping 命令使用了 ICMP 的哪两种报文？::回送请求（Echo Request）和回送回答（Echo Reply）。
- IPv6 地址中，::符号的使用有什么限制？::在一个地址中只能使用一次，用于替换连续的全零组。
- IPv6 允许中间路由器对数据报进行分片吗？::不允许，分片只能由源主机进行。
- IPv6 的任播（Anycast）地址有何特点？::标识一组接口，数据报仅交付给路由距离最近的一个接口。
- 双协议栈过渡技术中，主机如何决定使用 IPv4 还是 IPv6？::通过 DNS 查询结果：返回 IPv4 地址则用 IPv4，返回 IPv6 则用 IPv6。
- RIP 协议中，跳数为 16 代表什么含义？::代表目的网络不可达。
- RIP 协议中“坏消息传播得慢”会导致什么问题？::导致无穷计数问题，路由器间循环更新错误路由直到达到 16。
- RIP 路由器每隔多久向邻居发送一次路由更新？::默认每隔 30 秒发送一次完整的路由表。
- RIP 协议直接使用 IP 数据报传送吗？::不是，RIP 是应用层协议，使用 UDP 传送（端口 520）。
- OSPF 协议使用什么算法计算最短路径？::Dijkstra 最短路径算法。
- OSPF 中，所有区域必须连接到哪个特殊区域？::主干区域（Area 0），用于连通其他区域。
- OSPF 路由器之间交换的是什么信息？::交换本路由器与相邻路由器的链路状态信息，而非完整路由表。
- OSPF 协议数据是直接封装在 IP 数据报中吗？::是，OSPF 是网络层协议，直接使用 IP 数据报传送（协议号 89）。
- BGP 协议使用哪种传输层协议建立连接？::TCP，端口号为 179。
- BGP 路由选择中，若本地偏好相同，优先选择哪条路由？::选择 AS-PATH 最短（经过自治系统数量最少）的路由。
- BGP 中的 AS-PATH 属性记录了什么信息？::记录了该路由所经过的自治系统（AS）的序列。
- 同一 AS 内的 BGP 路由器之间建立的会话称为什么？::内部 BGP（iBGP）会话。
- IPv4 多播地址属于哪一类地址？::D 类地址，范围是 224.0.0.0 到 239.255.255.255。
- 移动 IP 中，负责截获发往移动节点分组并转发的是谁？::归属代理（Home Agent）。
- 以太网多播 MAC 地址与 IP 多播地址的映射关系是怎样的？::多对一映射，32 个不同的 IP 多播地址可能映射到同一个 MAC 地址。
- 移动节点在被访网络发送数据时，源 IP 地址填什么？::填其永久地址（归属地址），无需经过归属代理转发。
