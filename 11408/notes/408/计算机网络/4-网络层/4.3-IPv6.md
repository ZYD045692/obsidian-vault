# 4.3 IPv6

> [!abstract] 一句话总结
> IPv6 通过 128 位地址空间解决耗尽问题，以固定 40B 首部、扩展首部机制及双栈/隧道技术实现高效路由与平滑过渡。

## 核心要点
### 考点1：IPv6 主要特点
**IPv6 拥有更大地址空间、固定首部、仅源主机分片、支持即插即用及资源预分配，从根本上解决 IPv4 地址耗尽问题。**
地址空间倍数：$2^{128}/2^{32}=2^{96}$；首部长度：固定 40B；分片策略：仅源主机分片，路由器不分片。

> [!tip] 考试怎么用
> 注意区分 IPv4 与 IPv6 在分片位置（源 vs 路由器）、首部长度（可变 vs 固定）及检验和（有 vs 无）上的差异。

### 考点2：IPv6 基本首部格式
**IPv6 基本首部固定 40B，含 8 个字段，取消了检验和、选项及分片相关字段，改用扩展首部实现灵活功能。**
字段列表：版本 (4)、通信量类 (8)、流标号 (20)、有效载荷长度 (16)、下一个首部 (8)、跳数限制 (8)、源/目的地址 (128)。

> [!tip] 考试怎么用
> 牢记‘取消’的字段（检验和、总长度、标识/标志/片偏移、选项），‘下一个首部’字段兼具 IPv4 协议字段和扩展首部指针功能。

### 考点3：IPv6 地址类型
**IPv6 地址分为单播、多播和任播三类，其中任播是新增类型，实现“一址多用、就近交付”。**
任播定义：标识一组接口，数据报仅交付给路由距离最近的一个；多播：一点对多点；单播：点对点。

> [!tip] 考试怎么用
> 重点掌握任播的定义及交付规则，区分其与多播（交付给所有组成员）的不同。

### 考点4：IPv6 地址表示与特殊地址
**IPv6 采用冒号十六进制记法，支持前导零省略和双冒号替换（仅一次），包含未指明、环回等特殊地址。**
缩写规则：1.省略前导零；2.双冒号::替换连续全零组（仅用一次）；环回地址：::1/128；未指明：::/128。

> [!tip] 考试怎么用
> 双冒号在一个地址中只能出现一次；未指明地址不能作目的地址；环回地址只有一个。

### 考点5：IPv4 向 IPv6 过渡策略
**过渡采用双协议栈和隧道技术，双栈通过 DNS 选择协议，隧道将 IPv6 数据报封装在 IPv4 中传输。**
双协议栈：主机同时配 IPv4/IPv6 地址，依 DNS 返回类型选择；隧道技术：IPv6 数据报封装为 IPv4 数据部分穿越 IPv4 网络。

> [!tip] 考试怎么用
> 明确双栈是“同时安装”，隧道是“封装传输”；双栈依赖 DNS 解析结果决定使用哪种协议。

## 易混与对比
**IPv4 与 IPv6 首部关键字段对比**

|特性|IPv4|IPv6|
|---|---|---|
|首部长度|可变 (4B 整数倍)|固定 40B|
|检验和|有 (首部检验和)|无 (取消)|
|分片位置|源主机和路由器|仅源主机|
|分片字段|标识、标志、片偏移 (在基本首部)|移至分片扩展首部|
|选项处理|在基本首部可变部分|在扩展首部|
|地址长度|32 位|128 位|

**IPv6 特殊地址用途辨析**

|地址类型|CIDR 记法|用途限制|
|---|---|---|
|未指明地址|::/128|不能作目的地址，仅作未配置主机的源地址|
|环回地址|::1/128|仅定义这一个，作用同 IPv4 环回|
|本地链路单播|FE80::/10|仅本地链路通信，路由器不转发|
|多播地址|FF00::/8|一点对多点，占地址空间 1/256|

**双协议栈与隧道技术区别**

|策略|实现方式|依赖条件|
|---|---|---|
|双协议栈|主机同时运行两套协议栈|依赖 DNS 解析返回的地址类型|
|隧道技术|将 IPv6 包封装在 IPv4 包内|需穿越 IPv4 网络区域|
|核心差异|终端同时具备两种能力|利用现有 IPv4 设施传输 IPv6 数据|

#card
- IPv6 地址空间是 IPv4 的多少倍？::$2^{96}$倍
- IPv6 数据报的分片操作由谁执行？::仅由源主机执行，中间路由器不允许分片
- IPv6 基本首部的长度是多少？::固定为 40 字节
- IPv6 是否支持即插即用自动配置？::支持，通常不需要使用 DHCP
- IPv6 如何处理实时音频视频的资源需求？::支持资源的预分配以保证带宽和时延
- IPv6 基本首部中哪个字段替代了 IPv4 的 TTL？::跳数限制字段
- IPv6 基本首部为何取消首部检验和字段？::因传输层已提供差错检测，为加快路由器处理速度
- 流标号字段的作用是什么？::标识属于同一流的数据报，以便路由器提供特定服务质量
- 若存在扩展首部，'下一个首部'字段指示什么？::指示紧随其后的第一个扩展首部的类型
- IPv6 基本首部中有效载荷长度字段最大值是多少？::65535 字节
- IPv6 新增的地址类型及其交付规则是什么？::任播，交付给一组接口中路由距离最近的一个
- 多播地址的数据报发送给谁？::发送给所有加入该多播组的接口
- 单播地址的通信模式是什么？::传统的点对点通信，发送给唯一指定的接收方
- 任播地址能否标识多个接口？::能，但数据报只交付给其中一个最近的接口
- IPv6 地址中双冒号::的使用限制是什么？::在一个地址中只能使用一次
- IPv6 的环回地址如何表示？::::1/128
- 未指明地址::/128 能否用作目的地址？::不能，仅用于尚未配置地址的主机作为源地址
- 地址 4BF5:0000:0000:0000:BA5F...如何最简缩写？::4BF5::BA5F...
- 多播地址的二进制前缀是什么？::11111111 (8 位)，即 FF00::/8
- 双协议栈主机如何决定使用 IPv4 还是 IPv6？::通过 DNS 返回的地址类型决定
- 隧道技术的核心操作是什么？::将 IPv6 数据报整个封装为 IPv4 数据报的数据部分
- 双协议栈主机需要配置几个 IP 地址？::两个，一个 IPv4 地址和一个 IPv6 地址
- 隧道技术中 IPv6 数据报何时被解封装？::当 IPv4 数据报离开 IPv4 网络后
