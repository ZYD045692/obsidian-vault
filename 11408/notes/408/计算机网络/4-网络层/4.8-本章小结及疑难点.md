# 4.8 本章小结及疑难点

> [!abstract] 一句话总结
> IP 层提供无连接不可靠的尽最大努力交付，依赖路由表逻辑寻址与 ARP 地址解析协同工作，路由器通过跨层解封装与重封装实现异构网络互连。

## 核心要点
### 考点1：尽最大努力交付的含义
**IP 不保证无差错、按时、按序、不重复交付，仅在首部检验和出错或缓存满时主动丢弃数据报。**
IP 层确保首部完整性（有错即丢），但不保证数据部分正确性；可靠性由高层协议（如 TCP）实现。

> [!tip] 考试怎么用
> 区分 IP 层保证的内容（首部完整）与不保证的内容（数据正确、可靠传输），注意丢弃数据报的两个特定条件。

### 考点2：ARP 请求与响应机制
**同局域网时目标主机单播响应自身 MAC；跨局域网时默认网关代理响应，返回网关接口 MAC。**
同网段：B 收到请求 -> B 单播响应 (返回 B 的 MAC)；跨网段：路由器代理 -> 路由器单播响应 (返回路由器接口 MAC)。

> [!tip] 考试怎么用
> 易错点是跨网段通信时，ARP 解析得到的是默认网关的 MAC 地址，而非最终目的主机的 MAC 地址。

### 考点3：路由转发与 ARP 协同
**路由器查路由表得下一跳 IP，再通过 ARP 解析为 MAC 填入帧首部，IP 数据报内容不被修改。**
流程：查路由表 (得下一跳 IP) -> ARP 解析 (得下一跳 MAC) -> 封装帧 -> 发送；路由表不能直接使用硬件地址。

> [!tip] 考试怎么用
> 理解 IP 地址抽象性的意义：避免路由表因使用平面化硬件地址而剧增，保持互联网可扩展性。

### 考点4：路由器的多层处理能力
**路由器工作在物理、数据链路、网络三层，通过解封装与重封装实现异构网络互连。**
物理层：收发比特流；链路层：解析 MAC、帧解/封装；网络层：读 IP 首部、查表转发；区别：中继器 (L1)、交换机 (L2)。

> [!tip] 考试怎么用
> 掌握路由器与中继器、交换机的本质区别在于能处理网络层协议并更换链路层帧头以适应不同网络。

## 易混与对比
**IP 可靠性 vs TCP 可靠性**

|特性|IP 层 (尽最大努力)|高层 (如 TCP)|
|:---|:---|:---|
|无差错交付|不保证 (仅保首部完整)|保证|
|按序交付|不保证|保证|
|不重复交付|不保证|保证|
|丢弃策略|仅校验错或缓存满|拥塞控制等机制|
|结论|提供不可靠服务|提供可靠传输服务|

**同网段 vs 跨网段 ARP 响应**

|场景|请求对象|响应者|返回的 MAC 地址|
|:---|:---|:---|:---|
|同局域网|目标主机 B|目标主机 B|B 的硬件地址|
|跨局域网|目标主机 B (不可达)|默认网关 (路由器)|路由器接口硬件地址|
|关键点|直接通信|代理 ARP 机制|下一跳而非终点的 MAC|

**路由器 vs 中继器 vs 交换机**

|设备|工作层次|核心功能|互连能力|
|:---|:---|:---|:---|
|中继器|物理层|接收发送比特流|仅同类型物理介质延伸|
|交换机|数据链路层|帧转发、MAC 解析|同类型链路层网络|
|路由器|网络层 + 下层|IP 查表、帧重封装|异构网络 (如以太网连 PPP)|

## 闪卡
#card
- IP 协议是否保证数据报按发送顺序交付？::不保证，IP 提供的是无序交付服务。
- IP 层在什么情况下会主动丢弃数据报？::仅当首部检验和出错或因缓存满无法处理时。
- 若应用需要可靠传输，应由哪一层协议实现？::由高层协议（如 TCP）实现，IP 层不负责。
- 交付给目的主机的 IP 数据报，其首部状态如何？::均未检出差错，因为出错的数据报已被丢弃。
- 主机 A 广播 ARP 请求获取同局域网主机 B 的 MAC，谁响应？::计算机 B 直接单播响应，返回 B 自身的硬件地址。
- 若目标主机 B 不在同一局域网，谁发送 ARP 响应？::连接该局域网的路由器（默认网关）代理发送响应。
- 跨局域网通信时，ARP 响应返回的是谁的硬件地址？::返回路由器在该局域网接口的硬件地址。
- ARP 请求无法到达非同一局域网的目标主机时如何处理？::由默认网关代理响应，解析出网关的 MAC 地址。
- 路由器转发数据报时，是否会修改 IP 数据报的内容？::不会修改 IP 数据报内容，仅重新封装帧。
- 路由器如何确定数据报的下一跳物理地址？::先查路由表得下一跳 IP，再用 ARP 解析为 MAC 地址。
- 能否在路由表中直接使用硬件地址以避免 ARP 查询？::不能，会导致表项剧增、管理复杂，破坏 IP 地址的抽象性。
- IP 地址抽象性对互联网的主要贡献是什么？::屏蔽底层网络差异，是互联网可扩展性的基础。
- 路由器在数据链路层主要完成什么操作？::识别帧结构、解析 MAC 地址、完成帧的解封装与重新封装。
- 路由器为何能互连以太网与 PPP 等底层技术不同的网络？::因为它能解封装输入帧并根据下一跳接口重新封装成新帧。
- 路由器与仅工作在物理层的中继器有何本质区别？::路由器能处理网络层协议并做出转发决策，中继器只能放大比特流。
- 路由器在网络层依据什么做出转发决策？::读取 IP 数据报首部，根据目的 IP 地址查询路由表。
