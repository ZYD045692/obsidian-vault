# 4.6 移动 IP

> [!abstract] 一句话总结
> 移动 IP 通过归属代理截获并隧道转发至转交地址，使移动节点在切换网络时保持永久 IP 不变以维持 TCP 连接。

## 核心要点
### 考点1：移动 IP 基本概念与实体
**移动 IP 允许移动主机切换接入点时保持永久 IP 不变，从而对上层应用透明并保障会话连续性。**
三种实体：移动节点（永久 IP）、归属代理（归属网络路由器）、外地代理（被访网络路由器）。

> [!tip] 考试怎么用
> 区分 DHCP 获取新 IP（非移动 IP）与移动 IP（IP 不变）；若 IP 变则 TCP 中断。

### 考点2：地址体系与转交地址
**移动站拥有固定的永久地址，漫游时由外地代理分配仅用于内部路由的临时转交地址。**
永久地址：$131.8.6.7/16$（归属网络 $131.8.0.0/16$）；转交地址：$15.5.6.7/8$（被访网络）。

> [!tip] 考试怎么用
> 转交地址应用程序不可见，仅用于移动站、归属代理和外地代理间通信。

### 考点3：移动 IP 通信流程
**通信者发往永久地址，归属代理截获后封装隧道至转交地址，外地代理解封装交付。**
流程：1.本地直连；2.漫游注册获转交地址；3.B→A：归属代理隧道封装转发；4.A→B：直接用永久地址源发；5.移动更新或注销。

> [!tip] 考试怎么用
> A 发送数据给 B 时不需经过归属代理，直接用永久地址作源地址经外地代理转发。

### 考点4：移动 IP 协议功能需求
**网络层需增加登记、注册、隧道封装和拆封四种新功能以支持移动 IP 机制。**
四功能：①移动站→外地代理登记；②外地代理→归属代理注册；③归属代理隧道封装；④外地代理隧道拆封。

> [!tip] 考试怎么用
> 记忆四个协议方向：登记（MN-FA）、注册（FA-HA）、封装（HA）、拆封（FA）。

## 易混与对比
**DHCP 动态获取 IP 与移动 IP 的区别**

|特性|DHCP 换网|移动 IP|
|---|---|---|
|IP 地址|改变（新网络网段）|不变（永久地址）|
|TCP 连接|中断|保持连续|
|机制本质|重新接入|隧道转发|
|应用场景|普通漫游|需会话保持的移动场景|

**数据发送方向的路径差异**

|方向|源地址|路径特点|是否经归属代理|
|---|---|---|---|
|B → A (接收)|B 的 IP|归属代理截获→隧道→外地代理|是|
|A → B (发送)|A 的永久地址|外地代理直接转发|否|

**三种地址的角色对比**

|地址类型|归属|使用者|可见性|
|---|---|---|---|
|永久地址|归属网络|应用程序、通信对端|全局可见|
|转交地址|被访网络|代理间通信|应用不可见|
|MAC 地址|链路层|外地代理→移动站交付|局部链路有效|

## 闪卡
#card
- 移动 IP 的核心目标是什么？::切换网络时保持永久 IP 不变，确保发往该站分组自动正确投递。
- 移动 IP 机制对哪一层完全透明？::对上层应用（如 TCP 连接）完全透明，保障会话连续性。
- 关机换网获新 IP 属于移动 IP 吗？::不属于，因 IP 地址已改变，无法维持原 TCP 连接。
- 归属代理部署在哪里？::连接在归属网络（初始接入网络）上的路由器。
- 外地代理的主要作用是什么？::连接在被访网络上，协助移动节点接收数据并分配转交地址。
- 永久地址与归属网络的关系？::关联固定不变，永久地址属于归属网络网段。
- 转交地址由谁分配？::由被访网络中的外地代理分配。
- 转交地址属于哪个网络？::属于被访网络（当前接入网络），标识移动站当前位置。
- 应用程序能否直接使用转交地址？::不能，转交地址仅用于代理间通信，对应用透明。
- 外地代理如何向移动站交付 IP 分组？::通过 MAC 地址进行链路层直接交付。
- 移动站在归属网络时如何通信？::按传统 TCP/IP 方式直接通信，无需代理介入。
- 漫游时移动站首先做什么？::向外地代理登记，获得临时转交地址并注册至归属代理。
- 归属代理收到发往 A 的分组如何处理？::截获分组，构建 IP 隧道封装后转发至转交地址。
- 移动站 A 发送数据给 B 的路径？::以永久地址为源，经外地代理直接转发，不经过归属代理。
- 移动站返回归属网络后做什么？::向归属代理注销转交地址，恢复本地直连通信。
- 移动站到外地代理需什么协议？::登记协议，用于移动站向外地代理申请转交地址。
- 外地代理到归属代理需什么协议？::注册协议，用于将转交地址通知归属代理。
- 归属代理需具备什么功能？::隧道封装协议，将原始分组封装在新 IP 包中。
- 外地代理接收隧道数据需什么功能？::隧道拆封协议，解封装还原原始分组。
- 移动 IP 新增功能位于哪一层？::网络层，需增加上述四种新功能。
