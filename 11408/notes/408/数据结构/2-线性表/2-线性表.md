# 线性表

> [!abstract] 一句话总结
> 线性表核心矛盾在于顺序存储的随机访问优势与链式存储的动态增删灵活性之间的权衡。

## 核心考点
### 考点1：线性表逻辑定义与基本操作
**线性表是 n 个相同类型元素的有限序列，具有唯一表头和表尾，元素间存在一对一逻辑关系。**
逻辑特性：$a_1$为表头，$a_n$为表尾；除首尾外，每个元素有且仅有一个直接前驱和后继。基本操作集：InitList, Length, LocateElem, ListInsert, ListDelete。

> [!tip] 考试怎么用
> 区分逻辑结构（线性表）与存储结构（顺序/链式），基本操作的具体实现依赖存储结构。

### 考点2：顺序表的存储结构与随机存取
**顺序表用连续存储单元依次存放元素，逻辑相邻即物理相邻，支持$O(1)$随机存取。**
地址公式：$LOC(a_i) = LOC(a_1) + (i-1) \times sizeof(ElemType)$。特点：存储密度高，但插入删除需移动大量元素。

> [!tip] 考试怎么用
> 注意位序从 1 开始，数组下标从 0 开始，计算地址或代码实现时需转换（$i-1$）。

### 考点3：顺序表插入删除的时间复杂度
**顺序表插入和删除操作的平均时间复杂度均为$O(n)$，主要耗时在元素移动。**
插入平均移动：$\frac{n}{2}$；删除平均移动：$\frac{n-1}{2}$。最好情况$O(1)$（表尾插/删），最坏$O(n)$（表头插/删）。

> [!tip] 考试怎么用
> 计算平均复杂度时，假设在每个位置操作概率相等，即$p_i = \frac{1}{n+1}$或$\frac{1}{n}$。

### 考点4：单链表结构与头结点优势
**单链表通过指针链接离散结点，引入头结点可统一空表与非空表、首结点与其他结点的操作。**
结点结构：data + next。头结点作用：1. 首元结点操作与其他结点一致；2. 空表时头指针非空（指向头结点）。

> [!tip] 考试怎么用
> 带头结点时，头指针 L 永远不为 NULL，判空条件是$L \rightarrow next == NULL$。

### 考点5：单链表插入删除的指针操作
**单链表插入删除需先定位前驱结点，修改指针顺序至关重要，防止断链。**
插入*s 到*p 后：$s \rightarrow next = p \rightarrow next; p \rightarrow next = s;$。删除*q（*p 后继）：$p \rightarrow next = q \rightarrow next; free(q);$。

> [!tip] 考试怎么用
> 插入时若先执行$p \rightarrow next = s$，会丢失原后继地址；删除时需先保存被删结点数据。

### 考点6：双链表的双向链接维护
**双链表结点含 prior 和 next 指针，插入删除需同时维护两个方向的链接，防止断链。**
在*p 后插*s：①$s \rightarrow next = p \rightarrow next$; ②$p \rightarrow next \rightarrow prior = s$; ③$s \rightarrow prior = p$; ④$p \rightarrow next = s$。

> [!tip] 考试怎么用
> 修改指针顺序有严格要求，必须先处理后继结点的 prior 指针，防止$p \rightarrow next$被覆盖后无法访问后继。

### 考点7：循环链表的环状特性与尾指针
**循环链表尾结点指针指向头结点形成环，使用尾指针可使头尾插入操作均达到$O(1)$。**
判空条件：$L \rightarrow next == L$（带头结点）。尾指针 r 优势：$r \rightarrow next$即头结点，访问首尾均快。

> [!tip] 考试怎么用
> 循环链表无 NULL 指针，遍历终止条件是回到头结点；合并两个循环链表只需修改两个指针。

### 考点8：静态链表的数组模拟机制
**静态链表用数组模拟链式存储，next 域存储后继元素的数组下标（游标），适合无指针语言。**
结构：$data$ + $next$（整型下标）。结束标志：$next = -1$。优点：无需指针，内存连续；缺点：容量固定。

> [!tip] 考试怎么用
> 静态链表的插入删除只需修改数组元素的 next 值，无需移动数据，但需管理空闲链表。

### 考点9：顺序表与链表的综合对比选型
**顺序表适合随机访问频繁、长度稳定的场景；链表适合增删频繁、长度变化大的场景。**
存取：顺序$O(1)$ vs 链$O(n)$。增删：顺序$O(n)$ vs 链$O(1)$（定位后）。空间：顺序密度高 vs 链有指针开销。

> [!tip] 考试怎么用
> 若需折半查找必须用顺序表；若表长未知且频繁增删，首选链表；若强调存储密度，选顺序表。

## 易混与对比
**头指针、头结点与首元结点**

|概念|定义|是否必选|作用|
|---|---|---|---|
|**头指针**|指向链表第一个结点的指针|必选|标识链表，为空时表示空表（不带头结点）|
|**头结点**|位于首元结点前的附加结点|可选|统一操作，使空表与非空表处理一致|
|**首元结点**|存储第一个数据元素的结点|必选|存放实际数据 $a_1$|

**随机存取 vs 顺序存取**

|特性|顺序表|链表|
|---|---|---|
|**物理结构**|地址连续|地址任意，指针链接|
|**访问方式**|随机存取（下标直接计算）|顺序存取（必须从头遍历）|
|**访问第 i 个元素**|$O(1)$|$O(n)$|
|**适用场景**|频繁查询、折半查找|频繁插入删除、长度不定|

**插入/删除操作的时间复杂度细节**

|操作类型|顺序表|链表（已知位置指针）|链表（仅知位序）|
|---|---|---|---|
|**主要开销**|移动元素|修改指针|查找前驱 + 修改指针|
|**平均复杂度**|$O(n)$|$O(1)$|$O(n)$|
|**原因**|需移动$n/2$个元素|仅需改几个指针|查找前驱需遍历$O(n)$|

**位序与数组下标的转换**

|概念|起始值|对应关系|常见错误|
|---|---|---|---|
|**线性表位序**|1|第$i$个元素|误用$i$直接访问数组|
|**数组下标**|0|第$i$个元素对应下标$i-1$|边界判断混淆（如$i>length$）|
|**代码实现**|-|`data[i-1]`|插入时循环条件`j>=i`对应下标`j-1`|

## 闪卡
#card
- 线性表中元素的数据类型有何要求？::所有元素数据类型必须相同，占用相同存储空间。
- 线性表长度为 0 时称为什么？::空表，此时不存在表头和表尾元素。
- LocateElem(L,e)操作返回什么？::返回值为 e 的元素在表中的位置（位序），未找到通常返回 0。
- ListInsert(&L,i,e)中 i 的合法范围？::$1 \leq i \leq L.length+1$，允许在表尾后插入。
- 顺序表实现随机存取的数学依据是什么？::元素地址与位序呈线性关系，可通过首地址直接计算任意元素地址。
- 顺序表静态分配溢出如何处理？::静态分配无法扩容，会导致溢出异常；需改用动态分配。
- 动态分配顺序表扩容的核心步骤？::开辟更大新空间，复制原数据到新空间，释放旧空间，更新指针。
- 顺序表的存储密度是多少？::存储密度为 1，因为结点只存数据，无额外指针开销。
- 顺序表在表头插入元素需移动多少个元素？::需移动全部$n$个元素，时间复杂度为$O(n)$。
- 顺序表删除第 i 个元素，需前移多少个元素？::需将第$i+1$至$n$个元素前移，共$n-i$个。
- 为何顺序表按值查找复杂度为$O(n)$？::无序表需逐个比较，平均比较次数为$\frac{n+1}{2}$。
- 顺序表按位查找 GetElem 的复杂度？::$O(1)$，直接通过数组下标访问，无需遍历。
- 不带头结点的单链表判空条件是什么？::头指针 L 为 NULL（L == NULL）。
- 带头结点的单链表第一个数据结点是谁？::头结点的后继结点，即$L \rightarrow next$指向的结点。
- 单链表结点中 next 域的作用？::存储直接后继结点的地址，建立逻辑上的线性关系。
- 为何单链表不支持随机存取？::物理地址不连续，必须从头指针开始顺链指针逐个遍历查找。
- 单链表在第 i 个位置插入，需找到哪个结点？::需找到第$i-1$个结点（前驱），以便修改其 next 指针。
- 已知结点*p，在其后插入*s 的复杂度？::$O(1)$，无需遍历，直接修改指针即可。
- 如何实现单链表的$O(1)$前插操作？::在*p 后插入新结点*s，然后交换*p 与*s 的数据域内容。
- 删除单链表尾结点需要知道什么？::需要知道尾结点的前驱结点，否则需从头遍历查找，复杂度$O(n)$。
- 双链表插入操作中，哪步必须最先执行？::$s \rightarrow next = p \rightarrow next$，防止丢失原后继结点地址。
- 双链表删除结点*q（*p 后继）的关键步骤？::$p \rightarrow next = q \rightarrow next;$ 且$q \rightarrow next \rightarrow prior = p;$。
- 双链表相比单链表的主要优势？::可直接访问前驱结点，已知结点指针时，插入删除复杂度降为$O(1)$。
- 双链表结点的 prior 域指向哪里？::指向该结点的直接前驱结点，头结点的 prior 通常为 NULL（非循环）。
- 循环单链表如何判断到达表尾？::当前结点的 next 指针指向头结点（或起始结点）。
- 为何循环链表常用尾指针而非头指针？::尾指针可直接访问头结点（$r \rightarrow next$）和尾结点，头尾操作均为$O(1)$。
- 循环双链表为空时的指针状态？::头结点的 prior 和 next 均指向自身（$L \rightarrow prior == L \land L \rightarrow next == L$）。
- 循环链表相比普通链表的最大特点？::从任意结点出发均可遍历整个链表，没有真正的“终点”。
- 静态链表中指针域 next 存储的是什么？::存储后继结点在数组中的下标（相对地址），而非内存地址。
- 静态链表如何表示链表结束？::将尾结点的 next 域设置为 -1（或特定常量）。
- 静态链表相比动态链表的主要局限？::需预先分配固定大小数组，容量受限，无法动态无限扩展。
- 静态链表的插入操作需要移动元素吗？::不需要，只需修改相关结点的 next 下标值，类似动态链表。
- 哪种结构支持折半查找？为什么？::顺序表，因为其支持随机存取，可直接计算中间位置下标。
- 频繁在表头插入删除应选哪种结构？::链表（尤其是带头结点），无需移动元素，复杂度$O(1)$。
- 顺序表动态扩容的潜在风险是什么？::需申请更大连续空间并复制数据，可能因无足够连续内存而失败。
- 链表的存储密度为何小于 1？::因为每个结点除数据外还需存储指针域，增加了额外空间开销。
