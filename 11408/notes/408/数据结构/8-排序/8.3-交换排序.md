# 8.3 交换排序

> [!abstract] 一句话总结
> 交换排序通过元素间比较与位置互换实现有序，冒泡排序每趟确定一个全局极值，快速排序每趟确定一个枢轴最终位置并递归分治。

## 核心要点
### 考点1：冒泡排序基本思想与流程
**冒泡排序通过依次比较相邻元素并交换逆序对，每趟将当前未排序部分的最小（或最大）元素移至其最终位置。**
核心操作：若 $A[i-1] > A[i]$ 则交换；最多进行 $n-1$ 趟，若某趟无交换则提前终止。

> [!tip] 考试怎么用
> 注意每趟产生的有序子序列具有全局有序性，已排序部分所有元素均小于（或大于）未排序部分。

### 考点2：冒泡排序代码实现
**冒泡排序使用双重循环，外层控制趟数，内层进行相邻比较与交换，并用 flag 标志优化。**
```c\nvoid BubbleSort(ElemType A[], int n) {
 for (int i=0; i<n-1; i++) {
 bool flag=false;
 for (int j=n-1; j>i; j--)
 if (A[j-1] > A[j]) { swap(A[j-1], A[j]); flag=true; }
 if (flag==false) return;
 }
}
```

> [!tip] 考试怎么用
> flag 标志用于检测是否发生交换，若无交换可直接返回，最好情况时间复杂度降为 $O(n)$。

### 考点3：冒泡排序性能分析
**冒泡排序空间复杂度 $O(1)$，最好时间复杂度 $O(n)$，最坏和平均时间复杂度 $O(n^2)$，是稳定排序。**
最坏比较次数 $\sum_{i=1}^{n-1}(n-i)=\frac{n(n-1)}{2}$，移动次数 $\sum_{i=1}^{n-1}3(n-i)=\frac{3n(n-1)}{2}$。

> [!tip] 考试怎么用
> 稳定性源于仅交换逆序相邻元素，相等元素不会交换；适用于顺序和链式存储。

### 考点4：快速排序基本思想与划分
**快速排序通过选取枢轴将序列划分为左右子表，左子表元素小于枢轴，右子表元素大于等于枢轴，枢轴归位。**
划分过程：双向扫描，$j$ 从右找小于 pivot，$i$ 从左找大于 pivot，交替移动直至 $i==j$。

> [!tip] 考试怎么用
> 每趟划分仅确保枢轴元素到达最终位置，不产生全局有序子序列；递归直到子表长度为 1 或 0。

### 考点5：快速排序代码实现
**快速排序由递归函数 QuickSort 和划分函数 Partition 组成，Partition 负责枢轴归位。**
```c\nint Partition(ElemType A[], int low, int high) {
 ElemType pivot = A[low];
 while (low < high) {
 while (low < high && A[high] >= pivot) --high;
 A[low] = A[high];
 while (low < high && A[low] <= pivot) ++low;
 A[high] = A[low];
 }
 A[low] = pivot; return low;
}
```

> [!tip] 考试怎么用
> 考研常考以首元素为枢轴的划分过程，注意 while 循环中 low<high 的判断顺序防止越界。

### 考点6：快速排序性能分析
**快速排序平均时间复杂度 $O(n\log_2 n)$，最坏 $O(n^2)$，空间复杂度最好 $O(\log_2 n)$、最坏 $O(n)$，是不稳定排序。**
最坏场景：初始序列基本有序或逆序，每次划分极不平衡；优化：三数取中法或随机选枢轴。

> [!tip] 考试怎么用
> 快速排序是内部排序中平均性能最优的；仅适用于顺序存储，因需随机访问。

## 易混与对比
**冒泡排序 vs 快速排序的有序子序列特性**

|特性|冒泡排序|快速排序|
|---|---|---|
|每趟结果|产生全局有序子序列（已排部分均小于/大于未排部分）|仅枢轴元素归位，左右子表内部无序|
|元素定位|每趟精确放置一个极值元素到最终位置|每趟精确放置一个枢轴元素到最终位置|
|有序性范围|已排序部分整体有序|仅枢轴位置确定，子表需递归处理|

**稳定性对比**

|算法|是否稳定|原因|
|---|---|---|
|冒泡排序|稳定|仅交换逆序相邻元素，相等元素不交换|
|快速排序|不稳定|划分时相等元素可能因跨越枢轴移动而改变相对次序，如 $\{3,2,2\} \to \{2,2,3\}$|

**适用存储结构**

|算法|适用存储|原因|
|---|---|---|
|冒泡排序|顺序存储、链式存储|仅需相邻元素比较与交换，无需随机访问|
|快速排序|仅顺序存储|划分过程需随机访问任意位置元素，链表无法高效实现|

**时间复杂度极端情况**

|算法|最好情况|最坏情况|
|---|---|---|
|冒泡排序|$O(n)$（初始有序）|$O(n^2)$（初始逆序）|
|快速排序|$O(n\log_2 n)$（每次均分）|$O(n^2)$（初始有序/逆序，划分极不平衡）|
