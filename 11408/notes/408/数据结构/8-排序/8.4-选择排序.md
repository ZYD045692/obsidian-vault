# 8.4 选择排序

> [!abstract] 一句话总结
> 选择排序通过每趟选取极值归位，其中简单选择排序时间恒为$O(n^2)$且不稳定，堆排序利用完全二叉树性质将时间优化至$O(n\text{log}_2n)$但仍不稳定。

## 核心要点
### 考点1：简单选择排序思想与实现
**第$i$趟从$L[i \text{...} n]$选出最小元素与$L[i]$交换，经$n-1$趟完成排序。**
```c\nvoid SelectSort(ElemType A[], int n) {
 for(int i=0; i<n-1; i++) {
 int min=i;
 for(int j=i+1; j<n; j++) if(A[j]<A[min]) min=j;
 if(min!=i) swap(A[i], A[min]);
 }
}
```

> [!tip] 考试怎么用
> 注意循环边界是$n-1$趟；交换前需判断`min!=i`以减少不必要的移动。

### 考点2：简单选择排序性能分析
**时间复杂度恒为$O(n^2)$，比较次数与初态无关，移动次数最少为 0，算法不稳定。**
比较次数：$n(n-1)/2$；移动次数：$0 \text{~} 3(n-1)$；空间复杂度：$O(1)$。

> [!tip] 考试怎么用
> 常考陷阱：认为初始有序时比较次数减少（实际不变）；易错点：误判为稳定排序。

### 考点3：堆的定义与性质
**堆是完全二叉树，大根堆满足$L(i) \text{≥} L(2i)$且$L(i) \text{≥} L(2i+1)$，小根堆反之。**
大根堆：$L(i) \text{≥} L(2i)$ 且 $L(i) \text{≥} L(2i+1)$；小根堆：$L(i) \text{≤} L(2i)$ 且 $L(i) \text{≤} L(2i+1)$。

> [!tip] 考试怎么用
> 区分大/小根堆的不等号方向；注意堆顶分别是最大值或最小值。

### 考点4：初始建堆操作
**从最后一个分支结点$\text{⌊}n/2\text{⌋}$开始自底向上，对每个结点执行自上而下的筛选调整。**
```c\nvoid BuildMaxHeap(ElemType A[], int len) {
 for (int i=len/2; i>0; i--) HeapAdjust(A, i, len);
}
```

> [!tip] 考试怎么用
> 起始位置必须是$\text{⌊}n/2\text{⌋}$；调整方向是“自上而下”筛选，但遍历结点是“自底向上”。

### 考点5：堆调整与删除堆顶
**输出堆顶后将堆底元素移至堆顶，再自上而下筛选恢复堆性质，单次调整耗时$O(h)$。**
```c\nvoid HeapAdjust(ElemType A[], int k, int len) {
 A[0]=A[k];
 for (int i=2*k; i<=len; i*=2) {
 if (i<len&&A[i]<A[i+1]) i++;
 if (A[0]>=A[i]) break;
 A[k]=A[i]; k=i;
 }
 A[k]=A[0];
}
```

> [!tip] 考试怎么用
> 调整时需比较左右孩子取较大者（大根堆）；若新堆顶已大于孩子则提前结束。

### 考点6：堆排序完整流程与性能
**建堆后执行$n-1$次“交换堆顶堆底 + 调整”，总时间复杂度$O(n\text{log}_2n)$，不稳定。**
```c\nvoid HeapSort(ElemType A[], int len) {
 BuildMaxHeap(A, len);
 for (int i=len; i>1; i--) {
 Swap(A[i], A[1]);
 HeapAdjust(A, 1, i-1);
 }
}
```

> [!tip] 考试怎么用
> 最好、最坏、平均时间复杂度均为$O(n\text{log}_2n)$；仅适用于顺序存储。

### 考点7：堆的插入操作
**新元素置于堆末端，然后自下而上与父结点比较交换，直至满足堆定义。**
插入步骤：1.尾部插入；2.若违反堆性质则与父结点交换；3.重复直至根或满足性质。

> [!tip] 考试怎么用
> 插入调整方向是“自下而上”，与删除/建堆的“自上而下”相反。

### 考点8：堆在 Top-K 问题中的应用
**求最大 K 个数建小顶堆，求最小 K 个数建大顶堆，利用堆顶极值特性筛选数据。**
求最大 K 个：建大小为$K$的小顶堆，若新数$>$堆顶则替换并调整；复杂度$O(\text{log}_2K)$。

> [!tip] 考试怎么用
> 易混点：求“最大”反而用“小顶堆”来保留较大的数，剔除小的堆顶。

## 易混与对比
**简单选择排序 vs 堆排序**

|特性|简单选择排序|堆排序|
|:---|:---|:---|
|时间复杂度|恒为$O(n^2)$|恒为$O(n\text{log}_2n)$|
|比较次数|与初态无关，固定$n(n-1)/2$|与初态有关，但量级不变|
|移动次数|最少 0，最多$3(n-1)$|较多，取决于调整过程|
|稳定性|不稳定|不稳定|
|存储结构|顺序、链式均可|仅顺序存储|

**堆操作的调整方向**

|操作类型|调整方向|说明|
|:---|:---|:---|
|初始建堆|自底向上遍历，自上而下筛选|从$\text{⌊}n/2\text{⌋}$到 1，每个结点向下沉|
|删除堆顶|自上而下筛选|堆底元素补顶后向下沉|
|插入元素|自下而上筛选|新元素补尾后向上浮|

**Top-K 问题堆类型选择**

|目标|堆类型|原理|
|:---|:---|:---|
|选最大的 K 个数|小顶堆|堆顶是最小值，新数比堆顶大则替换，保留大的|
|选最小的 K 个数|大顶堆|堆顶是最大值，新数比堆顶小则替换，保留小的|

- 简单选择排序适用于哪种存储结构？::适用于顺序存储和链式存储的线性表。
- 大根堆的根结点具有什么特征？::最大元素位于根结点，任意非根结点值不大于其双亲。
- 小根堆的根结点具有什么特征？::最小元素位于根结点，性质与大根堆恰好相反。
- 堆逻辑上对应哪种数据结构？::可视为一棵完全二叉树。
- 堆中结点$i$的左右孩子下标分别是？::左孩子$2i$，右孩子$2i+1$（假设下标从 1 开始）。

- 建堆时遍历结点的顺序是怎样的？::从$\text{⌊}n/2\text{⌋}$开始依次向前处理至$i=1$（自底向上）。
- 建堆时对单个结点的调整方向是？::自上而下的筛选操作。
- 建堆过程的时间复杂度是多少？::$O(n)$，关键字总比较次数不超过$4n$。
- 删除堆顶后，哪个元素被移至堆顶？::将堆底元素移至堆顶。
- 堆调整过程中，若根结点小于左右孩子较大者则？::将其与该较大的子结点交换，并继续向下调整。
- 堆调整操作的时间复杂度与什么成正比？::与树高$h$成正比，为$O(h)$。
- HeapAdjust 函数中`i<len&&A[i]<A[i+1]`的作用？::确保有右孩子且右孩子更大时，下标$i$指向右孩子。
- 堆排序总共进行多少次堆顶输出与调整？::需进行$n-1$次。
- 堆排序在最好情况下的时间复杂度？::$O(n\text{log}_2n)$，与初态无关。
- 堆排序是否稳定？为什么？::不稳定，相等关键字元素在调整交换中可能改变相对位置。
- 堆排序适用于哪种存储结构？::仅适用于顺序存储的线性表（依赖随机访问）。
- 堆插入新元素时首先放在什么位置？::先将新元素置于堆末端。
- 堆插入后的调整方向是？::自下而上地与其父结点比较并交换。
- 堆插入操作何时停止调整？::直至满足堆定义或到达根结点。
- 从海量数据选最大的 K 个数应构建什么堆？::构建大小为$K$的小顶堆。
- Top-K 问题中若新读入数小于小顶堆堆顶如何处理？::舍弃该数，不进入堆。
- Top-K 算法处理每个新元素的时间复杂度？::$O(\text{log}_2k)$。
- Top-K 算法的空间复杂度是多少？::$O(k)$。
