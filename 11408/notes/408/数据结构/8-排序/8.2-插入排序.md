# 8.2 插入排序

> [!abstract] 一句话总结
> 插入排序通过构建有序序列，将待排元素逐个插入正确位置，其中直接插入是基础，折半优化查找，希尔利用增量预排序。

## 核心要点
### 考点1：直接插入排序算法流程
**每次将一个待排序记录按其关键字大小插入到前面已经排好序的子序列中，直到所有记录插入完毕。**
```c\nfor (i = 2; i <= n; i++) if (A[i] < A[i-1]) { A[0] = A[i]; for (j = i - 1; A[0] < A[j]; --j) A[j + 1] = A[j]; A[j + 1] = A[0]; }
```

> [!tip] 考试怎么用
> 注意哨兵 A[0] 的作用既是暂存也是防止下标越界；初始有序子序列长度为 1，共执行 n-1 趟。

### 考点2：直接插入排序性能分析
**空间复杂度为 O(1)，时间复杂度平均和最坏为 O(n^2)，最好是 O(n)，且算法是稳定的。**
最好 $O(n)$（已有序）；最坏 $O(n^2)$（逆序，比较 $\frac{n(n-1)}{2}$ 次）；平均 $O(n^2)$。

> [!tip] 考试怎么用
> 稳定性判定依据：从后往前比较，遇到相同关键字停止移动，故相对顺序不变。

### 考点3：折半插入排序优化点
**将查找插入位置的操作由顺序查找改为折半查找，减少了关键字比较次数，但元素移动次数不变。**
```c\nwhile (low <= high) { mid = (low + high) / 2; if (A[mid] > A[0]) high = mid - 1; else low = mid + 1; }
```

> [!tip] 考试怎么用
> 易错点：虽然比较次数降为 O(n log n)，但移动次数仍取决于初始序列，总时间复杂度仍为 O(n^2)。

### 考点4：希尔排序基本思想
**通过逐步缩小增量的方式，对相隔一定距离的元素构成的子序列进行多次直接插入排序，使表逐渐趋于基本有序。**
增量序列 $d_1 > d_2 > \\\cdots > d_t = 1$；每趟对 $d_k$ 个子序列分别进行直接插入排序。

> [!tip] 考试怎么用
> 最后一趟增量必为 1，此时所有记录属于同一子序列，且序列已高度有序。

### 考点5：希尔排序性能与特性
**空间复杂度 O(1)，时间复杂度依赖增量序列（约 O(n^1.3)），是不稳定排序，仅适用于顺序存储。**
时间复杂度：常见范围约 $O(n^{1.3})$，最坏 $O(n^2)$；稳定性：不稳定。

> [!tip] 考试怎么用
> 不稳定的原因：相同关键字记录可能被划分到不同子表，在子表排序中相对次序可能改变。

## 易混与对比
**直接插入 vs 折半插入**

|特性|直接插入排序|折半插入排序|
|---|---|---|
|查找方式|顺序查找|折半查找|
|比较次数|$O(n^2)$|$O(n \log_2 n)$|
|移动次数|取决于初始序列|取决于初始序列（未减少）|
|总时间复杂度|$O(n^2)$|$O(n^2)$|
|存储结构|顺序、链式|仅顺序|

- **稳定性对比**：直接插入和折半插入均为**稳定**排序，因为插入时遇到相同关键字即停止移动；希尔排序是**不稳定**排序，因为跨子表的跳跃移动可能打乱相同关键字的相对顺序（如原文图 8.2 中 49 与 $\underline{49}$）。
- **哨兵 A[0] 的作用差异**：在直接插入和折半插入中，A[0] 既作暂存单元又作**哨兵**（防止下标越界）；在希尔排序中，A[0] 仅作**暂存单元**，循环条件需显式判断 `j > 0`，因为跳跃式比较可能直接跨过下标 1。

## 闪卡
#card
- 直接插入排序第 i 趟操作的对象是什么？::将 L(i) 插入到已有序的子序列 L[1...i-1] 中。
- 直接插入排序中设置哨兵 A[0] 的主要作用？::暂存待插入元素，并作为边界标记避免内层循环判断 j>=0。
- 直接插入排序在链式存储下是否需要移动元素？::不需要，链式存储只需修改指针指向，无须移动元素。
- 若初始序列完全有序，直接插入排序的比较次数？::n-1 次，每趟仅需比较 1 次，时间复杂度 O(n)。
- 直接插入排序的空间复杂度是多少？::O(1)，仅使用常数个辅助单元。
- 直接插入排序在什么情况下时间效率最高？::表中元素已有序，时间复杂度为 O(n)。
- 直接插入排序是否稳定？为什么？::稳定，因为插入时从后往前比较，相同关键字元素相对顺序不改变。
- 直接插入排序适用于哪种存储结构？::适用于顺序存储和链式存储的线性表。
- 折半插入排序相比直接插入排序主要减少了什么操作？::减少了关键字的比较次数，比较次数约为 O(n log n)。
- 折半插入排序的时间复杂度是否因优化而降低阶数？::否，元素移动次数未变，总时间复杂度仍为 O(n^2)。
- 折半插入排序是否适用于链式存储？::不适用，折半查找要求线性表必须采用顺序存储。
- 折半插入排序的稳定性如何？::稳定，插入过程保持了相同关键字元素的相对顺序。
- 希尔排序中增量 dk 的最终值必须是多少？::必须为 1，以确保所有记录在同一子序列中完成最终排序。
- 希尔排序每一趟排序的对象是什么？::由当前增量 dk 划分出的 dk 个子序列，每个子序列包含下标间隔为 dk 的记录。
- 希尔排序为何又称“缩小增量排序”？::因为算法通过逐步缩小增量 dk 的值来分组并进行多趟排序。
- 希尔排序中 A[0] 的作用与直接插入排序有何不同？::希尔排序中 A[0] 只是暂存单元，不是哨兵，因为 j 可能减至 0 以下需显式判断。
- 希尔排序是否是稳定的排序算法？::不稳定，相同关键字记录在不同子表排序中可能改变相对次序。
- 希尔排序的时间复杂度能否精确计算？::不能，依赖于所选增量序列，最优增量序列仍是数学未解难题。
- 希尔排序适用于链式存储吗？::不适用，希尔排序仅适用于顺序存储的线性表。
- 希尔排序在什么情况下退化为 O(n^2)？::最坏情况下，或增量序列选择不当时，时间复杂度退化为 O(n^2)。
