# 3.3 栈和队列的应用

> [!abstract] 一句话总结
> 栈利用 LIFO 特性解决嵌套与回溯问题（括号、递归、表达式），队列利用 FIFO 特性解决顺序缓冲与分层处理问题（打印缓冲、层次遍历）。

## 核心要点
### 考点1：栈在括号匹配中的应用
**括号匹配完全符合后进先出特性，左括号入栈表示新增期待，右括号出现时检查栈顶是否匹配。**
算法步骤：1) 遇左括号压栈；2) 遇右括号若栈非空且栈顶匹配则弹栈，否则非法；3) 扫描结束栈空则合法。

> [!tip] 考试怎么用
> 注意扫描结束后栈非空代表有未匹配的左括号，这也是非法情况。

### 考点2：中缀表达式转后缀表达式（手算）
**手算转换遵循“加括号、移运算符、去括号”三步，将运算符移至对应右括号之后。**
步骤：1) 按优先级逐层加括号；2) 运算符移到所在括号右括号后；3) 删除所有括号。

> [!tip] 考试怎么用
> 此方法适合手算选择题，计算机实现需借助运算符栈。

### 考点3：中缀转后缀（机算/栈实现）
**借助运算符栈，操作数直接输出，运算符根据优先级与栈顶比较决定入栈或弹出。**
规则：1) 操作数直接输出；2) '('入栈，')'弹出至'('；3) 运算符优先级高于栈顶或栈顶为'('则入栈，否则弹出栈顶直到条件满足再入栈。

> [!tip] 考试怎么用
> 同级运算符相遇也要弹出栈顶（左结合性），扫描结束后需弹出栈内剩余运算符。

### 考点4：后缀表达式求值
**从左至右扫描，操作数入栈，遇运算符弹出两个操作数（先右后左）计算并将结果入栈。**
运算逻辑：弹出 $Y$ (右)，弹出 $X$ (左)，计算 $X \text{<op>} Y$，结果压回栈。

> [!tip] 考试怎么用
> 极易错点：减法和除法不满足交换律，必须先弹出的是右操作数，后弹出的是左操作数。

### 考点5：栈在递归中的应用
**递归通过系统栈保存每层调用的返回地址、局部变量及形参，递归深度过大易导致栈溢出。**
递归两要素：1) 递归体（分解子问题）；2) 边界条件（递归出口）。任何递归均可转为非递归（显式栈）。

> [!tip] 考试怎么用
> 递归效率低主因是大量重复计算（如斐波那契），而非栈操作本身慢。

### 考点6：队列在层次遍历中的应用
**利用队列 FIFO 特性，在处理当前层结点时将下一层子结点按序入队，实现逐层访问。**
流程：1) 根结点入队；2) 队非空则出队首并访问；3) 若出队结点有左右孩子则依次入队；4) 重复直到队空。

> [!tip] 考试怎么用
> 必须先入左孩子再入右孩子，以保证从左到右的遍历顺序。

### 考点7：队列在计算机系统中的应用
**队列用于解决速度不匹配（打印缓冲）和资源竞争（CPU 调度），核心是先进先出原则。**
应用 1：打印缓冲区（主机快写，打印机慢读）；应用 2：多用户 CPU 请求队列（按请求时间顺序分配）。

> [!tip] 考试怎么用
> 打印缓冲区满时主机暂停，空时打印机等待，本质是协调生产消费速度。

## 易混与对比
**中缀转后缀：手算 vs 机算**

|特征|手算方法|机算方法 (栈)|
|---|---|---|
|核心策略|加括号 -> 移运算符 -> 去括号|扫描序列，利用栈暂存运算符|
|适用场景|选择题快速推导|编程实现、复杂表达式|
|括号处理|显式添加和删除|'('入栈，')'触发弹出直到'('|

**后缀表达式求值：操作数顺序**

|运算符类型|弹出顺序|计算表达式|易错点|
|---|---|---|---|
|加法/乘法|先 $Y$ 后 $X$|$X+Y$ 或 $X \times Y$|交换律成立，顺序不影响结果|
|减法/除法|先 $Y$ (右) 后 $X$ (左)|$X-Y$ 或 $X/Y$|**顺序颠倒会导致结果错误**|

**递归效率低 vs 栈溢出**

|问题现象|根本原因|解决方案|
|---|---|---|
|运行时间过长|大量重复计算 (如 $F(n)$ 多次计算 $F(n-2)$)|记忆化搜索、动态规划|
|程序崩溃 (Stack Overflow)|递归深度过大，系统栈空间耗尽|改为非递归 (显式栈)、尾递归优化|

**栈与队列的核心应用场景区分**

|数据结构|核心特性|典型应用场景|逻辑本质|
|---|---|---|---|
|栈 (Stack)|LIFO (后进先出)|括号匹配、表达式求值、递归调用|嵌套结构、回溯、最近优先|
|队列 (Queue)|FIFO (先进先出)|层次遍历、打印缓冲、CPU 调度|顺序处理、缓冲、公平排队|

## 闪卡
#card
- 遇到左括号时的操作是什么？::将其压入栈中，表示新增一个待匹配的期待，优先级最高。
- 遇到右括号且栈为空时，序列是否合法？::不合法，算法直接终止。
- 扫描结束后栈非空说明什么？::存在未匹配的左括号，序列非法。
- 右括号与栈顶左括号不匹配时如何处理？::判定序列非法，算法终止。
- 手算转换的第一步操作是什么？::按运算优先级对整个表达式逐层加括号。
- 运算符移动的目标位置在哪里？::移到其所在括号的右括号之后。
- 最后一步如何得到后缀表达式？::删除所有括号。
- 遇到操作数时的处理方式？::直接加入后缀表达式。
- 遇到右括号')'时的操作流程？::不断弹出栈顶运算符加入后缀表达式，直到遇到'('并丢弃'('。
- 当前运算符优先级低于或等于栈顶时怎么做？::依次弹出栈中运算符加入后缀表达式，直到栈空、遇'('或遇更低优先级，再入栈。
- 扫描结束后栈中还有元素如何处理？::将栈中剩余运算符依次弹出并加入后缀表达式。
- 遇到操作符时，第一个弹出的数是左还是右操作数？::右操作数 $Y$。
- 遇到操作符时，第二个弹出的数是左还是右操作数？::左操作数 $X$。
- 执行减法 $X-Y$ 时，栈中弹出顺序是怎样的？::先弹出 $Y$，后弹出 $X$。
- 所有项处理完毕后，结果在哪里？::栈顶元素。
- 递归工作栈中保存了哪些信息？::返回地址、局部变量及形参。
- 递归定义必须满足哪两个条件？::递归体（分解问题）和边界条件（确保终止）。
- 递归效率低下的主要原因是什么？::存在大量重复计算。
- 递归深度过大容易导致什么错误？::栈溢出。
- 任何递归算法是否都能转换为非递归？::是，通常需借助显式栈模拟。
- 层次遍历开始时首先执行什么操作？::将根结点入队。
- 取出队首结点访问后，接下来做什么？::若存在左/右孩子，则将其按序入队。
- 何时判定层次遍历结束？::当队列为空时。
- 为什么层次遍历适合用队列而不是栈？::需要先进先出 (FIFO) 以保持层级顺序。
- 打印数据缓冲区解决了什么问题？::主机与打印机之间的速度不匹配问题。
- 打印机从缓冲区取数据的原则是什么？::先进先出 (FIFO)。
- 多用户系统中 CPU 请求通常如何排队？::按照请求的时间顺序排成队列。
- 缓冲区满时主机会执行什么操作？::暂停输出并转向其他任务。
