# 3.4 数组和特殊矩阵

> [!abstract] 一句话总结
> 本节核心在于利用矩阵元素的分布规律（对称、三角、带状、稀疏），通过下标映射将二维结构压缩至一维存储以节省空间。

## 核心要点
### 考点1：数组的定义与操作
**数组是线性表的推广，一旦定义维数与维界固定，仅支持存取和修改元素操作。**
数组由 $n$ ($n \geq 1$) 个相同类型元素组成；基本操作：Init, Destroy, GetElem, SetElem。

> [!tip] 考试怎么用
> 注意数组不支持插入和删除操作，这是与线性表的关键区别。

### 考点2：二维数组的地址计算
**多维数组需按行优先或列优先映射为一维，地址公式取决于优先顺序及下标范围。**
行优先：$LOC(a_{i,j})=LOC(a_{0,0})+[i(h_{2}+1)+j]L$；列优先：$LOC(a_{i,j})=LOC(a_{0,0})+[j(h_{1}+1)+i]L$。

> [!tip] 考试怎么用
> 务必确认下标是从 0 开始还是从 1 开始，公式中的 $h_1, h_2$ 是最大下标值。

### 考点3：对称矩阵压缩存储
**利用 $a_{ij}=a_{ji}$ 特性，仅存下三角（含对角线）于 $B[n(n+1)/2]$，上三角元素通过对称性访问。**
下标映射（从 1 开始）：$k=\frac{i(i-1)}{2}+j-1$ ($i \geq j$)；$k=\frac{j(j-1)}{2}+i-1$ ($i < j$)。

> [!tip] 考试怎么用
> 考试常考 $i<j$ 时的下标计算，需交换 $i,j$ 代入下三角公式。

### 考点4：三角矩阵压缩存储
**三角矩阵需存储有效三角区及一个常量（重复区），数组长度为 $n(n+1)/2+1$。**
下三角：$i<j$ 时 $k=n(n+1)/2$；上三角：$i>j$ 时 $k=n(n+1)/2$；有效区公式类似对称矩阵或等差求和。

> [!tip] 考试怎么用
> 注意上三角矩阵行优先存储时，第 $i$ 行前方元素个数是等差数列求和。

### 考点5：三对角矩阵压缩存储
**非零元素仅分布在 $|i-j| \leq 1$ 的三条对角线上，按行优先存入一维数组。**
下标映射（从 1 开始）：$k = 2i + j - 3$；逆映射：$i=\lfloor(k+1)/3\rfloor+1, j=k-2i+3$。

> [!tip] 考试怎么用
> 熟记 $k=2i+j-3$ 公式，注意下标起始值对常数的影响。

### 考点6：稀疏矩阵的三元组存储
**稀疏矩阵仅存储非零元素的三元组 (行，列，值)，失去随机存取特性，需额外存行列总数。**
存储结构：三元组表 (i, j, $a_{ij}$)；需额外信息：行数、列数、非零元个数 $t$。

> [!tip] 考试怎么用
> 三元组表通常按行优先排序；插入删除效率低，适合静态存储。

## 易混与对比
- **下标起始值对公式的影响**：教材推导多假设矩阵下标从 1 开始，而 C 语言数组从 0 开始。若题目给定 $A[0..n-1][0..n-1]$，需将公式中的 $i,j$ 替换为 $i+1, j+1$ 或重新推导常数项（如对称矩阵 $k=i(i+1)/2+j$）。
- **三角矩阵与对称矩阵存储长度差异**：对称矩阵长度为 $n(n+1)/2$，因为上下三角完全复用；三角矩阵长度为 $n(n+1)/2+1$，因为重复区（全 0 或全 C）需单独占一个位置存储常量。
- **随机存取特性的有无**：数组、对称/三角/三对角矩阵压缩后仍可通过公式 $O(1)$ 计算地址，保留随机存取；稀疏矩阵三元组表需顺序查找，失去随机存取特性。
- **行优先与列优先的系数区别**：行优先地址公式中，行下标 $i$ 乘以列数（$h_2+1$）；列优先地址公式中，列下标 $j$ 乘以行数（$h_1+1$）。切勿记反系数。
