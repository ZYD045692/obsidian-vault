# 栈、队列和数组

> [!abstract] 一句话总结
> 本章核心在于利用栈的 LIFO 特性处理嵌套与回溯，利用队列的 FIFO 特性处理缓冲与层次，并通过压缩存储解决特殊矩阵的空间冗余问题。

## 核心考点
### 考点1：栈的逻辑特性与数学性质
**栈是仅允许在一端（栈顶）进行插入和删除的线性表，遵循后进先出（LIFO）原则。**
n 个不同元素按固定次序入栈，可能的出栈序列总数为卡特兰数：$\frac{1}{n+1}C_{2n}^{n}$。

> [!tip] 考试怎么用
> 重点考查出栈序列合法性判断及卡特兰数计算，注意栈顶指针初始化值对判空判满条件的影响。

### 考点2：顺序栈与共享栈实现
**顺序栈利用连续存储单元，共享栈让两个栈底位于数组两端向中间延伸以优化空间。**
共享栈满条件：$top1 - top0 == 1$；存取时间复杂度均为 $O(1)$。

> [!tip] 考试怎么用
> 注意共享栈两栈顶指针移动方向相反，判满条件是两指针相邻而非等于数组边界。

### 考点3：循环队列的假溢出解决
**循环队列通过取模运算将存储空间逻辑组织为环状，解决顺序队列的假溢出问题。**
牺牲一个单元法：队空 $front==rear$，队满 $(rear+1)\%MaxSize==front$，长度 $(rear-front+MaxSize)\%MaxSize$。

> [!tip] 考试怎么用
> 必须掌握三种判满方法（牺牲单元、size 计数、tag 标志），考试常考牺牲单元法的指针计算。

### 考点4：链式队列的结构特点
**链式队列是带头结点或不带头结点的单链表，同时维护队头 front 和队尾 rear 指针。**
不带头结点判空：$front==NULL$；带头结点判空：$front==rear$。不存在队满溢出。

> [!tip] 考试怎么用
> 注意不带头结点时删除最后一个元素需特殊处理 rear 指针，带头结点逻辑更统一。

### 考点5：双端队列及其受限形式
**双端队列允许两端插入删除，输出受限端仅能插入，输入受限端仅能删除。**
输入受限双端队列无法得到的序列如 4,2,3,1；输出受限无法得到 4,1,3,2（针对 1,2,3,4 输入）。

> [!tip] 考试怎么用
> 常考判断特定序列能否由受限双端队列得到，需结合栈和队列特性模拟验证。

### 考点6：栈在表达式求值中的应用
**利用栈将中缀表达式转为后缀表达式并求值，后缀表达式无需括号且隐含运算次序。**
转换规则：操作数直接输出；运算符比较优先级，高入栈，低或等弹出栈顶直到遇'('或更低。

> [!tip] 考试怎么用
> 手算转换时注意括号处理，求值时注意弹出顺序：先弹出的是右操作数。

### 考点7：递归与栈的底层机制
**递归通过系统栈保存每层调用的返回地址和局部变量，递归深度过大易导致栈溢出。**
递归三要素：边界条件、递归体、参数传递。任何递归均可转换为非递归（显式栈模拟）。

> [!tip] 考试怎么用
> 理解递归调用树，注意斐波那契数列等存在大量重复计算，效率较低。

### 考点8：数组的存储地址计算
**多维数组按行优先或列优先映射到一维内存，地址计算依赖下标范围和元素大小。**
行优先 $LOC(i,j)=LOC(0,0)+[i(h_2+1)+j]L$；列优先 $LOC(i,j)=LOC(0,0)+[j(h_1+1)+i]L$。

> [!tip] 考试怎么用
> 务必看清题目给定的下标起始值（0 或 1）及存储方式（行优先/列优先）。

### 考点9：特殊矩阵的压缩存储
**对称、三角、三对角矩阵利用元素分布规律压缩至一维数组，节省大量存储空间。**
对称矩阵 $k=i(i-1)/2+j-1$ ($i\ge j$)；三对角矩阵 $k=2i+j-3$ (下标从 1 开始)。

> [!tip] 考试怎么用
> 重点掌握对称矩阵和三对角矩阵的下标映射公式，注意下标是从 0 还是 1 开始。

### 考点10：稀疏矩阵的三元组表示
**稀疏矩阵仅存储非零元素的三元组 (行，列，值)，失去随机存取特性但节省空间。**
存储方式包括三元组顺序表和十字链表，需额外记录行数、列数和非零元个数。

> [!tip] 考试怎么用
> 明确稀疏矩阵压缩后无法通过下标直接访问，必须遍历查找或特定结构定位。

## 易混与对比
**栈顶指针初始化差异**

|初始化方式|栈空条件|栈满条件|入栈操作|出栈操作|
|---|---|---|---|---|
|top=-1 (指向元素)|top==-1|top==MaxSize-1|data[++top]=x|x=data[top--]|
|top=0 (指向下一位)|top==0|top==MaxSize|data[top++]=x|x=data[--top]|

**循环队列判空与判满**

|方法|队空条件|队满条件|元素个数|
|---|---|---|---|
|牺牲一个单元|front==rear|(rear+1)%N==front|(rear-front+N)%N|
|增设 size|size==0|size==N|size|
|增设 tag|front==rear 且 tag==0|front==rear 且 tag==1|需计算或维护|

**特殊矩阵下标映射**

|矩阵类型|存储区域|下标映射公式 (1-based)|数组长度|
|---|---|---|---|
|对称矩阵|下三角|$i(i-1)/2+j-1$ ($i\ge j$)|$n(n+1)/2$|
|下三角矩阵|下三角 + 常量|同上，上三角存常量|$n(n+1)/2+1$|
|上三角矩阵|上三角 + 常量|$(i-1)(2n-i+2)/2+(j-i)$|$n(n+1)/2+1$|
|三对角矩阵|三条对角线|$2i+j-3$|$3n-2$|

**链式队列带头结点与否**

|特性|不带头结点|带头结点|
|---|---|---|
|判空条件|front==NULL|front==rear|
|入队逻辑|需判断是否为空队|统一在 rear 后插入|
|出队逻辑|删最后一元素需改 rear|统一删除 front->next|
|代码复杂度|边界处理繁琐|逻辑统一简洁|

## 闪卡
#card
- 栈的操作特性概括为什么？::后进先出（Last In First Out, LIFO）。
- n 个元素依次入栈，合法出栈序列总数公式？::$\frac{1}{n+1}C_{2n}^{n}$，即卡特兰数。
- 栈顶指针 top 初始为 -1 时，栈空条件？::S.top == -1。
- 栈顶指针 top 初始为 0 时，栈满条件（容量 MaxSize）？::S.top == MaxSize。
- 共享栈中两个栈的栈底分别位于何处？::分别置于数组的两端（0 和 MaxSize-1）。
- 共享栈的栈满判断条件是什么？::两栈顶指针相邻，即 $top1 - top0 == 1$。
- 顺序栈发生上溢的原因是什么？::栈中元素个数达到数组上界 MaxSize。
- 共享栈相比独立顺序栈的主要优势？::动态调节空间，仅当整个数组占满才溢出，利用率更高。
- 什么是顺序队列的“假溢出”？::数组仍有空闲但 rear 已达上界，无法继续入队的现象。
- 循环队列中 rear 指针进 1 的操作？::$Q.rear = (Q.rear + 1) \% MaxSize$。
- 牺牲一个单元法中，队满的条件？::$(Q.rear + 1) \% MaxSize == Q.front$。
- 循环队列当前元素个数计算公式？::$(Q.rear - Q.front + MaxSize) \% MaxSize$。
- 不带头结点的链式队列判空条件？::$Q.front == NULL$ 且 $Q.rear == NULL$。
- 带头结点的链式队列判空条件？::$Q.front == Q.rear$。
- 链式队列相比顺序队列的最大优势？::动态分配内存，不存在队满或溢出问题。
- 链式队列出队时若删去最后一个结点需做什么？::将 $Q.rear$ 重新指向 $Q.front$（或置 NULL）。
- 输出受限的双端队列哪端不能删除？::其中一端仅允许插入，不允许删除。
- 输入受限的双端队列哪端不能插入？::其中一端仅允许删除，不允许插入。
- 若双端队列某端插入只能从该端删除，退化为？::两个栈底相邻接的栈。
- 输入序列 1,2,3,4，哪种序列受限双端队列均不可得？::4, 2, 3, 1。
- 中缀转后缀时遇到右括号')'如何处理？::不断弹出栈顶运算符直到遇到左括号'('，并丢弃左右括号。
- 后缀表达式求值时，遇到运算符弹出两个数顺序？::先弹出右操作数 Y，后弹出左操作数 X，计算 X op Y。
- 表达式树的后序遍历对应哪种表达式？::后缀表达式（逆波兰式）。
- 中缀表达式转后缀表达式是否需要括号？::不需要，后缀表达式结构已隐含运算顺序。
- 递归调用过程中系统使用什么结构保存现场？::递归工作栈。
- 递归定义必须满足的两个条件？::有边界条件（出口）和递归体（规模缩小）。
- 递归算法效率低下的主要原因？::存在大量重复计算（如斐波那契数列）。
- 将递归转为非递归通常借助什么数据结构？::显式的栈。
- 二维数组按行优先存储的含义？::先行后列，先存行号小的，同行内先存列号小的。
- 行优先存储下 A[i][j] 的地址公式（下标从 0 开始）？::$LOC(a_{0,0})+[i(h_{2}+1)+j]L$。
- 列优先存储下 A[i][j] 的地址公式（下标从 0 开始）？::$LOC(a_{0,0})+[j(h_{1}+1)+i]L$。
- 数组一旦定义，其维数和维界是否可变？::固定不变，仅支持存取和修改元素操作。
- n 阶对称矩阵压缩存储所需一维数组长度？::$n(n+1)/2$。
- 对称矩阵下三角元素 $a_{ij}(i\ge j)$ 映射下标 k (从 0 开始)？::$k = i(i-1)/2 + j - 1$。
- 三对角矩阵非零元素 $a_{ij}$ 映射下标 k (从 1 开始)？::$k = 2i + j - 3$。
- 三角矩阵压缩存储需额外存储什么？::常量区的那个常数值。
- 稀疏矩阵压缩存储的基本单元是什么？::三元组 (行标 i, 列标 j, 值 $a_{ij}$)。
- 稀疏矩阵压缩存储后是否保留随机存取特性？::否，失去了随机存取特性。
- 三元组表外还需保存哪些全局信息？::矩阵的行数、列数和非零元素总个数。
- 适合频繁插入删除的稀疏矩阵存储结构？::十字链表。
