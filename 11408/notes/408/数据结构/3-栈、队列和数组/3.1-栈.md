# 3.1 栈

> [!abstract] 一句话总结
> 栈是仅允许在一端（栈顶）进行插入和删除的线性表，其核心逻辑特性为后进先出（LIFO）。

## 核心要点
### 考点1：栈的定义与特性
**栈是操作受限的线性表，仅允许在栈顶进行插入和删除，遵循后进先出（LIFO）原则。**
若入栈序列为 $a_{1},a_{2},\dots,a_{n}$，则合法出栈序列总数为卡特兰数 $\frac{1}{n+1}C_{2n}^{n}$。

> [!tip] 考试怎么用
> 判断出栈序列合法性时，需模拟入栈过程，若当前需出栈元素不在栈顶且已入栈元素无法再入栈，则序列非法。

### 考点2：栈的基本操作
**栈的基本操作包括初始化、判空、入栈、出栈、读栈顶和销毁，算法题中可直接调用。**
Push(&S,x): 栈未满时 x 成新栈顶；Pop(&S,&x): 栈非空时弹出栈顶并通过 x 返回。

> [!tip] 考试怎么用
> 注意 Pop 和 GetTop 操作前必须判断栈是否为空，否则会导致下溢错误。

### 考点3：顺序栈的实现（top=-1）
**顺序栈利用连续存储单元，top 指向栈顶元素，初始为 -1，入栈先加指针后赋值。**
栈空：`S.top==-1`；栈满：`S.top==MaxSize-1`；入栈：`S.data[++S.top]=x`；出栈：`x=S.data[S.top--]`。

> [!tip] 考试怎么用
> 务必区分 top 指向栈顶元素还是栈顶下一个位置，这决定了判空判满条件及加减顺序。

### 考点4：顺序栈的实现（top=0）
**若 top 指向栈顶元素的下一个位置，初始为 0，入栈先赋值后加指针，出栈先减指针后取值。**
栈空：`S.top==0`；栈满：`S.top==MaxSize`；入栈：`S.data[S.top++]=x`；出栈：`x=S.data[--S.top]`。

> [!tip] 考试怎么用
> 此类实现中，top 的值等于栈中当前元素个数，判满条件是 top 等于数组最大容量。

### 考点5：共享栈
**两个顺序栈共享一维数组，栈底在两端，栈顶向中间延伸，仅当两栈顶相邻时才溢出。**
0 号栈顶 top0 初值 -1，1 号栈顶 top1 初值 MaxSize；栈满条件：`top1 - top0 == 1`。

> [!tip] 考试怎么用
> 共享栈能更高效利用空间，适用于两个栈数据量变化互补的场景，存取时间复杂度仍为 $O(1)$。

### 考点6：链栈
**链栈采用单链表实现，规定所有操作在表头进行，通常不带头结点，不存在栈满溢出。**
typedef struct LinkNode{ ElemType data; struct LinkNode *next; } LiStack; 操作均在表头进行。

> [!tip] 考试怎么用
> 链栈优点是可动态分配空间，适合多栈共存或无法预估最大长度的场景，无栈满概念。

## 易混与对比
**顺序栈顶指针两种定义的差异**

|特征|top 指向栈顶元素|top 指向栈顶下一位置|
|---|---|---|
|初始值|-1|0|
|栈空条件|top == -1|top == 0|
|栈满条件|top == MaxSize-1|top == MaxSize|
|入栈操作|`data[++top]=x`|`data[top++]=x`|
|出栈操作|`x=data[top--]`|`x=data[--top]`|

**顺序栈与链栈的优缺点对比**

|特性|顺序栈|链栈|
|---|---|---|
|存储方式|地址连续的存储单元|链式存储，结点分散|
|栈满判断|需预判大小，可能上溢|理论上无栈满（除非内存耗尽）|
|空间利用率|固定，可能浪费或不足|动态分配，灵活|
|适用场景|数据量可预估，单栈|多栈共存，数据量波动大|

- DestroyStack(&S) 执行了什么动作？::销毁栈 S 并释放其占用的存储空间。
- top 初始化为 -1 时，栈空的条件表达式？::S.top == -1
- top 初始化为 -1 时，栈满的条件表达式？::S.top == MaxSize - 1
- top 指向栈顶元素时，入栈操作的代码步骤？::先将 top 加 1，再将元素存入 S.data[top]。
- top 指向栈顶元素时，出栈操作的代码步骤？::先取出 S.data[top]，再将 top 减 1。
- top 初始化为 0 时，栈空的条件表达式？::S.top == 0
- top 初始化为 0 时，栈满的条件表达式？::S.top == MaxSize

- top 指向栈顶下一位置时，出栈代码逻辑？::先将 top 减 1，再取出 S.data[top]。
- 共享栈中两个栈的栈底分别位于何处？::分别置于数组的两端。
- 共享栈中 0 号栈顶指针 top0 的初始值？::-1
- 共享栈中 1 号栈顶指针 top1 的初始值？::MaxSize
- 共享栈发生栈溢出的判断条件？::top1 - top0 == 1（两栈顶相邻）

- 本节约定的链栈是否带头结点？::不带头结点，栈顶指针直接指向栈顶元素。
- 链栈是否存在栈满溢出的问题？::不存在，便于动态分配存储空间。
- 链栈在什么场景下比顺序栈更灵活？::多栈共存或无法预估最大使用空间的场景。
