# 7.3 树形查找

> [!abstract] 一句话总结
> 树形查找通过 BST 实现动态有序访问，利用 AVL 严格平衡保障 $O(/log n)$ 查找，借助红黑树适度平衡优化插入删除开销。

## 核心要点
### 考点1：二叉排序树 (BST) 定义与性质
**BST 中序遍历必得递增序列，且左子树关键字均小于根，右子树关键字均大于根。**
定义：若左子树非空则 $Key_{left} < Key_{root}$；若右子树非空则 $Key_{right} > Key_{root}$。

> [!tip] 考试怎么用
> 判断是否为 BST 不能只看局部父子关系，必须验证整棵子树范围；中序遍历是验证 BST 的充要条件。

### 考点2：BST 的查找、插入与构造
**查找失败时的最后访问结点即为新结点的父结点，新插入结点必为叶结点。**
```c\nBSTNode *BST_Search(BiTree T,ElemType key){
 while(T!=NULL && key!=T->data){
 if(key<T->data) T=T->lchild;
 else T=T->rchild;
 }
 return T;
}
```

> [!tip] 考试怎么用
> 构造 BST 时，相同关键字序列若插入顺序不同，生成的树形态可能不同；重复关键字通常被忽略。

### 考点3：BST 的删除操作
**删除双孩子结点时，需用其直接前驱或直接后继替代，再删除该前驱或后继。**
情形③处理：用 z 的直接后继（右子树最小）替代 z，转化为删除只有 0 或 1 个孩子的情形。

> [!tip] 考试怎么用
> 删除后重新插入同一结点，树形态不一定恢复原状，因为新结点必为叶结点。

### 考点4：平衡二叉树 (AVL) 定义与平衡因子
**AVL 树中任意结点的平衡因子只能是 -1、0 或 1，即左右子树高度差绝对值不超过 1。**
平衡因子 $BF = H_{left} - H_{right}$，且 $|BF| \leq 1$。最少结点数递推：$n_h = n_{h-1} + n_{h-2} + 1$。

> [!tip] 考试怎么用
> 计算含 n 个结点的 AVL 树最大深度（最多比较次数）需利用 $n_h$ 递推公式反推。

### 考点5：AVL 树的插入调整 (LL/RR/LR/RL)
**插入失衡后，找到最小不平衡子树根结点 A，根据新结点位置执行四种旋转之一恢复平衡。**
LL(右单旋): A 左孩 B 上提；RR(左单旋): A 右孩 B 上提；LR: 先左旋 B 再右旋 A；RL: 先右旋 B 再左旋 A。

> [!tip] 考试怎么用
> LR 和 RL 是双旋转，本质是先转化为 LL 或 RR 情形；调整对象始终是“最小不平衡子树”。

### 考点6：AVL 树的删除调整
**AVL 删除可能导致多次失衡，需从删除点向上回溯，对每个失衡结点依次调整直至根。**
步骤：1.按 BST 删除；2.向上找第一个失衡点 z；3.调整 z；4.若子树高度减 1，继续检查 z 的父结点。

> [!tip] 考试怎么用
> 删除操作与插入的最大区别：插入最多调整一次，删除可能沿路径向上多次调整。

### 考点7：红黑树定义与性质
**红黑树是适度平衡的 BST，保证从根到叶最长路径不超过最短路径的 2 倍，高度 $h \leq 2\log_2(n+1)$。**
性质：①红/黑；②根黑；③叶 (NULL) 黑；④无连续红；⑤任意路径黑结点数相同。黑高 $bh \geq h/2$。

> [!tip] 考试怎么用
> 红黑树适合插入删除频繁场景（调整少），AVL 适合查找频繁场景（树更矮）；C++ map 基于红黑树。

### 考点8：红黑树的插入调整
**新结点必染红，若父红则违例，根据叔结点颜色分三种情形：变色上溯、单旋、双旋。**
情形 3(叔红): 父叔变黑，爷变红，z 上移两层继续检查；情形 1/2(叔黑): 旋转 + 变色，一次终止。

> [!tip] 考试怎么用
> 情形 3 可能导致连锁反应直至根（根需强制变黑）；情形 1 和 2 执行旋转后必然结束。

### 考点9：红黑树的删除调整
**删除黑结点产生“双黑”违例，根据兄弟结点及其孩子颜色分四种情形，通过旋转或变色消除双黑。**
情形 1(兄红): 变色 + 旋转转情形 2/3/4；情形 2(兄黑右红): 变色 + 旋转结束；情形 3(兄黑左红): 旋转转情形 2；情形 4(兄黑子黑): 去黑上推。

> [!tip] 考试怎么用
> 情形 4 是唯一可能重复执行的情形（指针上移），其他情形常数步内结束；删除比插入更复杂。

## 易混与对比
**BST、AVL 与红黑树的性能对比**

|特性|二叉排序树 (BST)|平衡二叉树 (AVL)|红黑树|
|---|---|---|---|
|平衡标准|无限制|严格 ($|BF|\leq 1$)|适度 (最长$\leq$2 倍最短)|
|最坏高度|$O(n)$|$O(\log_2 n)$|$O(\log_2 n)$|
|查找效率|低 (退化时)|最高 (树最矮)|较高|
|插入/删除开销|低 (仅指针)|高 (频繁旋转)|较低 (旋转少)|
|适用场景|数据随机|查找多、增删少|增删频繁 (如 C++ map)

- **AVL 与红黑树调整次数差异**：**AVL 树**：插入最多调整 1 次（局部修复即全局平衡）；删除可能调整 $O(\log n)$ 次（高度变化向上传播）。
  **红黑树**：插入最多调整 2 次旋转（变色可能多次但旋转少）；删除最多 3 次旋转（情形 4 仅变色上溯，不增加旋转次数）。
- **BST 删除后重插是否复原**：**不一定**。\nBST 删除双孩子结点时，是用前驱/后继替代，原结点位置被占；重新插入时，新结点必作为叶结点插入，位置通常不同于原位置，导致树形态改变。
- **红黑树黑高与内部结点关系**：黑高为 $h$ 的红黑树：
  最少内部结点数：$2^h - 1$（全黑路径）。
  最多内部结点数：$2^{2h} - 1$（红黑交替路径）。
  此性质用于证明红黑树高度 $h \leq 2\log_2(n+1)$。

## 闪卡
#card
- 如何验证一棵二叉树是否为二叉排序树？::对其进行中序遍历，若得到的关键字序列严格递增则是，否则不是。
- BST 中任意结点左子树上的所有结点关键字满足什么条件？::均小于该根结点的关键字。
- BST 中任意结点右子树上的所有结点关键字满足什么条件？::均大于该根结点的关键字。
- BST 的查找、插入、删除操作基于什么核心结构特性？::利用其有序结构支持高效的动态查找，具有天然递归结构。
- BST 插入新结点时，该结点最终一定处于什么位置？::一定是叶结点，且是查找失败时访问的最后一个结点的孩子。
- 若输入序列有序（如 1,2,3...），构造出的 BST 形态及 ASL 是多少？::退化为单支树（高度 n），ASL 退化为 $(n+1)/2$。
- BST 查找算法中，若 key 小于当前结点值，下一步操作是什么？::在当前结点的左子树上继续查找。
- 构造 BST 时，若遇到已存在的关键字，通常如何处理？::插入失败，忽略该关键字，树结构不变。
- 删除 BST 中只有左子树或只有右子树的结点，如何操作？::将其唯一的子树上移，替代该结点与其父结点连接。
- 删除 BST 中同时有左右子树的结点，首选替代方案是什么？::用该结点的直接后继（或前驱）替代它，再删除那个后继（或前驱）。
- 在 BST 中删除某结点后再重新插入该结点，树是否一定复原？::不一定，因为新插入的结点必然成为叶结点，位置可能改变。
- 删除叶结点时，对 BST 性质有何影响？::直接删除即可，不会破坏二叉排序树的性质。
- 平衡二叉树中，任意结点的平衡因子取值范围是多少？::只能取 -1、0 或 1。
- 深度为 h 的平衡二叉树最少包含多少个结点（递推公式）？::$n_h = n_{h-1} + n_{h-2} + 1$，其中 $n_0=0, n_1=1$。
- 含有 12 个结点的平衡二叉树，查找时最多比较多少次？::5 次（因 $n_4=7, n_5=12$，故 12 个结点最大深度为 5）。
- AVL 树与普通 BST 的核心区别是什么？::AVL 树严格限制任意结点左右子树高度差绝对值不超过 1。
- LL 型失衡（左孩子的左子树插入）应采用何种旋转？::右单旋转（将左孩子向右上旋转代替根）。
- RR 型失衡（右孩子的右子树插入）应采用何种旋转？::左单旋转（将右孩子向左上旋转代替根）。
- LR 型失衡的旋转步骤是什么？::先对左孩子进行左旋，再对根结点进行右旋（先左后右）。
- RL 型失衡的旋转步骤是什么？::先对右孩子进行右旋，再对根结点进行左旋（先右后左）。
- AVL 插入调整时，是否可能需要多次旋转？::不需要，插入操作只需对最小不平衡子树进行一次调整即可恢复全树平衡。
- AVL 树删除结点后，若导致不平衡，调整范围是什么？::从删除结点向上回溯，对所有失衡的最小不平衡子树依次调整，可能直到根。
- AVL 删除操作中，若一次调整使子树高度减 1，后续操作是什么？::需继续检查该子树根结点的父结点是否失衡，可能引发连锁调整。
- AVL 删除调整的分类依据与插入是否相同？::相同，均根据失衡结点及其较高子树根的相对位置分为 LL、RR、LR、RL 四种。
- 红黑树中，从根到叶的最长路径长度最多是最短路径的多少倍？::2 倍（因最短全黑，最长红黑交替，黑结点数相同）。
- 红黑树的叶结点（外部结点/NULL）规定是什么颜色？::黑色。
- 红黑树中是否允许出现两个相邻的红色结点？::不允许，红结点的父结点和孩子结点必须均为黑色。
- 有 n 个内部结点的红黑树，其高度 h 的上界公式是什么？::$h \leq 2\log_2(n+1)$。
- 相比 AVL 树，红黑树的主要优势场景是什么？::插入和删除操作频繁的场景，因为其结构调整频率更低。
- 红黑树插入新结点时，初始颜色应设为什么？为什么？::红色。若设黑色会破坏性质⑤（黑高不等），设红色仅可能破坏性质④（易局部修复）。
- 红黑树插入时，若叔结点是红色，应采取什么策略？::将父结点和叔结点染黑，爷结点染红，并将爷结点视为新 z 向上回溯检查。
- 红黑树插入时，若叔结点是黑色且呈 LL 型，如何调整？::对爷结点右单旋，原父结点染黑，原爷结点染红。
- 红黑树插入调整中，哪种情形可能导致多次循环向上回溯？::叔结点为红色的情形（情形 3），其他情形旋转后即结束。
- 红黑树删除黑色叶结点后，替换它的 NULL 结点被视为具有什么属性？::双黑结点（即该路径黑结点数少 1，需补偿）。
- 红黑树删除调整中，若兄弟结点是红色（情形 1），第一步操作是什么？::交换兄弟与父结点颜色，并对父结点旋转，转化为兄弟为黑色的情形。
- 红黑树删除调整中，情形 4（兄弟及孩子均黑）的处理后果是什么？::从兄弟和当前结点各去一重黑，父结点增加一重黑，指针上移继续检查。
- 红黑树删除调整中，哪种情形是唯一可能需要重复执行多次的？::情形 4（兄弟及孩子均为黑色），每次执行指针上升一层。
