# 5.4 树、森林

> [!abstract] 一句话总结
> 树与森林通过'左孩子 - 右兄弟'法则与二叉树同构，其存储、转换及遍历操作均基于此映射关系展开。

## 核心要点
### 考点1：树的双亲表示法
**利用数组连续存储，结点含数据域与指示双亲下标的伪指针域，根结点双亲域为 -1。**
typedef struct{ ElemType data; int parent; } PTNode;
查找双亲 $O(1)$，查找孩子需遍历数组 $O(n)$。

> [!tip] 考试怎么用
> 易混淆二叉树顺序存储：双亲表示法下标仅标识结点，父子关系显式记录；二叉树顺序存储下标隐含父子关系（$2i+1$）。

### 考点2：树的孩子表示法
**将每个结点的孩子构成单链表，所有链表头指针存入顺序表（数组）中。**
n 个头指针数组 + n 个孩子链表；叶结点对应空链表。

> [!tip] 考试怎么用
> 查找孩子高效，查找双亲需遍历所有链表，效率较低。

### 考点3：树的孩子兄弟表示法
**采用二叉链表，结点含数据域、第一个孩子指针、下一个兄弟指针，又称二叉树表示法。**
typedef struct CSNode{ ElemType data; struct CSNode *firstchild, *nextsibling; } CSNode;

> [!tip] 考试怎么用
> 最大优点是自然将树转为二叉树复用算法；缺点是回溯双亲困难，可增设 parent 域形成三叉链表。

### 考点4：树转换为二叉树
**遵循'左孩子 - 右兄弟'原则：左指针指第一个孩子，右指针指下一个右兄弟。**
步骤：1.兄弟连线；2.留长子删其他；3.顺时针旋转 $45^{\\\circ}$。

> [!tip] 考试怎么用
> 转换后的二叉树根结点必无右子树，因为原树根无兄弟。

### 考点5：森林转换为二叉树
**先将各树转为二叉树，再将各二叉树根视为兄弟，依次作为前一棵的右子树连接。**
等效做法：先在森林各树根间加连线，再整体应用树转二叉树规则。

> [!tip] 考试怎么用
> 森林转二叉树后，第一棵树的根即为二叉树的根，其余树根沿右链排列。

### 考点6：二叉树转换为森林
**断开根右指针，左子树为第一棵树，右子树递归转换为剩余森林，最后还原各二叉树为树。**
规则：根及左子树$\\to$第一棵树；右子树$\\to$剩余森林；结果唯一。

> [!tip] 考试怎么用
> 若二叉树根无右子树，则对应单棵树；若有右子树，则对应多棵树组成的森林。

### 考点7：树和森林的遍历
**树先根遍历对应二叉树先序，树后根遍历对应二叉树中序；森林同理。**
树先根=访问根 + 遍历子树；树后根=遍历子树 + 访问根。
森林先序=访问首树根 + 遍历首树子树森林 + 遍历剩余森林。

> [!tip] 考试怎么用
> 森林中序遍历在某些教材称后序遍历，因根最后访问，但 408 标准称中序。

## 易混与对比
**双亲表示法 vs 二叉树顺序存储**

|特性|树的双亲表示法|完全二叉树顺序存储|
|---|---|---|
|下标含义|仅标识结点位置|隐含父子关系 ($i$ 的孩子为 $2i+1, 2i+2$)|
|关系记录|显式 parent 域|隐式计算|
|适用范围|任意树|仅限完全二叉树或近似完全二叉树|

**树/森林遍历与二叉树遍历对应表**

|原结构|遍历名称|对应二叉树遍历|
|---|---|---|
|树|先根遍历|先序遍历|
|树|后根遍历|中序遍历|
|森林|先序遍历|先序遍历|
|森林|中序遍历|中序遍历|

**孩子表示法 vs 孩子兄弟表示法**

|特性|孩子表示法|孩子兄弟表示法|
|---|---|---|
|结构|数组 + n 个单链表|二叉链表 (firstchild, nextsibling)|
|查孩子|高效|高效|
|查双亲|低效 (遍历所有链表)|低效 (需额外 parent 域)|
|优势|直观存储孩子集合|可无缝转换为二叉树复用算法|

## 闪卡
#card
- 双亲表示法中根结点的 parent 域值是多少？::-1，表示无双亲。
- 双亲表示法查找某结点双亲的时间复杂度？::$O(1)$，直接通过 parent 域获取。
- 双亲表示法查找某结点所有孩子的时间复杂度？::$O(n)$，需遍历整个数组筛选。
- 双亲表示法与完全二叉树顺序存储的本质区别？::前者下标不隐含关系，后者下标隐含 $2i+1$ 等关系。
- 孩子表示法中叶结点的孩子链表状态？::空链表（NULL）。
- 孩子表示法查找某结点双亲的操作方式？::遍历所有孩子链表，检查是否包含该结点。
- 孩子表示法适合频繁进行什么操作？::查找结点的孩子。
- 孩子兄弟表示法中 nextsibling 指针的作用？::指向当前结点的下一个右侧兄弟。
- 孩子兄弟表示法能否直接高效访问双亲？::不能，需遍历或增设 parent 指针。
- 孩子兄弟表示法的最大优势是什么？::能自然将树转换为二叉树，复用二叉树算法。
- 树转二叉树后，原树根结点的右子树情况？::必为空，因为根结点没有兄弟。
- 树转二叉树的'左孩子 - 右兄弟'规则中左指针指向？::原树中该结点的第一个孩子。
- 树转二叉树的手工画法第三步操作？::以树根为轴心，顺时针旋转 $45^{\\circ}$。
- 森林转二叉树时，第二棵树的根成为第一棵树根的什么？::右子树（或右孩子）。
- 森林转二叉树的等效简便画法？::先连各树根，再整体按'左孩右兄'旋转。
- 森林中第 k 棵树的根在对应二叉树中的位置？::第一棵树根的第 k-1 层右孩子路径上。
- 二叉树转森林时，根的右子树代表什么？::除去第一棵树后的剩余森林。
- 二叉树转换为森林的结果是否唯一？::是，结果唯一。
- 何时二叉树转换为单棵树而非森林？::当二叉树根结点的右指针为空时。
- 树的先根遍历序列对应其二叉树的哪种序列？::先序遍历序列。
- 树的后根遍历序列对应其二叉树的哪种序列？::中序遍历序列。
- 森林的中序遍历在某些教材中也被称为什么？::后序遍历（因根最后访问）。
- 森林先序遍历的第一步操作？::访问森林中第一棵树的根结点。
