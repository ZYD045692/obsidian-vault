# 5.3 二叉树的遍历和线索二叉树

> [!abstract] 一句话总结
> 二叉树遍历通过固定 NLR 顺序将非线性结构线性化，而线索二叉树利用 $n+1$ 个空指针域存储前驱后继以消除递归栈开销。

## 核心要点
### 考点1：三种递归遍历定义与代码
**先序 (NLR)、中序 (LNR)、后序 (LRN) 的区别仅在于访问根结点的时机，左右子树遍历顺序固定为先左后右。**
时间复杂度均为 $O(n)$；递归栈空间复杂度最坏 $O(n)$（单支树）。
```c\nvoid PreOrder(BiTree T) {
 if (T != NULL) { visit(T); PreOrder(T->lchild); PreOrder(T->rchild); }
}
```

> [!tip] 考试怎么用
> 手写代码时注意判断 `T != NULL` 是递归出口；考题常给序列反推树结构或计算特定结点访问次序。

### 考点2：层次遍历算法
**层次遍历遵循从上到下、从左到右顺序，必须借助队列实现，根结点首先入队。**
基本思想：根入队 -> 出队访问 -> 左右孩子非空则依次入队。
```c\nwhile(!IsEmpty(Q)) { DeQueue(Q, p); visit(p); if(p->lchild) EnQueue(Q, p->lchild); ... }
```

> [!tip] 考试怎么用
> 这是唯一非递归且不需要栈的遍历方式；常考求树的宽度或按层输出结点。

### 考点3：由遍历序列构造二叉树
**仅凭一种遍历序列无法唯一确定二叉树；必须包含中序序列，配合先序、后序或层序中的任意一种方可唯一重构。**
构造逻辑：先序/后序/层序定根 -> 中序划分左右子树 -> 递归构造。
注意：先序 + 后序、先序 + 层序、后序 + 层序均无法唯一确定。

> [!tip] 考试怎么用
> 解题步骤：1.找根；2.在中序中切分；3.确定左右子树元素集合；4.递归。

### 考点4：线索二叉树基本概念
**利用 $n$ 个结点的二叉链表中 $n+1$ 个空指针域存放遍历序列中的前驱和后继，称为线索。**
结点结构：`lchild, ltag, data, rtag, rchild`。
规则：$ltag=1$ 指前驱，$rtag=1$ 指后继；$0$ 表示指向孩子。

> [!tip] 考试怎么用
> 计算空指针数公式：$2n_0 + n_1 = n_0 + (n_0 + n_1 + n_2) - n_2 = n + 1$（利用 $n_0=n_2+1$）。

### 考点5：中序线索二叉树的构造与遍历
**线索化本质是遍历过程，用 pre 记录前驱；遍历时若 rtag=1 直接取后继，否则找右子树最左下结点。**
查找后继逻辑：
若 $p->rtag==1$，后继为 $p->rchild$；
若 $p->rtag==0$，后继为 `Firstnode(p->rchild)`（右子树最左下）。

> [!tip] 考试怎么用
> 构造时注意处理首尾结点（通常加头结点形成循环）；遍历无需递归或栈。

### 考点6：先序与后序线索二叉树特点
**先序找后继简单（有左找左，无左找右，无孩找线索）；后序找后继复杂，通常需父指针。**
后序找后继三种情况：
1. x 是根 -> 无后继；
2. x 是右孩 或 (左孩且双亲无右) -> 后继是双亲；
3. x 是左孩且双亲有右 -> 后继是双亲右子树的最左下结点。

> [!tip] 考试怎么用
> 后序线索树若无父指针，无法高效查找后继，这是其与中序/先序的最大区别。

## 易混与对比
**遍历序列重构二叉树的条件**

|组合方式|能否唯一确定|原因|
|:---|:---|:---|
|先序 + 中序|**能**|先序定根，中序分左右|
|后序 + 中序|**能**|后序定根，中序分左右|
|层序 + 中序|**能**|层序定根（逐层），中序分左右|
|先序 + 后序|**不能**|无法区分左右子树边界（如单支树歧义）|
|先序 + 层序|**不能**|缺乏中序的左右划分信息|

**线索二叉树查找后继的差异**

|遍历类型|rtag=0 时找后继方法|是否需要父指针|
|:---|:---|:---|
|**中序**|右子树的最左下结点|否|
|**先序**|若有左孩则左孩，否则右孩|否|
|**后序**|需判断是左孩还是右孩，可能涉及双亲|**是** (通常推荐三叉链表)|

- **空指针域数量计算**：误区：认为只有叶子结点有空指针。
  正解：$n$ 个结点共有 $2n$ 个指针域，非空指针数为 $n-1$（除根外每个结点有一个入边），故空指针数 $= 2n - (n-1) = n+1$。也可推导为 $2n_0 + n_1 = n+1$。

## 闪卡
#card
- 先序遍历中根结点相对于左右子树的访问顺序？::根结点最先访问 (NLR)。
- 中序遍历序列中，根结点左侧和右侧分别是什么？::左侧是左子树中序序列，右侧是右子树中序序列。
- 后序遍历中，根结点何时被访问？::在左子树和右子树均遍历完成后最后访问。
- 单支树情况下，递归遍历的空间复杂度是多少？::$O(n)$，等于树的高度。
- 层次遍历必须使用的辅助数据结构是什么？::队列 (Queue)。
- 层次遍历中，结点出队后紧接着执行什么操作？::访问该结点，并将其非空的左右孩子依次入队。
- 若二叉树为空，层次遍历算法直接执行什么？::不执行任何操作（或队列为空直接结束）。
- 哪两种遍历序列组合无法唯一确定一棵二叉树？::先序和后序（或先序和层序、后序和层序）。
- 由先序和中序序列构造时，先序序列的第一个结点代表什么？::整棵二叉树的根结点。
- 由后序和中序序列构造时，如何确定根结点？::后序序列的最后一个结点是根结点。
- 由层序和中序序列构造时，层序序列中紧跟根结点后的结点一定是？::若存在左子树则是左子树根，否则是右子树根（需结合中序判断）。
- n 个结点的二叉树中，空指针域的总数是多少？::$n+1$ 个。
- 线索二叉树中 ltag=1 表示 lchild 指向哪里？::指向该结点在指定遍历序列中的前驱。
- 线索二叉树中 rtag=0 表示 rchild 指向哪里？::指向该结点的右孩子。
- 引入线索二叉树的主要目的是什么？::加快查找前驱和后继的速度，实现无栈遍历。
- 中序线索化过程中，pre 指针的作用是什么？::指向刚刚访问过的结点，作为当前结点 p 的前驱。
- 在中序线索二叉树中，若 rtag=0，如何找到结点 p 的后继？::进入右子树，找到该子树中序序列的第一个结点（最左下结点）。
- 带头结点的中序线索二叉树，头结点的 rchild 指向哪里？::指向中序序列的最后一个结点。
- 中序线索二叉树遍历是否需要使用栈？::不需要，利用线索直接跳转。
- 在先序线索二叉树中，若结点有左孩子，其后继是谁？::其左孩子。
- 在后序线索二叉树中，若结点 x 是双亲的右孩子，其后继是谁？::其双亲结点。
- 为什么后序线索二叉树查找后继通常需要三叉链表？::因为某些情况下后继是双亲，而标准二叉链表无法直接获取双亲。
- 后序序列中，根结点的后继存在吗？::不存在（根是后序序列最后一个结点）。
