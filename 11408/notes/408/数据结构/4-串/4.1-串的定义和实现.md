# 4.1 串的定义和实现

> [!abstract] 一句话总结
> 串是字符受限的线性表，其核心矛盾在于定长截断与动态分配的存储权衡，以及以子串为单位的操作特性。

## 核心要点
### 考点1：串的定义与特性
**串是由零个或多个字符组成的有限序列，逻辑结构同线性表但操作对象通常为子串。**
定义式：$S=^{\prime}a_{1}a_{2}\cdots a_{n}^{\prime}\quad(n\geqslant0)$；空串 $n=0$ 记为 $\varnothing$；空格串长度等于空格个数。

> [!tip] 考试怎么用
> 严格区分空串（长度 0）与空格串（长度>0）；子串位置由首字符在主串中的序号决定。

### 考点2：串的最小操作子集
**赋值、比较、求长、联接、求子串五种操作构成最小操作子集，其余操作均可由此推导。**
最小集：StrAssign, StrCompare, StrLength, Concat, SubString；其他如 Index, StrCopy 可基于此实现。

> [!tip] 考试怎么用
> 考题常问哪些是原子操作；注意 StrCompare 返回值规则：$S>T \to >0, S=T \to 0, S<T \to <0$。

### 考点3：定长顺序存储
**使用预分配固定数组存储，串长超限部分会被截断，需显式记录长度或用结束符。**
结构：`typedef struct{ char ch[MAXLEN]; int length; } sString;`；超限处理：截断多余部分。

> [!tip] 考试怎么用
> 注意 MAXLEN 限制；插入或联接结果超限时，教材默认采取“截断”策略而非报错。

### 考点4：堆分配存储
**存储单元连续但动态申请，通过 malloc/free 管理，解决了定长存储的空间限制。**
结构：`typedef struct{ char *ch; int length; } HString;`；分配：`ch = (char*)malloc(len*sizeof(char));`

> [!tip] 考试怎么用
> ch 指向动态分配的基地址；分配失败返回 NULL；仍需手动维护 length 字段。

### 考点5：块链存储
**采用链表结构，每个结点（块）可存多个字符，最后一块不满时常用特殊字符补齐。**
结点内容：1 个或多个字符；补齐策略：最后一块占不满时通常用

## 闪卡
#card
- 串的长度 n 为 0 时称为什么？::空串，用符号 $\varnothing$ 表示。
- 空格串与空串的区别是什么？::空格串含空格字符，长度>0；空串无字符，长度=0。
- 子串在主串中的位置如何标识？::以子串第 1 个字符在主串中的序号（位置）来标识。
- 串与线性表在基本操作上的主要差异？::线性表以单个元素为单位，串通常以子串为单位。
- 串类型的最小操作子集包含哪五个操作？::赋值、比较、求长、联接、求子串。
- StrCompare(S,T) 当 S<T 时返回什么值？::返回值小于 0。
- Index(S,T) 操作若未找到子串返回什么？::返回 0。
- 除清空和销毁外，其他串操作能否由最小集实现？::能，其余操作均可基于最小操作子集实现。
- 定长顺序存储中串长超过 MAXLEN 如何处理？::多余部分被舍弃，称为截断。
- 定长存储表示串长的两种方式？::独立整型变量显式记录；或末尾加'\0'隐含计算。
- 定长顺序存储的根本缺陷是什么？::存在串长上限硬性规定，无法动态扩展。
- 定长存储结构体中 length 字段的作用？::显式记录串的实际长度，区别于数组最大容量。
- 堆分配存储中 ch 指针指向哪里？::指向动态分配的连续存储空间起始地址（基地址）。
- 堆分配存储如何解决定长存储的缺陷？::运行时动态申请大小等于串长的空间，取消上限规定。
- C 语言中堆分配失败时 malloc 返回什么？::返回 NULL。
- 堆分配存储是否需要 length 字段？::需要，结构体中仍需整型变量记录串长。
