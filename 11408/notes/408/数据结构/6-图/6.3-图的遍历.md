# 6.3 图的遍历

> [!abstract] 一句话总结
> 图遍历通过 visited 数组防重，BFS 借队列按层扩散求最短路径，DFS 借递归栈纵深探索判连通分量。

## 核心要点
### 考点1：广度优先搜索 (BFS) 机制
**BFS 类似树层序遍历，按路径长度递增顺序访问，需借助辅助队列实现非递归分层处理。**
核心代码逻辑：
```c\nEnQueue(Q, v); visited[v]=TRUE;\nwhile(!QueueEmpty(Q)) {
 DeQueue(Q, u);
 for(w=FirstNeighbor(G,u); w>=0; w=NextNeighbor(G,u,w))
 if(!visited[w]) { visit(w); visited[w]=TRUE; EnQueue(Q,w); }
}
```

> [!tip] 考试怎么用
> 注意 BFS 序列唯一性取决于存储结构：邻接矩阵唯一，邻接表因邻接点顺序不定而不唯一。

### 考点2：BFS 性能与最短路径
**BFS 空间复杂度为 $O(|V|)$，时间复杂度邻接表为 $O(|V|+|E|)$、邻接矩阵为 $O(|V|^2)$，可解非带权图单源最短路径。**
最短路径递推公式：$d[w] = d[u] + 1$（当 $w$ 是 $u$ 未访问邻接点时）。
时间复杂度结论：邻接表 $O(|V|+|E|)$，邻接矩阵 $O(|V|^2)$。

> [!tip] 考试怎么用
> 仅适用于非带权图（边权视为 1），带权图最短路径需用 Dijkstra 算法。

### 考点3：广度优先生成树
**BFS 过程中经过的边与顶点构成生成树，邻接矩阵存储时生成树唯一，邻接表存储时可能不唯一。**
生成树唯一性判据：
1. 邻接矩阵：表示唯一 $\to$ 同一源点生成树唯一。
2. 邻接表：表示不唯一 $\to$ 邻接点访问顺序不确定 $\to$ 生成树可能不唯一。

> [!tip] 考试怎么用
> 若题目给定具体邻接表结构，则生成树是确定的；若只给逻辑图且说用邻接表，则答案可能不唯一。

### 考点4：深度优先搜索 (DFS) 机制
**DFS 类似树先序遍历，遵循尽可能“深”的策略，无法继续时回溯，通常以递归形式实现。**
核心递归代码逻辑：
```c\nvisit(i); visited[i]=TRUE;\nfor(j=FirstNeighbor(G,i); j>=0; j=NextNeighbor(G,i,j))
 if(!visited[j]) DFS(G, j);
```

> [!tip] 考试怎么用
> DFS 序列同样受存储结构影响：邻接矩阵唯一，邻接表不唯一；注意回溯发生在无未访问邻接点时。

### 考点5：DFS 性能与生成森林
**DFS 空间复杂度 $O(|V|)$（递归栈），时间复杂度同 BFS；非连通图 DFS 生成的是生成森林。**
生成森林定义：若图非连通，DFS 为每个连通分量分别生成一棵树，这些树构成深度优先生成森林。
复杂度：邻接表 $O(|V|+|E|)$，邻接矩阵 $O(|V|^2)$。

> [!tip] 考试怎么用
> 连通图得生成树，非连通图得生成森林；生成树/森林的唯一性规则与 BFS 相同。

### 考点6：图遍历与连通性判定
**调用 BFS/DFS 的次数等于无向图的连通分量数；有向图需外层循环确保覆盖所有顶点。**
判定逻辑模板：
```c\nfor(i=0; i<G.vexnum; ++i)
 if(!visited[i]) { count++; Traverse(G, i); }
// count 即为连通分量数（针对无向图）
```

> [!tip] 考试怎么用
> 无向图一次遍历覆盖一个连通分量；有向图即使弱连通，单次遍历也不一定覆盖所有顶点。

## 易混与对比
**BFS 与 DFS 的核心差异对比**

|特性|广度优先搜索 (BFS)|深度优先搜索 (DFS)|
|---|---|---|
|**类比对象**|树的层序遍历|树的先序遍历|
|**核心策略**|按路径长度递增，分层访问|尽可能“深”地探索，无路则回溯|
|**辅助结构**|队列 (Queue)|递归栈 (System Stack)|
|**典型应用**|非带权图单源最短路径|连通性判定、拓扑排序基础|
|**序列唯一性**|邻接矩阵唯一，邻接表不唯一|邻接矩阵唯一，邻接表不唯一|

- **存储结构对遍历结果的影响**：**误区**：认为图的遍历序列天生唯一。
  **正解**：
  1. **邻接矩阵**：表示唯一 $\to$ 邻接点查找顺序固定（下标从小到大） $\to$ **BFS/DFS 序列唯一**，生成树唯一。
  2. **邻接表**：边的输入顺序不同 $\to$ 链表节点顺序不同 $\to$ **BFS/DFS 序列不唯一**，生成树不唯一。
  *注：此结论适用于同一源点出发的情况。*
- **连通分量计数的适用范围**：**无向图**：调用 `BFS/DFS` 的次数 **严格等于** 连通分量数。
  **有向图**：调用次数 **不等于** 强连通分量数。因为有向图存在单向可达性，外层循环仅是为了强制访问那些从之前起点不可达的顶点，不能直接用于计算强连通分量（需 Tarjan 或 Kosaraju 算法）。

## 闪卡
#card
- BFS 算法必须借助什么辅助数据结构？::辅助队列，用于暂存当前层顶点的下一层邻接顶点。
- BFS 访问顶点的顺序依据是什么？::按路径长度递增顺序，先访问距离为 1 的，再访问距离为 2 的。
- 基于邻接矩阵的 BFS 序列是否唯一？::是唯一的，因为邻接矩阵表示唯一且邻接点访问顺序固定。
- 基于邻接表的 BFS 序列是否唯一？::不唯一，因为边的输入顺序不同导致邻接表结构及访问顺序不同。
- BFS 求解单源最短路径的前提条件？::图必须是非带权图，定义最短路径为所含边数的最小值。
- 采用邻接表存储时 BFS 的时间复杂度？::$O(|V| + |E|)$，每个顶点入队一次，每条边访问一次。
- 采用邻接矩阵存储时 BFS 的时间复杂度？::$O(|V|^2)$，查找每个顶点邻接点需扫描整行耗时 $O(|V|)$。
- BFS 算法的空间复杂度是多少？::$O(|V|)$，最坏情况下辅助队列需容纳所有顶点。
- 什么情况下 BFS 生成的生成树是唯一的？::当图采用邻接矩阵存储且起始顶点相同时，生成树唯一。
- 为什么邻接表存储的 BFS 生成树可能不唯一？::因为边的输入顺序不同导致邻接表中邻接点排列顺序不同。
- 广度优先生成树由什么构成？::由遍历过程中所经过的边与访问的顶点共同构成。
- DFS 算法通常采用什么方式实现？::递归形式，依赖系统提供的递归工作栈。
- DFS 何时执行回退（回溯）操作？::当当前顶点没有更多未被访问的邻接顶点时，回退至上一顶点。
- 基于邻接表的 DFS 序列是否唯一？::不唯一，取决于邻接表中邻接点的存储顺序。
- 基于邻接矩阵的 DFS 序列是否唯一？::是唯一的，因为邻接矩阵表示唯一且遍历顺序固定。
- DFS 算法的空间复杂度及原因？::$O(|V|)$，最坏情况下递归深度可达顶点数 $|V|$。
- 什么情况下 DFS 会生成生成森林？::当图是非连通图时，为每个连通分量生成一棵树，构成森林。
- DFS 时间复杂度是否与访问顺序有关？::无关，仅取决于图的存储结构（邻接表或邻接矩阵）。
- 基于邻接表的 DFS 生成树是否唯一？::不唯一，原因同 BFS，取决于邻接点访问顺序。
- 无向图中调用 DFS 的次数代表什么？::恰好等于该图的连通分量数。
- 为何有向图遍历也需要外层 for 循环？::因为即使图弱连通，从某点出发也可能无法到达所有其他顶点。
- 如何判断无向图是否连通？::若只需一次遍历（调用一次 BFS/DFS）即可访问所有顶点，则图连通。
- 有向图单次 DFS 能否保证访问所有顶点？::不能，仅当从初始顶点到所有其他顶点都存在路径时才可以。
