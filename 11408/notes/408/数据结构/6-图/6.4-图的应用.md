# 6.4 图的应用

> [!abstract] 一句话总结
> 本节核心在于掌握贪心策略构建最小生成树、动态规划与松弛操作求解最短路径、以及利用拓扑序解决 DAG 上的表达式压缩与工程关键路径问题。

## 核心要点
### 考点1：最小生成树 (MST) 性质与通用框架
**MST 是连通图总权值最小的生成树，边数恒为 $n-1$，权值互异时唯一，但 MST 路径不一定是最短路径。**
通用框架：$T=\emptyset$; while ($T$ 未形成树) { 选最小代价边 $(u,v)$ 且不构成回路; $T=T \cup \{(u,v)\}$; }

> [!tip] 考试怎么用
> 易错点：MST 总权值最小不代表任意两点间路径最短；权值相同边存在时 MST 可能不唯一。

### 考点2：Prim 算法
**Prim 算法从单一顶点出发，每次选择连接已选集合 $U$ 与未选集合 $V-U$ 的最小权边，适合稠密图。**
时间复杂度：$O(|V|^2)$，与边数 $|E|$ 无关，适用于边稠密图。

> [!tip] 考试怎么用
> 模拟时注意：每次扩展的是“连接树内与树外”的最小边，而非全局最小边。

### 考点3：Kruskal 算法
**Kruskal 算法按边权递增顺序选边，若边连接两个不同连通分量则加入，适合稀疏图。**
时间复杂度：$O(|E|\log_2|E|)$，依赖并查集判断回路，适用于边稀疏图。

> [!tip] 考试怎么用
> 模拟时需用并查集思想：若边两端点已在同一集合，加入会成环，必须舍弃。

### 考点4：Dijkstra 单源最短路径
**Dijkstra 基于贪心策略，每次选未确定点中距离源点最近的点加入集合 $S$，不适用于负权边。**
松弛操作：若 $\text{dist}[j] + \text{arcs}[j][k] < \text{dist}[k]$，则 $\text{dist}[k] = \text{dist}[j] + \text{arcs}[j][k]$。

> [!tip] 考试怎么用
> 致命限制：图中不能有负权边，否则一旦点加入 $S$ 无法更新，导致结果错误。

### 考点5：Floyd 多源最短路径
**Floyd 通过动态规划迭代更新矩阵 $A^{(k)}$，允许负权边但不允许负权环，复杂度 $O(|V|^3)$。**
状态转移：$A^{(k)}[i][j]=\min\{A^{(k-1)}[i][j], A^{(k-1)}[i][k]+A^{(k-1)}[k][j]\}$。

> [!tip] 考试怎么用
> 注意下标含义：$A^{(k)}$ 表示允许经过编号 $\le k$ 的顶点作为中间点的最短路径。

### 考点6：有向无环图 (DAG) 描述表达式
**DAG 通过共享公共子表达式节点来压缩存储空间，避免二叉树表示中的重复存储。**
特点：公共子表达式只需存储一次，多个父结点通过入边共享该子结点。

> [!tip] 考试怎么用
> 判别关键：观察表达式中是否有重复出现的子结构（如 $(c+d)$ 多次出现）。

### 考点7：拓扑排序
**拓扑排序是 AOV 网的线性序列，满足前驱在后继之前；存在环则无法完成排序。**
算法步骤：1.选入度为 0 点输出; 2.删该点及出边; 3.重复至空或无入度 0 点（有环）。

> [!tip] 考试怎么用
> 唯一性判据：若每一步入度为 0 的顶点恰好只有一个，则拓扑序列唯一。

### 考点8：关键路径 (AOE 网)
**关键路径是源点到汇点的最长路径，决定工程最短工期；关键活动的时间余量 $d(i)=0$。**
核心公式：$v_e(k)=\max\{v_e(j)+Weight(j,k)\}$; $v_l(k)=\min\{v_l(j)-Weight(k,j)\}$; $d(i)=l(i)-e(i)$。

> [!tip] 考试怎么用
> 缩短工期需加快所有关键路径上的公共关键活动，仅加快一条路径可能无效。

## 易混与对比
**Prim 算法 vs Kruskal 算法**

|特性|Prim 算法|Kruskal 算法|
|---|---|---|
|**生长方式**|从顶点出发，逐步扩展树|从边出发，逐步合并森林|
|**选择依据**|连接 $U$ 与 $V-U$ 的最小边|全局权值最小且不成环的边|
|**适用场景**|边稠密图 ($O(|V|^2)$)|边稀疏图 ($O(|E|\log|E|)$)|
|**数据结构**|辅助数组 dist/closest|并查集 + 堆排序

**Dijkstra vs Floyd vs BFS**

|算法|问题类型|权值限制|时间复杂度|
|---|---|---|---|
|**BFS**|单源最短|仅无权图|$O(|V|+|E|)$|
|**Dijkstra**|单源最短|不能有负权边|$O(|V|^2)$|
|**Floyd**|多源最短|可有负权，不可负环|$O(|V|^3)$

**AOV 网 vs AOE 网**

|特性|AOV 网 (顶点活动)|AOE 网 (边活动)|
|---|---|---|
|**含义**|顶点表示活动，边表示先后关系|顶点表示事件，边表示活动及耗时|
|**权值**|边无权值|边有权值 (持续时间)|
|**核心问题**|拓扑排序 (检测环)|关键路径 (求最长路径)|
|**零入度点**|可开始的活动|源点 (工程起点)

**最早/最迟发生时间计算方向**

|参数|计算方向|依赖关系|运算符号|
|---|---|---|---|
|**$v_e$ (事件最早)**|源点 $\to$ 汇点 (拓扑序)|依赖前驱|$\max$ (取最大)|
|**$v_l$ (事件最迟)**|汇点 $\to$ 源点 (逆拓扑序)|依赖后继|$\min$ (取最小)|
|**$e$ (活动最早)**|等于起点事件 $v_e$|-|-|
|**$l$ (活动最迟)**|等于终点事件 $v_l$ - 权值|-|-

## 闪卡
#card
- MST 的边数与顶点数 $n$ 的关系？::MST 的边数恒等于 $n-1$。
- 图中所有边权值互不相同时，MST 是否唯一？::是，当所有边权值互不相同时，MST 是唯一的。
- MST 中任意两点间路径是否一定是原图最短路径？::否，MST 保证总权值最小，不保证任意两点路径最短。
- 若图本身是一棵树，其 MST 是什么？::若图本身是树（边数=顶点数 -1），其 MST 就是它本身。
- Prim 算法每一步选择的边需满足什么条件？::一端在已选集合 $U$，另一端在 $V-U$，且权值最小。
- Prim 算法的时间复杂度是多少？::$O(|V|^2)$，与边数无关。
- Prim 算法更适合处理稠密图还是稀疏图？::更适合处理边稠密的图。
- Prim 算法执行过程中，集合 $U$ 如何变化？::初始含一个顶点，每轮增加一个顶点，直至 $U=V$。
- Kruskal 算法选择边的首要依据是什么？::按边权值从小到大的顺序依次考察。
- Kruskal 算法中，何种情况下需舍弃当前边？::当该边连接的两个顶点属于同一连通分量（会构成回路）时。
- Kruskal 算法的时间复杂度是多少？::$O(|E|\log_2|E|)$。
- Kruskal 算法更适合处理稠密图还是稀疏图？::更适合处理边稀疏但顶点较多的图。
- Dijkstra 算法能否处理带负权边的图？::不能，负权边会导致已确定最短路径的顶点被错误地不再更新。
- Dijkstra 算法中集合 $S$ 的含义是什么？::$S$ 记录已确定从源点出发最短路径的顶点集合。
- Dijkstra 算法的时间复杂度（邻接矩阵）？::$O(|V|^2)$。
- Dijkstra 算法的核心策略是什么？::贪心策略，每次从未确定集合中选 dist 最小的顶点。
- Floyd 算法能否处理带负权边的图？::可以，只要图中不存在负权回路。
- Floyd 算法中 $A^{(k)}[i][j]$ 的几何意义？::从 $v_i$ 到 $v_j$ 仅允许经过编号 $\le k$ 的顶点作为中间点的最短路径。
- Floyd 算法的时间复杂度是多少？::$O(|V|^3)$。
- Floyd 算法是否适用于无向图？::适用，将无向边视为两条方向相反权值相同的有向边即可。
- 用 DAG 描述表达式的主要优势是什么？::公共子表达式只需存储一次，显著节省存储空间。
- DAG 描述表达式时，会出现重复的操作数顶点吗？::不会，不会出现重复的操作数顶点。
- DAG 图的基本定义是什么？::不含任何有向环路的有向图。
- 拓扑排序失败的充要条件是什么？::有向图中存在环（无法找到新的入度为 0 的顶点）。
- 拓扑序列唯一的充要条件是什么？::每一步选择时，入度为 0 的顶点恰好只有一个。
- 邻接表存储下拓扑排序的时间复杂度？::$O(|V| + |E|)$。
- DFS 如何实现拓扑排序？::将顶点按 DFS 结束时间降序排列。
- 关键路径的长度代表什么？::代表完成整个工程所需的最短时间。
- 关键活动的判定条件是什么？::活动的时间余量 $d(i) = l(i) - e(i) = 0$。
- 事件 $v_k$ 的最早发生时间 $v_e(k)$ 如何计算？::取所有前驱事件最早时间加边权的最大值。
- 存在多条关键路径时，如何缩短工期？::必须加快同时出现在所有关键路径上的公共关键活动。
