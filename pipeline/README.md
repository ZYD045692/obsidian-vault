# 扫描书 → Obsidian 知识库处理流程（固定规范）

> 目标：把扫描版考研书（王道 408 / 张宇数学）变成 **可直接观看、可检索、可复习** 的 Obsidian 知识库。
> 核心原则：**问题直接改 books，拆分稿从 books 一次性生成，无中间加工。**

> 📁 **脚本位置**：本流程配套的 `_*.py` / `_*.cjs` / `_*.js` 脚本统一放在 **vault 顶层的 `pipeline/scripts/`**（工具目录，与内容层 `11408/` 分离）；裁剪产物放顶层 `cropped-pdf/`。下面所有命令示例均按此路径给出，也可以先 `cd pipeline/scripts` 再执行。
>
> ⚠️ **请在 vault 根目录执行**：脚本分两种定位方式——多数脚本用相对路径（如 `BASE = "11408/split"`）依赖**运行时 cwd**，少数用脚本自身位置（`__file__` 向上推算）定位 vault 根。在 vault 根目录下运行两者都成立。

## 处理流水线（7 步，每本书都必须走完）

> ⚠️ **标题层级统一是横切必做项**（2026-08-17 实战发现）：OCR 会把答案行/提示框/页眉/题干行误标成标题，
> 导致 Obsidian 大纲（Outline）层级错乱。每本书在**侦察、清洗、校验**三阶段都要过一遍（见第 1/2/6 步），
> 否则拆分稿的大纲就是乱的。
>
> ⚠️ **OCR 前先裁页眉页脚**（2026-08-31 实战发现）：手拍/扫描版 PDF 每页是一整张图，OCR 会把页眉（书名行）
> 和页码数字识别进正文（页眉成 `## 概率论与数理统计辅导讲义` 标题、页码成孤立数字行），清洗量巨大。
> 新书 OCR 前先按【第 0 步】做 PDF 预处理，从源头消除，再开始第 1 步。

### 第 0 步：OCR 前 PDF 预处理（去页眉页脚，扫描版新书必做）

目的：把 PDF 每页的页眉（书名/章节名竖杠条）和页脚页码裁掉，再做 OCR。手拍扫描页常倾斜，必须**逐页单独处理**，不能全书一刀切裁同一比例，否则切到正文。

前置：确认正文边界（哪些页是正文、哪些是序言/目录/广告页，跳过不处理），并按正文结构（如基础篇/强化篇、章）规划切割。

1. **侦察页眉/页码位置**（脚本 `_calc_pageno_pos.py`）：抽样渲染放大判断。
   - 页眉条：有页眉页顶部约 4.5%~7% 高度；**章首页（封面页）无页眉** → 章首页不裁顶部，避免切章标题
   - 页码带：约 93.3%~95.3% 高度；**偶数页页码右下、奇数页页码左下**（书对开排版）；章首页无页码
2. **裁页眉**：有页眉页统一裁顶部 **7.5%**（页眉条下沿+余量）；章首页只留 4px 安全余量
3. **裁页码**（重点，必须精确）：用 tesseract 逐页定位页码数字带 top（`-l chi_sim --psm 11 tsv`，左右两区各扫一次），裁剪线 = 页码 top 上方仅留 0.3% 安全间隙（**比例制，不可用固定像素偏移**——不同分辨率下固定 px 会切正文）；定位失败页兜底裁 93%
4. **输出**：落到 vault 顶层的 `cropped-pdf/<书>-分章/`，再按 基础/强化（或篇章）→ 章节 分目录，每章合成一个 PDF（平铺 `基础/第一章.pdf`，不要章子目录）
5. 对裁剪后的 PDF 再做 OCR（页眉页码已消失，正文起点即真实内容）

脚本（方法参考实现于李良概统，新增扫描书按此另写）：`pipeline/scripts/_crop_liang_pdfs.py`（`--all --book 基础|强化` 或 `--all` 全书）、`_calc_pageno_pos.py`（页码定位验证，先跑确认页码带与章边界）。

> 注意：页码在 tesseract 返回框的 top 处评估，但 band 坐标要换算回全页（crop 起点偏移）；偏移量用页高比例（FOOTER_GAP=0.003），不是固定像素。

### 第 1 步：侦察

1. 确认 books 的 .md 结构：正文起点行号、标题层级（`# 章` / `### 节` / `#### 子块`）、题区标记词
2. **扫描标题层级**：用 `_scan_headings.py` 检查章/节/小节层级是否统一、是否有跳级；用 `_dump_headings.py` 导出标题序列人工看是否存在答案行（`### 03. D`）、提示框（`## 注意`）、页眉残留（`## 考研数学基础30讲 · XX分册`）、题干行（`## 1 ）为什么要…`）被 OCR 误标为标题 —— 见《标题层级统一（专章）》
3. 统计 imgs 图片数、引用与文件是否一一对应
4. 扫描广告特征词、二维码、重复标题、缺失章节标题
5. 记录 `BODY_START`（正文起点行号）——校验脚本要用

### 第 2 步：清洗 books（直接改 books，禁止改拆分稿再合并）

- **删广告文字**：公众号 / 微信（含"一手+V"）/ QQ群 / 联系方式 / 价格（"4.9元包邮"）/ 页眉页脚 / "配套课程"类
- **删二维码广告图片**：见下方《二维码处理》专章
- **删重复标题**：OCR 常把同一标题打两遍（如 `# 第1章 xxx` 后紧跟 `# xxx`），只留一份
- **删目录/前言/版权页/页眉**：正文起点（BODY_START）之前的部分，保留需要的前言类内容时单独判断
- **修错字标题**：如"多元函数和分学"→"多元函数积分学"
- **修结构标题**：见《结构问题（专章）》——章标题 `## 第N章`、节标题脚注污染 `###  $^{*}N.M$`、重复章标题、习题区标题被污染成 `###`，**拆分前必须清完**
- **统一标题层级（必跑，2026-08-17 新增）**：见《标题层级统一（专章）》。目标层级：
  - 408：`# 第N章`=H1 / `## N.M 节`=H2 / `### N.M.K 小节`=H3 / `####`=H4；`### 考点追踪`=H3；`#### 题型`=H4；`#### N. 数字条目`=H4；`##### （N）括号条目`=H5；`### （一）考纲子项`=H3
  - 30讲数学：`## 第N讲`=H2 / `### 三件套`=H3 / `#### 内容节`=H4 / `##### 子项`=H5
  - 30讲数学题目（2026-08-17 新增，进大纲方便跳转）：精讲区 `例N.M …` → 父级+1（多为 H6，无子项处 H5/H4）；习题精练区 `#### 习题`/`#### 解答` 下的 `N.M …` 题号行 → H5。题号后允许跟空白或全角（；**标题只留纯编号（`例1.1`/`1.1`），题干挪回正文行**（题干太长不进标题）。脚本 `_add_ti_headings.py` + `_shorten_ti_headings.py`
  - 408课后习题（2026-08-18 新增，进大纲方便跳转）：`本节试题精选/本节习题精选` 与 `答案与解析` 区内，题型小节（一、单项/二、综合）下 `NN.` 题号行 → `##### NN` 纯编号标题，题干/答案/【解答】挪回正文行。脚本 `_add_ti_headings_408.py`（幂等）+ `_check_ti_continuity_408.py`（必跑）
  - 1000题：`# 篇`=H1 / `## 第N章`=H2 / `### 题型`=H3
  - 答案行、提示框、题干行、页眉残留 → 去 `#`/加粗/删除（脚本：`_norm_408_headings.py`、`_norm_math_headings.py`、`_norm_1000_headings.py` + 对应 `_pass2.py`）
  - **改完 books 必须同步拆分脚本标题正则**（`_resplit_6books.py` 的 `SEC=^##`、`EX/ANS=^###`；`_split_1000.py` 的 `ZHANG/LING/TEST=^##`）
- **去公式边界空格**：`$ x $` → `$x$`（Obsidian MathJax 要求 `$` 与内容紧贴，否则不渲染）。只删**开 `$` 后、闭 `$` 前的空格**（配对法，不能一刀切——`x $y$` 的 `$` 前空格是文本分隔）；`$$ x $$` 同理；填空占位 `=$ ___` → `=\underline{\qquad}$`
- **不加快速跳转目录**（2026-08-17 起弃用）：原在 books 最前加 `## 📑 快速跳转` + `[[#章名]]` 锚点，但 Obsidian 阅读视图点 H2 锚点跳转失效，且大纲（Outline）已能正常跳转，故**不再添加**；历史文件可用 `_remove_toc.py` 移除该块（对拆分零影响，拆分脚本 `find_body` 本就跳过它）
- **检查 `$` 成对**：每行 `count($) - 2*count($$)` 必须为偶数，奇数行 = OCR 丢/多 `$`，逐行人工修
- **补缺章标题**：内容在、标题丢 → 按前后文补 `# 第N章 章名`；内容真缺 → 记录清单报告用户，不擅自造内容
- 清洗后**不得引入新内容**，只删/改不增

### 第 3 步：写/复用拆分脚本

统一模式（参考 `pipeline/scripts/_resplit_6books.py`）：

- 输入：books 正文（BODY_START 起）+ 现状拆分稿的文件名/frontmatter（作为边界元数据）
- 规则：
  - 408：`# 第N章` → 章目录；`### x.y` → 考点文件；`#### x.y.k 本节(试题|习题)精选`/`答案与解析` → 习题文件；章内第一节前 → 导读
  - 数学：`## 第N讲` → 每讲一个文件
  - **1000题（分篇 → 分科）**：目录分三科（高等数学/线性代数/概率论与数理统计），每科章号重新计数
    - 结构：`1000题-试题册/{基础篇, 强化篇, 综合篇}/{高数, 线代, 概率}/…`
    - 基础篇/强化篇：先按篇分，篇内再按科目分（高数/线代/概率），文件名 `第N章 章名.md`
    - 基础篇高数下的"零基础"部分 → `基础篇/高数/零基础摸底.md`
    - 综合篇：`综合篇/测试卷一.md` ~ 测试卷四.md（不分科，直接放篇目录下）
    - 解析册同结构
- **图片引用**：一律改写为指向 books 的相对路径（根据文件深度算 `../` 数量）
  - split/<书>/<章>/导读.md → 3 级 `../../../books/<书>/imgs/`
  - split/<书>/<章>/考点|x.md → 4 级 `../../../../books/<书>/imgs/`
  - split/数学/<书>/xxx.md → 3 级
- 输出：frontmatter 沿用现状文件；正文 = books 原文切片；**不生成脚本噪音行**

### 第 4 步：一次性生成

`python pipeline/scripts/_resplit_6books.py --apply`（或对应书的拆分脚本）从 books 覆盖生成拆分稿。
流程上禁止：先改拆分稿再手工合并回 books、在拆分稿上做内容级修补。

### 第 5 步：完整性校验（全部通过才算完成）

| 校验 | 方法 | 标准 |
|---|---|---|
| 字数完整度 | `clean_text()` 去掉 frontmatter/标题/图片标签/表格/噪音后，比对 books vs 拆分稿总字符 | **≥ 97%，目标 100%** |
| 行指纹 | 每行归一化（去空白/HTML/标题符/$/标点），比"多提取（拆分稿有 books 无）"与"少提取" | **多提取 = 0**；少提取仅允许标题行 |
| 图片引用 | 拆分稿每处 `<img src>` 解析相对路径 | **全部存在，0 坏**；books 引用数 = 拆分稿引用数 |
| 公式渲染 | `_validate_dir.cjs` 检查 MathJax 语法 | **FAIL = 0** |
| 公式边界空格 | 配对法：开 `$` 后、闭 `$` 前不得有空格 | **0 处** |
| 结构完整性 | `_scan_origin_structure.py` | 无破坏性结构异常（章/节/习题区标题格式） |
| **标题层级/大纲** | `_scan_headings.py` | **0 跳级**；无答案行（`N. A`）、提示框（`注意`）、题干行、页眉残留被当标题（拆分前必查） |
| 习题完整性 | `_check_chapter_exams.py` + `_check_exam_gaps.py` | 每章有习题文件；books 习题区全对应（`_check_sec_exam_gaps.py` 核实无习题节） |
| `$` 成对性 | 每行 `count($) - 2*count($$)` 为偶数 | **0 行奇数** |
| 图片指纹 | books imgs 引用集合 = 拆分稿引用集合 | 差集为空 |

## 习题完整性检查（假设每章都有习题）

```bash
python pipeline/scripts/_check_chapter_exams.py    # 每章考点/习题文件数，无习题的章标 ⚠
python pipeline/scripts/_check_exam_gaps.py        # books 习题区 vs 拆分稿习题文件，找出漏拆
python pipeline/scripts/_check_sec_exam_gaps.py    # "有考点无习题"的节，回 books 核实是否真无习题区
```

判断标准：
- **习题文件数 < 考点文件数** = 正常（「本章小结/疑难点/易混淆点」等收尾节无习题区）
- **习题文件数 < books 习题区数** = 漏拆，必须查（典型：习题区标题被污染成 `###`）
- 回 books 确认时：无习题文件的节若 books 里也没有 `本节习题精选`，即正常
