# HTML 表格转换

**问题**：扫描书里大量 `<table border=1>` 的 HTML 表格，Obsidian 对其中的 `$...$` 公式渲染不可靠；且 Markdown 表格里数学公式若含 `|`（如 `\frac{|A|}{\lambda}`），`|` 会被当成列分隔符，表格直接裂开。

**处理**：把「含公式的真多列表格」转成 Markdown 管道表格（`_convert_tables_all.py`）。
- 单列表格（注/证/结论的边框盒）**不转**——它们是盒子，不是数据表。
- `colspan/rowspan` 表格**跳过**——Markdown 无法表达合并单元格。
- 单元格内 `|X|`（绝对值/行列式）→ `\lvert X \rvert`（否则管道冲突）。
- 保留单元格内的 `<img>`（拆分脚本靠它改图片路径）；单元格内换行压成空格（否则拆断表格行）。
- 转换后校验每行列数一致；不一致则跳过。

**易错点**：
- **Obsidian/格式化插件会自动对齐表格**：把 `|A|` 拆成 `| A |` 并补多余空列 → 转换后务必检查每行列数一致、`$..$` 内无裸 `|`。
- `re.sub` 替换串里的 `\l` 会被当转义报错 → 用 `lambda m: r"..."` 返回字面量。
- 只转「含 `$` 的多列表格」；纯文本框、无公式表保持 HTML（它们渲染正常）。

**配套**：`_scan_html_tables.py`（扫描）、`_convert_tables_all.py`（转换，含 DRY_RUN）、`_check_bare_pipes.py`（校验 $ 内无裸 |）、`_inspect_tables.py`（抽查）。
