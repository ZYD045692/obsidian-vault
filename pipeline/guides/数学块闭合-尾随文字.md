# 数学块闭合 $$ 尾随文字

> **现象**：Obsidian 文件大纲里一大片标题消失（高数 16/17/18 讲整片不见），文件里标题明明存在。
> **原因**：多行 `$$` 数学块的**闭合行 `$$` 后面跟了文字**（如 `\end{array}\right.$$ 按最高次写一般式`）。Obsidian 不认这种闭合 → 数学块不关闭 → 后续 `$$` 配对全部错位 → 标题被吞进数学块，大纲消失。 parity 类校验（`$$` 计数/行级奇偶）**全部查不出**，因为总数恰好配平。
> **定位法（实测有效）**：二分排除——把文件劈半 + 末尾加 `## 第99讲 测试标题`，看测试标题是否进大纲，逐步缩小到行。
> **修复**：尾随文字移到 `$$` 下一行（注释独立成段）。
> **排查命令**：
> ```python
> # 找「闭合 $$ 后还有非 LaTeX 文字」的行
> for i, l in enumerate(lines):
>     if "$$" in l:
>         tail = l.split("$$")[-1].strip()
>         if tail and not tail.startswith("\\"): print(i+1, l)
> ```
> 注意：`$$\left\{\begin{array}{l}`（开启行带 LaTeX 代码）和 `\end{array}\right.$$`（闭合在行尾）都是**正常**的，只有闭合 `$$` 后尾随正文文字才是问题。
