# 标题级残留

第一轮统一层级后，大纲仍会出现「数字乱七八糟、正文混进标题、缺节缺项」。根因：OCR 把**部分子项标题降成正文**、把**标题和正文注释挤在同一行**、**拆词**、**丢节标题**。逐条按上下文补：

| 问题 | 特征（真实例） | 处理 |
|---|---|---|
| **标题混入正文注释** | `1 余子式 “子式=行列式”，…`、`3 正交矩阵 行（列）向量长度为1…`、`1 定义 只要有一个就行 → …`、`3 求区间(a,b)… 开区间上的连续函数也可能有最值` | 拆成 `标题` + 另起一段放注释正文 |
| **同一标题拆成两行** | `2 n 阶行列式的定义` 紧跟 `$n(n \geqslant 2)$ 阶行列式` | 合并成一条：`2 $n(n \geqslant 2)$ 阶行列式的定义` |
| **子项标题被降成正文** | 内容区短行 `1 化为基本形 →…`、`4 范德蒙德行列式`、`4 用初等变换求逆矩阵的方法`、`5 旋度`、`2 概念及其敛散性`、`1 空间曲线`、`3 判别拐点的第一充分条件` | 提升为同级标题（`#### `/`##### `） |
| **节标题缺 一/二/三** | `行列式的本质定义` 应为 `一 …`；`矩阵的本质` 应为 `一 …`；`逆矩阵的定义` 应为 `三 …` | 按出现顺序补中文序号，与已有 四五六… 对齐 |
| **子项编号跳号/缺号** | 1,2,7（缺3~6）；2,3,4（缺1）；1,2,4（缺3）；`③ 斜渐近线` | ①从正文找 `N Title` 恢复；②首项无号补 `1`；③明显 OCR 错的重新编号（7→3、4→3、③→3） |
| **整节标题丢失** | 线代第3讲 `3 极大线性无关组…` 实为新节「三」；高数第18讲中间两节只剩 1~5 子项，从 `1 概念` 定义内容判断是「第一型曲线积分」「第一型曲面积分」 | 提升为新节（H4）+ 子项降回 `#####`；节名靠 `1 概念` 内容推断 |
| **OCR 拆词** | `二 次型`→`二次型`、`三 重积分`→`三重积分`、`二 阶常系数`→`二阶常系数` | 按数学术语还原（注意别把真序号如 `三 行列式…` 误删） |
| **游离【考纲内容】** | 某章【考纲内容】/【复习提示】块出现在**上一章末尾** → 大纲挂错章 | 整体移到对应 `# 第N章` 之后（含【知识框架】图块、"在学习本章时…"引导段） |
| **答案行当标题** | `31. ①C ②B`、`23. ① B、② D、③ C…`、`04. ① C, ② C` | 去 `#` 变正文 |
| **缺章标题** | 1000题试题册基础篇缺「第5章 几何应用」，几何题直接挂第4章下 | 按解析册章序/前后文补插 |

**判断原则**：能根据上下文唯一确定的才改（①② 前补 `1 …`、正文 `N Title` 恢复、跳号重排）；节名靠 `1 概念` 定义内容推断（如第一型/第二型曲线积分）；编号以「节=一二三 对齐、子项=连续 1,2,3…」为目标；实在无法确定的（如丢失的中间节标题）宁缺勿造。

**配套脚本**：`_fix_num_gaps.py`（补子项编号）、`_fix_structural2.py`（重建丢节）、`_split_headings.py`（拆标题混行）、`_move_orphan_kg.py`（移游离考纲块）。

**易错点**：
- 改完后 Obsidian 若打开着该 books 文件，可能把磁盘改动覆盖回旧版 → 改前请先保存/关闭 Obsidian 里的对应文件。
- 重编号前先看正文里是否真有中间项（如 `(1)(2)(3)(4)` 是某一条的子点，不是缺失项），避免误改。
- `三 行列式…`（真序号）与 `三 重积分`（拆词）要区分，前者保留序号，后者还原术语。
- **考点追踪 H3 盒夹断子项（408 通用，2026-08-17 第二轮实战）**：`### 考点追踪` 是固定 H3，常插在 `#### N.` 父项与其 `##### （N）` 子项之间。此时把 (N) 升为 H5 会**跳级**（H3→H5），且大纲里 (N) 会挂到考点追踪 H3 下（错父）。处理规则：①同一簇 (N) 若被考点追踪夹住 → 保持 H4（与已存在的 `#### （N）` 兄弟一致），别强行降 H5；②裸 (N) 行提升时与兄弟同级（H4 簇就升 H4，H5 簇就升 H5）；③个别考点追踪盒正好卡在 H5 簇中间 → 该条考点追踪保留正文（宁缺勿改），并报告用户。改完必跑 `_scan_headings.py` 复查 0 跳级。
- **脚本增删行会位移后续行号**：处理"拆行/插入/删除"类修改时，脚本要**从最大行号往小处理**（bottom-up），否则前插/删除会让后续行号错位（日志里行号仅供参考，改完重新动态定位核对）。
