# 结构问题

> OCR 会把标题结构弄坏，导致拆分脚本静默丢整章/整节/整个习题区，校验字数/公式都测不出来。**这类问题必须在清洗 books 阶段检查并修完。**

### 问题类型 → 后果 → 修复

| 类型 | 症状（实际例子） | 后果 | 修复 |
|---|---|---|---|
| 章标题降级 | `## 第5章`（双井号） | 拆分脚本只认 `# 第N章`，整章并入上一章 | `## 第N章` → `# 第N章 章名`，并删后面重复的章名行 |
| 节标题脚注污染 | `###  $^{*}7.1$ I/O 系统基本概念 $^{①}$` | 节号被 `$…$` 包住，SEC 正则匹配不到，整节并入上一节 | 去掉 `$…$`/脚注 → `### 7.1 I/O 系统基本概念` |
| 重复章标题 | `# 第7章` 出现两次（章节页+正文页） | 拆分时第二个覆盖第一个，**中间内容丢失** | 删第二个，保留第一个（或合并） |
| 习题区标题污染 | `###  $^{7}$1.3 本节习题精选`（应 `#### 7.1.3`） | 习题区并入考点文件，习题丢 | 改 `#### 7.1.3 本节习题精选` / `#### 7.1.4 答案与解析` |
| 子节标题污染 | `####  $^{*}7.1.1$ 输入/输出系统` | 不影响拆分边界，但结构脏 | 去掉 `$^{*}$` |
| 节名含 `/` | 节名 `I/O` → 文件名 `7.1-I/O …md` | `/` 被当路径分隔符，文件落错目录（`7.1-I/O` 变两层） | 拆分脚本加 `safe()` 清洗非法字符 |

### 检查与修复命令（拆分前必跑）

```bash
python pipeline/scripts/_scan_origin_structure.py     # 8 本 books 结构扫描 → 应输出全部"✓ 无破坏性结构异常"
python pipeline/scripts/_fix_origin_structure.py      # 有异常时精确修复（章/节/习题区/子节标题）
```
