## Frontmatter 规范

学习笔记（`11408/notes/` ）通常包含以下 YAML 字段：

```yaml
---
type: 考点          # 可选：MOC / 考点 / 习题 / 小节 / 笔记
course: 数据结构     # 课程名
chapter_no: 1
chapter_title: 绪论
section: "1.1"
point_title: "1.1 数据结构的基本概念"
status: 未开始       # 学习状态：未开始 / 学习中 / 已完成
mastery: 0          # 掌握度 0-100
tags:
  - 408/数据结构
  - 考点
source: "[[11408/split/数据结构/1-绪论/考点/1.1-数据结构的基本概念]]"
gen: qwen3.5-35b-a3b-think
---
```

- `type` 决定 Dataview 统计口径，不要随意改动。
- `source` 指向拆分稿中的原文位置，保持其为有效 wikilink。
- frontmatter 已有 `gen:` 的笔记视为已生成，批量填充脚本会跳过。
- 更新学习状态时**只改** `status` / `mastery` ，勿动其他字段。

## 笔记目标路径

| 类型 | 目标 |
|---|---|
| 408 考点 | `notes/408/{课程}/{N-章名}/{x.y-节名}.md` （章号不补前导 0） |
| 数学讲级（高数，有小节） | `notes/数学/30讲-高数/{第N讲-讲名}/{第N讲-讲名}.md` |
| 数学讲级（线代，只有讲级） | `notes/数学/30讲-线代/{第N讲-讲名}.md` |
| 数学小节（仅高数） | `notes/数学/30讲-高数/{第N讲-讲名}/{x.y-标题}.md` |

- 线代**不切小节**（只出讲级笔记）；讲级落盘路径按"是否有小节"自适应（`math_lecture.lecture_note_path` ）。
- 扫描时目标文件缺失会**幂等建 stub**（已有文件绝不覆盖，保留用户笔记）。
- 生成后写 `gen: <model>-think` frontmatter；`gen:` 存在即视为「已生成」，后续运行跳过（断点续跑）。

## 内容区块

考点笔记的固定区块：

- `## 核心要点` — 用 `**考点 N：标题**` 分点
- `## 易混与对比` — 表格形式对比概念
- `## 真题与错题` — 链接到拆分稿的习题解析
- `## 关联考点` — 前置/后续/易混 wikilink
- `## 闪卡` — Obsidian Spaced Repetition 格式：`问题::答案` （标签见下一节）

## 闪卡标签（#card / #flashcards）

生成物使用 `#card` ，**不进入** SR 复习队列。原因是批量生成的卡片需要先做质量检查（问题是否自包含、答案是否准确、是否重复）；若直接用 `#flashcards` ，所有新卡片会立即涌入复习队列，负担不可控，也难以批量修正。

`#card` 相当于「待机」状态。确认某篇/某批可以复习后，执行：

```bash
python note-gen/toggle_card_tag.py --on  路径或glob     # #card → #flashcards，进队列
python note-gen/toggle_card_tag.py --off 路径或glob     # 出队列
```

完整命令（批量/glob/`--dry`）见 `note-gen/README.md` 的「闪卡与 SR 复习队列」；模型侧的卡片结构见 `note-gen/提示词与模型.md` 的「模型输出结构」。

## MOC

各科 MOC（`408-MOC` 、`数学-MOC` 、`408/{课程}/{课程}-MOC` 、`数学/30讲-*/{高数,线代}-MOC` ）只放章节/讲级 wikilink 清单，从拆分稿目录结构机械重建，**不放闪卡与正文内容**。生成新笔记不影响 MOC。

## 链接与引用

- 笔记内部链接统一使用 Obsidian wikilink：`[[路径/文件名]]` 或 `[[路径/文件名|显示名]]`
- 数学公式使用 `$...$` 行内或 `$$...$$` 块级 LaTeX
- 图片统一用 wikilink：`![[图片名.png]]`
- 流程文档（各目录 README、`TODO.md` 、`pipeline/guides/` ）不属于笔记数据库，互相引用用普通路径，不用 wikilink

## Dataview 查询

MOC 页用 Dataview 做统计，例如：

```dataview
TABLE course AS 课程, length(rows) AS 考点数
FROM "11408/notes"
WHERE type = "考点"
GROUP BY course
SORT course ASC
```

修改笔记时注意不要破坏 Dataview 查询所需的 frontmatter 字段。
